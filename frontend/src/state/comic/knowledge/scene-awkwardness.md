# 気まずさ・すれ違い
> novira オリジナルの手引き

## この場面の役目
言葉にできない居心地の悪さ、噛み合わない会話、相手の気持ちに気づけないもどかしさを読者に体験させる。気まずさは「何も起きない時間」の長さと、周囲の無関係な動きとの対比で生まれる。

## 読者に見せるもの
- 二人の間の沈黙と、それを埋めようとして失敗する行動。
- 視線のずれ。同時に話し出す、同時に黙る、目を合わせられない。
- すれ違いなら、双方の認識の違い。読者だけが両方の事情を知っている形にすると切なさやおかしさが出る。

## コマ運び
1. 二人を同じコマに入れ、間に空白を取った引きの構図で始める。
2. 片方が話しかけようとして口を開くコマ。
3. 間のコマ。背景、時計、窓の外、湯気の立つ飲み物など動かないものを描く。
4. 飲み物を飲む、スマホを見るなど意味のない動作のアップ。
5. 気まずさの頂点で、どちらかが的外れな一言を言う。吹き出しは小さく短く。

縦に細いコマを並べると間が長く感じられる。すれ違いでは、左右のコマで二人を別々に描き、同じ時刻に違うことを考えている構図が効く。

## 台詞のコツ
- 「あ、」「その、」「……いや、なんでもない」のような途切れた言葉。
- 天気や食べ物など、どうでもいい話題に逃げる。
- 本音は台詞に出さず、表情や手の動きに任せる。

## よくある失敗
- 気まずさをモノローグで「気まずい」と説明してしまう。
- 沈黙のコマが少なく、すぐ解決して緊張が続かない。
- すれ違いの原因が不自然で、読者が登場人物に苛立つだけになる。
- 全コマが同じ構図で、変化のない退屈な絵になる。
