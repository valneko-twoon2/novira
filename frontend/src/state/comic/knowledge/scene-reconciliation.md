# 和解・赦し・救い
> novira オリジナルの手引き

## この場面の役目
すれ違い、対立、罪悪感のあとで、二人（または自分自身）が歩み寄り、重荷を下ろす場面。派手な出来事より、心の動きの小さな変化を丁寧に追うことで効く。

## 読者に見せるもの
- 何がわだかまりだったか（過去の一言、行き違い）
- 先に折れる側の勇気、ためらい
- 受け取る側の揺れと、受け入れる瞬間
- 空気が緩むこと（表情、肩の力、背景の明るさ）

## コマ運び
1. 沈黙：向き合う二人を引きで。間を取り、動かない時間を1〜2コマ使う。
2. 一言目：話し始める側の顔のアップ。目をそらす、唇を噛むなど迷いを見せる。
3. 受け止め：相手の目のアップ。すぐ答えを出さず、反応を遅らせる。
4. 緩み：涙、小さな笑み、手が触れるなど。背景を明るくしたり、描き込みを減らして余白を作る。
5. 余韻：二人が並ぶ後ろ姿や、窓の光など。台詞なしで閉じてもよい。

## 台詞と絵
- 謝罪や赦しの言葉は短く、不器用でよい。「ごめん」「うん」だけでも成立する。
- 感情を全部言葉にしない。言い淀み、沈黙、「……」を使う。
- 涙は大げさにせず、一粒や、目元だけで見せるほうが響く。
- 小道具（渡す物、置かれた物）が気持ちを代弁すると説明が減る。

## よくある失敗
- 対立の理由を説明しすぎて、感情が冷める
- 一言で簡単に解決し、重みが出ない
- 双方が長々と自分の気持ちを語る
- 悪いのが一方だけに見え、相手の救いがない

## チェックリスト
- 沈黙のコマがあるか
- 先に動く側の迷いが見えるか
- 受け取る側の反応に間があるか
- 最後に緩みを示す絵があるか

親密さそのものを積む場面は scene-trust、涙を誘う別れは別の手引きを選ぶ。
