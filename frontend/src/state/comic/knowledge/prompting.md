# コマの絵のプロンプトの書き方
> novira オリジナルの手引き

コマのプロンプトは、画像モデルに渡す**英語**の指示。ユーザーの言語に関わらず英語で書く。1コマには「そのコマに写るもの」だけを書き、人物の見た目・場所の背景・画質の語はアプリが足す。いちばん手軽で確実なのは `scene` 操作で書くこと（shot、angle、people の doing と face、things を埋めると、アプリが下の規則どおりにプロンプトを組み立てる）。直接 `panel` の `prompt` を書くときも、同じ規則に従う。

## 1. まず書き方の型を知る：promptStyle

`get_comic_page` の `promptStyle` が、いまのメインモデルに合う書き方を告げる。

| promptStyle | 対象 | 書き方 |
|---|---|---|
| `tags` | SD系（SDXL、SD 1.x/2.x）。モデルが未選択のときも tags | カンマ区切りの短い**タグ**。1項目は1〜4語（`holding cup`、`from side`、`smile`）。文や感情の説明を書かない |
| `sentences` | それ以外の新しい系統のモデル | 1〜2文の平易な英文 |

tags のモデルで長いフレーズ（`holding a warm cup of coffee` のような）を並べると、読み落としや取り違えが起きる。実際に、フレーズで書いた男性が全コマで女性として描かれ、同じ絵柄・同じ種でタグにすると男性になった例がある。アプリも「4語を超える項目」を検査して書き直しを求める。

## 2. tags の並べ順

1. **人数**（`1girl`、`2boys`、`1girl, 1boy`、`solo`、人のいないコマは `no humans`）
2. **構図**（距離と角度）
3. **向き・ポーズ・動作**
4. **表情**
5. **見せたい物と、その場所での光**

人物の見た目（髪・服）と場所の説明は書かない。アプリが前後に足す。

### 人数のタグ
- 数を言わないとモデルは人や動物を増やす。最初に正確な数を書く。人物1人なら `solo`。
- キャストの `tags` は「数と種類」から始める（`1girl`、`1boy`、`1other`）。複数人のコマでは、アプリがキャストのこの語から `1girl, 1boy` や `2girls` を数える。
- 男性だけのコマには `male focus` が自動で付く。タグモデルは女性へ寄る癖があるため。
- 余計に増えてほしくないもの（`multiple dogs`、`extra people`、`crowd`）は `negativePrompt` に入れる。

### 構図・カメラの語
| 狙い | 語の例 |
|---|---|
| 状況説明の引き | `wide shot`、`establishing shot` |
| 全身 | `full body` |
| 膝上 | `cowboy shot` |
| 胸から上 | `upper body` |
| 顔のアップ | `close-up`、`portrait`、`face focus` |
| 後ろ姿 | `from behind` |
| 横から | `from side` |
| 見上げ・見下ろし | `from below`、`from above` |
| 斜めの構図 | `dutch angle` |
| 肩越し | `over the shoulder` |

`scene` の shot（wide、full、knees、chest、face）と angle（eye、above、below）は、この語に置き換わる。

**構図の語はアプリも読む。** プロンプトに `close-up` などがあると、そのコマには顔に関わる部分（髪・目・顔・小物）だけを人物の語から足し、後ろ姿なら目と顔を外す。何も書かないと全身扱いになる。だから、構図の語はコマのカメラと必ず合わせる。縦長のコマには全身の立ち姿、横長のコマには風景や複数人が合う。

## 3. アプリが足すもの（書かない）

| 足されるもの | どこで | 書かないもの |
|---|---|---|
| 画質の語（`masterpiece, best quality` など）と共通のネガティブ | コマの style（`style` 操作でコマ全体かページごとに変える） | 画質タグ、一般的な悪い絵の否定語 |
| 人物の語（tags と、構図で見える parts） | キャスト | 髪型、目の色、服、体つきの再説明 |
| 場所の語、世界の語 | プロンプトの**後ろ**に自動で。アップのコマでは場所の語を弱めて主役を押しのけないようにする | 背景の詳しい描写。コマが見せる範囲だけ書く（`by the window`、`door behind her`） |
| 人物ごとのネガティブ、場所のネガティブ | `cast` / `places` の `negative` | その人物や場所だけに要る禁止語 |
| 吹き出し・文字・コマ枠 | 別の層で描く | `speech bubble`、`text` など。書くと検査で差し戻される |
| 白黒・セピアなどの仕上げ | `effect` 操作 | 白黒にするために色の語を変えない（絵は色つきで描き、`effect` で変える） |

`scene` の things に書いた物は、読み落とされないよう少し強調（重み付け）される。物語で肝心な物（虹、鍵など）は things に入れる。

## 4. 人物・動物・怪物

- **同じ見た目を保つ**: 人物の語はキャストにだけ書き、パネルでは繰り返さない。衣装が変わる話は別キャストにする（例 `Grandpa (pyjamas)`）。
- 複数人のコマは、`pose` の各人に `who`（キャスト名）を付ける。付けないと顔や服が混ざる。
- 怪物・精霊・動物は `nonHuman: true` のキャストとして登録し、コマでは `cast` に入れるだけにして、プロンプトに外見を書かない。ポーズには写らないので、位置はプロンプトに（`dog at the bottom right`）。動物は種、毛色、大きさ、向きを固定する。
- 男性の見た目を、フレーズや性格の言葉で書かない。年齢は年数ではなくタグ（`child`、`teenage`、`mature male`、`old woman`）で。

## 5. 場所の語

場所はプロンプトに書き込まず、`places` に登録して各コマの `place` で指す。語は、それが何か、中にある物、色と光を、promptStyle の書き方で（例 `classroom, wooden desks, green chalkboard, large windows, afternoon sunlight`）。昼と夜は別の場所として登録する。時代・地域・季節・色調は `world` に一度だけ。

## 6. ネガティブ

- コマの `negativePrompt` には、そのコマで避けたいものだけ（増えがちな人や動物、写ってはいけない物）。
- 全コマ共通の否定語は style にあり、人物と場所固有の否定語はそれぞれの `negative` にある。コマ側で繰り返さない。
- 人物のいない風景のコマは、`no humans` を入れ、人物の tags はキャストから外す。

## 7. ポーズと構図を合わせる

ポーズの人物の大きさが構図を決める（全身は size 0.8〜0.9、膝上は 1.2 で首が y 0.3 付近、胸上は 1.6 で首が y 0.4 付近）。頭がコマからはみ出すと棒人形が人体として読まれない。顔のアップにはポーズを付けない。向き（左を向く、後ろ姿、右側に立つ）はポーズとプロンプトが同じことを言うようにする。逆光のシルエットや強い色かぶり、極端な切り取りは人物を隠すので、場面が要求するときだけ使う。

## 8. 書く前の点検

- 最初に人数を書いたか。
- 1項目が4語以内のタグか（tags のとき）。
- 構図の語がコマの形・カメラと合うか。
- 人物の見た目、背景、画質語を繰り返していないか。
- 複数人のコマに `who` つきのポーズがあるか。
- 肝心の物を things（または重み付き）にしたか。
