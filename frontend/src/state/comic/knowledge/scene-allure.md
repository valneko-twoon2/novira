# 非露骨な色気
> novira オリジナルの手引き

## この場面の役目
裸や性行為を描かずに、相手を意識する空気、惹かれ合う気配、触れそうで触れない緊張を読者に感じさせる。色気は「見せる量」ではなく「見る側の想像が動く余白」で作る。

## 読者に見せるもの
- 視線の動き。目が合う、すぐ逸らす、相手の手や首筋に一瞬とどまる。
- 距離の変化。肩が触れる近さ、振り向いたら顔が近い、手が伸びて途中で止まる。
- 小さな身体反応。耳の赤み、息を整える仕草、髪や襟元を直す指。
- 服は着たまま。乱れは袖口や髪の一筋程度にとどめる。

## コマ運び
1. 引きのコマで二人の距離と場所を見せる。
2. 視線のアップ。目、口元、指先など部位を一つに絞る。
3. 反応のコマ。相手が気づく、または気づかないふりをする。
4. 間のコマ。台詞なしで、窓の光や揺れる髪などを一コマ挟む。
5. 終わりは寸止め。触れる直前、あるいは別の話題にそらして余韻を残す。

吹き出しは少なめにし、小さな声や言いよどみ（「……」「えっと」）を使う。説明的な独白で気持ちを言い切らない。

## 絵と台詞の指示
- 絵では光と構図で雰囲気を作る。逆光、夕方の赤、近いアングル、浅い被写界深度。
- 台詞は日常の言葉に含みを持たせる。「近いね」「……そう？」程度で十分。
- 年齢が曖昧なキャラクターは性的な含みを一切持たせない。成人と明示できる登場人物だけで扱う。

## よくある失敗
- 身体の露出や強調に頼り、ただの扇情的な絵になる。
- 全員が常に誘惑する側になり、緊張が生まれない。
- 気持ちを台詞で全部説明して余白が消える。
- 密着が続き、緩急がなく単調になる。
