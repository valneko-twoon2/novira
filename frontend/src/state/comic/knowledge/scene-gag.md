# ギャグ・笑いのずらし
> novira オリジナルの手引き

## この場面の役目
読者に笑ってもらう。笑いの基本は「期待させて、外す」こと。シリアスな流れの中の一点の脱力でも、全編コメディのテンポでも、ずらしの位置とタイミングが肝になる。ツッコミ中心の場面は scene-tsukkomi を参照。

## 笑いが生まれる仕組み
- 落差。真剣な状況に、くだらない事実が出てくる。
- 繰り返しと裏切り。同じことを二回やり、三回目で変える。
- 過剰。一つの行動を極端に大きくする。
- 認識のずれ。本人は大真面目だが、周りから見ると変。
- 真顔。おかしなことを誠実な顔で言う。

## コマ運び
1. 前振りは普通に、むしろ丁寧に描く。ここで読者に正しい期待を持たせる。
2. 直前に間のコマを一つ入れる。小さな予兆（汗、視線、静けさ）が溜めになる。
3. オチは次のコマ、またはページをめくった先に置く。ページ末で引き、めくり直後に外す手法が強い。
4. オチのコマは大きく、情報を一つにする。ごちゃごちゃさせない。
5. オチの後に、無表情のリアクションや静かな後始末を小さく入れると余韻が笑いになる。

絵のテンションは前振りで抑え、オチで崩す。崩し方（顔の変形、効果線、デフォルメ）を、そこだけに限定する。

## 台詞のコツ
- 説明を削る。言い切らないことが笑いになる。
- ボケの台詞は短く、語尾を揃える。
- 擬音や書き文字を絵の一部として使う。

## よくある失敗
- 前振りが説明的で、オチを先に言ってしまう。
- オチが二つ以上あり、焦点がぼやける。
- 毎コマ全力で崩して、緩急がなくなる。
- 人を傷つけるだけの内容を笑いにする。
