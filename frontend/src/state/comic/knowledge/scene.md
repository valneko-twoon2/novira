# 場面の効果から手引きを選ぶ
> novira オリジナルの手引き

場面ごとの手引きは16種あり、`get_manga_guide` のトピック名は `scene-` で始まる。この文書は選ぶための表。**場面の主な効果を一つ決め、対応するトピックを1つだけ読む。** 全部を読み込む必要はない。複数の効果が混ざる場面は、その場面で読者にいちばん強く残したい効果を主にし、ほかは副として扱う。

## 状況から選ぶ

| 場面が必要としていること | トピック | 意味 |
|---|---|---|
| 笑いを作る、予想をずらす | `scene-gag` | ギャグ。積み上げと、そのずらしで笑わせる |
| 異常な言動に反応して笑いを締める | `scene-tsukkomi` | ツッコミ。おかしな物事への反応で笑いを完成させる |
| 露骨にせず色気を匂わせる | `scene-allure` | 非露骨な色気 |
| 人物の格好よさ、格上感を見せる | `scene-stature` | 格好よさ・格上感 |
| 不穏さ、恐怖を高める | `scene-horror` | 不穏・恐怖 |
| 怒り、口論、決裂を描く | `scene-conflict` | 衝突と決別 |
| 悲しみ、喪失、その余韻を描く | `scene-grief` | 悲しみ・喪失・余韻 |
| 好意、照れ、恋の予感を描く | `scene-romance` | 恋愛的な近づき |
| 親密さ、信頼を見せる | `scene-trust` | 心の距離が縮んだ状態 |
| 気まずさ、すれ違いを描く | `scene-awkwardness` | 噛み合わない空気 |
| 危機、焦り、切迫感を出す | `scene-urgency` | 時間や状況に追われる緊張 |
| 驚き、発覚、種明かしをする | `scene-revelation` | 情報が明らかになる瞬間 |
| 爽快感、逆転、解放を与える | `scene-payoff` | 溜めた圧力が抜ける瞬間 |
| 可愛げ、愛着を持たせる | `scene-endearment` | 人物を好きにさせる |
| 駆け引き、探り合いを描く | `scene-bargaining` | 腹の探り合い、取引 |
| 和解、赦し、救いを描く | `scene-reconciliation` | 関係の修復 |

## 似た場面の見分け方

- **gag と tsukkomi**: 笑いの種そのもの（ボケ、積み上げ、ずらし）を作るなら gag。すでにある異常に誰かが反応して笑いを成立させるなら tsukkomi。
- **allure と romance**: 見る側の目を引く魅力なら allure。人物同士の気持ちの動きなら romance。
- **stature と endearment**: 距離を置いて見上げさせるなら stature。近づけて好きにさせるなら endearment。
- **horror と urgency**: 正体の分からない不安がじわじわ迫るなら horror。逃げる、間に合わせるなど、状況に追われるなら urgency。
- **conflict と awkwardness と bargaining**: 感情をぶつけ合うなら conflict。言えない・噛み合わないなら awkwardness。感情を隠して利を探るなら bargaining。
- **grief と reconciliation**: 失った後の沈みと余韻なら grief。壊れた関係が戻るなら reconciliation。
- **trust と romance**: 恋の色を含まない安心や信頼なら trust。好意が意識されているなら romance。
- **revelation と payoff**: 隠れていた事実が分かるなら revelation。我慢や劣勢が報われて抜けるなら payoff。

迷ったら、読者に残す感情を一言で言う。その言葉に近い行の効果を選ぶ。
