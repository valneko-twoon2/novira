# 爽快感・逆転・解放
> novira オリジナルの手引き

## この場面の役目
溜めた我慢や抑圧を一気に解き放ち、読者に「やった」という解放感を渡す場面。逆転劇、反撃、決着、壁の突破が当てはまる。解放の大きさは、その前にどれだけ溜めたかで決まる。

## 読者に見せるもの
- 何が抑えられていたか（理不尽、劣勢、周囲の侮り）
- 形勢が変わる決定的な一瞬
- 相手や周囲の反応（驚き、崩れる表情）
- 主人公が静かに、または堂々と立つ姿

## コマ運び
1. 溜め：小さめのコマを続け、主人公の耐える顔、握る手、相手の余裕を見せる。吹き出しは少なめ。
2. 引き金：ごく短い一言や小さな動作。アップ1コマで十分。
3. 解放：大ゴマまたは横幅いっぱいのコマ。構図は引きか見上げ、効果線で勢いを出す。ここは台詞を削り、絵に任せる。
4. 余韻：相手のリアクション、周囲のざわめき、主人公の横顔。ここで初めて短い台詞を置く。

溜めのコマを増やすほど解放が効く。逆に解放の直前で説明を挟むと勢いが死ぬ。

## 台詞と絵
- 決め台詞は一つに絞り、短く言い切る。長い口上は避ける。
- 勝ち誇りすぎず、淡々と言うほうが格好よく見えることが多い。
- 相手の驚きは目の見開き、汗、口の開きで描き、台詞で説明しない。

## よくある失敗
- 溜めが足りず、逆転が唐突になる
- 解放のコマが小さく、他と同じ大きさになる
- 勝った後に説明台詞が長く続く
- 相手を貶めすぎて後味が悪くなる

## チェックリスト
- 溜めのコマが最低2つあるか
- 解放のコマが最大の大きさか
- 解放のコマの台詞は一言以内か
- 相手の反応を1コマ入れたか

勝利の格好よさを強く出したいときは scene-stature、笑いに落とすなら scene-gag も検討する。
