# ツッコミ・異常への反応
> novira オリジナルの手引き

## この場面の役目
ボケや異常な出来事に、読者の代わりに驚き、突っ込み、反応する場面。読者が感じた違和感を言語化し、笑いと共感を同時に生む。反応の質とタイミングで笑いの強さが決まる。

## 読者に見せるもの
- ボケ・異常の内容（絵を見て一目で分かること）
- ツッコミ役の反応：驚愕、呆れ、絶叫、冷静な指摘
- 周囲の無関心さや、本人の真顔（ズレが大きいほど笑える）

## コマ運び
1. ボケ：まず異常を画面に出す。吹き出しは少なく、絵で状況が分かるように。
2. 間：ツッコミ役の固まる顔、汗、沈黙の1コマ。この間が笑いの溜めになる。
3. ツッコミ：大きめのコマ。顔のアップか、全身で反応する構図。フォントを大きくし、短い言葉を置く。
4. 追い打ち：ボケ側のとぼけた返し、周囲の無反応。ツッコミを受けても変わらないとさらに笑える。
5. 落ち：小さなコマで一言か、疲れたツッコミ役の姿で閉じる。

## 台詞と絵
- ツッコミは短く的確に。何がおかしいかを一言で指す。
- 説明的な長いツッコミは避け、ボケの中身を繰り返さない。
- 表情は誇張してよいが、ボケ側の表情は真顔にするとズレが際立つ。
- 擬音や集中線で勢いを足してもよい。

## よくある失敗
- ボケが絵で伝わらず、ツッコミが空回りする
- 間がなく、すぐツッコんでしまう
- ツッコミが説明の連続になる
- 毎回同じ反応で飽きられる

## チェックリスト
- ボケが一目で分かるか
- 間のコマがあるか
- ツッコミは短いか
- 落ちのコマがあるか

笑い全般は scene-gag、驚きの種明かしは scene-revelation を参照。
