# 駆け引き・探り合い
> novira オリジナルの手引き

## この場面の役目
互いに本心や手札を隠し、言葉の裏を読み合う緊張を描く。交渉、取引、恋の探り合い、腹の探り合いなど。勝敗よりも「どちらが主導権を握っているか」の揺れを読者に追わせる。

## 読者に見せるもの
- 各人が何を欲しがっているか（読者には先に、または途中で伝える）。
- 言葉と表情のずれ。笑顔の下の計算、余裕の裏の焦り。
- 主導権の移動。優位に立つ側が変わる瞬間。

## コマ運び
1. 向かい合う二人を引きで見せ、座る位置や机の距離で力関係を示す。
2. 片方の発言、もう片方の目元のアップ。表情は小さく変える。
3. 手元のコマ。指を組む、書類を押さえる、グラスを置くなどの仕草で心理を語る。
4. 切り返しを増やす（A→B→A）。読む速度が上がり緊張が高まる。
5. 決め手の一言の直前に、静かな間のコマを置く。
6. 決着は小さな仕草でつけてもよい。相手の視線が泳ぐ、口角が上がるなど。

吹き出しは短く、質問と答えを交互に。長い説明の台詞は避ける。

## 台詞のコツ
- 質問に質問で返す。答えをはぐらかす。
- 事実の一部だけを渡し、残りは相手に想像させる。
- 相手の言葉をそのまま繰り返して圧をかける。
- 本心は最後まで出さず、読者が気づける小さな手がかりだけ置く。

## よくある失敗
- 双方が自分の作戦を台詞で説明してしまい、探り合いにならない。
- 表情が常に同じで、揺れが読み取れない。
- 主導権が最初から最後まで変わらない。
- 決着の理由が読者に伝わらず、唐突に見える。
