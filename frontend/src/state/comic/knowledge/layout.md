# コマ割り
> novira オリジナルの手引き

1 ページを何コマにし、どの大きさと形で切るかの考え方。novira は本全体のコマ割りも検査し、同じ切り方の繰り返しを知らせる。ここの規則はそれに合わせてある。

## 1. 読む順番

- 日本語の漫画は右から左、上から下へ読む。コマは右上のコマが最初、左下のコマが最後。
- 横に並ぶコマは、右のコマが先。左右に並べた二つのコマでは、台詞も右のコマのものを先に読む。
- 順番が迷う切り方（大きな斜めのコマが入り組む、縦長コマが縦横両方に隣接する）は避ける。迷うときは、コマの隙間（余白）の幅で段を分ける。
- コマ割りの出力は読む順に並べる。1 番目が最初に読むコマ。

## 2. 1 ページのコマ数

| コマ数 | 使いどころ |
|---|---|
| 1 | 扉、決めの絵、場面転換、強い感情。多用しない |
| 2〜3 | 大きく見せたい場面、ゆっくりした時間 |
| 4〜5 | 会話や動きの基本形。迷ったら 5 コマ前後 |
| 6〜7 | 細かい動作、速い展開 |
| 8 以上 | 特別な演出のときだけ。1 コマが小さくなり、絵と台詞が収まらない |

長い本では、5 コマのページが最も多くなる構成が自然。1 ページのコマは、台詞と絵が収まる大きさを保てる数にする。

## 3. 大きさで強弱をつける

- そのページで一番大事なコマを最大にする。面積で言うと、他のコマの 2 倍程度が目安。
- 全部同じ大きさのコマは単調。大中小を混ぜる。
- 小さいコマは短い時間と細かい反応、大きいコマは広がり、衝撃、感情。
- 大きなコマは、ページの上か下の端に寄せると、読む流れを妨げにくい。
- コマの間隔（余白）は一定にする。余白を広げると時間が経った感じ、なくすと連続した動きになる。

## 4. 切り方の型

- 段組み：横に 2〜3 段に分け、段ごとに左右を割る。最も読みやすい。
- 縦割り：縦長のコマを並べる。静かな場面や人物の並びに向く。
- 斜め切り：動き、衝撃、不安に使う。1 ページに 1〜2 本まで。
- 大ゴマ＋小ゴマ：大きな一枚の上に小さなコマを重ねる。感情や状況の説明に便利。
- コマ抜け：絵がコマ枠をはみ出す。勢いを出すが、読む順番が曖昧になるので、一ページに一つまで。

## 5. 同じ切り方を繰り返さない

novira は本全体のページ構成を次の点で調べ、守れないと指摘する。

- 「横に 3 段を全幅で積んだページ」を近くに置かない。同じ型の間に、少なくとも 4 ページの別の型を挟む。
- 20 ページの間に、その型は 3 ページまで。
- 20 ページ以上の本では、5 コマのページを最も多くする。
- 隣り合うページが同じ切り方（1 コマのページは除く）にならないようにする。

3 段積みは書きやすいため、気づかないうちに増える。ページ案を作ったら、最後に切り方を並べて確かめる。

## 6. 見開きとめくり

- 左右 2 ページを 1 つの絵として見せる見開きは、山場に 1 度か 2 度。
- めくった直後に大きなコマを置くと、驚きが出る。めくる前のページの最後は小さなコマで溜める。
- 見開きの途中で台詞や重要な顔をノド（綴じ目）に置かない。

## 7. 手順

1. ビートごとに、そのページの「一番大事なコマ」を決める。
2. 大事なコマを最大にして、残りの大きさを決める。
3. 読む順に並ぶか確かめる（右上から左下）。
4. 台詞の量を見積もり、収まらないコマは大きくするか、台詞を削る。
5. 前後のページと切り方を比べ、繰り返しを直す。

## チェックリスト

- [ ] 読む順が右上から左下で迷わない
- [ ] そのページの主役のコマが最大
- [ ] コマの余白が揃っている
- [ ] 3 段積みが近くに続いていない
- [ ] 隣のページと同じ切り方ではない
- [ ] 1 ページのコマ数が多すぎない

## よくある失敗

- 全ページが 3 段積みで、本が単調になる。
- 斜めのコマを多用し、読む順が分からなくなる。
- 台詞の量に対してコマが小さい。
- 山場が小ゴマで、他と変わらない。
- 同じ型のページを連続させる。

## 8. ページの種類ごとの考え方

- 扉や冒頭のページは、1〜2 コマの大きな絵で雰囲気を見せる。台詞は少なく、あとの本文に引き継ぐ。
- 会話中心のページは、4〜5 コマで、段組みを基本にする。コマの大きさは、台詞の量に合わせて変える。
- 動きのページは、斜めや縦長のコマを混ぜて勢いを出し、決めの一コマだけ大きくする。
- 静かなページは、コマ数を減らして余白を広げる。空白は無駄ではなく、時間の長さになる。
- 最終ページは、余韻を出す大きめのコマで終える。小さなコマを詰めて終わらない。

## 9. 人物とコマの関係

- 二人が向かい合う会話は、左右のコマに分け、それぞれの人物を同じ側に置き続ける。
- 人物の動く向きは、読む向き（右から左）に沿うと進みやすい。逆に動かすときは、理由（戻る、抵抗する）を持たせる。
- 複数の人物を一つの大きなコマに収める場面は、全員の顔が見える位置関係にする。

## 10. 直し方

- 繰り返しを指摘されたときは、そのページのコマ数を一つ変えるか、一つのコマを大きくして、切り方を変える。
- 台詞が収まらないときは、まずコマを大きくし、次に隣のコマを小さくする。ページ全体の読む順は変えない。
- 順番が分かりにくいと言われたら、余白を広げて段を分け、斜めのコマを減らす。

## 11. 例：5 コマの会話ページ

- 上段：場所を見せる横長の 1 コマ（小さめ）。
- 中段：右に話し手の中景、左に聞き手の反応。
- 下段：右に小さな反応、左に最大の決めのコマ（感情のアップ）。
- 読む順は 右上 → 中右 → 中左 → 下右 → 下左 で、迷わない。
