# 不穏・恐怖
> novira オリジナルの手引き

## この場面の役目
読者に「何かがおかしい」「見てはいけないものが近い」という不安を持たせる。恐怖は見せることより、見えない部分を想像させることで強まる。最後まで正体を見せなくてもよい。

## 読者に見せるもの
- 日常の中の小さな違和感。位置の変わった物、音の抜けた空間、いないはずの気配。
- 登場人物の気づきの遅れと、読者のほうが先に気づく状況。
- 逃げ場のない構図。狭い廊下、暗い奥行き、ふと振り返る背後。
- 正体はぼかす。影、輪郭、一部分だけ。

## コマ運び
1. 平穏な日常を丁寧に描く。差が大きいほど違和感が効く。
2. 小さな異変を背景の端に置く。主役の台詞の裏でひっそりと。
3. 引きと寄りを不規則に。足音を待つ間のコマは長く、細く。
4. 見つけるコマは、主人公の視線の先を見せず、顔のアップだけにして次のページへ。
5. 次のページで初めて見せる、または見せずに暗転させる。ページめくりの仕組みを使う。
6. 終わりは安心させない。解決しても、最後の一コマで違和感を残す。

吹き出しは減らし、効果音は小さく、擬音は静かな語（「…ぎ」「ひた」）。ベタや影を多めにし、白い余白を恐怖の間として使う。

## 台詞のコツ
- 登場人物は怖がる前に、まず否定する（「気のせいだよね」）。
- 説明しすぎず、設定や由来は断片だけ。
- 日常的な口調のまま異常な内容を言わせる。

## よくある失敗
- 怪物を最初から全身で見せ、想像の余地が残らない。
- 叫び声や効果線に頼りすぎて、静かな恐怖が消える。
- 不穏な描写が続くだけで、緊張の上がり下がりがない。
- 過度に残虐な描写で驚かせようとする。
