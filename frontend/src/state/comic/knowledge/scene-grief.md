# 悲しみ・喪失・余韻
> novira オリジナルの手引き

## この場面の役目
失ったものの大きさを、読者が自分の胸で感じられるようにする。悲しみは「泣いている顔」よりも、空いた場所、残された物、止まった日常で伝わる。叫びより静けさが深く届くことが多い。

## 読者に見せるもの
- 失われたものが、それまでどれほど日常にあったか。
- 事実を受け止められない時間。ぼうっとする、いつもの動作を続けてしまう。
- 残された物。使われない席、冷めた食事、片方だけの靴、しまわれた手紙。
- 時間の経過。同じ場所の光や季節が変わる。

## コマ運び
1. 知らせや出来事は短く、淡々と。大げさな演出は避ける。
2. 反応は引きの構図で。広い空間に小さく人物を置くと孤独が出る。
3. 台詞なしのコマを続ける。物のアップ、窓の外、床、手。
4. 涙は我慢する表情を先に、こぼれる瞬間を後に。ただ流させるより抑えたほうが強い。
5. 余韻は大きな余白で。ページ下半分を空ける、小さなコマを一つ置くなど。
6. 最後は小さな前進か、変わらない風景で閉じる。無理に慰めを入れない。

吹き出しは最小限。声に出ない言葉は枠の外や小さな文字で。モノローグも短くし、感情の名前（「悲しい」）は書かない。

## 台詞のコツ
- 周囲の人は気の利いたことを言えない。言葉に詰まる様子が真実味を出す。
- 本人は、場違いに日常的なことを言う（「ご飯、食べなきゃ」）。
- 故人や去った人の言葉を、回想で一行だけ。

## よくある失敗
- 泣き叫ぶ場面だけで感情を表そうとする。
- 感動を誘う説明台詞が多く、白けてしまう。
- 悲しみの直後にすぐ明るい展開へ移す。
- 回想を長く入れて、現在の時間が止まる。
