# 設計: 各機能の今の仕様

機能ごとに 1 ページ。そのページは、その機能の現行仕様（動き、作り、安全上の境界、既知の限界）を書く。コードを変える前にその機能のページを読み、変更でページが事実でなくなるなら同じコミットで直す。ファイルのページは `node scripts/tools/docs-check.mjs --find <パス>` で引ける（各ページは前書きの `covers` に、説明するコードを書いている）。ページの書き方は `.claude/rules/docs.md`。部品のつながりと変更の入口は [../architecture/README.md](../architecture/README.md)。

ページは大（領域）と中（話題）の 2 階層のフォルダに置く。番号は並び順で、各フォルダの `README.md` はその中の一覧になる。新しいページは、その話題のフォルダの次の空き番号をもらう（ほかのページの番号は振り直さない）。

| 領域 | 内容 |
|---|---|
| [01-app/](01-app/README.md) | アプリの土台。起動と停止、データフォルダ、安全上の方針、画面の骨格、エンジンの設定、リリースと CI |
| [02-generation/](02-generation/README.md) | 生成とモデル。キューとワーカー、ComfyUI のグラフ、下書き、プリセット、動画・音楽・音声、ワークフロー、モデルの導入と検索 |
| [03-assistant/](03-assistant/README.md) | AI アシスタント。プロバイダー、道具、試し描きの繰り返し、履歴、絵の受け渡し、Web での調べもの |
| [04-gallery/](04-gallery/README.md) | ギャラリーと画像の仕上げ。ファイルと共有、ごみ箱、ビューアー、画像の道具 |
| [05-comic/](05-comic/README.md) | コミック。キャンバスとページ、コマの描き方、3D ラフ、シーンの操作 |
| [06-server/](06-server/README.md) | ブラウザ用サーバー。ローカルの起動、家庭内ネットワーク、ペアリング、外出先からの接続、アプリとの関係 |
