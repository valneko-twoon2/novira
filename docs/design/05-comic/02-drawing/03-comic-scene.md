# コミックのシーン（scene 操作）

一覧に戻る: [README.md](README.md)

アシスタントがコマを 1 つの `scene` 操作として書く方法と、アプリがそれから作るもの。コマの描き方は [01-comic-drawing.md](01-comic-drawing.md) に、ページレイアウトは [03-comic-pages.md](../01-canvas/03-comic-pages.md) にある。

## 動作

- アシスタントには、各コマを `edit_comic` の 1 つの `scene` 操作として書くよう伝えてある（`frontend/src/state/comic/scene.ts`。`applyComicOps` で展開する）。内容は、ショット、アングル、舞台、最大 4 人の人物（登場人物の名前、1 人用の既製ポーズ、立ち位置、向き、行動、表情）、ポーズなしの登場人物の名前、読者に見せたいもの、話者ごとのセリフ、メモ。
- アプリはこれを、コマを作る操作に変える。どれもユーザーの部分に限る。`panel`（プロンプト、登場人物、舞台、メモ）、`pose`（ショットに合わせて各人物を置く。指定がなければ互いに離し、ほかの人物へ向ける。誰かと本人の言葉 `poseWords` も持つ。顔のショットにはポーズを付けない）、セリフが与えられたときは、コマの吹き出しの代わりに、セリフごとに話者へ向けた吹き出し 1 つ。
- プロンプトには、複数の登場人物の人数（人数タグ、なければ言葉）、solo か no humans、人物がすべて男性なら male focus、構図、アングル、向き、各人物の行動、ものを入れる。ものは `SCENE_THINGS_WEIGHT` で指定する。
