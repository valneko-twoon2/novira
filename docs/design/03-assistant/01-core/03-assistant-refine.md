# AI アシスタント: 複数枚で近づける

一覧に戻る: [README.md](README.md)

利用者が、画像や説明に似せるために数回試すようアシスタントに頼むと（「これみたいにして」「何枚か試して近づけて」）、ループを回し続けるのはモデルではなくアプリになる。各回答のあと、アプリが次の 1 枚のためにアシスタントへ送り直す。アシスタント全体は [01-assistant.md](01-assistant.md)。

## 動作

- アシスタントは `refine` ツール（`action: start`、1 文の目標、目標画像の名前、2 から 30 の `maxRounds`（省略時 30））で開始し、同じ回答で最初の試し描きを生成する（[02-assistant-pictures.md](../02-context/02-assistant-pictures.md)）。設定「エージェントの試し描き」（`assistantTrialPictures`。設定 > 生成 > エージェント）が必要で、切れていれば呼び出しは失敗して何も始まらない。
- 状態は `frontend/src/state/agent.ts` の `refining`（`frontend/src/state/agentRefine.ts` の `Refinement`: 目標、目標画像、描いた枚数、最大枚数、動いているチャット）。各リクエストのあと `afterRequest` が 1 枚加算する。ただしアシスタントが `finish` で `refine` を呼んだ場合（ループ終了）と、`start` で呼んだ場合（1 枚目からやり直し）は除く。
- 動いている間、各回答の終わりにウィンドウが次のターンを自分で送る（`continuation`）。枚数の番号、目標、目標画像を示す英語のメッセージで、目標画像と最新の画像を `view_picture` で見て、違う所だけを直し、試し描きをもう 1 枚生成し、近づいたか直近 2 枚が近づかなくなったら `finish` を呼ぶよう指示する。最後の 1 枚に添えるメッセージは、その後で終えるよう指示する。アシスタントは回答だけではループを終えられない。終えるのは `finish`、最後の 1 枚、利用者だけ。
- 利用者は、メッセージを書く（次の 1 枚の代わりに送られる）、停止ボタン、別のチャットへの切り替えで終える。リクエストの失敗でも終わる。枚数の上限は 30。
- チャットは自動メッセージごとに、中央に小さな注記（「近づける作業: N / M 枚目」。`agent.refine.step`）を出し、メッセージに `step` として保持する。モデルが読むのは英語のメッセージ。各回の画像はその回の答えの下に出る。
- 画像の読み取りは、ほかの読み取りと同じく利用者の許可を求める。「always」ならラウンドは質問なしで進む。

## 境界

独自の境界はない。すべての呼び出しは `mcp::dispatch` とそのスキーマ検査を通り、`refine` が変えるのはウィンドウのこの状態だけで、画像、プロンプト、ファイルは変えない。

## 既知の限界

- モデルが画像を近いと判断するかどうかはモデル次第。アプリが保証するのは、上限まで再度聞くことだけ。
- 長いループは長いチャットになる。コンテキスト予算に収まらない過去のターンは送られなくなるため（[01-assistant-history.md](../02-context/01-assistant-history.md)）、目標と目標画像の名前をすべての自動メッセージで繰り返す。
- 実行をまたいで保持しない。アプリを閉じると近づける処理は終わり、注記はチャットに残る。
