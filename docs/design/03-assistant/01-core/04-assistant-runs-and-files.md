# AI アシスタント: 実行、キュー、ボード、書き出し、エンジンの場所

一覧に戻る: [README.md](README.md)

アシスタントが、作った画像をまとめて扱うとき（ボードの画像を選ぶ、別の形式で書き出す）と、実行の回数・取り消し・エンジンのフォルダの場所を扱うときの道具。アシスタント全体は [01-assistant.md](01-assistant.md)。

## 動作

- 規則（`backend/crates/novira-core/src/agent/prompt.rs` の `INSTRUCTIONS`）: 作る前にアプリにすでにある機能を探す。作った画像の変換・圧縮・縮小は書き出しで行い、ワークフローを組まない。ツールにないことは「できない」で止めず、アプリが出せるもの（エンジンのフォルダのパス、機能の場所）と最短の手順を示す。実行の前に回数を確かめ、誤って入れた自分のキューはすぐ取り消す。実行して確かめるよう頼まれたら 1 回走らせ、結果を見てから答える。確かめていない動きを事実として言わない。入れたばかりの拡張機能のノードが見つからないときは、ComfyUI の再起動が要ると伝える。
- `generate` の `count`（1〜100）: 画面の回数欄の代わりに実行の回数を決める（`enqueueActive` の `pictures`）。`count` なしで回数欄が 2 回以上にしたときは、その旨と `cancel_queue` の勧めを答えに添える。ワークフローの 1 回の実行は、グラフのすべてのノードを 1 度ずつ動かす。
- `cancel_queue`: このアプリの起動中にアシスタントが `generate` で入れ、まだ終わっていない（待ち・実行中）項目だけを `cancelQueueItem` で取り消す。利用者が入れた項目、終わった項目、キューにない項目は、理由をつけて残す。1 件も取り消せなければエラーになる。
- `list_gallery_images` の `board`: ボードの名前か、上のボードから `/` でつないだパスで絞る（`boardsNamed`。NFKC で幅をそろえ、大小と `/` の前後の空白は無視する。パス全体が一致するものを先に、なければ末尾が一致するもの）。`none` はボードのない画像。サブフォルダの画像は含めない。一致しないか複数一致するときは、画像の代わりにボードのパスの一覧（最大 200）を返す。各画像の答えにはボードのパスが付く。
- `export_pictures`: ギャラリーの画像の名前と、形式（PNG・JPEG・WebP）、JPEG の品質、長辺、情報を外すかを受け取り、書き出しのダイアログ（[02-gallery-share.md](../../04-gallery/01-files/02-gallery-share.md)）をその設定で開く（`useShareDialog` の `preset`）。ギャラリーにない名前と補助画像は除き、答えの `notFound` で伝える。ファイルを書くのは、利用者が実行ボタンを押してフォルダを選んだときだけ。終わった画面の「フォルダを開く」でそのフォルダが開く。
- `get_engine_info`: ComfyUI への接続のしかた（自前のインストール、利用者の ComfyUI フォルダ、アドレス）、エンジンの状態、インストール先またはフォルダ、出力フォルダ（`EngineSettings.comfyuiOutputDir`。アドレスだけで接続しているときは「不明」）、データフォルダのフルパスを返す。

## 境界

| 対象 | 守り方 |
|---|---|
| 取り消し | `cancel_queue` が取り消せるのは、アシスタント自身が入れた項目だけ（ウィンドウのメモリ上の集合。アプリを開き直すと空になる） |
| 書き出し | `export_pictures` はダイアログを開くだけで、ファイルの書き込みとフォルダの選択は利用者がダイアログで行う。透かしの設定は変えない |
| 許可 | `export_pictures`・`get_engine_info`・`cancel_queue` は、画像もプロンプトも読まないので読み取りの許可を求めない。`board` 付きの `list_gallery_images` は、ほかの一覧と同じく許可を求める |

## 既知の限界

- `get_engine_info` は、エンジンのフォルダのフルパスをモデルに渡す。パスには Windows のユーザー名が含まれうるので、CLI やサーバーのプロバイダーに届く。利用者が場所を尋ねたときに使うよう説明で定めているが、許可は求めない。
- ワークフローの結果がギャラリーに入るのは、グラフの出力ノード 1 つの最初のファイルだけ。拡張機能の保存ノードが ComfyUI の出力フォルダに書いたファイルは、ギャラリーに入らない。作った画像の変換は書き出しで行う。
