# 그림 수정하고 다시 쓰기

완성된 그림을 '조금 더 고치고 싶다', '같은 분위기로 몇 장 더 갖고 싶다', '이 캐릭터를 다른 장면에서도 쓰고 싶다'고 생각했을 때의 기능을 모은 장입니다.

대부분의 기능은 뷰어(그림을 크게 보는 화면) 위에 있는 도구 모음의 버튼이나 갤러리의 그림을 오른쪽 클릭한 메뉴에서 불러냅니다. 도구 모음의 버튼은 마우스를 올리면 이름이 나옵니다. 뷰어와 갤러리의 기본은 [갤러리](03-gallery.md)를 보세요.

## 어디에서 무엇을 쓰는지

| 하고 싶은 일 | 사용하는 것 | 따로 필요한 것 |
|---|---|---|
| 같은 설정으로 몇 장 더 만든다, 조금만 바꿔서 다시 만든다 | **{{ui:gallery.derive.menu}}** | 원본 그림에 사용한 모델이 설치되어 있을 것 |
| 배경을 지우고 사람이나 사물만 남긴다 | **{{ui:cutout.menu}}** | 확장 기능 ComfyUI-RMBG |
| 투명한 여백을 줄인다 | **{{ui:gallery.menu.trim}}**(오른쪽 클릭에서만) | 없음 |
| 그림의 일부를 선택해서 오려 내거나, 지우거나, 다시 그린다 | **{{ui:gallery.menu.segment}}** | 확장 기능 ComfyUI-segment-anything-2 등 |
| 작게 일그러진 얼굴을 깔끔하게 만든다 | **{{ui:facefix.menu}}** | 확장 기능 ComfyUI-Impact-Pack과 ComfyUI-Impact-Subpack |
| 그림에서 프롬프트를 작성한다 | **{{ui:caption.menu}}** | 확장 기능 ComfyUI-Florence2 |
| 캐릭터를 등록해서 다른 그림에서도 쓴다 | **{{ui:character.menu}}** | 참조 이미지용 확장 기능(IP-Adapter) |
| 설정을 바꾼 그림을 1장의 표에 나열한다 | **{{ui:xyplot.menu}}** | 없음 |
| 중간까지 그린 후보에서 고른다 | **{{ui:app.views.drafts}}** 탭 | 없음 |
| 여러 그림에 같은 처리를 적용한다 | **{{ui:gallery.menu.batch}}**(여러 장을 선택해서 오른쪽 클릭) | 처리에 따라 다름 |

## 확장 기능이 필요할 때

배경 제거, 범위를 선택하는 기능, 얼굴을 수정하는 기능 등은 그림을 만드는 엔진(ComfyUI)에 '확장 기능'을 추가해서 동작합니다. 확장 기능이 설치되어 있지 않으면 대화 상자에 '…하려면 확장 기능 ○○이(가) 필요합니다.'라고 나오고 설치하는 버튼이 나열됩니다.

1. **{{ui:cutout.install}}** 버튼을 누릅니다. 필요한 것을 자동으로 다운로드해서 설치합니다.
2. 설치가 끝나면 버튼이 **{{ui:cutout.restart}}**로 바뀝니다. 누르면 ComfyUI가 다시 시작합니다.
3. 다시 시작이 끝나면 같은 대화 상자를 그대로 사용할 수 있게 됩니다.

처음 사용할 때는 확장 기능이 사용하는 모델의 다운로드도 시작되므로 시간이 걸립니다. 인터넷에 연결되어 있어야 합니다.

> 확장 기능 중에는 설치에 시간과 용량이 드는 것이 있습니다. ComfyUI-Impact-Pack은 설치에 Git이 필요합니다. Git이 설치되어 있지 않은 컴퓨터에서는 설치에 실패합니다. 메시지가 나오면 내용을 확인하고 대처하세요.

확장 기능은 [워크플로](06-upscaling-workflows.md)의 '{{ui:workflows.panel.packs}}' 탭에서도 설치할 수 있습니다. 잘 되지 않을 때는 [문제가 생겼을 때](10-troubleshooting.md)도 보세요.

## 같은 설정으로 다시 만들기(파생)

![뷰어의 도구 모음에서 '파생시키기'를 연 모습](shot:derive-menu)

마음에 드는 그림을 뷰어에서 열고 도구 모음의 **{{ui:gallery.derive.menu}}** 버튼(가지가 갈라지는 아이콘)을 누릅니다. 갤러리에서는 그림을 오른쪽 클릭해서 **{{ui:gallery.derive.menu}}**를 선택합니다.

선택할 수 있는 것은 다음 3종류입니다.

| 항목 | 하는 일 |
|---|---|
| '같은 설정, 새 시드'(1장 또는 4장) | 프롬프트, 모델, 크기 등은 그대로 두고 시드만 바꿔서 그립니다. 구도는 바뀌지만 분위기는 같습니다. |
| '조금만 바꿔 다시 만들기'(1장 또는 4장) | 원본 그림을 토대로 약하게(강도 0.45로) 다시 그립니다. 구도와 색을 남긴 채 세부만 바뀝니다. |
| **{{ui:gallery.derive.custom}}** | 바꾸는 정도를 직접 정합니다(다음 항목). |

선택하면 새 그림이 대기열에 들어가고 원본 그림과 같은 보드에 나열됩니다. **생성 탭의 설정은 바뀌지 않습니다.** 입력 중인 프롬프트도 그대로 남습니다.

> 설정을 화면에 다시 불러온 뒤 직접 고쳐서 만들고 싶을 때는 **{{ui:gallery.menu.remix}}**를 사용합니다. 파생은 '버튼 하나로 원래 설정 그대로 만들기' 위한 것입니다.

### 바꾸는 정도를 선택해서 다시 만들기

![바꾸는 정도를 정하는 대화 상자](shot:derive)

**{{ui:gallery.derive.custom}}**를 선택하면 대화 상자가 열립니다.

1. 슬라이더 **{{ui:gallery.derive.dialog.strength}}**를 움직입니다. 왼쪽({{ui:gallery.derive.dialog.close}})일수록 원본의 구도와 색이 남고, 오른쪽({{ui:gallery.derive.dialog.free}})일수록 다른 그림에 가까워집니다.
2. **{{ui:gallery.derive.dialog.count}}**를 1, 2, 4, 8 중에서 선택합니다.
3. **{{ui:gallery.derive.dialog.create}}** 버튼을 누릅니다.

기준은 0.25 정도에서 원본과 거의 같은 그림, 0.75 정도에서 캐릭터는 남지만 구도가 크게 바뀌는 그림입니다. 그림에 따라 다르므로 몇 번 시험해 보세요. 슬라이더의 값은 그 한 번에만 사용됩니다.

### 이어받는 것과 이어받지 않는 것

- 이어받는다: 프롬프트, 네거티브 프롬프트, 모델, LoRA, 크기, 스텝 수, CFG 스케일, 스케줄러 등 그림을 만들었을 때의 설정.
- 참조 이미지와 컨트롤 레이어도 그림과 함께 기억하고 있으므로 그대로 사용됩니다. 다만 그 이미지가 갤러리에서 삭제되어 있으면 만들 수 없습니다. 이유가 알림에 나옵니다.
- 이어받지 않는다: 마스크, 영역 가이던스, 초안 설정. 이 기능이 생기기 전에 만든 그림에서 참조 이미지 등을 사용했던 경우도 기억하고 있지 않으므로 이어받을 수 없습니다. 이어받지 못했을 때는 알림으로 알려 줍니다.

다음 경우에는 버튼을 누를 수 없거나 알림이 나오고 만들 수 없습니다.

- 문장으로 만든 그림(이미지에서 이미지, 인페인트, 아웃페인트 포함)이 아닌 경우. 확대한 그림, 동영상, 음성 등은 대상이 아닙니다.
- 원본 그림에 사용한 모델이 설치되어 있지 않은 경우. 모델 이름을 덧붙인 알림이 나옵니다.

## 배경 제거하기

![배경을 제거하는 대화 상자](shot:cutout)

그림 속의 대상을 자동으로 구별해서 배경을 제거한 그림을 만듭니다. 클릭해서 지정할 필요는 없습니다.

1. 그림을 뷰어에서 열고 가위 아이콘의 **{{ui:cutout.menu}}** 버튼을 누릅니다(오른쪽 클릭 메뉴에도 있습니다).
2. 필요하면 설정을 바꿉니다.
   - **{{ui:cutout.model}}**: 보통은 그대로 두어도 괜찮습니다.
   - **{{ui:cutout.sensitivity}}**: 낮출수록 경계가 애매한 부분도 남깁니다.
   - **{{ui:cutout.edge}}**: 플러스로 윤곽을 넓히고 마이너스로 깎습니다.
   - **{{ui:cutout.background}}**: **{{ui:cutout.background.alpha}}** 또는 **{{ui:cutout.background.white}}**를 선택합니다.
3. **{{ui:cutout.run}}** 버튼을 누릅니다.

완성된 그림은 원본 그림과 같은 보드에 새 그림으로 저장됩니다. **원본 그림은 그대로 남습니다.** 결과가 마음에 들지 않으면 설정을 바꾸고 **{{ui:cutout.again}}** 버튼을 누릅니다. **{{ui:cutout.open}}**로 뷰어에 표시할 수 있습니다.

흰 배경은 나중에 [캐릭터](#캐릭터를-등록해서-사용하기)의 참조 이미지로 삼을 때 적합합니다. 배경의 색이 새로 만드는 그림에 옮겨 가기 어려워집니다.

## 투명한 여백 줄이기

배경을 투명하게 한 그림은 그림 바깥쪽에 투명한 여백이 남습니다. **{{ui:gallery.menu.trim}}**을 사용하면 그림이 있는 부분에 딱 맞게 잘라 낸 투명한 그림을 새로 저장합니다. 스티커나 소재로 사용할 때 편리합니다.

- 갤러리의 그림을 오른쪽 클릭해서 선택합니다. 배경을 제거한 직후에는 대화 상자의 **{{ui:cutout.trim}}**(배경을 투명하게 했을 때만 나옵니다)에서도 같은 일을 할 수 있습니다.
- 거의 보이지 않을 만큼 옅은 그림자는 여백으로 잘려 나갑니다.
- 투명한 부분이 그림의 가장자리까지 닿지 않는 그림에서는 '자를 여백이 없습니다'라고 나오고 아무것도 저장하지 않습니다. 전면이 투명한 그림도 줄일 수 없습니다.

## 범위를 선택해서 수정하기

![그림의 어디를 선택할지 클릭으로 지정하는 대화 상자](shot:segment)

그림 속에서 '이것'이라고 생각하는 것을 클릭으로 선택합니다. 선택한 부분을 오려 내거나, 지우거나, 다시 그릴 수 있습니다.

1. 그림을 뷰어에서 열고 **{{ui:gallery.menu.segment}}** 버튼을 누릅니다.
2. 처음에만 확장 기능 ComfyUI-segment-anything-2가 필요합니다. 화면의 안내에 따라 설치합니다([확장 기능이 필요할 때](#확장-기능이-필요할-때)).
3. 선택하고 싶은 것 위를 클릭합니다. 부족한 곳은 다른 곳을 클릭해서 추가합니다. 넘친 곳은 버튼을 **{{ui:segment.mode.exclude}}**로 전환해서 클릭하거나 오른쪽 클릭(또는 `Shift`를 누른 채 클릭)으로 뺍니다. 지정한 점을 한 번 더 클릭하면 그 지정을 취소할 수 있습니다. **{{ui:segment.clear}}**로 처음부터 다시 할 수 있습니다.
4. **{{ui:segment.run}}** 버튼을 누릅니다. 선택된 범위가 파랗게 표시됩니다.
5. 파란 범위가 맞다면 다음 조작을 선택합니다. 반대로 '나머지 부분'을 선택하고 싶을 때는 **{{ui:segment.invert}}**을 켭니다.

| 버튼 | 할 수 있는 것 | 필요한 것 |
|---|---|---|
| **{{ui:segment.cutout}}** | 선택한 부분만 오려 내서 투명한 그림으로 저장합니다. | 없음 |
| **{{ui:segment.mosaic}}** | 선택한 부분을 굵은 블록(모자이크)으로 만들어 저장합니다. 블록 크기는 옆의 숫자로 바꿉니다. | 없음 |
| **{{ui:segment.erase}}** | 선택한 부분을 주변 그림에 어울리게 지웁니다. | 확장 기능 comfyui-inpaint-nodes. 모델 LaMa(약 200MB)가 있으면 자연스럽게 지워집니다. 없어도 간이로 지울 수 있습니다. |
| **{{ui:segment.redraw.title}}** | 선택한 부분만 문장으로 지시해서 다시 그립니다. 다른 부분은 바뀌지 않습니다. | 이미지용 모델 |
| **{{ui:segment.toCanvas}}** | 그림과 선택 범위를 [캔버스](05-canvas.md)로 보냅니다. 선택 범위는 인페인트 마스크가 됩니다. | 없음 |

다시 그릴 때는 **무엇을 그릴지**를 문장으로 씁니다(예: blue hair, red scarf). 모델이 잘하는 표기법(애니메이션풍 모델이라면 영어 태그 등)에 맞추면 생각대로 나오기 쉬워집니다. **{{ui:segment.redraw.strength}}**를 낮출수록 원래의 형태와 색이 남습니다.

결과는 원본 그림과 같은 보드에 새 그림으로 저장됩니다. 원본 그림은 바뀌지 않습니다.

## 얼굴 수정하기

![얼굴을 수정하는 대화 상자](shot:facefix)

멀리서 본 구도의 그림에서는 작게 그려진 얼굴이 일그러지기 쉽습니다. **{{ui:facefix.menu}}**는 그림 속의 얼굴을 자동으로 찾아서 얼굴만 높은 해상도로 다시 그리고 원본 그림에 되돌립니다. 얼굴 이외는 바뀌지 않습니다.

1. 그림을 뷰어에서 열고 **{{ui:facefix.menu}}** 버튼을 누릅니다(오른쪽 클릭 메뉴에도 있습니다).
2. 처음에만 확장 기능 ComfyUI-Impact-Pack과 ComfyUI-Impact-Subpack이 필요합니다. **{{ui:facefix.install}}**로 설치하고 **{{ui:facefix.restart}}** 버튼을 누릅니다. 얼굴을 찾는 모델은 Subpack이 스스로 준비합니다.
3. 설정을 확인합니다.
   - **{{ui:facefix.model}}**: 원본 그림에 사용한 모델이 선택되어 있습니다.
   - **{{ui:facefix.prompt}}**: 원본 그림의 프롬프트가 들어 있습니다. 얼굴의 특징을 추가하면 효과가 있습니다.
   - **{{ui:facefix.strength}}**: 낮을수록 원래 얼굴에 가깝고 높을수록 크게 다시 그립니다.
   - **{{ui:facefix.sensitivity}}**: 올리면 확실한 얼굴만, 내리면 작은 얼굴이나 옆얼굴도 찾아냅니다. 다만 얼굴이 아닌 것도 찾아내기 쉬워집니다.
4. **{{ui:facefix.run}}** 버튼을 누릅니다.

결과는 원본 그림과 같은 보드에 저장됩니다. **{{ui:facefix.open}}** 버튼을 누르면 뷰어에서 원본 그림과 비교해 볼 수 있습니다. 마음에 들지 않으면 설정을 바꾸고 **{{ui:facefix.again}}** 버튼을 누릅니다.

> LoRA를 사용해서 만든 그림은 LoRA 없이 다시 그려집니다. 그래서 얼굴만 그림체가 조금 달라 보일 수 있습니다.

> '얼굴 검출 모델(YOLO)을 찾을 수 없습니다'라고 나오면 ComfyUI를 다시 시작하거나 확장 기능을 다시 설치하세요.

## 그림으로 프롬프트 만들기

![그림을 보고 태그를 작성한 대화 상자](shot:caption)

그림을 보고, 그 그림을 그리기 위한 프롬프트(태그나 문장)를 작성합니다. 마음에 드는 그림과 비슷한 그림을 만들고 싶을 때나, 프롬프트를 어떻게 쓸지 망설여질 때 씁니다.

1. 뷰어의 **{{ui:caption.menu}}** 버튼이나, 그림의 오른쪽 클릭 메뉴에서 **{{ui:caption.menu}}**를 고릅니다. 생성 탭의 프롬프트 칸 위에 있는 **{{ui:caption.fromPrompt}}** 버튼으로도 열 수 있습니다. 이 버튼에는 갤러리의 그림이나 컴퓨터의 이미지 파일을 끌어다 놓을 수 있습니다.
2. **{{ui:caption.style}}**에서 **{{ui:caption.style.tags}}** 또는 **{{ui:caption.style.sentence}}**을 고릅니다.
3. **{{ui:caption.run}}**를 누릅니다.
4. 나온 말은 그 자리에서 고칠 수 있습니다. **{{ui:caption.replace}}**, **{{ui:caption.append}}**, **{{ui:caption.copy}}** 중 하나를 누릅니다.

바꾸거나 더하는 곳은 생성 탭의 「{{ui:params.prompt.positive}}」입니다. 이 기능은 갤러리에 그림을 늘리지 않습니다.

> 이 기능에는 확장 기능 ComfyUI-Florence2가 필요합니다. 설치되어 있지 않으면 대화 상자에서 설치할 수 있습니다(이 장의 「확장 기능이 필요할 때」를 보세요). 처음 쓸 때는 말로 바꾸는 모델(Florence-2 PromptGen)을 내려받기 시작합니다.

## 캐릭터를 등록해서 사용하기

![캐릭터로 등록하는 대화 상자](shot:character)

마음에 드는 캐릭터의 그림을 등록해 두면 다른 장면의 그림에서도 같은 캐릭터에 가깝게 그릴 수 있습니다. 등록하는 것은 다음 3가지입니다.

- 참조 이미지(같은 캐릭터의 그림. 몇 장이든 가능)
- 외모를 설명하는 말(머리카락이나 눈 색, 옷 등. 프롬프트의 맨 앞에 추가됩니다)
- 닮게 하는 강도

### 등록하기

1. 갤러리에서 등록하고 싶은 그림을 선택합니다. 여러 장이면 `Ctrl`을 누른 채 클릭합니다.
2. 뷰어의 **{{ui:character.menu}}** 버튼 또는 오른쪽 클릭 메뉴의 **{{ui:character.menu}}**을 선택합니다. 생성 탭의 **{{ui:character.row.choose}}** 입력란을 열면 목록의 맨 아래에 **{{ui:character.row.register}}**이 있으며 여기에서도 열 수 있습니다.
3. **{{ui:character.name}}**과 **{{ui:character.tags}}**를 입력합니다. 바뀌지 않았으면 하는 특징(갈색 머리, 흰 블라우스, 파란 스커트 등)을 씁니다.
4. **{{ui:character.weight}}**를 정합니다. 올릴수록 참조 이미지를 닮지만 장면이나 구도의 자유도가 낮아집니다.
5. **{{ui:character.save}}** 버튼을 누릅니다.

**{{ui:character.addSelected}}**를 사용하면 나중에 갤러리에서 선택한 그림을 참조 이미지에 추가할 수 있습니다. **{{ui:character.removePicture}}**는 이미지 오른쪽 위의 ✕입니다.

**{{ui:character.whiteBg}}**를 켜면 등록하는 그림의 배경을 흰색으로 바꾼 그림을 만들고 그것을 참조 이미지로 삼습니다. 배경의 색이 생성한 그림에 옮겨 가는 것을 막을 수 있습니다. 원본 그림은 남고 흰 배경의 그림이 새로 저장됩니다. 배경 제거에 사용하는 확장 기능 ComfyUI-RMBG가 설치되어 있지 않을 때는 이 스위치를 사용할 수 없고 원본 그림이 그대로 사용됩니다.

### 사용하기

1. **{{ui:app.tabs.generate}}** 탭(또는 [캔버스](05-canvas.md) 탭)의 왼쪽 패널에서 **{{ui:character.row.choose}}**을 열고 사용하고 싶은 캐릭터를 선택합니다.
2. 캐릭터의 참조 이미지가 '{{ui:params.refImage.sectionLabel}}' 영역에 들어가고 외모를 설명하는 말이 프롬프트의 맨 앞에 추가됩니다.
3. 평소처럼 생성합니다.

사용할 때 앱이 자동으로 조정하는 경우가 있습니다. 알림으로 알려 줍니다.

- 참조 이미지를 사용하면 CFG 스케일이 높을 때 그림이 타기 쉬우므로 CFG 스케일이 5보다 높으면 4.5로 낮춥니다.
- 참조 이미지는 모두 8장까지입니다. 다른 참조 이미지와 합쳐서 8장을 넘을 때는 앞쪽의 그림부터 사용합니다.
- 참조 이미지가 여러 장일 때는 겹쳐서 너무 진해지지 않도록 한 장당 강도를 자동으로 낮춥니다.
- 갤러리에서 삭제된 그림은 사용할 수 없습니다. 전부 삭제되어 있으면 캐릭터를 사용할 수 없습니다.

등록한 캐릭터를 고치거나 삭제하려면 목록 항목의 '…' 버튼을 사용합니다.

> 같은 캐릭터에 '가까워지는' 기능이며 완전히 같은 얼굴이 되는 것은 아닙니다. 머리 모양, 색, 옷 등은 유지되기 쉽지만 이목구비는 조금 바뀝니다. 유지하고 싶은 특징은 외모를 설명하는 말에 써 두면 효과가 있습니다.

> 참조 이미지를 사용하려면 확장 기능 ComfyUI_IPAdapter_plus와 참조 이미지용 모델이 필요합니다. 설치되어 있지 않을 때는 생성 탭의 참조 이미지 영역에서 설치할 수 있습니다. 모델은 [모델](08-models.md) 장을 보세요.

## 비교 그리드로 설정 비교하기

![비교 그리드 대화 상자](shot:xyplot)

CFG 스케일이나 스텝 수를 바꾸면 그림이 어떻게 달라지는지를 1장의 표로 만들어 비교하는 기능입니다.

1. 생성 탭에서 평소처럼 프롬프트와 모델을 정합니다.
2. **{{ui:params.invoke.invoke}}** 버튼 오른쪽의 '▼'를 누르고 **{{ui:xyplot.menu}}**를 선택합니다.
3. **{{ui:xyplot.x}}**과 **{{ui:xyplot.y}}**에서 바꿀 설정을 선택합니다. 한쪽만으로도 만들 수 있습니다.
4. 값을 입력합니다. 숫자는 쉼표로 구분해서 나열합니다(예: 3, 5, 7).
5. **{{ui:xyplot.run}}** 버튼을 누릅니다.

대화 상자 아래에 '3열 × 2행 = 6장을 만듭니다.'처럼 만들 장수가 나옵니다.

바꿀 수 있는 설정은 다음과 같습니다.

| 설정 | 입력 방법 |
|---|---|
| {{ui:xyplot.axis.cfgScale}} | 숫자(1~30) |
| {{ui:xyplot.axis.steps}} | 정수(1~150) |
| {{ui:xyplot.axis.seed}} | 정수 |
| {{ui:xyplot.axis.strength}} | 숫자(0.05~1). 이미지에서 이미지로 만들 때만 효과가 있습니다. |
| {{ui:xyplot.axis.scheduler}} | 목록에서 선택합니다 |
| {{ui:xyplot.axis.model}} | 같은 계열의 모델을 목록에서 선택합니다 |
| {{ui:xyplot.axis.prompt}} | 한 줄에 하나씩 씁니다. 프롬프트에 추가됩니다 |

규칙은 다음과 같습니다.

- 하나의 설정에 넣을 수 있는 값은 8개까지입니다. 표는 모두 합쳐 36장까지입니다.
- 가로와 세로에 같은 설정은 선택할 수 없습니다.
- 모든 그림을 **같은 시드**로 그립니다(시드를 바꾸는 설정을 선택했을 때는 제외). 차이는 바꾼 설정뿐입니다.
- 설정은 그 시점의 생성 탭 폼에서 가져옵니다. 폼은 바뀌지 않습니다.
- 만들지 못한 그림은 표 안에서 ×가 됩니다. 다른 그림으로 표는 만들어집니다.

완성된 표는 갤러리에 1장의 그림으로 저장됩니다. **{{ui:xyplot.open}}**로 뷰어에 표시할 수 있습니다. 표의 바탕이 된 1장씩의 그림도 갤러리에 남습니다.

> 장수가 많으면 그만큼 시간이 걸립니다. 36장이라면 36회분의 생성이 필요합니다. 처음에는 2~3개의 값으로 시험해 보는 것을 추천합니다.

## 초안에서 고르기

![초안 탭에 중간까지 그린 후보가 나열된 모습](shot:drafts)

시드에 따라 그림은 크게 바뀝니다. 초안은 많은 시드로 '중간까지'만 그리고 마음에 드는 구도만 끝까지 그리는 기능입니다. 시간을 절약할 수 있습니다.

**{{ui:app.tabs.generate}}** 탭 가운데에 있는 **{{ui:app.views.drafts}}** 탭을 엽니다.

1. **{{ui:drafts.model}}**을 선택합니다. 처음에는 생성 탭의 모델이 선택되어 있습니다.
2. **{{ui:drafts.count}}**를 정합니다(1~24장. 처음에는 8장).
3. **{{ui:drafts.position}}**를 정합니다(25~60%. 처음에는 35%). 작을수록 빨리 만들어지지만 거친 그림이 됩니다.
4. **{{ui:drafts.start}}** 버튼을 누릅니다.

초안 그림은 완성된 것부터 순서대로 나열됩니다. 프롬프트 등의 설정은 생성 탭의 것이 사용됩니다.

그림을 클릭하면 선택됩니다(한 번 더 클릭하면 해제됩니다). 더블클릭하면 뷰어에서 크게 볼 수 있습니다. 별 버튼(**{{ui:drafts.keep}}**)와 ✕(**{{ui:drafts.reject}}**)은 자신을 위한 표시입니다. 아래 오른쪽에 있는 '○장 {{ui:manual.drafts.finish}}' 버튼(○는 선택한 장수)을 누르면 선택한 그림이 끝까지 그려집니다. 다시 선택하고 싶을 때는 **{{ui:drafts.clearSelection}}** 버튼을 누릅니다.

끝까지 그린 그림은 보통의 생성과 마찬가지로 갤러리에 들어가고 초안 위에 '{{ui:drafts.badge.finished}}'라고 나옵니다. 실패한 초안이 있을 때는 '실패한 ○장 {{ui:manual.drafts.retry}}' 버튼이 나옵니다.

> '{{ui:manual.drafts.finish}}'라고 해도 중간부터 재개하는 것은 아닙니다. 같은 시드로 처음부터 끝까지 다시 그립니다. 그래서 완성까지 걸리는 시간은 보통의 생성과 같습니다. 초안에서 본 구도의 그림이 만들어집니다.

> 초안은 문장으로 그림을 만드는 생성에서만 사용할 수 있습니다. 참조 이미지 등을 넣어 두면 메시지가 나오고 시작할 수 없습니다. 초안 그림은 갤러리 목록에는 나열되지 않습니다.

초안은 '시작한 순서'대로 위쪽 탭에 나열됩니다. 필요 없어지면 탭의 ✕로 닫습니다.

## 한꺼번에 처리하기

![한꺼번에 처리하는 대화 상자](shot:batch)

배경 제거나 확대를 선택한 여러 그림에 한 번에 적용할 수 있습니다.

1. 갤러리에서 그림을 여러 장 선택합니다(`Ctrl`을 누른 채 클릭, 또는 `Shift`를 누른 채 클릭으로 범위 선택).
2. 선택한 그림 위에서 오른쪽 클릭하고 **{{ui:gallery.menu.batch}}**를 선택합니다.
3. 처리를 선택합니다.
   - **{{ui:batch.op.removeBackground.title}}**: 배경을 투명하게 합니다. 확장 기능 ComfyUI-RMBG가 필요합니다. 설치되어 있지 않을 때는 설치 버튼이 나옵니다.
   - **{{ui:batch.op.upscale.title}}**: 확대용 모델로 크게 합니다. 모델이 없을 때는 [모델](08-models.md) 화면에서 설치합니다.
4. **{{ui:batch.run}}** 버튼을 누릅니다.

그림 1장마다 대기열에 하나씩 들어갑니다. 진행 상황은 **{{ui:app.tabs.queue}}** 탭에서 볼 수 있습니다. 결과는 원본 그림과 같은 보드에 새 그림으로 들어갑니다. 원본 그림은 바뀌지 않습니다.

그림 1장을 설정을 바꿔 가며 정성껏 처리하고 싶을 때는 이 장의 개별 기능([배경 제거하기](#배경-제거하기))을 사용합니다. 1장을 크게 만들 때는 [업스케일](06-upscaling-workflows.md) 탭도 사용할 수 있습니다.
