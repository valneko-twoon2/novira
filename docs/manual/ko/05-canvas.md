# 캔버스

![캔버스 탭 전체. 가운데가 캔버스, 오른쪽 아래가 레이어 목록](shot:canvas)

**{{ui:app.tabs.canvas}}** 탭은 그림을 '그리고, 놓고, 일부만 다시 그리는' 작업대입니다. 이미지를 놓고 넓히거나, 다시 그리고 싶은 곳에 마스크를 씌우거나, 막대 인간으로 포즈를 정할 수 있습니다.

화면은 3개로 나뉘어 있습니다.

- 왼쪽: 생성 탭과 같은 설정 패널(프롬프트, 모델, 크기 등). 캔버스에서는 **{{ui:params.compositing.title}}** 항목이 늘어납니다.
- 가운데: 캔버스. 위쪽에 도구 버튼이 나열됩니다.
- 오른쪽: 그림을 넣는 **{{ui:canvas.layers.title}}** 목록.

아무것도 없는 상태에서 **{{ui:params.invoke.invoke}}** 버튼을 누르면 점선 테두리(생성 범위) 안에 평소처럼 그림을 만듭니다. 캔버스의 진가는 거기에 그림이나 밑그림을 놓았을 때 나옵니다. 레이어와 마스크는 자동으로 저장되며, 앱을 다시 열면 그대로 돌아옵니다(실행 취소 기록은 저장되지 않습니다).

## 그림 놓기, 그리기

캔버스에 그림을 놓는 방법은 몇 가지 있습니다.

- 브러시로 그립니다. 레이어를 선택하지 않았으면 {{ui:canvas.add.raster}}가 자동으로 만들어집니다.
- 갤러리의 그림을 캔버스로 드래그합니다. 놓을 곳(래스터, 컨트롤, 인페인트 마스크 등)을 선택하는 칸이 나오므로 거기에 드롭합니다.
- `Ctrl+V`로 클립보드의 이미지를 새 래스터 레이어로 붙여넣습니다(갤러리에도 저장됩니다).
- 갤러리의 그림을 오른쪽 클릭(뷰어에서는 붓 아이콘)해서 **{{ui:gallery.menu.sendToCanvas}}**에서 보낼 곳을 선택합니다.

보낼 곳은 다음과 같습니다.

| 보낼 곳 | 무엇이 되는지 |
|---|---|
| **{{ui:gallery.canvas.newCanvasRaster}}** | 캔버스를 일단 비우고 그 그림과 같은 크기로 시작합니다. |
| **{{ui:gallery.canvas.newCanvasControl}}** | 마찬가지로 새로 시작하지만 그림은 컨트롤 레이어가 됩니다. |
| **{{ui:gallery.canvas.raster}}** | 현재 캔버스에 래스터 레이어로 추가합니다. |
| **{{ui:gallery.canvas.control}}** | 컨트롤 레이어로 추가합니다. |
| **{{ui:gallery.canvas.inpaint}}** | 인페인트 마스크로 추가합니다. |
| **{{ui:gallery.canvas.regional}}** | 영역 가이던스의 참조 이미지로 추가합니다([영역 가이던스](#영역-가이던스는-아직-사용할-수-없습니다)를 보세요). |

## 도구

위쪽 바에 도구가 나열되어 있습니다. 키보드의 문자 키로도 전환할 수 있습니다.

| 도구 | 키 | 용도 |
|---|---|---|
| **{{ui:canvas.tool.brush}}** | `B` | 그림을 그립니다. 색은 바의 색 버튼으로 바꿉니다. |
| **{{ui:canvas.tool.eraser}}** | `E` | 그린 곳을 지웁니다. |
| **{{ui:canvas.tool.mosaic}}** | `M` | 칠한 곳을 모자이크로 만듭니다(가릴 때). 블록 크기는 바의 숫자로 바꿉니다. 그림이 있는 레이어에만 적용됩니다. |
| **{{ui:canvas.tool.rect}}** | `U` | 사각형을 칠합니다. |
| **{{ui:canvas.tool.lasso}}** | `L` | 자유로운 모양을 그려 그 안을 색으로 채웁니다(마스크에서는 마스크 영역이 됩니다). |
| **{{ui:canvas.tool.pose}}** | `O` | 컨트롤 레이어에 막대 인간 포즈를 놓고 관절을 움직입니다(아래의 '캔버스에서 포즈 만들기'). |
| **{{ui:canvas.tool.move}}** | `V` | 레이어를 움직입니다. 방향키로 선택한 레이어를 1px씩(Shift로 10px씩) 움직일 수 있습니다. |
| **{{ui:canvas.tool.bbox}}** | `C` | 생성 범위(바운딩 박스)를 움직이거나 크기를 바꿉니다. |
| **{{ui:canvas.tool.view}}** | `H` | 표시를 옮깁니다. |
| **{{ui:canvas.tool.colorPicker}}** | `I` | 그림 속에서 색을 집어 냅니다. |

그 밖에 다음 조작을 할 수 있습니다.

- 브러시의 굵기는 바의 **{{ui:canvas.toolbar.brushWidth}}** 또는 `[`와 `]` 키로 바꿉니다. `Q`로 직전에 사용한 도구와 전환합니다.
- 확대와 축소는 마우스 휠 또는 `+`와 `-` 키입니다. `Ctrl+0`으로 전체가 보이고 `Ctrl+1`로 실제 크기(100%)가 됩니다.
- 표시를 옮기려면 `Space`를 누른 채 드래그하거나 휠 버튼을 누른 채 드래그합니다.
- **{{ui:canvas.toolbar.undo}}**(`Ctrl+Z`)와 **{{ui:canvas.toolbar.redo}}**(`Ctrl+Shift+Z`)로 그린 것을 되돌리거나 다시 실행할 수 있습니다.

톱니바퀴 **{{ui:canvas.settings.title}}**에는 격자 표시, 생성 범위 바깥쪽을 어둡게 하는 표시, 그린 선을 생성 범위 안으로만 제한하는 설정, 표시 중인 래스터 레이어를 하나로 합치는 조작 등이 있습니다.

## 생성 범위(바운딩 박스)

캔버스 안의 점선 테두리가 '이번에 그림을 만드는 범위'입니다. 생성할 때마다 이 테두리 안만 만들어지며 그 크기가 그림의 크기가 됩니다.

- **{{ui:canvas.tool.bbox}}**(`C`)로 전환해서 테두리를 드래그로 움직입니다. 모서리나 변을 드래그하면 크기가 바뀝니다.
- 왼쪽 패널의 **{{ui:params.image.bboxWidth}}**와 **{{ui:params.image.bboxHeight}}**로도 크기를 정할 수 있습니다.
- **{{ui:canvas.actions.fitBboxToLayers}}**(`Shift+C`)로 놓은 그림에 테두리를 맞춥니다.

## 레이어

오른쪽 아래의 **{{ui:canvas.layers.title}}**에 캔버스에 놓은 것이 목록으로 나옵니다. **{{ui:common.add}}** 버튼으로 추가합니다.

![레이어의 '추가' 메뉴를 연 모습](shot:canvas-add-layer)

레이어에는 역할이 다른 종류가 있습니다.

| 종류 | 역할 |
|---|---|
| **{{ui:canvas.add.raster}}** | 보통의 그림 레이어입니다. 그리거나 그림을 놓습니다. 여기에 있는 것이 '원본 그림'이 됩니다. |
| **{{ui:canvas.add.control}}** | 형태, 선, 포즈 등의 단서로 삼는 그림입니다. 생성을 이끄는 단서가 되며 그림의 내용으로는 들어가지 않습니다. |
| **{{ui:canvas.add.inpaint}}** | '여기를 다시 그린다'는 범위를 칠해서 지정합니다. |
| **{{ui:canvas.add.regional}}** | 장소별로 다른 프롬프트를 지정하는 레이어입니다. 현재의 데스크톱 버전에서는 생성에 사용할 수 없습니다. |
| **{{ui:canvas.add.globalRef}}** | 그림 전체의 분위기를 따르게 하는 참조 이미지입니다. 생성 탭의 참조 이미지와 같은 것입니다. |

레이어 목록에서는 다음 조작을 할 수 있습니다.

- 눈 아이콘으로 표시와 숨김, 자물쇠 아이콘으로 잠금을 전환합니다. 숨긴 레이어는 생성에 사용되지 않습니다. 잠근 레이어에는 그릴 수 없습니다.
- 이름을 더블클릭하면 이름을 바꿀 수 있습니다.
- 오른쪽 클릭으로 복제, 순서 변경(앞뒤로 움직임. 같은 종류의 레이어는 목록 안에서 드래그해도 순서를 바꿀 수 있습니다), **{{ui:canvas.entityMenu.flipHorizontal}}**, **{{ui:canvas.entityMenu.flipVertical}}**, **{{ui:canvas.entityMenu.rotateRight}}**, **{{ui:canvas.entityMenu.rotateLeft}}**, **{{ui:canvas.entityMenu.scaleUp}}**, **{{ui:canvas.entityMenu.scaleDown}}**, **{{ui:canvas.pose.random}}**(컨트롤 레이어만), 다른 종류로 변환, 클립보드로 복사, **{{ui:canvas.entityMenu.saveToGallery}}**, **{{ui:canvas.entityMenu.exportToFile}}**, 삭제를 할 수 있습니다.
- **{{ui:canvas.layers.more}}**('…')에서 표시 중인 래스터 레이어를 하나로 합치기, 모든 레이어 삭제도 할 수 있습니다.

![레이어의 오른쪽 클릭 메뉴](shot:canvas-layer-menu)

선택한 레이어 아래에 그 레이어의 설정이 열립니다.

- {{ui:canvas.add.inpaint}}: 마스크의 색이나 칠하기 무늬(화면에서 보이는 모양만), **{{ui:canvas.mask.denoiseLimit}}**(켜고 내리면 마스크 안에서도 원본 그림이 남기 쉬워집니다). 마스크의 오른쪽 클릭 메뉴에서 **{{ui:canvas.entityMenu.invertMask}}**을 고르면 생성 범위 안의 마스크 영역과 빈 영역이 서로 바뀝니다.
- {{ui:canvas.add.control}}: 다음 '{{ui:canvas.add.control}}' 항목을 보세요.

## 어떤 식으로 다시 그려지는지

캔버스에서 **{{ui:params.invoke.invoke}}** 버튼을 누르면 앱이 생성 범위 안을 보고 그림을 만드는 방식을 자동으로 정합니다. 직접 선택할 필요는 없습니다.

| 생성 범위 안의 상태 | 만드는 방식 |
|---|---|
| 표시 중인 래스터 레이어에 아무것도 그려져 있지 않다 | 문장으로 새로 만듭니다(텍스트에서 이미지). |
| 래스터 레이어에서 일부만 채워져 있다 | 비어 있는 부분을 추가해서 넓힙니다(아웃페인트). 빈 부분은 먼저 색으로 채워집니다. |
| 전체가 채워져 있고 인페인트 마스크에 칠이 없다 | 현재 그림을 토대로 다시 그립니다(이미지에서 이미지). |
| 전체가 채워져 있고 인페인트 마스크에 칠이 있다 | 마스크 부분만 다시 그립니다(인페인트). 마스크 바깥은 원본 그림 그대로입니다. |

이미지에서 이미지일 때의 바꾸는 정도는 왼쪽 패널의 **{{ui:params.image.strength}}**로 정합니다. 0이면 원본 그대로, 1이면 완전히 다시 그립니다.

아웃페인트에서 빈 부분을 무엇으로 채울지는 왼쪽 패널의 **{{ui:params.compositing.title}}**에 있는 **{{ui:params.compositing.infillTitle}}**에서 선택합니다. **{{ui:params.compositing.infill.color}}**이라면 선택한 색(검정, 흰색, 회색 등)으로 채웁니다. 다른 것을 선택하면 주변의 색을 어우러지게 해서 채웁니다. 이음매의 흐림 정도는 **{{ui:params.compositing.maskBlur}}**로 정합니다.

> 인페인트는 보통의 모델에서 그대로 사용할 수 있습니다. 전용 '인페인트용 모델'은 필요 없습니다.

## 결과를 채택할지 정하기(스테이징)

캔버스에서 만든 그림은 곧바로 캔버스에 들어가지 않습니다. 생성 범위 위에 겹쳐서 표시되며 아래의 바(**{{ui:canvas.staging.title}}**)에서 채택할지 정합니다.

| 버튼 | 하는 일 |
|---|---|
| 좌우 화살표(`←` `→`) | 여러 장 만들었을 때 다음 그림이나 이전 그림을 봅니다. |
| **{{ui:canvas.staging.accept}}**(`Enter`) | 이 그림을 새 래스터 레이어로 캔버스에 넣습니다. 다른 그림은 버려집니다. |
| **{{ui:canvas.staging.hideResults}}** | 결과를 숨기고 원본 그림과 비교합니다. |
| **{{ui:canvas.staging.saveToGallery}}** | 이 그림을 갤러리에 저장합니다. |
| **{{ui:canvas.staging.discard}}** | 이 그림만 버립니다. |
| **{{ui:canvas.staging.discardAll}}**(`Esc`) | 전부 버립니다. |

> 결과 그림은 그대로는 갤러리에 나열되지 않습니다. 갤러리에 남기고 싶은 그림은 먼저 **{{ui:canvas.staging.saveToGallery}}** 버튼을 누르세요. 버린 그림은 사라집니다.

결과 바의 왼쪽 끝 손잡이(⋮⋮)는 그림을 다른 곳으로 드래그해서 건네기 위한 것입니다.

## 컨트롤 레이어

컨트롤 레이어는 '이 형태, 이 선, 이 포즈에 따라 그려 줘'라는 단서입니다. 선화, 윤곽, 포즈 그림 등을 넣습니다.

사용하려면 메인 모델에 맞는 ControlNet 모델이 필요합니다. 설치 방법은 [모델](08-models.md) 장을 보세요. 레이어를 선택하고 설정의 **{{ui:common.model}}**을 선택합니다. 모델이 없는 채로 두면 생성 쪽에 '컨트롤 레이어 1에 모델이 없습니다' 등이 나오며 만들 수 없습니다.

설정은 다음과 같습니다.

- **{{ui:canvas.control.weight}}**: 단서에 따르는 강도입니다.
- **{{ui:canvas.control.begin}}**과 **{{ui:canvas.control.end}}**: 생성 과정에서 몇 %부터 몇 %까지 적용할지입니다.
- **{{ui:canvas.control.controlMode}}**: **{{ui:canvas.control.mode.balanced}}**과 **{{ui:canvas.control.mode.moreControl}}**가 있습니다. **{{ui:canvas.control.mode.morePrompt}}**는 현재로서는 **{{ui:canvas.control.mode.balanced}}**과 같은 동작입니다.
- **{{ui:canvas.control.filter}}**: 그림을 선이나 깊이 등 단서용 그림으로 변환합니다. 앱 안에서 하는 간이 변환입니다. **{{ui:canvas.control.process}}**로 시험해 보고 괜찮으면 **{{ui:common.apply}}**으로 그림에 반영합니다.

## 포즈 만들기(막대 인간)

![막대 인간으로 포즈를 정하는 대화 상자](shot:pose)

막대 인간을 움직여서 포즈를 정할 수 있습니다. 문장으로 포즈를 지정해도 잘 되지 않을 때 편리합니다.

1. **{{ui:app.tabs.canvas}}** 탭의 레이어에서 **{{ui:common.add}}** 버튼을 누르고 **{{ui:pose.menu}}**을 선택합니다.
2. **{{ui:pose.preset}}**에서 가까운 포즈를 선택합니다({{ui:pose.preset.standing}}, {{ui:pose.preset.armsUp}}, {{ui:pose.preset.sitting}}, {{ui:pose.preset.walking}}).
3. 관절의 동그라미를 드래그해서 자세를 바꿉니다. 동그라미를 선택하고 화살표 키로도 움직일 수 있습니다(`Shift`를 누르면 크게 움직입니다). **{{ui:pose.mirror}}**으로 좌우를 반전할 수 있고 **{{ui:pose.reset}}**로 처음 상태로 돌아갑니다.
4. **{{ui:pose.size}}**를 선택합니다. 보통은 캔버스의 크기로 괜찮습니다.
5. **{{ui:pose.use}}** 버튼을 누릅니다.

포즈는 컨트롤 레이어로 캔버스에 들어갑니다. 캔버스가 비어 있으면 그 크기로 새로 시작합니다.

사용하려면 OpenPose에 대응하는 ControlNet 모델이 필요합니다. 설치되어 있으면 앱이 레이어의 모델로 자동으로 선택합니다. 설치되어 있지 않을 때는 알림으로 알려 드립니다. 모델을 설치한 뒤 레이어의 설정에서 선택하세요.

> 1명분의 포즈만 정할 수 있습니다. 손가락이나 얼굴의 방향까지는 정할 수 없으므로 얼굴이나 손은 프롬프트로 지정하세요.

> 포즈의 효과는 레이어의 **{{ui:canvas.control.weight}}**로 정해집니다. 포즈 레이어는 처음부터 최대 강도로, 처음부터 끝까지 적용되도록 설정됩니다. 포즈의 자유도를 주고 싶을 때는 내리세요.

### 캔버스에서 포즈 만들기

![포즈 도구로 캔버스에 막대 인간을 놓은 모습](shot:canvas-pose)

**{{ui:canvas.tool.pose}}** 도구(`O`)를 사용하면 캔버스 위에서 직접 포즈를 만들 수 있습니다. 놓은 포즈는 나중에 몇 번이든 고칠 수 있습니다.

- 아무것도 없는 곳을 클릭하면 서 있는 막대 인간이 놓입니다. 컨트롤 레이어를 선택하지 않았을 때는 새 컨트롤 레이어가 만들어지고, 포즈용 강도와 OpenPose에 대응하는 모델(설치되어 있으면)이 설정됩니다.
- 관절의 원을 드래그하면 그 끝의 팔다리째 회전합니다(뼈의 길이는 바뀌지 않습니다). 목을 드래그하면 몸 전체가 움직입니다. `Shift`를 누른 채 드래그하면 그 관절만 움직입니다.
- `Alt`를 누른 채 관절을 클릭하면 그 관절을 숨기거나 다시 표시할 수 있습니다(화면 밖으로 나간 팔다리 등에).
- `R` 키나 바의 **{{ui:canvas.pose.random}}** 버튼을 누르면 선택한 레이어의 포즈가 새로운 랜덤 포즈로 바뀝니다. 몇 번이든 누를 수 있으므로 마음에 들 때까지 시험해 볼 수 있습니다.
- 포즈 도구 바의 숫자와 번개 버튼으로, 포즈를 바꿔 가며 그 장수만큼 이어서 생성합니다(최대 16장). 포즈마다 시드도 바뀌므로 같은 설정으로 다양한 자세의 그림이 늘어섭니다. 생성할 수 있는 상태가 아니면 이유가 표시되고 시작되지 않습니다.
- 하나의 레이어에 몇 명이든 놓을 수 있습니다. 좌우 반전, 회전, 확대·축소는 레이어의 오른쪽 클릭 메뉴에서 할 수 있습니다.
- 문장으로도 부탁할 수 있습니다. **{{ui:app.tabs.canvas}}** 탭을 연 채로 AI 어시스턴트를 열고 '달리는 포즈', '왼손을 들어 줘'처럼 전하면 막대 인간이 놓입니다(최대 4명까지). 놓은 뒤에 '조금 더 앞으로 숙여 줘'라고 전하면 그 포즈를 고쳐 줍니다. 부탁한 포즈는 말에서 추측한 것이므로, 마음에 들지 않으면 관절을 드래그해서 고치세요.
- 그림 속 사람으로도 만들 수 있습니다. 갤러리에서 그림을 오른쪽 클릭해 **{{ui:canvas.poseFromImage.menu}}**를 선택하거나 포즈 도구 막대의 같은 이름의 버튼을 누르면, 그림 속 사람의 골격을 읽어 막대 인간으로 놓습니다(최대 4명). 놓은 포즈는 일반 포즈처럼 고칠 수 있습니다. 사용하려면 확장 기능(comfyui_controlnet_aux)이 필요하며, 없으면 그 자리에서 설치를 안내합니다. 처음 읽을 때는 모델을 내려받느라 시간이 걸립니다. 사람이 너무 작거나 가려져 있으면 찾지 못할 수 있습니다.
- 포즈 도구 막대의 **{{ui:canvas.pose.presets}}** 버튼을 누르면 왼쪽에 카테고리, 오른쪽에 포즈 카드가 늘어선 창이 열립니다. 카드에는 생성 범위와 같은 모양의 틀 안에 OpenPose 막대 인간이 그려져 있습니다. '{{ui:canvas.pose.group.panel}}'(클로즈업과 롱샷, 두 사람, 세 명 이상, 일상의 한 장면, 드라마·감정)는 인물의 위치와 크기까지 정해져 있으며 선택한 레이어의 모든 포즈를 바꿉니다. '{{ui:canvas.pose.group.standard}}'와 '{{ui:canvas.pose.group.manga}}'은 선택한 레이어의 첫 번째 포즈와 바뀌며 위치와 크기는 그대로입니다. 포즈가 없으면 새로 놓입니다. 팔을 들거나 다리를 차올려 틀을 벗어나는 포즈는 틀에 맞게 작아집니다.
- 포즈 도구 막대의 **{{ui:canvas.pose3d.menu}}** 버튼으로 포즈를 3D로 편집할 수 있습니다(선택한 컨트롤 레이어의 첫 번째 포즈, 없으면 서 있는 인형에서 시작). 관절을 끌면 뼈의 길이가 유지된 채 움직이며, 뼈를 안쪽(뒤)이나 앞쪽으로 향하게 할 수도 있습니다. 배경을 끌면 몸의 방향이 바뀌고 휠로 확대·축소합니다. **{{ui:canvas.pose3d.front}}**, **{{ui:canvas.pose3d.side}}**, **{{ui:canvas.pose3d.back}}**, **{{ui:canvas.pose3d.top}}** 버튼으로 정해진 방향으로 돌릴 수 있습니다. **{{ui:canvas.pose3d.apply}}**을 누르면 지금 보이는 모양이 포즈로 캔버스에 들어가고(깊이도 기억하므로 다시 3D로 열어 돌릴 수 있습니다), 누르지 않고 닫으면 원래대로입니다. 3D 보기에는 브라우저의 WebGL이 필요하며, 사용할 수 없으면 그 취지가 표시됩니다.

## 영역 가이던스는 아직 사용할 수 없습니다

**{{ui:canvas.add.regional}}**는 화면에 준비되어 있지만 현재의 데스크톱 버전에서는 생성에 사용할 수 없습니다. 칠이 있는 영역 가이던스 레이어가 있으면 생성이 거부되고 실패 메시지(영어)가 나옵니다. 캔버스에서 생성할 때는 영역 가이던스 레이어를 숨기거나 삭제하세요.

## 저장과 뒷정리

- 캔버스의 그림을 갤러리에 저장하려면 위쪽 바의 **{{ui:canvas.toolbar.saveToGallery}}**(디스크 아이콘)을 누릅니다. 생성 범위 안에 있는 표시 중인 래스터 레이어가 1장으로 합쳐져서 저장됩니다.
- 레이어 하나만 저장하려면 레이어를 오른쪽 클릭해서 **{{ui:canvas.entityMenu.saveToGallery}}**을 선택합니다.
- **{{ui:canvas.settings.title}}**에는 **{{ui:canvas.actions.clearCanvas}}**, **{{ui:canvas.actions.clearHistory}}**, **{{ui:canvas.actions.clearStaging}}**도 있습니다. **{{ui:canvas.actions.clearCanvas}}**는 모든 레이어를 지웁니다.

그림을 수정하는 기능은 [그림 수정하고 다시 쓰기](04-improve.md)에도 있습니다. '{{ui:gallery.menu.segment}}'의 결과는 캔버스로 보내서 더 다시 그릴 수 있습니다.
