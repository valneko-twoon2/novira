# 이미지 만들기

이 장에서는 **{{ui:app.tabs.generate}}** 탭에서 그림을 만드는 방법을 설명합니다.
화면 구성은 [시작하기](01-start.md)를, 완성된 그림을 보는 방법과 정리 방법은 [갤러리와 뷰어](03-gallery.md)를 보세요.

만드는 흐름은 언제나 같습니다.

1. 모델을 선택한다
2. 프롬프트를 쓴다
3. 필요하면 크기나 시드 같은 설정을 조정한다
4. **{{ui:params.invoke.invoke}}** 버튼을 누른다

누르는 순간 바로 그림이 그려지기 시작하는 것이 아니라, 먼저 '{{ui:app.tabs.queue}}'(순서를 기다리는 줄)에 들어갑니다. 차례가 오면 한 장씩 그려집니다.

선택한 모델, 프롬프트, 설정은 앱을 닫아도 남아 있어서 다음에 실행했을 때도 그대로 사용할 수 있습니다.

## 프롬프트 쓰기

![프롬프트에 문장을 쓰고 시드를 고정으로 한 생성 탭](shot:generate-prompt)

왼쪽 패널의 '{{ui:params.prompt.title}}'에는 입력란이 2개 있습니다.

- **{{ui:params.prompt.positive}}**: 그려 주었으면 하는 것을 씁니다.
- **{{ui:params.prompt.negative}}**: 나오지 않았으면 하는 것을 씁니다. 예를 들어 `blurry, watermark`(흐림, 워터마크)처럼 씁니다. 비워 두어도 생성할 수 있습니다.

쓰는 방법의 기준입니다.

- 단어나 짧은 문장을 쉼표(`,`)로 구분해서 나열합니다.
- 많은 모델은 영어로 쓰는 편이 생각대로 나오기 쉽습니다. 모델 설명에 쓰는 방법이 지정되어 있다면 그에 맞추세요.
- 중요한 말은 앞쪽에 둡니다.

입력란 위에 있는 작은 버튼의 기능은 다음과 같습니다. 버튼은 아이콘뿐이며, 가져다 대면 이름이 나옵니다.

| 버튼 | 기능 |
|---|---|
| **{{ui:params.prompt.recommendedPositive}}** / **{{ui:params.prompt.recommendedNegative}}** | 선택한 모델의 종류에서 널리 쓰이는 품질 단어를 '{{ui:params.prompt.positive}}'에, 피하고 싶은 단어를 '{{ui:params.prompt.negative}}'의 맨 끝에 추가합니다. 태그로 쓰는 모델(Illustrious, NoobAI, Pony, Anima 등)은 `masterpiece, best quality` 같은 태그를 맨 앞에, 문장으로 쓰는 모델(FLUX, Qwen-Image 등)은 품질을 나타내는 말을 맨 끝에 추가합니다. 네거티브를 쓰지 않는 모델(FLUX.1)에는 네거티브를 추가하지 않습니다. 이미 들어 있는 단어는 중복해서 추가하지 않습니다 |
| **{{ui:params.prompt.expand}}** | 포지티브와 네거티브를 좌우로 나란히 놓은 큰 창에서 편집합니다 |
| **{{ui:params.prompt.textView}}** / **{{ui:params.prompt.tagView}}** | 입력란의 표시 방식을 글자 그대로의 표시와 단어별 태그(라벨)의 나열 사이에서 전환합니다. 태그를 누르면 팝업이 열리며, 단어를 고치거나, 슬라이더로 강도를 바꾸거나, 1로 되돌리거나, 태그를 지울 수 있습니다. 강도를 바꾼 태그는 `(smile:1.3)` 형태로 프롬프트에 쓰입니다. 아래 입력란에 단어를 입력하고 Enter를 누르면 태그를 추가할 수 있습니다 |
| **{{ui:params.promptBook.open}}** | 단어를 뜻과 함께 모아 둔 프리셋을 엽니다 (뒤에서 설명) |
| **{{ui:caption.fromPrompt}}** | 갤러리에서 선택한 그림(선택한 것이 없으면 고른 이미지 파일)을 보고 프롬프트에 쓸 수 있는 말을 바로 작성합니다. 결과는 뷰어의 띠에 나옵니다. 갤러리의 그림이나 컴퓨터의 이미지 파일을 이 버튼에 끌어다 놓아도 됩니다 ([그림 수정하고 다시 쓰기](04-improve.md)에서 설명) |

### 토큰 수

입력란 위의 '0 / 77 토큰'은 지금 쓰고 있는 말의 양을 나타내는 기준입니다.
토큰은 모델이 말을 읽을 때의 구분 단위를 말합니다. 상한 수를 넘으면 숫자가 경고 색으로 바뀝니다. 모델에 따라서는 상한을 넘은 부분이 잘 반영되지 않을 수 있습니다.
수는 '대략적인' 값입니다. 정확한 수는 아닙니다.

### 조합을 한꺼번에 만들기 `{red|blue}`

포지티브 입력란에 `{red|blue}`처럼 중괄호 안을 세로선(`|`)으로 구분해서 쓰면, 선택지마다 각각 다른 그림이 만들어집니다.

- `a {red|blue} flower`라고 쓰면 `a red flower`와 `a blue flower`의 2가지가 됩니다.
- 중괄호를 2개 이상 쓰면 모든 조합이 됩니다. `a {red|blue} {cat|dog}`라면 4가지입니다.
- 중괄호 안에 다시 중괄호를 넣을 수도 있습니다.
- 중괄호 자체를 글자로 쓰고 싶을 때는 앞에 `\`를 붙입니다(`\{`).
- 조합의 수는 최대 100가지까지입니다.

'{{ui:params.invoke.iterations}}'(뒤에서 설명)가 2 이상일 때는 조합의 수 × 장수만큼의 그림이 만들어집니다. 예를 들어 2가지이고 장수가 3이면 6장입니다.
이 표기를 쓸 수 있는 것은 포지티브 입력란뿐입니다. 네거티브 입력란에서는 중괄호가 그대로 글자로 취급됩니다.

어떤 문장으로 펼쳐지는지는 포지티브 입력란 위의 **{{ui:params.prompt.dynamicPreview}}** 버튼(`{ }` 아이콘)으로 확인할 수 있습니다. 누르면 조합 목록이 나옵니다. 네거티브 입력란에도 같은 버튼이 있으며, 네거티브에도 `{a|b}`나 와일드카드를 쓸 수 있습니다. 조합은 포지티브와 네거티브의 모든 쌍으로 만들어집니다.

### 와일드카드 `__이름__`

![와일드카드 창. 왼쪽에 목록이, 오른쪽에 선택한 목록의 이름과 항목이 나와 있다](shot:wildcards)

포지티브 입력란에 `__이름__`(이름 앞뒤에 밑줄 두 개씩)을 쓰면, 그 이름의 '{{ui:params.wildcards.title}}' 목록의 항목이 하나씩 들어갑니다. 자주 쓰는 선택지를 목록으로 만들어 두면 매번 `{red|blue}`를 쓰지 않아도 됩니다.

- `1girl, __hair-color__`라고 쓰면 목록 hair-color의 항목 수만큼 프롬프트가 만들어집니다.
- 항목 안에도 `{a|b}`나 다른 와일드카드를 쓸 수 있습니다. 와일드카드 안의 와일드카드는 6단계까지입니다.
- 조합 수의 상한(100가지)은 `{ }`와 같습니다.
- 없는 이름, 항목이 빈 목록, 자기 자신을 쓰는 목록을 쓰면 **{{ui:params.invoke.invoke}}** 버튼을 누를 수 없고, 버튼 아래에 이유가 나옵니다.

목록은 **{{ui:params.prompt.dynamicPreview}}** 버튼 창의 맨 아래에 있는 **{{ui:params.wildcards.open}}**에서 엽니다. 처음부터 hair-color(머리색), expression(표정), time-of-day(시간대)의 세 가지가 들어 있습니다.

| 조작 | 기능 |
|---|---|
| **{{ui:params.wildcards.new}}** | 빈 목록을 추가합니다 |
| '{{ui:params.wildcards.name}}' 입력란 | 목록의 이름을 바꿉니다. 문자, 숫자, `-`, `_`를 쓸 수 있고, 처음과 끝은 문자나 숫자입니다 |
| '{{ui:params.wildcards.entries}}' 입력란 | 한 줄에 하나씩 씁니다. 빈 줄과 `#`으로 시작하는 줄은 항목이 되지 않습니다 |
| **{{ui:params.wildcards.import}}** / **{{ui:params.wildcards.export}}** | 목록 하나를 한 줄에 한 항목인 .txt 파일로 읽고 씁니다. 가져온 파일은 파일 이름을 이름으로 한 새 목록이 됩니다 |
| **{{ui:common.delete}}** | 선택한 목록을 삭제합니다 |

목록은 이 앱 안(지금 쓰는 컴퓨터)에 저장됩니다.

### 무작위로 고르기

조합이 너무 많을 때는 **{{ui:params.prompt.dynamicPreview}}** 버튼의 창에서 '{{ui:params.prompt.dynamicMode}}'을 바꿉니다.

- **{{ui:params.prompt.modeCombinatorial}}**(기본 설정): 조합마다 장수만큼 그림을 만듭니다.
- **{{ui:params.prompt.modeRandom}}**: 장수만큼 그림을 만들고, 한 장마다 조합을 하나 고릅니다. 무엇을 고를지는 그 그림의 시드로 정해지므로, 같은 시드로 다시 그리면 같은 프롬프트가 됩니다.

어느 방식이든, 완성된 그림에는 실제로 쓴 프롬프트가 저장됩니다.

## 시드

그림은 '{{ui:params.seed.label}}'라는 숫자로부터 만들어집니다. 같은 시드와 같은 설정이라면 같은 그림이 만들어집니다.

왼쪽 패널 위쪽의 '{{ui:params.seed.label}}' 줄에 버튼이 2개 있습니다.

- **{{ui:params.seed.random}}**(주사위): 생성할 때마다 새 시드를 사용합니다. 매번 다른 그림이 됩니다. 처음에는 이쪽입니다.
- **{{ui:params.seed.fixed}}**(자물쇠): 지금의 시드로 그립니다. 같은 설정으로 몇 번을 만들어도 같은 그림이 됩니다. 프롬프트의 단어를 하나 바꿨을 때의 차이를 보고 싶을 때 편리합니다.

고정으로 하면 시드 숫자 입력란과 '{{ui:params.seed.shuffle}}' 버튼은 잠깁니다(실수로 바꾸는 것을 막기 위해서입니다).
정해진 숫자를 사용하고 싶을 때는 '{{ui:params.seed.random}}' 상태에서 숫자 입력란에 입력한 뒤 '{{ui:params.seed.fixed}}'으로 전환하세요.
마음에 드는 그림의 시드를 사용하고 싶을 때는 갤러리에서 그 그림을 열고 '{{ui:gallery.menu.useSeed}}'을 누르면 시드를 고정한 채로 불러올 수 있습니다([갤러리와 뷰어](03-gallery.md) 참조).

고정한 채로 장수를 늘리면 두 번째 장부터는 시드가 1씩 늘어난 그림이 됩니다.

## 모델 선택하기

![모델 목록이 열려 있다. FLUX, SDXL, SD1.X 등 계열별로 나뉘어 있다](shot:model-picker)

왼쪽 패널 위쪽에 있는 모델 카드에서 그림을 그릴 모델을 선택합니다.

1. 모델 이름 입력란을 클릭합니다.
2. 목록에서 선택합니다. 목록은 모델의 계열(FLUX, SDXL, SD1.X 등)별로 나뉘어 있습니다. 수가 많을 때는 위쪽 검색란에 이름의 일부를 입력해서 좁힐 수 있습니다.

Anima, Flux, FLUX.2, Chroma, Qwen-Image, Z-Image, SD3, HiDream, AuraFlow, HunyuanImage 모델도 여기서 선택할 수 있습니다. 본체, 텍스트 인코더, VAE가 별도의 파일로 배포될 때는 텍스트 인코더와 VAE를 설치된 모델 중에서 앱이 이름으로 찾아 사용합니다. 부족한 파일이 있는 모델을 설치하면 곧바로 '{{ui:params.parts.title}}'과 확인 창이 나오며, 이름과 크기를 확인한 뒤 부족한 파일만 설치할 수 있습니다. 나중에 하겠다며 닫았을 때도 생성 버튼 아래에 그 모델에 부족한 파일의 안내와, 화면을 옮기지 않고 그 파일을 설치하는 버튼이 나옵니다. 5GB를 넘을 때는 버튼을 누른 뒤에도 확인 창이 나옵니다. 모델 화면의 **{{ui:models.install.tab.starter}}**에서도 설치할 수 있습니다. 이 모델들에서도 마스크, 컨트롤 레이어, 고해상도 보정은 사용할 수 있습니다. 참조 이미지는 SD1.X와 SDXL 모델에서만 사용할 수 있습니다. '{{ui:params.generation.scheduler}}'에서 선택한 것은 쓰이지 않으며, 각 계열마다 정해진 샘플러와 스케줄러(Flux라면 `euler / simple`)로 그립니다(Anima만은 선택한 스케줄러로 그립니다). '{{ui:params.generation.scheduler}}' 입력란에는 실제로 사용하는 조합이 표시됩니다. '{{ui:params.generation.sampler}}'와 '{{ui:params.generation.noiseSchedule}}'을 선택하면 어느 계열의 모델이든 선택한 쪽이 우선됩니다.

- **편집 모델.** FLUX Kontext와 Qwen-Image-Edit는 건네준 그림을 고쳐 씁니다. 원본 그림을 소스(이미지에서 이미지)에 넣고, 바꾸고 싶은 내용을 프롬프트에 씁니다. FLUX Fill은 마스크한 부분을 다시 그립니다(마스크가 있는 인페인트나 아웃페인트에서 사용). 이 모델들에서는 고해상도 보정, 초안, 컨트롤 레이어를 사용할 수 없습니다. 앱은 파일의 내용으로, Kontext와 Qwen의 편집 모델은 파일 이름의 `kontext`나 `edit`라는 단어로 일반 모델과 구분합니다. 이름을 바꾸지 마세요.
- **FLUX.2.** klein은 적은 스텝으로 동작합니다(증류판은 CFG 1). dev는 CFG 값을 가이던스로 사용합니다. 원본 그림을 소스(이미지에서 이미지)에 넣으면 FLUX.2가 프롬프트에 따라 고쳐 씁니다. 마스크, 컨트롤 레이어, 고해상도 보정은 FLUX.2에서 사용할 수 없습니다(초안은 사용할 수 있습니다).
- **양자화(GGUF) 모델.** 확장자가 `.gguf`인 모델이나 텍스트 인코더는 확장 기능 ComfyUI-GGUF가 불러옵니다. 확장 기능 화면에서 한 번 설치하고(https://github.com/city96/ComfyUI-GGUF) 엔진을 다시 시작하세요. 설치하기 전까지는 생성이 실패하고 그 사실이 표시됩니다.
- **다른 입력이 필요한 모델.** 제어용 동영상, 음성, 카메라 움직임, 포즈 동영상이 필요한 모델(Wan Fun Control, Wan Animate, Flux Canny 등)은 아직 동작시킬 수 없습니다. 생성이 실패하고 그 모델에 필요한 것이 표시됩니다.
3. 선택한 모델에 ✓가 붙고 카드의 그림(커버 이미지)도 바뀝니다.

목록 아래의 **{{ui:app.tabs.short.models}}** 버튼으로 {{ui:app.tabs.models}} 탭(가지고 있는 모델 관리)으로, **{{ui:app.tabs.short.browse}}** 버튼으로 {{ui:app.tabs.browse}} 탭(인터넷에서 찾기)으로 이동할 수 있습니다. 모델을 늘리는 방법은 [모델 준비하기](08-models.md)에서 설명합니다.

모델에 추천 설정(스텝 수, CFG, 스케줄러, 크기)이 등록되어 있으면 모델을 선택했을 때 자동으로 들어갑니다.
계열이 다른 모델로 전환하면 새 모델과 맞지 않는 LoRA 등은 해제됩니다(해제된 수가 알림으로 표시됩니다).

모델 입력란 아래의 **{{ui:params.profile.title}}** 버튼을 누르면 그 모델의 추천값이 목록으로 나옵니다. 현재 설정이 추천에서 벗어나 있으면 버튼이 눈에 띄는 색이 되고, **{{ui:params.profile.apply}}**으로 추천값에 맞출 수 있습니다. 스텝 수는 추천값보다 조금 아래부터 조금 위까지를 허용 범위로 봅니다. Anima 모델은 적은 스텝에서 그림이 무너지기 쉬워서(한 가지 색으로 칠해지는 경우도 있습니다) 범위의 하한이 높은 편입니다(추천이 30이면 24 이상).

> 모델이 하나도 설치되어 있지 않을 때는 입력란에 '{{ui:params.model.noModels}}'라고 나오고 생성할 수 없습니다. 먼저 [모델 준비하기](08-models.md)를 끝내세요.

## 고해상도 보정

![고해상도 보정 구획을 열고 켠 모습](shot:hires-fix)

처음부터 큰 크기로 그리면 인물이 둘이 되거나 형태가 무너지기 쉽습니다. **{{ui:params.hires.title}}**은 먼저 설정한 크기로 그리고, 그것을 확대한 뒤 같은 시드와 설정으로 한 번 더 그립니다. 한 번의 생성으로 세부까지 그려진 큰 그림이 만들어집니다. 이 구획은 {{ui:app.tabs.generate}} 탭과 {{ui:app.tabs.comic}} 탭에 있습니다.

- **{{ui:params.hires.enable}}**: 켜면 사용합니다.
- **{{ui:params.hires.scale}}**: 1.25~2배입니다. 완성 크기는 구획의 제목과 맨 아래 줄에 나옵니다.
- **{{ui:params.hires.strength}}**: 0.2~0.75입니다. 낮으면 첫 번째 그림을 거의 유지하고, 높으면 크게 다시 그립니다. 기본값은 0.45입니다.
- **{{ui:params.hires.method}}**: **{{ui:params.hires.methodSmooth}}**은 모델 없이 확대합니다. {{ui:app.tabs.upscaling}} 탭에서 쓰는 업스케일 모델이 설치되어 있으면 그것도 고를 수 있습니다.
- **{{ui:params.hires.steps}}**: 두 번째의 스텝 수입니다. 0이면 첫 번째와 같은 수로 그립니다.

시간은 두 번 그리는 만큼 걸립니다. 진행 정도는 두 번을 이어서 셉니다. LoRA와 참조 이미지는 두 번째에도 쓰입니다.

완성 크기가 모델이 잘 그리는 크기를 크게 넘을 때(긴 변이 SDXL은 2048px, SD1.X는 1536px 정도)는 생성 버튼 아래에 주의가 나옵니다. 생성은 할 수 있지만, 그림이 무너지면 확대율을 낮추세요.

그림에는 첫 번째의 크기와 {{ui:params.hires.title}} 값이 저장됩니다. 갤러리의 '{{ui:gallery.menu.useAll}}'으로 불러오면 {{ui:params.hires.title}}도 그대로 들어갑니다.

## 생성 횟수와 생성 버튼

![생성 버튼 옆의 화살표를 눌러 연 메뉴](shot:invoke-menu)

왼쪽 패널 위쪽에 생성 조작이 모여 있습니다.

- **{{ui:params.invoke.invoke}}**(파란 버튼): 대기열의 맨 끝에 추가해서 생성합니다. `Ctrl+Enter`로도 누를 수 있습니다.
- **× 옆의 숫자**: 한 번의 조작으로 만드는 장수입니다. '3'으로 하면 3장을 만듭니다.
- **빨간 × 버튼**: 지금 그리고 있는 것을 취소합니다.
- 각 버튼 오른쪽의 **∨**: 그 밖의 조작 메뉴입니다.

누를 수 없을 때는 버튼이 회색이 되고 버튼 아래 줄에 이유(모델이 선택되지 않았음 등)가 나옵니다. 버튼에 커서를 올리면 이유 목록을 볼 수 있습니다.
그리는 동안에는 버튼이 '{{ui:params.invoke.generating}}'으로 바뀌고 진행 상황(%)과 대기열의 대기 수가 나옵니다.

### 생성 버튼의 ∨ 메뉴

- **{{ui:params.invoke.addBack}}**(`Ctrl+Enter`): 누른 순서대로 차례로 그립니다. 보통의 생성과 같습니다.
- **{{ui:params.invoke.addFront}}**(`Ctrl+Shift+Enter`): 대기열의 맨 앞에 끼워 넣습니다. 급하게 한 장만 시험해 보고 싶을 때 사용합니다.
- **{{ui:xyplot.menu}}**: 지금 설정을 바탕으로 설정을 1~2개만 바꾼 그림을 1장의 표에 나열합니다. 같은 시드로 그리므로 차이는 바꾼 설정뿐입니다. CFG 스케일, 스텝 수, 모델 등을 가로와 세로로 선택하고 값을 입력한 뒤 **{{ui:xyplot.run}}** 버튼을 누릅니다.

### 취소 메뉴

빨간 × 버튼 오른쪽의 ∨를 누르면 다음 메뉴가 나옵니다.

- **{{ui:params.invoke.cancelCurrent}}**(`Shift+X`)
- **{{ui:params.invoke.clearQueue}}**(`Ctrl+Shift+X`): 기다리는 것도, 그리고 있는 것도 모두 지웁니다. 확인은 나오지 않습니다.
- **{{ui:params.invoke.pause}}** / **{{ui:params.invoke.resume}}**: 대기열의 처리를 멈추거나 다시 시작합니다.
- **{{ui:params.invoke.openQueue}}**

## 프리셋

![프리셋 목록. 기본 제공 프리셋과 저장한 프리셋이 나열되어 있다](shot:presets)

자주 쓰는 설정 조합은 프리셋으로 저장할 수 있습니다. 왼쪽 패널 맨 위의 '{{ui:presets.label}}' 카드를 누르면 목록이 열립니다.

프리셋에는 다음 항목이 함께 들어갑니다.

- 프롬프트(포지티브와 네거티브)
- 모델과 각 설정(크기, 스텝 수, CFG, 스케줄러, VAE 등)
- LoRA와 참조 이미지
- {{ui:params.hires.title}}, **{{ui:app.tabs.upscaling}}** 탭의 설정, 인페인트 설정(마스크 흐림, 여백 채우기 등), 동적 프롬프트를 만드는 방식

시드와 장수, 업스케일할 이미지는 들어가지 않습니다.

사용 방법은 다음과 같습니다.

- 목록의 항목을 클릭하면 그 설정이 반영됩니다(**{{ui:presets.apply}}**).
- 목록 아래의 **{{ui:presets.saveNew}}**(또는 카드 옆의 저장 버튼)으로 현재 설정을 이름을 붙여 저장합니다.
- 항목 오른쪽의 '…'에서는 **{{ui:presets.apply}}**, **{{ui:presets.overwrite}}**, **{{ui:presets.rename}}**, **{{ui:presets.delete}}**를 할 수 있습니다.
- 목록은 '{{ui:presets.group.mine}}'과 '{{ui:presets.group.builtin}}'으로 나뉘어 있습니다. 기본 제공 프리셋은 처음부터 들어 있는 견본입니다.

### 프리셋을 무작위로 돌리기

여러 프리셋을 무작위로 번갈아 사용하면서 한꺼번에 생성할 수 있습니다. 프롬프트도 크기도 크게 다른 그림을 연달아 여러 장 만들고 싶을 때 사용합니다.

1. '{{ui:presets.label}}' 카드 오른쪽에 있는 교차한 화살표 버튼({{ui:presets.run.title}})을 누릅니다.
2. 사용할 프리셋에 체크합니다.
3. '×' 입력란에 {{ui:presets.run.count}}를 입력하고 **{{ui:presets.run.queue}}** 버튼을 누릅니다.

한 장마다 체크한 프리셋 중 하나가 같은 확률로 선택되고, 시드도 무작위가 됩니다. 프리셋에 들어 있지 않은 설정에는 왼쪽 패널의 현재 설정이 사용됩니다. 왼쪽 패널의 설정은 바뀌지 않습니다.

- 프리셋마다 모델이 다르면 전환할 때마다 모델을 불러오는 데 시간이 걸립니다.
- 프롬프트에 동적 프롬프트가 있을 때는 한 장마다 프롬프트 하나가 시드로부터 선택됩니다(모든 조합을 만들지는 않습니다).
- 체크한 프리셋 중 어느 하나가 생성할 수 없는 상태일 때는 그 이름과 이유가 표시되고 대기열에 추가할 수 없습니다.
- 체크와 장수는 다음에 열었을 때도 남아 있습니다.

## 프롬프트 프리셋

![프롬프트 프리셋. 분류별로 단어와 뜻이 나열되어 있고 '포지티브', '네거티브' 추가 버튼이 있다](shot:prompt-book)

영어 단어를 외우지 못했더라도 프롬프트를 조립할 수 있도록 **{{ui:params.promptBook.open}}**이 있습니다. 포지티브와 네거티브 각 입력란 위의 버튼에서 엽니다.

- 왼쪽에서 분류(인원과 인물, 인물의 관계와 상호작용, 포즈, 움직임, 표정, 시선, 구도, 헤어스타일, 복장 등)를 선택하면 그 분류의 단어만 나열됩니다. 위쪽 검색란에서는 단어, 뜻, 분류, 메모를 한꺼번에 찾을 수 있습니다.
- 단어 오른쪽의 '{{ui:params.prompt.positive}}', '{{ui:params.prompt.negative}}'를 누르면 그 단어가 프롬프트에 추가됩니다. 추가한 단어에는 체크가 붙고 한 번 더 누르면 해제됩니다.
- 맨 위 입력란에 단어와 뜻을 입력하고 **{{ui:params.promptBook.register}}** 버튼을 누르면 나만의 단어를 추가할 수 있습니다. 단어 오른쪽의 연필로 편집, 휴지통으로 삭제할 수 있습니다.

## 참조 이미지

**{{ui:params.refImage.sectionLabel}}**는 이미 있는 그림의 '분위기'나 '스타일'을 새 그림에 가깝게 만들기 위한 기능입니다. 그대로 복사하는 것이 아니라 색감이나 화풍, 전체적인 인상을 단서로 삼습니다.

1. 프롬프트 아래의 **＋** 버튼을 눌러 칸을 하나 추가합니다.
2. 갤러리의 그림을 그 칸에 드래그 앤 드롭합니다. 컴퓨터의 이미지 파일을 드롭해도 사용할 수 있습니다.
3. 칸을 클릭하면 설정 창이 열립니다.

설정 창에서는 다음을 정할 수 있습니다.

- **{{ui:params.refImage.model}}**: 참조 이미지 전용 모델(IP-Adapter). 선택한 모델의 계열에 맞는 것이 필요합니다.
- **{{ui:params.refImage.methodLabel}}**: 전체, 스타일만, 구도만 등 무엇을 단서로 삼을지(모델 계열에 따라서는 나오지 않습니다).
- **{{ui:params.refImage.weight}}**: 가깝게 만드는 강도.
- **{{ui:params.refImage.begin}}**과 **{{ui:params.refImage.end}}**: 그리는 과정의 어디부터 어디까지 적용할지.

필요한 모델이나 확장 기능이 설치되어 있지 않을 때는 칸에 경고 표시가 나오고 설정 창과 생성 버튼 아래에 안내가 나옵니다. 안내의 버튼으로 설치할 수 있습니다.

> 참조 이미지는 '분위기를 가깝게 만들기' 위한 것입니다. '이 그림을 바탕으로 다시 그리고 싶을' 때는 다음의 i2i를 사용합니다.

## i2i(원본 그림에서 다시 그리기)

**{{ui:params.i2i.title}}** 구획에 그림을 놓으면 그 그림을 밑그림 삼아 다시 그립니다. 구도나 색을 그대로 살리면서 프롬프트에 맞춰 바꾸고 싶을 때 사용합니다.

1. 구획을 열고 갤러리의 그림(또는 컴퓨터의 이미지 파일)을 칸에 드롭합니다. 참조 이미지 설정 창의 **{{ui:params.refImage.openI2i}}**에서도 놓을 수 있습니다.
2. 너비와 높이는 놓은 그림의 형태에 가장 가까운, 모델이 잘 그리는 크기로 바뀝니다. 나중에 직접 바꿔도 됩니다.
3. **{{ui:params.image.strength}}**로 얼마나 다시 그릴지를 정합니다. 0에 가까울수록 원본 그림 그대로이고, 1에 가까울수록 원본 그림을 신경 쓰지 않고 그립니다. 0.5 전후부터 시험해 보는 것을 추천합니다.

{{ui:params.hires.title}}을 켜면 원본 그림에서 다시 그린 그림을 확대해 한 번 더 그립니다. 해제하려면 칸 오른쪽 위의 ×를 누릅니다. 칠한 부분만 다시 그리고 싶을 때는 [캔버스에서 덧그리기](05-canvas.md)를 사용합니다.

### 캐릭터

참조 이미지 위의 '{{ui:character.row.label}}' 항목에서는 등록한 인물(같은 인물의 그림을 몇 장이든, 외모를 설명하는 말과 함께)을 불러올 수 있습니다.
선택하면 그 인물의 참조 이미지와 외모를 설명하는 말이 설정됩니다. 인물을 등록하는 방법은 [그림 수정하고 다시 쓰기](04-improve.md)에서 설명합니다.

## 대기열

![대기열 탭. 처리 중인 항목과 기다리는 항목이 목록으로 나와 있다](shot:queue)

**{{ui:app.tabs.queue}}** 탭에서는 생성 대기 상태를 보거나 조작할 수 있습니다. 기다리는 항목이 있으면 사이드 내비게이션의 {{ui:app.tabs.queue}} 탭에 숫자 배지가 나옵니다.

화면 위쪽에는 다음이 있습니다.

- 처리 상태('{{ui:queue.processor.running}}' 또는 '{{ui:queue.processor.paused}}')와 조작 버튼.
- 항목 수의 내역({{ui:queue.status.pending}}, {{ui:queue.status.inProgress}}, {{ui:queue.status.completed}}, {{ui:queue.status.failed}}, {{ui:queue.status.canceled}}).
- 오른쪽 위에 지금 그리고 있는 항목의 진행 상황.

버튼의 기능은 다음과 같습니다.

| 버튼 | 기능 |
|---|---|
| **{{ui:queue.action.pause}}** / **{{ui:queue.action.resume}}** | 대기 중인 처리를 멈추거나 다시 시작합니다. 그리고 있는 것은 그대로 끝까지 그립니다 |
| **{{ui:queue.action.cancelCurrent}}** | 지금 그리고 있는 것을 멈춥니다 |
| **{{ui:queue.action.cancelAllExceptCurrent}}** | 기다리고 있는 것을 모두 취소합니다 |
| **{{ui:queue.action.prune}}** | 끝난 항목(완료, 실패, 취소)을 목록에서 지웁니다 |
| **{{ui:queue.action.clear}}** | 모든 항목을 지웁니다. 확인 창이 나옵니다 |

아래 목록의 행을 클릭하면 그 항목의 자세한 정보(시각, 완성된 그림, 실패했을 때의 이유, 설정 내용)가 열립니다.
행 오른쪽의 ×로 그 항목만 취소할 수 있습니다. 실패했거나 취소한 항목에는 다시 시도 버튼이 나옵니다.

## 단축키

문자를 입력하는 중에는 동작하지 않는 것은 입력란에서 나온 뒤에 누르세요.

| 조작 | 키 |
|---|---|
| 생성한다(대기열의 맨 끝에 추가) | `Ctrl+Enter`(프롬프트를 입력하는 중에도 사용할 수 있습니다) |
| 대기열의 맨 앞에 추가해서 생성한다 | `Ctrl+Shift+Enter` |
| 그리고 있는 것을 취소한다 | `Shift+X` |
| 대기열을 모두 지운다(확인 없음) | `Ctrl+Shift+X` |
| 프롬프트 입력란으로 이동한다 | `Alt+A` |
| 왼쪽 패널, 오른쪽 패널을 열고 닫는다 | `T`, `G` |
| 좌우 패널을 한꺼번에 열고 닫는다 | `F` |
| 탭을 전환한다(사이드 내비게이션 순서대로, {{ui:app.tabs.generate}} 탭부터 {{ui:app.nav.extensions}} 탭까지) | `1`부터 `9`까지 |
| 단축키 목록을 연다 | `Shift+?` |

단축키는 사이드 내비게이션의 **{{ui:app.nav.settings}}** 메뉴에 있는 '{{ui:app.nav.hotkeys}}'에서도 확인할 수 있습니다.
