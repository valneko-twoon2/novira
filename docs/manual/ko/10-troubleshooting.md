# 문제가 생겼을 때

잘 되지 않을 때의 원인과 시도해 볼 일을 정리했습니다. 화면에 나오는 말로 찾아보세요.

먼저 다음 2가지를 보면 원인의 단서를 잡을 수 있는 경우가 많습니다.

- **{{ui:app.tabs.queue}}** 탭: 실패한 항목에 이유가 나옵니다([아래](#생성에-실패한다) 참조).
- {{ui:app.devlog.title}}: 앱 내부의 기록입니다([에이전트·설정](09-assistant-settings.md) 참조).

## 시작과 엔진

novira는 이미지 등을 만들기 위해 '이미지 생성 엔진'(ComfyUI와 그것을 실행하는 Python)을 사용합니다. 엔진은 앱이 직접 설치하고 직접 시작합니다.

### 시작하는 데 시간이 걸린다

처음 시작했을 때는 엔진의 다운로드와 압축 해제가 있으므로 시간이 걸립니다. **{{ui:engine.firstRunNote}}**

첫 화면에는 **{{ui:splash.step.downloading}}**, **{{ui:splash.step.extracting}}**, **{{ui:splash.step.starting}}**의 3단계가 나옵니다. 다운로드 중에는 크기, 속도, 남은 시간도 나옵니다. 끝날 때까지 기다리세요.

엔진 준비가 끝나면 화면이 전환됩니다. 두 번째부터는 시작하고 엔진이 응답할 때까지의 짧은 시간뿐입니다.

### 화면 위에 나오는 메시지

엔진을 준비 중이거나 잘 되지 않았을 때는 화면 위에 메시지가 나옵니다.

| 메시지 | 의미 |
|---|---|
| {{ui:engine.title.downloading}} | 엔진을 다운로드하고 있습니다. 수 GB가 됩니다. 회선이 느리면 시간이 걸립니다 |
| {{ui:engine.title.extracting}} | 다운로드한 파일의 압축을 풀고 있습니다 |
| {{ui:engine.title.starting}} | 엔진을 시작하고 연결되기를 기다리고 있습니다 |
| {{ui:engine.title.error}} | 준비에 실패했습니다. 아래에 이유가 나옵니다 |

### '{{ui:engine.title.error}}'라고 나왔다

시작했을 때의 첫 화면에 나왔다면 **{{ui:splash.open}}** 버튼을 누르면 엔진 없이 앱을 열 수 있습니다. 그 경우 이미지 등은 만들 수 없지만 이미지를 보거나 모델을 정리하는 것은 할 수 있습니다.

시도해 볼 일:

1. 이유의 문장을 읽습니다. 인터넷에 연결되어 있는지, 디스크의 여유 공간이 있는지 확인합니다.
2. 다시 시도합니다. 엔진 준비에 실패한 뒤에도 다음에 생성을 시작할 때 앱이 준비를 다시 합니다. 그래도 고쳐지지 않으면 앱을 닫고 다시 엽니다.
3. 다운로드가 끝났고 압축 해제만 실패했을 때는 다운로드한 파일이 남아 있으므로, 다시 시도하면 압축 해제부터 진행합니다.
4. 보안 소프트웨어가 새 파일을 검사하고 있어서 압축 해제가 멈추는 경우가 있습니다. 앱은 몇 번 자동으로 다시 시도하지만 계속되면 데이터 폴더(아래 참조)를 검사 대상에서 제외하거나 일시적으로 꺼 보세요.
5. 이유에 'see logs/comfyui.log'라고 나와 있으면 엔진의 로그에 자세한 이유가 있습니다([로그 보는 법](#로그-보는-법)).

> 엔진은 Windows용 ComfyUI이며 기본적으로 NVIDIA GPU용을 설치합니다. AMD GPU나 직접 설치한 ComfyUI를 사용하는 설정도 있지만 이것은 고급 사용자용입니다([고급 사용자용](#고급-사용자용-설정)).

### 엔진이 도중에 멈춘 것처럼 보인다

엔진이 시작되고 나서 응답할 때까지 기다리는 시간은 기본적으로 3분입니다. 그 시간이 지나면 'ComfyUI did not answer in time'이라는 뜻의 오류가 됩니다. 시작 도중에 엔진이 종료되었을 때는 'ComfyUI exited while starting'이라고 나옵니다. 둘 다 엔진의 로그(`comfyui.log`)에 이유가 남습니다.

## 생성할 수 없다

### 생성 버튼을 누를 수 없다

**{{ui:app.tabs.generate}}** 화면의 생성 버튼에 마우스를 올리면 **{{ui:params.invoke.cannotInvoke}}**라는 이유 목록이 나옵니다. 동영상, 음악, 음성, 로고 화면에서는 버튼 아래에 이유가 나열됩니다. 나와 있는 이유를 하나씩 해결하면 버튼을 누를 수 있게 됩니다.

| 나오는 이유 | 해결 방법 |
|---|---|
| {{ui:params.readiness.noModel}} | 모델을 선택합니다. 설치되어 있지 않을 때는 다음의 '모델이 설치되어 있지 않다'로 |
| {{ui:params.readiness.loraMissing}} | 선택했던 LoRA를 찾을 수 없습니다. 삭제했거나 이동했을 수 있습니다. LoRA를 다시 선택하거나 뺍니다 |
| LoRA '○○'은(는) 모델과 호환되지 않습니다 | 베이스(SDXL이나 SD1.X 등)가 다릅니다. 같은 베이스의 LoRA로 바꾸거나 뺍니다 |
| 참조 이미지 ○: 이미지가 선택되지 않았습니다, 또는 모델이 선택되지 않았습니다 | 참조 이미지 칸에 이미지를 넣고 모델을 선택합니다 |
| 참조 이미지에는 확장 기능 ○○이(가) 필요합니다 | 참조 이미지 칸의 안내에서 확장 기능을 설치합니다([확장 기능이 부족하다](#확장-기능이-부족하다)) |

| {{ui:params.readiness.upscaleNoModel}} | 업스케일용 모델을 선택합니다. 설치되어 있지 않을 때는 {{ui:app.tabs.models}} 탭의 **{{ui:models.install.tab.starter}}** 탭에서 설치할 수 있습니다 |
| {{ui:video.problem.prompt}}, {{ui:music.problem.tags}}, {{ui:voice.problem.text}}, {{ui:logo.problem.text}} | 필수 칸이 비어 있습니다. 입력합니다 |
| {{ui:video.problem.image}} | '이미지에서'일 때 움직일 이미지가 선택되지 않았습니다 |
| {{ui:voice.problem.description}} | '목소리를 말로 만들기'일 때 목소리 설명이 비어 있습니다 |
| {{ui:video.problem.pack}}, {{ui:music.problem.pack}}, {{ui:voice.problem.pack}}, {{ui:logo.problem.pack}} | 전용 모델이 설치되어 있지 않습니다. 다음 항목으로 |

### 동영상, 음악, 음성, 로고의 모델이 설치되어 있지 않다

각각의 화면 왼쪽 패널에 카드가 나와 있으므로 **{{ui:pack.install}}** 버튼을 누릅니다. 설치가 끝날 때까지는 만들 수 없습니다.

- 다운로드가 도중에 실패하면 카드의 버튼이 **{{ui:pack.retry}}**(으)로 바뀝니다. 누르면 다시 시도합니다.
- 음성은 읽어 주는 엔진도 설치합니다. 이미지 생성 엔진의 준비가 먼저 끝나 있어야 합니다.
- 고속 동영상 모델은 표준 동영상 모델과는 별도의 다운로드입니다.

자세한 내용은 [동영상·음악·음성·로고](07-media.md)를 보세요.

### 모델이 설치되어 있지 않다

**{{ui:app.tabs.models}}** 탭에 **{{ui:models.empty.title}}**라고 나와 있을 때는 모델이 하나도 없는 것입니다.

- **{{ui:models.import}}** 화면의 **{{ui:models.install.tab.starter}}** 탭에서 첫 모델을 설치할 수 있습니다.
- **{{ui:app.tabs.browse}}** 탭에서 마음에 드는 모델을 찾아 다운로드할 수도 있습니다.
- 이미 모델 파일을 가지고 있을 때는 **{{ui:models.import}}** 화면의 **{{ui:models.install.tab.scan}}** 탭에서 폴더째 가져올 수 있습니다.

자세한 내용은 [모델](08-models.md)을 보세요.

### 확장 기능이 부족하다

'확장 기능 ○○이(가) 필요합니다'라고 나오는 기능이 있습니다. 얼굴 고치기, 범위 선택하기, 배경 지우기, 동영상의 프레임 보간하기, 참조 이미지 사용하기 등입니다.

1. 메시지 옆의 **{{ui:params.refImage.installPack}}** 버튼을 누릅니다.
2. 설치가 끝나면 **{{ui:params.refImage.restartEngine}}** 버튼을 눌러 엔진을 다시 시작합니다.
3. 다시 시작한 뒤에 한 번 더 시도합니다.

확장 기능은 **{{ui:app.tabs.workflows}}** 탭의 **{{ui:workflows.panel.packs}}** 항목에서도 목록으로 설치하거나 제거할 수 있습니다.

> 앱이 설치한 엔진이 아니라 직접 준비한 엔진에 연결하고 있을 때는 확장 기능의 설치를 앱에서 할 수 없습니다. 그 엔진 쪽에서 설치하세요.

### GPU의 메모리가 부족하다·다른 앱과 경합하고 있다

이미지, 동영상, 음악은 PC의 GPU를 사용합니다. 다른 앱(게임, 동영상 편집, 브라우저의 동영상 등)이 GPU를 사용하고 있으면 메모리가 부족해져서 실패하는 경우가 있습니다.

메모리가 부족하면 오류에 'OOM'(메모리 부족이라는 뜻) 글자가 나오는 경우가 있습니다.

메모리 부족으로 실패했을 때는 앱이 그것을 알아내어 **{{ui:queue.oom.title}}**라는 안내를 표시합니다. 안내는 갤러리 위, **{{ui:app.tabs.queue}}** 탭의 실패한 항목 아래, 동영상·음악·음성·로고 화면, 화면 오른쪽 아래의 알림에 나옵니다.

![GPU의 메모리가 부족할 때의 안내. 작게 해서 다시 시도와 메모리 절약 모드로 재시작 버튼이 나열되어 있다](shot:out-of-memory)

안내의 버튼으로 다음 중 한 가지를 시도할 수 있습니다.

- **{{ui:queue.oom.retrySmaller}}**: 같은 설정과 시드 그대로, 가로세로 비율을 유지하면서 면적을 약 75%로 하여 다시 만듭니다. 크기를 정해서 만드는 이미지에만 나옵니다(동영상, 음악, 음성, 로고, 업스케일에는 나오지 않습니다).
- **{{ui:queue.oom.lowMemory}}**: **{{ui:settings.lowMemory.label}}**([에이전트·설정](09-assistant-settings.md) 참조)을 켜고 엔진을 다시 시작합니다. 만드는 중인 항목이 있을 때는 엔진을 다음에 시작할 때부터 사용됩니다. 이미 켜져 있을 때는 나오지 않습니다.

메모리 부족으로 실패한 뒤 앱은 엔진에게 불러온 모델을 내려서 메모리를 비우도록 요청합니다. 그래서 다음 생성은 모델을 불러오는 것부터 시작하므로 시간이 조금 걸립니다.

시도해 볼 일:

- 게임이나 동영상 편집 등 GPU를 사용하는 다른 앱을 닫은 다음 다시 만듭니다.
- 이미지의 크기를 작게 합니다.
- 사용하고 있는 LoRA나 참조 이미지를 줄입니다.
- 동영상은 크기를 작게 해서 만들고, 완성된 뒤에 **{{ui:video.finish}}** 버튼으로 크게 만듭니다. **{{ui:video.light.title}}** 항목의 **{{ui:video.light.fp8}}**과 **{{ui:video.light.tiled}}**도 시도해 볼 수 있습니다.
- 앱을 다시 열어서 사용 중인 메모리를 해제합니다.

음성 모델은 한동안 사용하지 않으면 GPU에서 내려갑니다. 생성은 1건씩 순서대로 진행됩니다.

### 생성에 실패한다

이미지, 동영상, 음악 등의 생성이 실패하면 **{{ui:app.tabs.queue}}** 탭의 항목이 **{{ui:queue.status.failed}}**(으)로 바뀝니다. 항목을 눌러 열면 **{{ui:queue.detail.error}}** 항목에 이유가 나옵니다. 동영상, 음악, 음성, 로고 화면에서는 가운데 위쪽에도 실패한 표시와 이유가 나옵니다(최근 3건까지).

이유를 알았다면 항목의 **{{ui:queue.action.retry}}** 버튼으로 같은 설정 그대로 다시 시도할 수 있습니다.

이유의 문장은 엔진이나 앱의 내부에서 나오기 때문에 영어인 경우가 있습니다. 자주 나오는 것을 들어 둡니다.

| 이유의 문장(요점) | 의미와 시도해 볼 일 |
|---|---|
| ComfyUI does not see ... (check model roots / extra_model_paths) | 엔진이 그 모델을 찾지 못합니다. 모델 파일을 옮겼거나 찾는 폴더의 설정이 맞지 않습니다. 모델 탭에서 다시 설치하거나 위치를 확인합니다 |
| ComfyUI is not reachable at ... | 따로 준비한 엔진에 연결되지 않습니다. 그 엔진이 시작되어 있는지 확인합니다 |
| ComfyUI exited while starting / did not answer in time | 엔진을 시작할 수 없습니다. 엔진의 로그를 봅니다 |
| ... OOM | GPU의 메모리가 부족합니다. 앞의 항목을 참조하세요 |
| ... models are not supported by the ComfyUI backend yet | FLUX나 SD3.X 모델은 아직 이미지 생성에 사용할 수 없습니다. SDXL이나 SD1.X 모델을 선택합니다 |
| Reference images need the ... custom node pack | 참조 이미지에 필요한 확장 기능이 설치되어 있지 않습니다 |
| This ComfyUI is too old for video / music | 동영상이나 음악에 필요한 기능이 사용 중인 엔진에 없습니다. 앱이 설치한 엔진이라면 일어나지 않습니다. 직접 준비한 엔진이라면 업데이트합니다 |
| The video / music / logo models are not installed yet | 전용 모델이 설치되어 있지 않습니다. 각각의 화면에서 다운로드합니다 |
| ComfyUI has no ... node; install the custom node pack | 워크플로에서 사용하는 노드의 확장 기능이 설치되어 있지 않습니다 |
| Interrupted because novira was closed | 생성 도중에 앱이 닫혔습니다. 다시 만듭니다 |

### 그림이 완성되었는데 보이지 않는다

생성이 **{{ui:queue.status.completed}}**인데 갤러리에 나오지 않을 때는 다음을 확인합니다.

- **보드가 다르다**: 새 이미지는 **{{ui:gallery.boards.autoBadge}}** 표시가 붙은 보드(초기 상태에서는 **{{ui:gallery.boards.uncategorized}}**)에 들어갑니다. 다른 보드를 열고 있으면 거기에는 나오지 않습니다. 보드를 전환하거나, 새 이미지를 넣을 보드를 **{{ui:gallery.boards.setAutoAdd}}** 항목에서 다시 선택합니다.
- **로고는 '에셋'에 들어간다**: 로고는 **{{ui:gallery.view.images}}** 쪽이 아니라 **{{ui:gallery.view.assets}}** 쪽에 들어갑니다.
- **동영상과 음성의 보이는 모습**: 동영상은 ▶, 음성은 ♪가 붙은 썸네일로 나열됩니다. 검색이나 필터가 남아 있으면 가려집니다.

그래도 찾을 수 없을 때는 **{{ui:app.tabs.queue}}** 탭에서 항목의 **{{ui:queue.col.destination}}** 열을 확인합니다. 출력 위치가 **{{ui:queue.destination.canvas}}**인 항목은 갤러리가 아니라 캔버스에 나옵니다.

## 데이터 저장 위치와 백업

### 데이터는 어디에 있는가

이미지, 모델, 기록은 모두 **`novira-data`**라는 이름의 폴더에 들어갑니다. 위치는 다음과 같습니다.

- 배포 버전: 사용자 폴더(`C:\Users\<사용자 이름>`) 안의 `novira-data`. 이전처럼 실행 파일(`novira.exe`)과 같은 폴더에 이미 `novira-data`가 있는 경우에는 그쪽을 계속 사용합니다.
- 개발 중인 버전: 저장소 최상위 폴더 안의 `novira-data`.

환경 변수 `NOVIRA_DATA_DIR`로 다른 위치로 바꿀 수 있습니다.

| 폴더·파일 | 들어 있는 것 |
|---|---|
| `outputs` | 만든 이미지, 동영상, 음성 |
| `novira.sqlite` | 이미지 정보, 보드, 대기열, 모델 목록, 워크플로 등의 기록 |
| `thumbnails` | 축소 이미지 |
| `models` | 설치한 모델 |
| `comfyui` | 앱이 설치한 이미지 생성 엔진 |
| `cache` | 엔진이 사용하는 임시 데이터 |
| `voice` | 음성 읽기용 라이브러리 |
| `logs` | 로그(아래 참조) |
| `settings.json` | 고급 사용자용 설정(없어도 상관없습니다) |
| `secrets` | API 키와 토큰(암호화되어 있습니다) |
| `agent.json` | 에이전트에서 선택한 AI의 종류 |

앱이 설치한 엔진(ComfyUI와 Python)과 그 작업용 데이터도 데이터 폴더 안에 들어갑니다.

앱 화면의 설정(언어, 테마, 프리셋, AI 채팅의 기록 등)은 `novira-data`가 아니라 앱 화면 쪽의 저장 영역에 들어 있습니다.

### 백업

novira에는 백업을 만드는 기능과 백업에서 복원하는 기능이 있습니다. 소중한 그림을 지키려면 설정 화면의 **{{ui:share.backup.section}}** 항목을 사용하세요([에이전트·설정](09-assistant-settings.md) 참조). 백업에는 만든 그림과 앱 안에서 설정·등록한 것이 들어가지만 모델과 이미지 생성 엔진은 들어가지 않습니다. 그것들도 남기고 싶을 때는 직접 폴더를 복사합니다.

1. 앱을 닫습니다(생성 중인 것이 없는지도 확인합니다).
2. `novira-data` 폴더를 통째로 다른 드라이브 등에 복사합니다.

용량이 큰 것은 `models`와 `comfyui`입니다. 그림과 기록만 남기려면 `outputs`와 `novira.sqlite`가 중심입니다. `models`의 모델은 가져온 곳에서 다시 다운로드할 수 있는 경우가 많지만, 배포가 끝난 것은 되돌릴 수 없는 경우가 있습니다.

> API 키와 토큰은 Windows의 기능으로 암호화되어 있습니다. 다른 PC나 다른 사용자에게 옮기면 읽을 수 없는 경우가 있으므로, 그때는 설정에서 다시 입력하세요.

앱 화면의 설정이나 프리셋, AI 채팅의 기록은 이 복사본에는 포함되지 않지만 백업에는 들어갑니다.

## 로그 보는 법

로그는 3곳에서 볼 수 있습니다.

| 위치 | 내용 |
|---|---|
| {{ui:app.devlog.title}}(앱 안) | 앱 내부의 기록과 화면의 경고·오류. 설정에서 표시를 켭니다([에이전트·설정](09-assistant-settings.md)) |
| `novira-data\logs\novira.log` | 앱 자체의 기록. 커지면(2 MB를 넘으면) `novira.log.1`로 옮겨집니다 |
| `novira-data\logs\comfyui.log` | 이미지 생성 엔진의 기록. 시작할 수 없을 때나 생성이 실패했을 때의 이유가 나옵니다 |

로그는 새 줄이 아래에 추가됩니다. 무슨 일이 있었을 때는 맨 아래 근처를 보세요. 'error'나 'failed'를 포함한 줄이 단서입니다.

## 문제를 보고할 때

다음이 갖추어져 있으면 원인을 빨리 알 수 있습니다.

1. **무엇을 했더니 어떻게 되었는가**: 조작의 순서, 기대한 것, 실제로 일어난 일.
2. **화면의 말**: 오류의 문장(**{{ui:app.tabs.queue}}** 탭의 **{{ui:queue.detail.error}}**, 또는 화면 위에 나온 메시지)을 그대로 옮겨 적습니다.
3. **앱의 버전**: 설정 화면의 맨 아래나 **{{ui:app.nav.about}}** 화면에 나와 있습니다.
4. **개발자 로그**: **{{ui:app.devlog.copy}}** 버튼으로 복사한 문장.
5. **로그 파일**: `novira.log`와 `comfyui.log` 중 문제가 일어난 시각 부근.
6. **PC의 정보**: GPU의 종류와 메모리, Windows의 버전.

> 로그에는 프롬프트나 파일의 위치가 포함되어 있을 수 있습니다. 다른 사람에게 전달하기 전에 보여 주고 싶지 않은 부분이 없는지 확인하세요.

## 고급 사용자용 설정

데이터 폴더에 `settings.json`을 두면 엔진 등의 동작을 바꿀 수 있습니다. 보통은 필요하지 않습니다.

| 설정 이름 | 내용 |
|---|---|
| `comfyuiPackage` | 설치할 엔진의 종류. `nvidia`(기본) 또는 `amd` |
| `comfyuiUrl` | 이미 실행 중인 ComfyUI에 연결(앱은 엔진을 설치하지 않고 시작도 하지 않습니다) |
| `comfyuiDir` | 직접 설치한 ComfyUI의 폴더를 사용 |
| `modelRoots` | 모델을 찾을 폴더를 추가 |
| `comfyuiStartTimeoutSecs` | 엔진의 시작을 기다리는 초 수(기본은 180) |
| `lowMemoryMode` | 메모리 절약 모드(`true` 또는 `false`). 설정 화면의 **{{ui:settings.lowMemory.label}}** 항목에서 전환하면 여기에 기록됩니다 |

파일의 작성 방식이 잘못되어 있으면 앱은 시작되지 않고 이유를 표시합니다. 변경했다면 앱을 다시 엽니다.
