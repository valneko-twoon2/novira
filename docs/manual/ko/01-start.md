# 시작하기

## novira로 할 수 있는 것

novira는 이미지, 동영상, 음악, 음성을 만드는 Windows용 데스크톱 앱입니다.
프롬프트(만들고 싶은 것에 대한 설명)를 쓰고 **{{ui:params.invoke.invoke}}** 버튼을 누르면 컴퓨터 안에서 그림이 그려지고, 오른쪽 갤러리에 나열됩니다.
화면 구성과 조작은 이미지 생성 도구 InvokeAI의 화면을 바탕으로 했습니다. 써 본 적이 있다면 같은 감각으로 조작할 수 있습니다.

할 수 있는 일은 대략 다음과 같습니다.

- 문장으로 이미지를 만든다 (이 안내서의 중심입니다)
- 이미지를 바탕으로 다시 만들기, 일부만 다시 그리기, 확대
- 동영상, 음악, 음성, 로고, 글자가 들어간 이미지를 만든다
- AI 어시스턴트에게 설정이나 프롬프트를 상담한다

> 그림을 그리는 처리는 사용 중인 컴퓨터 안에서 이루어집니다. 모델 검색과 다운로드, AI 어시스턴트처럼 인터넷을 사용하는 기능은 사용하기로 선택했을 때만 통신합니다.

## 이미지가 만들어지는 원리

novira는 다음 4가지 부품으로 이루어져 있습니다.

| 부품 | 역할 |
|---|---|
| novira (이 앱) | 화면, 갤러리, 대기열, 모델 관리 |
| 이미지 생성 엔진 (ComfyUI) | 실제로 그림을 그리는 부분. novira가 직접 설치하고 직접 실행해서 동작시킵니다 |
| 모델 | 그림을 그리기 위한 학습 데이터. 하나가 수 GB인 파일이며, 엔진과는 별도로 준비합니다 |
| 데이터 폴더 | 만든 이미지, 모델, 엔진 본체 등을 넣어 두는 곳 |

엔진은 사용자가 직접 설치할 필요가 없습니다. 처음 실행할 때 novira가 자동으로 설치합니다.
엔진과 그 부품(Python 등)은 novira의 데이터 폴더 안에만 들어갑니다. 컴퓨터의 다른 곳이나 이미 있는 Python은 건드리지 않습니다.

데이터 폴더의 이름은 `novira-data`이며, 앱 폴더 안에 있습니다. 이미지나 모델을 옮기거나 백업할 때는 이 폴더를 사용합니다.

> 이미지 생성에는 GPU(그래픽 카드)를 사용합니다. 기본적으로 NVIDIA GPU용 엔진을 설치합니다.

모델은 '어떤 그림체로 그릴지'를 정하는 것입니다. 처음에 하나가 필요합니다. 설치하는 방법은 [모델 준비하기](08-models.md)에서 설명합니다.

## 처음 실행했을 때

앱을 열면 먼저 시작 화면(로고와 천천히 떠다니는 그림 비눗방울)이 나옵니다.
시작 화면 아래에는 지금 무엇을 하고 있는지 보여 주는 카드가 나옵니다.

처음 실행하면 이미지 생성 엔진의 설치가 시작됩니다. 카드에는 3단계가 차례로 표시됩니다.

1. **{{ui:splash.step.downloading}}**: ComfyUI와 Python을 다운로드합니다. 크기, 속도, 대략적인 남은 시간도 표시됩니다.
2. **{{ui:splash.step.extracting}}**: 다운로드한 파일의 압축을 풉니다.
3. **{{ui:splash.step.starting}}**: 엔진을 시작하고 연결되기를 기다립니다.

> {{ui:engine.firstRunNote}}

설치는 한 번뿐입니다. 두 번째부터는 시작 화면이 몇 초 만에 끝나고 엔진도 바로 움직이기 시작합니다.

엔진 준비가 끝나면 시작 화면이 사라지고 메인 화면이 열립니다.
데이터를 불러오는 동안에는 '{{ui:splash.wait.heading.loading}}', 엔진과 편집에 필요한 정보를 불러오기를 기다리는 동안에는 '{{ui:splash.wait.heading.preparing}}'라고 표시됩니다.

### 화면 위에 나오는 메시지

앱을 연 뒤에 엔진이 다시 시작되거나 다시 설치되면 화면 위쪽 가운데에 띠(배너)가 나와서 상황을 알려 줍니다.

- '{{ui:engine.title.downloading}}', '{{ui:engine.title.extracting}}', '{{ui:engine.title.starting}}': 작업 중입니다. 끝날 때까지 생성은 시작되지 않습니다. 끝나면 띠는 자연스럽게 사라집니다.
- '{{ui:engine.title.error}}': 엔진을 준비하지 못했습니다. 띠 아래 줄에 이유가 나옵니다.

시작 화면에서 오류가 나면 이유 아래에 **{{ui:splash.open}}** 버튼이 나옵니다. 누르면 엔진 없이 앱을 열 수 있습니다. 모델 확인이나 설정은 사용할 수 있지만 그림은 만들 수 없습니다.
오류가 계속되면 [문제가 생겼을 때](10-troubleshooting.md)를 보세요.

## 화면 구성

![생성 탭 전체. 왼쪽에 파라미터 패널, 가운데에 시작 화면, 오른쪽에 보드와 갤러리가 나란히 있다](shot:generate)

화면은 왼쪽부터 차례로 다음과 같이 배치되어 있습니다.

- 가장 왼쪽의 가늘고 긴 세로 띠: **사이드 내비게이션**. 탭을 전환합니다.
- 왼쪽 패널: **파라미터 패널**. 프롬프트나 모델 등 그림을 만들기 위한 설정이 들어 있습니다.
- 가운데: **메인 뷰**. 시작 화면, 이미지 뷰어, 캔버스 등 탭에 맞는 작업 공간입니다.
- 오른쪽 패널: **갤러리**. 보드(폴더 같은 것)와 만든 이미지의 썸네일이 나열됩니다.

### 사이드 내비게이션(탭)

| 탭 | 용도 | 숫자 키 |
|---|---|---|
| **{{ui:app.tabs.generate}}** | 이미지를 만든다. 위쪽 아이콘으로 동영상, 음악, 음성, 로고, 텍스트, 만화로도 전환할 수 있습니다 | `1` |
| **{{ui:app.tabs.canvas}}** | 이미지를 놓고 덧그리거나 일부만 다시 그린다 | `2` |
| **{{ui:app.tabs.comic}}** | 만화 페이지를 만든다. 컷 배치, 컷마다의 그림, 말풍선과 내레이션. {{ui:app.tabs.generate}} 탭 위쪽 아이콘의 맨 오른쪽에서도 열립니다 | `3` |
| **{{ui:app.tabs.upscaling}}** | 이미지를 키우면서 세부를 덧그린다 | `4` |
| **{{ui:app.tabs.workflows}}** | 부품(노드)을 연결해 나만의 생성 절차를 만든다 | `5` |
| **{{ui:app.tabs.models}}** | 가지고 있는 모델의 목록, 설치, 삭제 | `6` |
| **{{ui:app.tabs.browse}}** | 인터넷에 있는 모델을 찾아서 가져온다 | `7` |
| **{{ui:app.tabs.queue}}** | 생성 대기 상태를 보고 멈춘다. 기다리는 수가 배지로 나옵니다 | `8` |
| **{{ui:app.nav.extensions}}** | ComfyUI 확장 기능을 찾아서 설치하거나 제거한다 | `0` |

사이드 내비게이션 아래쪽에는 다음 항목도 있습니다.

- **{{ui:app.tabs.short.agent}}**: AI 어시스턴트 창을 현재 화면 위에 엽니다.
- **{{ui:app.nav.settings}}**: 메뉴에서 {{ui:app.nav.settings}}, {{ui:app.nav.hotkeys}}, {{ui:app.nav.about}} 항목을 엽니다.
- 맨 위의 'n' 로고: {{ui:app.nav.about}} 항목을 엽니다.

각각의 사용 방법은 다음 장에서 설명합니다.

- {{ui:app.tabs.upscaling}}, {{ui:app.tabs.workflows}}: [확대와 워크플로](06-upscaling-workflows.md)
- 동영상, 음악, 음성 등: [동영상, 음악, 음성, 로고, 텍스트](07-media.md)
- {{ui:app.tabs.models}}, {{ui:app.tabs.browse}}: [모델 준비하기](08-models.md)

### 가운데 탭(시작, 뷰어, 초안)

{{ui:app.tabs.generate}} 탭의 가운데 위쪽에는 작은 탭이 3개 있습니다.

- **{{ui:app.views.launchpad}}**: 시작 방법 안내입니다. '{{ui:params.launchpad.generate.textTitle}}', '{{ui:params.launchpad.generate.refTitle}}' 같은 카드와 단축키 힌트가 나옵니다.
- **{{ui:app.views.viewer}}**: 이미지를 크게 보는 곳입니다. 갤러리에서 이미지를 선택하면 여기에 표시됩니다.
- **{{ui:app.views.drafts}}**: 같은 설정에서 시드만 바꿔 중간까지 그린 후보를 많이 나열하고, 마음에 드는 것만 끝까지 그리는 화면입니다.

다른 탭에도 그 탭 전용의 작은 탭이 있습니다({{ui:app.tabs.canvas}} 탭이라면 {{ui:app.views.canvas}} 등).

### 패널 숨기기

이미지를 넓게 보고 싶을 때는 왼쪽과 오른쪽 패널을 숨길 수 있습니다.

- 가운데 위쪽 가장자리에 있는 작은 화살표 버튼으로 왼쪽 패널과 오른쪽 패널을 열고 닫습니다.
- 키보드에서는 `T`로 왼쪽 패널, `G`로 오른쪽 패널, `F`로 양쪽을 한꺼번에 열고 닫습니다.
- 패널과 패널의 경계를 드래그하면 너비를 바꿀 수 있습니다. 너비는 앱을 열어 둔 동안만 기억되며, 다시 실행하면 원래 너비로 돌아갑니다.

> `T`, `G`, `F` 같은 한 글자 단축키는 글자를 입력하는 중에는 동작하지 않습니다. 입력란에서 나온 뒤에 누르세요.

## 첫 이미지 만들기 (3단계)

처음 그림을 만드는 흐름입니다. 모델이 이미 설치되어 있다고 가정하고 설명합니다.

1. **모델을 선택한다.** 왼쪽 패널 위쪽에 있는 모델 입력란에서 사용할 모델을 선택합니다. 입력란에 '{{ui:params.model.noModels}}'라고 나와 있다면 먼저 [모델 준비하기](08-models.md)를 끝내세요.
2. **프롬프트를 쓴다.** '{{ui:params.prompt.positive}}' 입력란에 만들고 싶은 그림을 말로 씁니다. 예를 들어 `a lighthouse on a cliff at dusk, calm sea, warm light`처럼 단어나 짧은 문장을 쉼표로 이어 줍니다. 많은 모델은 영어로 쓰면 생각대로 나오기 쉽습니다.
3. **{{ui:params.invoke.invoke}} 버튼을 누른다.** 버튼을 누르거나 `Ctrl+Enter`를 누릅니다. 오른쪽 갤러리 위에 '{{ui:gallery.generating.title}}' 표시가 나오고 중간 단계의 그림과 진행 상황이 보입니다. 완성되면 가운데 뷰어에 그림이 나오고 갤러리에도 나열됩니다.

버튼이 회색이라 누를 수 없을 때는 버튼 아래 줄에 이유가 나옵니다(예를 들어 '{{ui:params.readiness.noModel}}'). 이유를 해결하면 누를 수 있게 됩니다.

만든 그림은 갤러리에 자동으로 저장됩니다. 마음에 들지 않으면 프롬프트나 설정을 조금 바꿔서 다시 누르기만 하면 됩니다.
자세한 내용은 다음 [이미지 만들기](02-generate.md)로 넘어가세요.
