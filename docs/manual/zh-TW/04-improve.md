# 修飾與沿用圖像

這一章彙整了當你想到「想把做好的圖像再修飾一點」「想要相同氛圍的圖像再多幾張」「想在其他場景也使用這個角色」時，可以使用的功能。

大部分的功能，都是從檢視器（放大檢視圖像的畫面）上方工具列的按鈕，或是在圖庫的圖像上按右鍵的選單來叫出。工具列的按鈕，只要將滑鼠移上去就會顯示名稱。檢視器與圖庫的基本用法，請見[圖庫](03-gallery.md)。

## 該從哪裡使用什麼

| 想做的事 | 使用的功能 | 另外需要的東西 |
|---|---|---|
| 用相同的設定再製作幾張、稍微改變後重做 | **{{ui:gallery.derive.menu}}** | 已安裝原圖所使用的模型 |
| 消除背景，只留下人或物 | **{{ui:cutout.menu}}** | 擴充功能 ComfyUI-RMBG |
| 去除透明的邊緣 | **{{ui:gallery.menu.trim}}**（僅限右鍵） | 無 |
| 選取圖像的一部分，進行去背、消除、重畫 | **{{ui:gallery.menu.segment}}** | 擴充功能 ComfyUI-segment-anything-2 等 |
| 修復小而崩壞的人臉 | **{{ui:facefix.menu}}** | 擴充功能 ComfyUI-Impact-Pack 與 ComfyUI-Impact-Subpack |
| 從圖像寫出提示詞 | **{{ui:caption.menu}}** | 擴充功能 ComfyUI-Florence2 |
| 登錄角色，在其他圖像中也使用 | **{{ui:character.menu}}** | 參考圖像用的擴充功能（IP-Adapter） |
| 將改變設定的圖像並排在一張表格中 | **{{ui:xyplot.menu}}** | 無 |
| 從畫到一半的候選圖中挑選 | **{{ui:app.views.drafts}}** 分頁 | 無 |
| 對多張圖像套用相同的處理 | **{{ui:gallery.menu.batch}}**（選取多張後按右鍵） | 依處理而異 |

## 需要擴充功能時

去除背景、選取範圍的功能、修復人臉的功能等，是在製作圖像的引擎（ComfyUI）中加入「擴充功能」才能運作。如果沒有安裝擴充功能，對話框會出現「…需要擴充功能 ○○。」，並排列出安裝的按鈕。

1. 按下 **{{ui:cutout.install}}**。會自動下載並安裝所需的東西。
2. 安裝完成後，按鈕會變成 **{{ui:cutout.restart}}**。按下後 ComfyUI 會重新啟動。
3. 重新啟動完成後，同一個對話框就能直接使用了。

第一次使用時，也會開始下載擴充功能所使用的模型，因此會花一些時間。需要連上網路。

> 擴充功能中，有些安裝需要花費時間與容量。ComfyUI-Impact-Pack 需要有 Git 才能安裝。沒有安裝 Git 的電腦會安裝失敗。出現訊息時，請閱讀後再處理。

擴充功能也可以從[工作流程](06-upscaling-workflows.md)的「{{ui:workflows.panel.packs}}」分頁安裝。如果不順利，也請參閱[遇到問題時](10-troubleshooting.md)。

## 以相同設定再製作一次（衍生）

![在檢視器的工具列中開啟「衍生更多」的樣子](shot:derive-menu)

在檢視器中開啟喜歡的圖像，按下工具列的 **{{ui:gallery.derive.menu}}** 按鈕（分岔圖示）。在圖庫中，則是在圖像上按右鍵，選擇 **{{ui:gallery.derive.menu}}**。

可以選擇的有下列 3 種。

| 項目 | 做什麼 |
|---|---|
| 「相同設定，新種子」（1 張或 4 張） | 提示詞、模型、尺寸等維持不變，只更換種子來畫。構圖會改變，但氛圍相同。 |
| 「稍作改動後重做」（1 張或 4 張） | 以原圖為基礎，用較弱的強度（強度 0.45）重畫。在保留構圖與顏色的同時，只有細節會改變。 |
| **{{ui:gallery.derive.custom}}** | 自行決定改變的程度（下一個項目）。 |

選擇後，新的圖像會進入佇列，並排列在與原圖相同的看板。**生成分頁的設定不會被改寫。** 輸入中的提示詞也會維持原樣。

> 想先把設定叫回畫面，再自行修改後製作時，請使用 **{{ui:gallery.menu.remix}}**。衍生是用來「只按 1 個按鈕，就以原本的設定製作」。

### 選擇改變的程度後重新製作

![決定改變程度的對話框](shot:derive)

選擇 **{{ui:gallery.derive.custom}}** 後，會開啟對話框。

1. 移動滑桿 **{{ui:gallery.derive.dialog.strength}}**。越往左（{{ui:gallery.derive.dialog.close}}），越會保留原本的構圖與顏色；越往右（{{ui:gallery.derive.dialog.free}}），越接近不同的圖像。
2. 從 1、2、4、8 中選擇 **{{ui:gallery.derive.dialog.count}}**。
3. 按下 **{{ui:gallery.derive.dialog.create}}**。

參考值大約是，0.25 左右會是和原圖幾乎相同的圖像，0.75 左右則是角色保留，但構圖大幅改變的圖像。依圖像而異，請多試幾次看看。滑桿的值只會用在那 1 次。

### 會沿用與不會沿用的內容

- 會沿用：提示詞、反向提示詞、模型、LoRA、尺寸、步數、CFG 比例、排程器等，製作圖像時的設定。
- 參考圖像與控制圖層，也會和圖像一起被記住，所以會直接使用。不過，如果該圖像已從圖庫刪除，就無法製作。原因會顯示在通知中。
- 不會沿用：遮罩、區域引導、草稿的設定。在這個功能出現之前製作的圖像，若曾使用參考圖像等，因為沒有記錄，也無法沿用。無法沿用時，會以通知告知。

下列情況，按鈕無法按下，或是會出現通知而無法製作。

- 不是從文字製作的圖像時（「從文字製作」包括圖像轉圖像、重繪、擴繪）。放大後的圖像、影片、語音等不在對象內。
- 沒有安裝原圖所使用的模型時。會出現附上模型名稱的通知。

## 移除背景

![移除背景的對話框](shot:cutout)

自動辨別拍到的東西，製作出去除背景的圖像。不需要用點擊來指定。

1. 在檢視器中開啟圖像，按下剪刀圖示的 **{{ui:cutout.menu}}**（右鍵選單中也有）。
2. 視需要變更設定。
   - **{{ui:cutout.model}}**：通常維持原樣即可。
   - **{{ui:cutout.sensitivity}}**：調得越低，邊界模糊的部分也會越被保留。
   - **{{ui:cutout.edge}}**：正值會擴大輪廓，負值會縮小。
   - **{{ui:cutout.background}}**：選擇 **{{ui:cutout.background.alpha}}** 或 **{{ui:cutout.background.white}}**。
3. 按下 **{{ui:cutout.run}}**。

做好的圖像，會以新圖像的形式，儲存在與原圖相同的看板。**原圖會保留。** 如果對結果不滿意，請變更設定後按下 **{{ui:cutout.again}}**。用 **{{ui:cutout.open}}**，可以顯示在檢視器中。

白色背景，適合之後作為[角色](#登錄並使用角色)的參考圖像。背景的顏色會比較不容易轉移到新製作的圖像。

## 去除透明的邊緣

背景透明的圖像，圖像外側會留下透明的邊緣。使用 **{{ui:gallery.menu.trim}}**，就會將圖像裁切到剛好貼合有圖的部分，並另存為新的透明圖像。用來做貼圖或素材時很方便。

- 在圖庫的圖像上按右鍵選擇。剛去除背景後，也可以從對話框的 **{{ui:cutout.trim}}**（只有在背景設為透明時才會出現）做到同樣的事。
- 淡到幾乎看不見的陰影，會被當作邊緣而裁掉。
- 透明的部分沒有延伸到圖像邊緣的圖像，會出現「沒有可裁掉的邊距」，並且什麼都不會儲存。整張都是透明的圖像也無法裁切。

## 選取範圍來修飾

![以點擊指定要選取圖像哪個部分的對話框](shot:segment)

用點擊選取圖像中「就是這個」的東西。可以對選取的部分進行去背、消除、重畫。

1. 在檢視器中開啟圖像，按下 **{{ui:gallery.menu.segment}}**。
2. 只有第一次，需要擴充功能 ComfyUI-segment-anything-2。請依照畫面的說明安裝（[需要擴充功能時](#需要擴充功能時)）。
3. 點擊想選取的東西。不足的地方，點擊其他位置來補上。超出的地方，將按鈕切換成 **{{ui:segment.mode.exclude}}** 後點擊，或是按右鍵（或按住 `Shift` 並點擊）來排除。再點擊一次指定過的點，就能取消那個指定。用 **{{ui:segment.clear}}** 可以從頭來過。
4. 按下 **{{ui:segment.run}}**。選取的範圍會以藍色顯示。
5. 藍色的範圍正確的話，請選擇下一個操作。相反地，想選取「剩下的部分」時，請開啟 **{{ui:segment.invert}}**。

| 按鈕 | 能做的事 | 需要的東西 |
|---|---|---|
| **{{ui:segment.cutout}}** | 只將選取的部分去背，並儲存為透明的圖像。 | 無 |
| **{{ui:segment.mosaic}}** | 把選取的部分做成粗方塊（馬賽克）並儲存。方塊大小用旁邊的數字調整。 | 無 |
| **{{ui:segment.erase}}** | 將選取的部分，與周圍的畫面融合後消除。 | 擴充功能 comfyui-inpaint-nodes。有模型 LaMa（約 200MB）時，會消除得很自然。沒有也能簡易地消除。 |
| **{{ui:segment.redraw.title}}** | 只將選取的部分，依文字的指示重畫。其他部分不會改變。 | 圖像用的模型 |
| **{{ui:segment.toCanvas}}** | 將圖像與選取範圍，傳送到[畫布](05-canvas.md)。選取範圍會成為重繪遮罩。 | 無 |

重畫時，要用文字寫下 **要畫什麼**（例：blue hair, red scarf）。配合模型擅長的寫法（動漫風格的模型就用英文標籤等），會比較容易得到想要的結果。**{{ui:segment.redraw.strength}}** 調得越低，越會保留原本的形狀與顏色。

結果會以新圖像的形式，儲存在與原圖相同的看板。原圖不會改變。

## 修復人臉

![修復人臉的對話框](shot:facefix)

在遠景的圖像中，小小的人臉經常會崩壞。**{{ui:facefix.menu}}** 會自動找出圖像中的人臉，只用高解析度重畫人臉，再放回原圖。人臉以外的部分不會改變。

1. 在檢視器中開啟圖像，按下 **{{ui:facefix.menu}}**（右鍵選單中也有）。
2. 只有第一次，需要擴充功能 ComfyUI-Impact-Pack 與 ComfyUI-Impact-Subpack。用 **{{ui:facefix.install}}** 安裝，再按下 **{{ui:facefix.restart}}**。尋找人臉的模型，由 Subpack 自行準備。
3. 確認設定。
   - **{{ui:facefix.model}}**：已選擇原圖所使用的模型。
   - **{{ui:facefix.prompt}}**：已填入原圖的提示詞。加上人臉的特徵會有效果。
   - **{{ui:facefix.strength}}**：越低越接近原本的人臉，越高則重畫的幅度越大。
   - **{{ui:facefix.sensitivity}}**：調高只會偵測確實的人臉，調低則連小臉與側臉也會偵測到。不過，也比較容易偵測到不是人臉的東西。
4. 按下 **{{ui:facefix.run}}**。

結果會儲存在與原圖相同的看板。按下 **{{ui:facefix.open}}**，可以在檢視器中與原圖比較。如果不喜歡，請變更設定後按下 **{{ui:facefix.again}}**。

> 使用 LoRA 製作的圖像，會在沒有 LoRA 的狀態下重畫。因此，有時只有人臉的畫風看起來會稍有不同。

> 出現「找不到人臉偵測模型（YOLO）」時，請重新啟動 ComfyUI，或重新安裝擴充功能。

## 從圖像產生提示詞

![查看圖像後寫出標籤的對話框](shot:caption)

查看圖像，寫出畫出這張圖的提示詞（標籤或句子）。想畫出與喜歡的圖相近的圖，或不知道提示詞該怎麼寫時使用。

1. 選擇檢視器的 **{{ui:caption.menu}}** 按鈕，或圖像右鍵選單中的 **{{ui:caption.menu}}**。也可以從生成分頁提示詞欄上方的 **{{ui:caption.fromPrompt}}** 按鈕開啟。可以把圖庫中的圖像或電腦裡的圖像檔案拖到這個按鈕上。
2. 在 **{{ui:caption.style}}** 中選擇 **{{ui:caption.style.tags}}** 或 **{{ui:caption.style.sentence}}**。
3. 按下 **{{ui:caption.run}}**。
4. 產生的文字可以當場修改。然後按下 **{{ui:caption.replace}}**、**{{ui:caption.append}}** 或 **{{ui:caption.copy}}**。

取代或追加的對象是生成分頁的「{{ui:params.prompt.positive}}」。這個功能不會在圖庫中增加圖像。

> 這個功能需要擴充功能 ComfyUI-Florence2。未安裝時可以從對話框安裝（參見本章的「需要擴充功能時」）。第一次使用時，會開始下載用於描述的模型（Florence-2 PromptGen）。

## 登錄並使用角色

![登錄為角色的對話框](shot:character)

事先登錄喜歡的角色圖像，之後在其他場景的圖像中，也能畫得接近同一個角色。要登錄的有下列 3 項。

- 參考圖像（同一個角色的圖像。幾張都可以）
- 外觀的描述詞（頭髮與眼睛的顏色、服裝等。會加到提示詞的開頭）
- 相似的強度

### 登錄

1. 在圖庫中，選取想登錄的圖像。有多張時，按住 `Ctrl` 並點擊。
2. 選擇檢視器的 **{{ui:character.menu}}** 按鈕，或右鍵選單的 **{{ui:character.menu}}**。開啟生成分頁的 **{{ui:character.row.choose}}** 欄位，清單的最下方有 **{{ui:character.row.register}}**，也可以從這裡開啟。
3. 輸入 **{{ui:character.name}}** 與 **{{ui:character.tags}}**。寫下不希望改變的特徵（棕色的頭髮、白色的襯衫、藍色的裙子等）。
4. 決定 **{{ui:character.weight}}**。調得越高，越像參考圖像，但場景與構圖的自由度會降低。
5. 按下 **{{ui:character.save}}**。

使用 **{{ui:character.addSelected}}**，之後可以將在圖庫中選取的圖像，加入參考圖像。**{{ui:character.removePicture}}** 是圖像右上角的 ✕。

開啟 **{{ui:character.whiteBg}}** 後，會製作出將要登錄的圖像背景換成白色的圖像，並將它作為參考圖像。可以防止背景的顏色轉移到生成的圖像上。原圖會保留，白色背景的圖像會被新儲存。沒有安裝用來去除背景的擴充功能 ComfyUI-RMBG 時，這個開關無法使用，會直接使用原圖。

### 使用

1. 在 **{{ui:app.tabs.generate}}** 分頁（或[畫布](05-canvas.md)分頁）的左側面板，開啟 **{{ui:character.row.choose}}**，選擇想使用的角色。
2. 角色的參考圖像會放進「{{ui:params.refImage.sectionLabel}}」欄，外觀的描述詞會加到提示詞的開頭。
3. 像平常一樣生成。

使用時，應用程式有時會自動調整。會以通知告知。

- 使用參考圖像時，CFG 比例太高，圖像容易過曝，所以 CFG 比例高於 5 時，會降到 4.5。
- 參考圖像全部最多 8 張。與其他參考圖像合計超過 8 張時，會從最前面的圖像開始使用。
- 參考圖像有多張時，為了避免重疊後過濃，會自動降低每 1 張的強度。
- 已從圖庫刪除的圖像，無法使用。全部都被刪除時，就無法使用該角色。

要修改或刪除已登錄的角色，請使用清單項目的「…」按鈕。

> 讓圖像「接近」同一個角色的功能，並不會變成完全相同的臉。髮型、顏色、服裝等比較容易保持，但五官會稍有改變。想保持的特徵，寫在外觀的描述詞中會比較有效。

> 要使用參考圖像，需要擴充功能 ComfyUI_IPAdapter_plus，以及參考圖像用的模型。沒有安裝時，可以從生成分頁的參考圖像欄安裝。模型請見[模型](08-models.md)這一章。

## 用對比網格比較設定

![對比網格的對話框](shot:xyplot)

改變 CFG 比例或步數，圖像會有什麼變化？這是把它做成一張表格來比較的功能。

1. 在生成分頁，像平常一樣決定提示詞與模型。
2. 按下 **{{ui:params.invoke.invoke}}** 按鈕右邊的「▼」，選擇 **{{ui:xyplot.menu}}**。
3. 用 **{{ui:xyplot.x}}** 與 **{{ui:xyplot.y}}** 選擇要改變的設定。只選一邊也能製作。
4. 輸入數值。數字用逗號分隔排列（例：3, 5, 7）。
5. 按下 **{{ui:xyplot.run}}**。

對話框的下方，會顯示像「將生成 3 欄 × 2 列 = 6 張。」這樣的製作張數。

可以改變的設定如下。

| 設定 | 輸入方式 |
|---|---|
| {{ui:xyplot.axis.cfgScale}} | 數字（1～30） |
| {{ui:xyplot.axis.steps}} | 整數（1～150） |
| {{ui:xyplot.axis.seed}} | 整數 |
| {{ui:xyplot.axis.strength}} | 數字（0.05～1）。只有在以圖像轉圖像製作時才有效。 |
| {{ui:xyplot.axis.scheduler}} | 從清單中選擇 |
| {{ui:xyplot.axis.model}} | 從清單中選擇相同系列的模型 |
| {{ui:xyplot.axis.prompt}} | 每行寫 1 個。會加到提示詞中 |

規則如下。

- 1 個設定可以放入的值最多 8 個。表格全部最多 36 張。
- 橫向與縱向，不能選擇相同的設定。
- 所有的圖像都用 **相同的種子** 來畫（選擇了改變種子的設定時除外）。差異只來自改變的設定。
- 設定取自當時生成分頁的表單。表單不會被改寫。
- 無法製作的圖像，在表格中會變成 ×。其他的圖像仍會做出表格。

做好的表格，會以 1 張圖像的形式儲存在圖庫。用 **{{ui:xyplot.open}}**，可以顯示在檢視器中。成為表格來源的一張張圖像，也會留在圖庫中。

> 張數越多，就越花時間。36 張就需要 36 次的生成。建議一開始先用 2 到 3 個值試試。

## 從草稿中挑選

![草稿分頁中，排列著畫到一半的候選圖](shot:drafts)

依種子不同，圖像會有很大的變化。草稿是用許多種子只畫「到一半」，再只把喜歡的構圖畫到最後的功能。可以節省時間。

開啟 **{{ui:app.tabs.generate}}** 分頁中央的 **{{ui:app.views.drafts}}** 分頁。

1. 選擇 **{{ui:drafts.model}}**。一開始，會選擇生成分頁的模型。
2. 決定 **{{ui:drafts.count}}**（1 到 24 張。一開始是 8 張）。
3. 決定 **{{ui:drafts.position}}**（25 到 60%。一開始是 35%）。越小越快完成，但畫面會比較粗糙。
4. 按下 **{{ui:drafts.start}}**。

草稿的圖像，會依完成的順序排列。提示詞等設定，使用的是生成分頁的內容。

點擊圖像就會選取（再點擊一次就會取消）。連按兩下，可以在檢視器中放大檢視。星號按鈕（**{{ui:drafts.keep}}**）與 ✕（**{{ui:drafts.reject}}**）是自己用的標記。按下右下方的「{{ui:manual.drafts.finish}} ○ 張」按鈕（○ 是選取的張數），選取的圖像就會畫到最後。想重新選取時，請按 **{{ui:drafts.clearSelection}}**。

畫到最後的圖像，會與一般的生成一樣進入圖庫，草稿上方會顯示「{{ui:drafts.badge.finished}}」。有失敗的草稿時，會出現「{{ui:manual.drafts.retry}}失敗的 ○ 張」按鈕。

> 雖說是「{{ui:manual.drafts.finish}}」，但並不是從中途重新開始。而是用相同的種子，從頭到尾重新畫過。因此，到完成所需的時間，與一般的生成相同。會做出你在草稿中看到的構圖的圖像。

> 草稿只能用在以文字製作圖像的生成。如果放入了參考圖像等，會出現訊息而無法開始。草稿的圖像，不會排列在圖庫的清單中。

草稿會依「開始的順序」排列在上方的分頁。不需要時，用分頁的 ✕ 關閉。

## 批次處理

![批次處理的對話框](shot:batch)

去除背景或放大，可以一次套用到選取的多張圖像。

1. 在圖庫中，選取多張圖像（按住 `Ctrl` 並點擊，或按住 `Shift` 並點擊來選取範圍）。
2. 在選取的圖像上按右鍵，選擇 **{{ui:gallery.menu.batch}}**。
3. 選擇處理。
   - **{{ui:batch.op.removeBackground.title}}**：將背景變透明。需要擴充功能 ComfyUI-RMBG。沒有安裝時，會出現安裝的按鈕。
   - **{{ui:batch.op.upscale.title}}**：用放大用的模型變大。沒有模型時，請從[模型](08-models.md)的畫面安裝。
4. 按下 **{{ui:batch.run}}**。

每 1 張圖像，都會各有 1 個項目進入佇列。進度可以在 **{{ui:app.tabs.queue}}** 分頁查看。結果會以新圖像的形式，放進與原圖相同的看板。原圖不會改變。

想要一邊改變設定，一邊仔細處理 1 張圖像時，請使用這一章的個別功能（[移除背景](#移除背景)）。要把 1 張圖像變大時，也可以使用[放大](06-upscaling-workflows.md)的分頁。
