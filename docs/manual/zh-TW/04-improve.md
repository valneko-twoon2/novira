# 修飾與沿用圖像

這一章整理了在做好的圖像上想「再稍微修改一下」、「想用同樣的氛圍再多做幾張」、「想在別的場景也使用這個角色」時的功能。

大部分的功能，都是從檢視器（放大檢視圖像的畫面）上方工具列的按鈕，或是在圖庫的圖像上按右鍵的選單來呼叫。工具列的按鈕在滑鼠移上去時會顯示名稱。檢視器與圖庫的基本操作，請見[圖庫](03-gallery.md)。

## 該從哪裡使用什麼

| 想做的事 | 使用的功能 | 另外需要的東西 |
|---|---|---|
| 用相同的設定再多做幾張，或稍微改變後重新製作 | **{{ui:gallery.derive.menu}}** | 已安裝原圖所使用的模型 |
| 去掉背景，只留下人物或物體 | **{{ui:cutout.menu}}** | 擴充功能 ComfyUI-RMBG |
| 去除透明的邊緣 | **{{ui:gallery.menu.trim}}**（僅限右鍵） | 無 |
| 塗抹圖像的一部分，進行消除、去背或重畫 | **{{ui:gallery.menu.segment}}** | 消除時需要擴充功能 comfyui-inpaint-nodes |
| 修好畫得很小而崩壞的臉 | **{{ui:facefix.menu}}** | 擴充功能 ComfyUI-Impact-Pack 與 ComfyUI-Impact-Subpack |
| 將圖像變成黑白的漫畫稿 | **{{ui:gallery.manga.menu}}**（僅限檢視器的工具列） | 擴充功能 ComfyUI-MangaScreen |
| 從圖像寫出提示詞 | **{{ui:caption.menu}}** | 擴充功能 ComfyUI-Florence2 |
| 登錄角色，並在其他圖像中也使用 | **{{ui:character.menu}}** | 參考圖像用的擴充功能（IP-Adapter） |
| 將改變設定的圖像並排在 1 張表中 | **{{ui:xyplot.menu}}** | 無 |
| 從畫到一半的候選圖中挑選 | **{{ui:app.views.drafts}}** 分頁 | 無 |
| 對許多張圖像套用相同的處理 | **{{ui:gallery.menu.batch}}**（選取多張後按右鍵） | 依處理而異 |

## 修飾工具的使用方法

{{ui:facefix.menu}}、{{ui:cutout.menu}}、{{ui:caption.menu}}、{{ui:canvas.poseFromImage.menu}} 這 4 個，集中在圖庫圖像右鍵選單的 **{{ui:gallery.tools.heading}}** 之下。全部都是在檢視器上方展開的橫條中使用。圖像會保持顯示在檢視器中，所以可以一邊放大、移動一邊確認。

- 選擇項目後，會立即以上次的設定執行。檢視器會顯示該圖像，橫條上會顯示進度。
- 按下項目右側的齒輪按鈕，不會執行，而是在橫條中開啟設定。更改設定後按下 **{{ui:gallery.tools.run}}**。更改後的設定，下次執行時也會使用。
- 檢視器工具列的 **{{ui:cutout.menu}}**・**{{ui:facefix.menu}}**・**{{ui:caption.menu}}** 按鈕，也可以開啟橫條的設定。再按一次就會關閉。
- 用橫條左側的按鈕，可以切換到其他工具。
- 結束後，橫條會顯示結果與使用的設定。按下 **{{ui:gallery.tools.edit}}** 會回到設定，更改後可以再執行一次。
- 處理會在佇列中進行。即使關閉橫條，或移到其他圖像、其他畫面，也不會停止。要停止，只能按橫條的 **{{ui:common.cancel}}**。製作圖像的處理結果，即使橫條已經關閉，也會儲存到圖庫。

## 需要擴充功能時

移除背景、修復人臉等功能，是在製作圖像的引擎（ComfyUI）中加入「擴充功能」才能運作。如果尚未安裝擴充功能，橫條會顯示「…需要擴充功能 ○○。」，並排列出安裝的按鈕。

1. 按下 **{{ui:gallery.tools.install}}**。會自動下載並安裝所需的項目。安裝在背景進行，下載的顯示中會呈現進度。即使關閉橫條也不會停止。
2. 安裝完成後，橫條的按鈕會變成 **{{ui:gallery.tools.restart}}**。按下後 ComfyUI 會重新啟動。
3. 重新啟動完成後，該工具就能直接使用。

第一次使用時，擴充功能所使用的模型也會開始下載，所以需要花一些時間。需要連上網路。這個下載會在執行的處理中進行，因此即使關閉橫條也不會停止。

> 擴充功能中，有些安裝時需要花費時間與容量。ComfyUI-Impact-Pack 安裝時需要 Git。在沒有安裝 Git 的電腦上，安裝會失敗。出現訊息時，請閱讀後再處理。

擴充功能也可以從[工作流程](06-upscaling-workflows.md)的「{{ui:workflows.panel.packs}}」分頁安裝。如果不順利，也請參閱[遇到問題時](10-troubleshooting.md)。

## 以相同設定再製作一次（衍生）

![在檢視器的工具列中開啟「衍生」的樣子](shot:derive-menu)

在檢視器中開啟喜歡的圖像，按下工具列的 **{{ui:gallery.derive.menu}}** 按鈕（分支圖示）。在圖庫中，則是在圖像上按右鍵，選擇 **{{ui:gallery.derive.menu}}**。

可以選擇以下 3 種。

| 項目 | 做什麼 |
|---|---|
| 「相同設定、不同種子」（1 張或 4 張） | 提示詞、模型、尺寸等維持不變，只更換種子來繪製。構圖會改變，但氛圍相同。 |
| 「稍微改變後重新製作」（1 張或 4 張） | 以原圖為基礎，用較弱的強度（強度 0.45）重畫。保留構圖與色彩，只有細節會改變。 |
| **{{ui:gallery.derive.custom}}** | 自己決定改變的程度（下一個項目）。 |

選擇後，新的圖像會進入佇列，並排列在與原圖相同的看板。**生成分頁的設定不會被改寫。** 輸入中的提示詞也會維持原樣。

> 想先把設定叫回畫面，再自己修改後製作時，請使用 **{{ui:gallery.menu.remix}}**。衍生是用來「按一個按鈕，就以原本的設定製作」。

### 選擇改變的程度後重新製作

![決定改變程度的對話方塊](shot:derive)

選擇 **{{ui:gallery.derive.custom}}** 後，會開啟對話方塊。

1. 移動滑桿 **{{ui:gallery.derive.dialog.strength}}**。越往左（{{ui:gallery.derive.dialog.close}}）越保留原本的構圖與色彩，越往右（{{ui:gallery.derive.dialog.free}}）越接近另一張圖像。
2. 從 1、2、4、8 中選擇 **{{ui:gallery.derive.dialog.count}}**。
3. 按下 **{{ui:gallery.derive.dialog.create}}**。

參考值是：約 0.25 時會是和原圖幾乎相同的圖像，約 0.75 時則會是角色保留、但構圖大幅改變的圖像。依圖像而異，請多試幾次。滑桿的值只會用於那 1 次。

### 會沿用與不會沿用的內容

- 會沿用：提示詞、反向提示詞、模型、LoRA、尺寸、步數、CFG 比例、排程器等，製作圖像時的設定。
- 參考圖像與控制圖層也會與圖像一起記住，所以會直接使用。不過，如果那張圖像已從圖庫刪除，就無法製作。原因會顯示在通知中。
- 不會沿用：遮罩、區域引導、草稿的設定。在這項功能出現之前製作的圖像，即使曾使用參考圖像等，因為沒有記住，所以也無法沿用。無法沿用時，會以通知告知。

以下情況，按鈕無法按下，或是會出現通知而無法製作。

- 不是用文字製作的圖像（包含圖像轉圖像、局部重繪、外延繪製）時。放大的圖像、影片、語音等不在對象之內。
- 沒有安裝原圖所使用的模型時。會出現附有模型名稱的通知。

## 移除背景

![在檢視器的橫條中移除背景，並與原圖比較的樣子](shot:cutout)

會自動辨識畫面中的物體，製作去除背景的圖像。不需要用點選來指定。

1. 在圖庫的圖像上按右鍵，選擇 **{{ui:gallery.tools.heading}}** 的 **{{ui:cutout.menu}}**，就會以上次的設定立即執行。想先更改設定時，用項目右側的齒輪，或檢視器工具列的剪刀按鈕開啟橫條。
2. 在橫條中，視需要更改設定。
   - **{{ui:cutout.model}}**: 通常維持原樣即可。
   - **{{ui:cutout.sensitivity}}**: 調得越低，連邊界模糊的部分也會保留。
   - **{{ui:cutout.edge}}**: 正值會擴大輪廓，負值會削減。
   - **{{ui:cutout.background}}**: 選擇 **{{ui:cutout.background.alpha}}** 或 **{{ui:cutout.background.white}}**。
3. 按下 **{{ui:gallery.tools.run}}**。

做好的圖像，會作為新的圖像儲存在與原圖相同的看板。**原圖會保持原樣。** 檢視器會變成將做好的圖像與原圖並列比較的顯示。如果對結果不滿意，按下 **{{ui:gallery.tools.edit}}** 更改設定，再執行一次。

白色背景適合之後用來作為[角色](#登錄並使用角色)的參考圖像。背景的顏色比較不容易轉移到新製作的圖像上。

## 去除透明的邊緣

背景透明的圖像，圖像外側會留下透明的邊緣。使用 **{{ui:gallery.menu.trim}}**，會將圖像裁切到剛好貼合有內容的部分，並另存為新的透明圖像。作為貼圖或素材使用時很方便。

- 在圖庫的圖像上按右鍵選擇。剛移除背景之後，從橫條的 **{{ui:cutout.trim}}**（只有在將背景設為透明時才會出現）也能做同樣的事。
- 淡到幾乎看不見的陰影，會被當作邊緣而裁掉。
- 透明部分沒有延伸到圖像邊緣的圖像，會顯示「沒有可裁切的邊緣」，且不會儲存任何東西。整面都是透明的圖像也無法裁切。

## 選取範圍來修飾

用筆刷塗抹想修改的部分來選取。圖像會在[畫布](05-canvas.md)中開啟，所以可以一邊放大、移動，一邊細緻地塗抹。

1. 在檢視器中開啟圖像，按下 **{{ui:gallery.menu.segment}}**（也可以從圖庫的右鍵選取）。
2. 畫布會在放入該圖像，並選取空白 **{{ui:canvas.add.inpaint}}** 的狀態下開啟。工具是 **{{ui:canvas.tool.brush}}**。
3. 塗抹想修改的部分。塗過頭的地方用 **{{ui:canvas.tool.eraser}}** 削掉。想選取其餘部分時，在遮罩上按右鍵，選擇 **{{ui:canvas.entityMenu.invertMask}}**。
4. 選擇對塗抹的部分要做什麼。選擇遮罩的列後，其下方會出現輸入欄與按鈕（消除與去背，在遮罩的右鍵選單中也有）。

| 想做的事 | 操作 | 需要的東西 |
|---|---|---|
| 與周圍的圖像融合並消除 | **{{ui:canvas.partFix.erase}}**。結果會暫放在畫布上，請選擇 **{{ui:canvas.staging.accept}}** 或捨棄。 | 擴充功能 comfyui-inpaint-nodes。有模型 LaMa（約 200MB）時會消除得很自然。沒有也能簡易地消除。 |
| 只將塗抹的部分儲存為透明的圖像 | **{{ui:canvas.partFix.cutOutAction}}** | 無 |
| 用文字指示重畫 | 在輸入欄寫下像「藍色緞帶」這樣想重畫的內容，按下 **{{ui:canvas.partFix.redraw}}**。會以生成分頁的模型與設定，只重畫塗抹的部分。輸入欄為空白時，會使用生成分頁的提示詞。生成分頁的提示詞不會被改寫。結果會暫放，請選擇 **{{ui:canvas.staging.accept}}** 或捨棄。 | 圖像用的模型 |
| 加上馬賽克 | 不使用遮罩，直接用 **{{ui:canvas.tool.mosaic}}** 工具塗抹。 | 無 |

原圖不會改變。去背的結果會作為新的圖像儲存到圖庫。

## 修復人臉

![在檢視器的橫條中開啟修復人臉設定的樣子](shot:facefix)

在遠景的圖像中，畫得很小的臉常常會崩壞。**{{ui:facefix.menu}}** 會自動找出圖像中的臉，只以高解析度重畫臉部，再放回原圖。臉部以外不會改變。

1. 在圖庫的圖像上按右鍵，選擇 **{{ui:gallery.tools.heading}}** 的 **{{ui:facefix.menu}}**，就會立即執行。想先確認設定再執行時，用項目右側的齒輪，或檢視器工具列的 **{{ui:facefix.menu}}** 按鈕開啟橫條。
2. 只有第一次，需要擴充功能 ComfyUI-Impact-Pack 與 ComfyUI-Impact-Subpack。請用橫條的 **{{ui:gallery.tools.install}}** 安裝，再按下 **{{ui:gallery.tools.restart}}**。尋找人臉的模型，由 Subpack 自行準備。
3. 確認設定。
   - **{{ui:facefix.model}}**: 會選取原圖所使用的模型。
   - **{{ui:facefix.detector}}**: 用來尋找人臉的模型。通常維持原樣即可。
   - **{{ui:facefix.prompt}}**: 已填入原圖的提示詞。加上臉部的特徵會有效果。
   - **{{ui:facefix.strength}}**: 越低越接近原本的臉，越高則重畫得越多。
   - **{{ui:facefix.sensitivity}}**: 調高時只找出確定的臉，調低時連小臉或側臉也會找出來。不過也更容易找到不是臉的東西。
4. 按下 **{{ui:gallery.tools.run}}**。

結果會儲存到與原圖相同的看板，檢視器會變成與原圖並列比較的顯示。如果不喜歡，按下 **{{ui:gallery.tools.edit}}** 更改設定，再執行一次。模型與重畫的內容，只有在對同一張圖像使用的期間會被記住。

> 使用 LoRA 製作的圖像，會在沒有 LoRA 的狀態下重畫。因此，只有臉部的畫風可能看起來有些不同。

> 出現「找不到尋找人臉的模型（YOLO）」時，請重新啟動 ComfyUI，或重新安裝擴充功能。

## 將圖像完成為漫畫稿

檢視器工具列的 **{{ui:gallery.manga.menu}}**，會將開啟的圖像變成清楚保留線條的黑白漫畫稿。陰影會變成平塗的面與真正的網點，黑色塗滿區域中的主要線條會細細地留白。繪製圖像時，永遠都是做出一般的彩色圖像，這個完稿是之後對喜歡的圖像進行的操作。

1. 在檢視器中開啟圖像，按下 **{{ui:gallery.manga.menu}}**。左側會顯示原圖。
2. 只有第一次，需要擴充功能 ComfyUI-MangaScreen。尚未安裝時會顯示說明，請按下 **{{ui:gallery.manga.installPack}}**，安裝後再按下 **{{ui:gallery.manga.restartEngine}}**。在安裝完成之前，下方的按鈕無法按下。
3. 視需要更改數值（會為下次記住）。
   - **{{ui:gallery.manga.screenLines}}**：橫向排列的網點行數。120 偏粗，200 為標準，300 偏細。
   - **{{ui:gallery.manga.whitePoint}}**：比這個亮的地方會變成紙的白色。調低時，皮膚或明亮頭髮的網點會消失。
   - **{{ui:gallery.manga.blackPoint}}**：比這個暗的地方會變成黑色塗滿。調高時，黑色的面會增加。
   - **{{ui:gallery.manga.gradation}}**：將平滑變深的陰影，不分段而是用網點的大小來表現。設為 0 時，只會有平塗的面。
   - **{{ui:gallery.manga.whiteLines}}**：將黑色塗滿區域中的線條留白的量。0 為停用。
   用 **{{ui:gallery.manga.reset}}** 可以恢復所有數值。
4. 按下 **{{ui:gallery.manga.tryRun}}**，右側會顯示結果，可以與原圖比較。僅試做的話不會儲存任何東西。
5. 滿意後按下 **{{ui:gallery.manga.save}}**。完成的圖像會作為新的圖像，儲存到與原圖相同的看板，原圖不會改變。用 **{{ui:gallery.manga.open}}** 可以開啟該圖像。

儲存時，會以目前看到的數值重新完稿，所以和試做一樣需要花時間。

## 從圖像產生提示詞

![在檢視器的橫條中，查看圖像並寫出標籤的樣子](shot:caption)

查看圖像，寫出用來畫出該圖像的提示詞（標籤或句子）。想製作接近喜歡的圖像的作品，或不知道提示詞怎麼寫時使用。

1. 在圖庫的圖像上按右鍵，選擇 **{{ui:gallery.tools.heading}}** 的 **{{ui:caption.menu}}**，就會立即寫出。生成分頁提示詞欄上方的 **{{ui:caption.fromPrompt}}** 按鈕也是一樣。這個按鈕會使用圖庫中選取的圖像，沒有選取時則會開啟選擇圖像檔案的畫面。也可以將圖庫的圖像或電腦裡的圖像檔案拖放到這個按鈕上使用。
2. 想改變寫法時，按下橫條的 **{{ui:gallery.tools.edit}}**，在 **{{ui:caption.style}}** 選擇 **{{ui:caption.style.tags}}** 或 **{{ui:caption.style.sentence}}**。
3. 按下 **{{ui:gallery.tools.run}}**。
4. 產生的詞彙，可以直接在橫條中當場修改。按下 **{{ui:caption.replace}}**、**{{ui:caption.append}}**、**{{ui:caption.copy}}** 其中之一。

取代的目標與加入的目標，是生成分頁的「{{ui:params.prompt.positive}}」。這項功能不會讓圖庫中增加圖像。

> 這項功能需要擴充功能 ComfyUI-Florence2。尚未安裝時，可以從橫條安裝（請見本章的「需要擴充功能時」）。第一次使用時，會開始下載用來轉換成文字的模型（Florence-2 PromptGen）。

## 登錄並使用角色

![登錄為角色的對話方塊](shot:character)

事先登錄喜歡的角色圖像，之後在別的場景的圖像中，也能畫得接近同一個角色。登錄的有以下 3 項。

- 參考圖像（同一個角色的圖像。幾張都可以）
- 外觀的詞彙（髮色、眼睛的顏色、服裝等。會加在提示詞的最前面）
- 相似的強度

### 登錄

1. 在圖庫中選取想登錄的圖像。有多張時，按住 `Ctrl` 點選。
2. 選擇檢視器的 **{{ui:character.menu}}** 按鈕，或右鍵選單的 **{{ui:character.menu}}**。開啟生成分頁的 **{{ui:character.row.choose}}** 欄位後，清單的最下方有 **{{ui:character.row.register}}**，也可以從這裡開啟。
3. 輸入 **{{ui:character.name}}** 與 **{{ui:character.tags}}**。寫下不希望改變的特徵（棕色頭髮、白色襯衫、藍色裙子等）。
4. 決定 **{{ui:character.weight}}**。調得越高越像參考圖像，但場景與構圖的自由度會降低。
5. 按下 **{{ui:character.save}}**。

使用 **{{ui:character.addSelected}}**，之後可以將在圖庫中選取的圖像，加入參考圖像。**{{ui:character.removePicture}}** 是圖像右上角的 ✕。

開啟 **{{ui:character.whiteBg}}** 後，會製作將登錄圖像的背景換成白色的圖像，並以它作為參考圖像。這樣可以避免背景的顏色轉移到生成的圖像上。原圖會保留，白色背景的圖像會另外新儲存。尚未安裝用於移除背景的擴充功能 ComfyUI-RMBG 時，這個開關無法使用，會直接使用原圖。

### 使用

1. 在 **{{ui:app.tabs.generate}}** 分頁（或[畫布](05-canvas.md)分頁）的左側面板，開啟 **{{ui:character.row.choose}}**，選擇想使用的角色。
2. 角色的參考圖像會放進「{{ui:params.refImage.sectionLabel}}」欄，外觀的詞彙會加在提示詞的最前面。
3. 像平常一樣生成。

使用時，應用程式有時會自動調整。會以通知告知。

- 使用參考圖像時，CFG 比例高容易使圖像過曝，所以若 CFG 比例高於 5，會降到 4.5。
- 參考圖像總共最多 8 張。與其他參考圖像合計超過 8 張時，會從最前面的圖像開始使用。
- 參考圖像有多張時，為了避免重疊而變得太濃，每張的強度會自動降低。
- 已從圖庫刪除的圖像無法使用。全部都被刪除時，就無法使用該角色。

要修改或刪除已登錄的角色，請使用清單項目的「…」按鈕。

> 這是讓圖像「接近」同一個角色的功能，並不會變成完全相同的臉。髮型、顏色、服裝等容易保留，但五官會稍有變化。想保留的特徵，寫在外觀的詞彙中會有效果。

> 要使用參考圖像，需要擴充功能 ComfyUI_IPAdapter_plus 與參考圖像用的模型。尚未安裝時，可以從生成分頁的參考圖像欄安裝。關於模型，請見[模型](08-models.md)這一章。

## 為角色選擇 LoRA

在角色的編輯對話方塊中，可以從 **{{ui:lora.section}}** 選擇 LoRA。選擇後，可以開關 **{{ui:lora.use}}**，並更改 **{{ui:lora.weight}}**，使用角色時，LoRA 與觸發詞（trigger word）會放進提示詞。LoRA 的訓練，是用另一個應用程式 novira-train 進行。

## 用對比網格比較設定

![對比網格的對話方塊](shot:xyplot)

改變 CFG 比例或步數，圖像會有什麼不同？這是把結果做成 1 張表來比較的功能。

1. 在生成分頁，像平常一樣決定提示詞與模型。
2. 按下 **{{ui:params.invoke.invoke}}** 按鈕右側的「▼」，選擇 **{{ui:xyplot.menu}}**。
3. 用 **{{ui:xyplot.x}}** 與 **{{ui:xyplot.y}}** 選擇要改變的設定。只選其中一邊也能製作。
4. 輸入數值。數字用逗號隔開並排（例：3, 5, 7）。
5. 按下 **{{ui:xyplot.run}}**。

對話方塊的下方，會像「將製作 3 欄 × 2 列 = 6 張。」這樣顯示要製作的張數。

可以改變的設定如下。

| 設定 | 輸入方式 |
|---|---|
| {{ui:xyplot.axis.cfgScale}} | 數字（1 到 30） |
| {{ui:xyplot.axis.steps}} | 整數（1 到 150） |
| {{ui:xyplot.axis.seed}} | 整數 |
| {{ui:xyplot.axis.strength}} | 數字（0.05 到 1）。只有在以圖像轉圖像製作時才有效。 |
| {{ui:xyplot.axis.scheduler}} | 從清單中選擇 |
| {{ui:xyplot.axis.model}} | 從清單中選擇同系列的模型 |
| {{ui:xyplot.axis.prompt}} | 每行寫 1 個。會加到提示詞中 |

規則如下。

- 1 個設定最多可輸入 8 個值。表格總共最多 36 張。
- 橫向與縱向，不能選相同的設定。
- 所有圖像都以**相同的種子**繪製（選擇了改變種子的設定時除外）。差異只來自改變的設定。
- 設定取自當時生成分頁的表單。表單不會被改寫。
- 無法製作的圖像，在表中會變成 ×。其他圖像仍會製作成表。

做好的表，會作為 1 張圖像儲存到圖庫。用 **{{ui:xyplot.open}}** 可以顯示在檢視器中。作為表格來源的每一張圖像，也會留在圖庫中。

> 張數多，就會花上相應的時間。36 張就需要 36 次的生成。建議一開始先用 2 到 3 個值來嘗試。

## 從草稿中挑選

![草稿分頁中並排著畫到一半的候選圖](shot:drafts)

依種子不同，圖像會有很大的變化。草稿是用許多種子只畫「到一半」，再只把喜歡的構圖畫到最後的功能。可以節省時間。

開啟 **{{ui:app.tabs.generate}}** 分頁中央的 **{{ui:app.views.drafts}}** 分頁。

1. 選擇 **{{ui:drafts.model}}**。一開始會選取生成分頁的模型。在生成分頁可以選擇的圖像模型，除了 SDXL 與 SD1.X 之外，Anima、Flux、FLUX.2、Z-Image 等只有本體的模型也可以選擇。編輯用的模型（Flux Fill、Flux Kontext、Qwen-Image-Edit）是用來修改原圖的，所以不在清單中，如果已選取，下方會顯示其名稱。
2. 決定 **{{ui:drafts.count}}**（1 到 24 張。一開始是 4 張，可以在設定的 **{{ui:settings.draftCount.label}}** 中更改）。張數與位置，即使切換到其他畫面，在關閉應用程式之前，都會維持在畫面上決定的值。
3. 決定 **{{ui:drafts.position}}**（25 到 60%。一開始是 35%）。越小越快完成，但圖像會比較粗糙。
4. 按下 **{{ui:drafts.start}}**。

草稿的圖像，會依完成的順序排列。提示詞等設定，會使用生成分頁的設定。

點選圖像即可選取（再點一次就會取消）。連按兩下，可以在檢視器中放大查看。星號按鈕（**{{ui:drafts.keep}}**）與 ✕（**{{ui:drafts.reject}}**）是給自己用的記號。按下右下方的「{{ui:manual.drafts.finish}} ○ 張」按鈕（○ 是選取的張數），選取的圖像就會畫到最後。想重新選取時，按下 **{{ui:drafts.clearSelection}}**。

畫到最後的圖像，會和一般的生成一樣進入圖庫，草稿上方會顯示「{{ui:drafts.badge.finished}}」。有失敗的草稿時，會出現「{{ui:manual.drafts.retry}}失敗 ○ 張」的按鈕。

> 雖說是「{{ui:manual.drafts.finish}}」，但並不是從中途繼續。而是用相同的種子，從頭到尾重新繪製。因此，直到完成所需的時間，與一般的生成相同。會做出和草稿中看到的構圖相同的圖像。

> 草稿可用於以文字製作圖像的生成，以及在 **{{ui:params.i2i.title}}** 放入圖像的重畫。在 {{ui:params.i2i.title}} 中，會依 **{{ui:params.image.strength}}** 在實際要畫的步數中，畫到位置所指的比例為止。草稿的圖像不會排在圖庫的清單中。

草稿會依「開始的順序」排列在上方的分頁。排在分頁的只有最新的 5 個。所有的草稿，都可以在分頁左側「記錄」按鈕所開啟的 **{{ui:drafts.history.title}}** 畫面中查看。

- 在左側欄選擇期間（{{ui:drafts.history.period.today}}・{{ui:drafts.history.period.yesterday}}・{{ui:drafts.history.period.week}}・{{ui:drafts.history.period.older}}）與模型，就只會排列對應的草稿。上方的欄位可以用提示詞或模型名稱的詞彙搜尋。
- 草稿依日期分開，並排列當時畫的圖像、時間、尺寸，以及草稿與完成的張數。
- 用 **{{ui:drafts.history.open}}** 開啟該草稿，用 **{{ui:drafts.history.reuse}}** 把該草稿的設定放回生成的欄位。

不需要時，用分頁或記錄的 ✕ 關閉。也可以用記錄畫面的「{{ui:drafts.closeOlder}}」，一次關閉分頁中沒有的舊草稿。

## 批次處理

![批次處理的對話方塊](shot:batch)

移除背景或放大，可以一次套用在選取的多張圖像上。

1. 在圖庫中選取多張圖像（按住 `Ctrl` 點選，或按住 `Shift` 點選來選取範圍）。
2. 在所選的圖像上按右鍵，選擇 **{{ui:gallery.menu.batch}}**。
3. 選擇處理。
   - **{{ui:batch.op.removeBackground.title}}**: 將背景變透明。需要擴充功能 ComfyUI-RMBG。尚未安裝時，會出現安裝的按鈕。
   - **{{ui:batch.op.upscale.title}}**: 用放大用的模型變大。沒有模型時，請從[模型](08-models.md)畫面安裝。
4. 按下 **{{ui:batch.run}}**。

每 1 張圖像，會各自放入佇列 1 個。進度可以在 **{{ui:app.tabs.queue}}** 分頁查看。結果會作為新的圖像，放進與原圖相同的看板。原圖不會改變。

想針對 1 張圖像，一邊更改設定一邊仔細處理時，請使用本章個別的功能（[移除背景](#移除背景)）。要放大 1 張圖像時，也可以使用[放大](06-upscaling-workflows.md)分頁。
