# Создание изображений

В этом разделе описано, как создавать картинки на вкладке **{{ui:app.tabs.generate}}**.
Об устройстве экрана рассказано в разделе [Начало работы](01-start.md), а о просмотре и упорядочивании готовых картинок — в разделе [Галерея и просмотр](03-gallery.md).

Порядок действий всегда один и тот же.

1. Выбрать модель
2. Написать промпт
3. При необходимости настроить размер, сид и другие параметры
4. Нажать **{{ui:params.invoke.invoke}}**

Рисование начинается не в момент нажатия: сначала задание попадает в «{{ui:app.tabs.queue}}» (ряд ожидающих). Когда подходит очередь, картинки рисуются по одной.

## Написание промпта

![Вкладка генерации с текстом в промпте и зафиксированным сидом](shot:generate-prompt)

В блоке «{{ui:params.prompt.title}}» на левой панели есть два поля.

- **{{ui:params.prompt.positive}}**: здесь пишется, что нужно нарисовать.
- **{{ui:params.prompt.negative}}**: здесь пишется, чего в картинке быть не должно. Например, `blurry, watermark` (размытие, водяные знаки). Генерировать можно и при пустом поле.

Несколько ориентиров для написания.

- Слова или короткие фразы перечисляются через запятую (`,`).
- Многие модели лучше выполняют запросы на английском. Если в описании модели указан способ написания, нужно следовать ему.
- Важные слова ставятся ближе к началу.

Маленькие кнопки над полями работают так.

| Кнопка | Действие |
|---|---|
| **{{ui:params.prompt.recommended}}** | Добавляет слова качества, подходящие выбранной модели (например, `masterpiece, best quality`), в начало поля «{{ui:params.prompt.positive}}», а часто используемые нежелательные слова — в конец поля «{{ui:params.prompt.negative}}». Уже имеющиеся слова повторно не добавляются |
| **{{ui:params.prompt.expand}}** | Позволяет править позитивный и негативный промпты в большом окне, где они стоят рядом |
| **{{ui:params.promptBook.open}}** | Открывает список слов с их значениями (описан ниже) |
| **{{ui:caption.fromPrompt}}** | По рисунку выписывает слова, которые можно использовать в промпте. Можно также перетащить на эту кнопку рисунок из галереи или файл изображения с компьютера (подробнее в разделе [Доработка изображений](04-improve.md)) |
| «Пресет» у каждого поля | Сохраняет и вызывает только текст промпта (описан ниже) |

### Число токенов

Надпись «0 / 77 токенов» над полем показывает примерный объём написанного.
Токен — единица, на которые модель делит текст при чтении. При превышении верхнего предела число окрашивается в предупреждающий цвет. У некоторых моделей часть текста сверх предела может действовать слабее.
Число приблизительное, не точное.

### Сразу несколько вариантов `{red|blue}`

Если в позитивном поле написать варианты в фигурных скобках, разделив их вертикальной чертой (`|`), например `{red|blue}`, для каждого варианта будет создана отдельная картинка.

- Запись `a {red|blue} flower` даёт два варианта: `a red flower` и `a blue flower`.
- Если скобок две и больше, получаются все сочетания. Запись `a {red|blue} {cat|dog}` даёт четыре варианта.
- Внутри фигурных скобок можно вкладывать другие фигурные скобки.
- Чтобы использовать саму фигурную скобку как символ, перед ней ставится `\` (`\{`).
- Число сочетаний не превышает 100.

Если «{{ui:params.invoke.iterations}}» (описано ниже) равно двум или больше, создаётся число картинок, равное числу сочетаний, умноженному на количество. Например, при двух вариантах и количестве 3 получится 6 картинок.
Такая запись работает только в позитивном поле. В негативном поле фигурные скобки считаются обычными символами.

Во что развернётся запись, можно проверить кнопкой **{{ui:params.prompt.dynamicPreview}}** (значок `{ }`) над позитивным полем. После нажатия показывается список сочетаний.

### Вайлдкарды `__имя__`

![Окно вайлдкардов: слева перечень списков, справа название выбранного списка и его записи](shot:wildcards)

Если в позитивном поле написать `__имя__` (по два подчёркивания до и после имени), вместо этой записи будет подставляться по одной записи из списка «{{ui:params.wildcards.title}}» с таким именем. Если часто используемые варианты собрать в список, не придётся каждый раз писать `{red|blue}`.

- Запись `1girl, __hair-color__` создаёт столько промптов, сколько записей в списке hair-color.
- В записях тоже можно писать `{a|b}` и другие вайлдкарды. Вложенность вайлдкардов — не более 6 уровней.
- Верхний предел числа сочетаний (100) такой же, как для `{ }`.
- Если указано несуществующее имя, список без записей или список, который использует сам себя, кнопка **{{ui:params.invoke.invoke}}** не нажимается, а причина показывается под ней.

Списки открываются кнопкой **{{ui:params.wildcards.open}}** в самом низу окна кнопки **{{ui:params.prompt.dynamicPreview}}**. Изначально есть три списка: hair-color (цвет волос), expression (выражение лица) и time-of-day (время суток).

| Действие | Что происходит |
|---|---|
| **{{ui:params.wildcards.new}}** | Добавляется пустой список |
| Поле «{{ui:params.wildcards.name}}» | Меняет имя списка. Допустимы буквы, цифры, `-` и `_`, а первым и последним символом должна быть буква или цифра |
| Поле «{{ui:params.wildcards.entries}}» | Одна запись в строке. Пустые строки и строки, начинающиеся с `#`, записями не считаются |
| **{{ui:params.wildcards.import}}** / **{{ui:params.wildcards.export}}** | Читает и записывает один список как файл .txt с одной записью в строке. Прочитанный файл становится новым списком с именем по имени файла |
| **{{ui:common.delete}}** | Удаляет выбранный список |

Списки хранятся внутри этого приложения, на том компьютере, который вы используете.

### Случайный выбор

Если сочетаний слишком много, в окне кнопки **{{ui:params.prompt.dynamicPreview}}** переключите режим «{{ui:params.prompt.dynamicMode}}».

- **{{ui:params.prompt.modeCombinatorial}}** (по умолчанию): для каждого сочетания создаётся столько картинок, сколько указано в количестве.
- **{{ui:params.prompt.modeRandom}}**: создаётся столько картинок, сколько указано в количестве, и для каждой выбирается одно сочетание. Выбор определяется сидом этой картинки, поэтому при повторном рисовании с тем же сидом получится тот же промпт.

В любом режиме вместе с готовой картинкой сохраняется фактически использованный промпт.

## Сид

Картинка создаётся из числа, которое называется «{{ui:params.seed.label}}». При одинаковых сиде и настройках получается одинаковая картинка.

В строке «{{ui:params.seed.label}}» в верхней части левой панели есть две кнопки.

- **{{ui:params.seed.random}}** (кубик): при каждой генерации используется новый сид. Каждый раз получается другая картинка. Изначально включён этот вариант.
- **{{ui:params.seed.fixed}}** (замок): рисование идёт с текущим сидом. Сколько бы раз ни создавалась картинка с теми же настройками, она будет одинаковой. Удобно, когда нужно увидеть, как меняется результат от замены одного слова в промпте.

Когда сид зафиксирован, поле с числом сида и кнопка «{{ui:params.seed.shuffle}}» блокируются (чтобы случайно его не изменить).
Чтобы использовать определённое число, нужно ввести его в поле при состоянии «{{ui:params.seed.random}}», а затем переключиться на «{{ui:params.seed.fixed}}».
Чтобы взять сид понравившейся картинки, нужно открыть её в галерее и нажать «{{ui:gallery.menu.useSeed}}»: сид загрузится зафиксированным (см. раздел [Галерея и просмотр](03-gallery.md)).

Если при зафиксированном сиде увеличить количество, у второй и следующих картинок сид будет увеличиваться на 1.

## Выбор модели

![Открытый список моделей, разделённый по семействам: FLUX, SDXL, SD1.X и другие](shot:model-picker)

Модель для рисования выбирается на карточке модели в верхней части левой панели.

1. Нажмите на поле с названием модели.
2. Выберите модель из списка. Список разделён по семействам моделей (FLUX, SDXL, SD1.X и другие). Если моделей много, их можно отфильтровать, введя часть названия в строке поиска вверху.
3. У выбранной модели появится отметка ✓, а картинка на карточке (обложка) сменится.

Кнопкой **{{ui:app.tabs.short.models}}** под списком можно перейти на вкладку {{ui:app.tabs.models}} (управление имеющимися моделями), а кнопкой **{{ui:app.tabs.short.browse}}** — на вкладку {{ui:app.tabs.browse}} (поиск в интернете). О том, как добавлять модели, рассказано в разделе [Подготовка моделей](08-models.md).

Если для модели зарегистрированы рекомендуемые настройки (число шагов, CFG, планировщик, размер), они подставляются автоматически при выборе модели.
При переходе на модель другого семейства LoRA и другие элементы, не подходящие новой модели, снимаются (число снятых показывается в уведомлении).

Кнопка **{{ui:params.profile.title}}** под полем модели показывает список рекомендуемых значений для этой модели. Если текущие настройки отличаются от рекомендуемых, кнопка становится заметного цвета, а кнопкой **{{ui:params.profile.apply}}** значения можно привести к рекомендуемым.

> Если не установлено ни одной модели, в поле написано «{{ui:params.model.noModels}}», и генерация невозможна. Сначала выполните действия из раздела [Подготовка моделей](08-models.md).

## Остальные настройки

Под промптом расположены сгруппированные блоки настроек. Они раскрываются и сворачиваются щелчком.

| Блок | Что в нём |
|---|---|
| **{{ui:params.refImage.sectionLabel}}** (сразу под промптом) | Изображения, под которые подгоняются атмосфера картинки и персонажи (описан ниже) |
| **{{ui:params.image.title}}** | {{ui:params.image.aspect}}, ширина и высота. Также есть кнопки «{{ui:params.image.swap}}», «{{ui:params.image.lock}}» и «{{ui:params.image.optimal}}» |
| **{{ui:params.generation.title}}** | LoRA (небольшие дополнительные модели, добавляющие стиль или персонажа), {{ui:params.generation.scheduler}}, {{ui:params.generation.steps}}, {{ui:params.generation.cfg}} |
| **{{ui:params.hires.title}}** | Вторая генерация: нарисованная картинка увеличивается и рисуется заново (описана ниже) |
| **{{ui:params.advanced.title}}** | {{ui:params.advanced.vae}}, {{ui:params.advanced.clipSkip}}, {{ui:params.advanced.seamless}} (картинки без видимых швов при стыковке) и другое |

Если есть сомнения, всё, кроме размера, можно оставить так, как подставилось при выборе модели.
При наведении курсора на название параметра («{{ui:params.generation.steps}}», «{{ui:params.generation.cfg}}» и т. д.) появляется краткое пояснение. В заголовке блока мелко показано краткое содержание текущих значений.

Чем больше размер, тем больше времени и нагрузки на компьютер. Рекомендуется сначала пробовать небольшой размер, а при хорошем результате увеличить картинку через [апскейл](06-upscaling-workflows.md).

## Исправление высокого разрешения

![Раскрытый блок высокого разрешения, переведённый во включённое состояние](shot:hires-fix)

Если сразу рисовать картинку большого размера, персонажей легко получается двое, а формы нередко искажаются. Функция **{{ui:params.hires.title}}** сначала рисует в заданном размере, затем увеличивает результат и рисует его заново с теми же сидом и настройками. За одну генерацию получается крупная картинка с проработанными деталями. Этот блок есть на вкладках {{ui:app.tabs.generate}} и {{ui:app.tabs.comic}}.

- **{{ui:params.hires.enable}}**: чтобы использовать функцию, её нужно включить.
- **{{ui:params.hires.scale}}**: от 1,25 до 2 раз. Итоговый размер показан в заголовке блока и в самой нижней строке.
- **{{ui:params.hires.strength}}**: от 0,2 до 0,75. При низком значении первая картинка почти сохраняется, при высоком — перерисовывается сильнее. Изначально 0,45.
- **{{ui:params.hires.method}}**: **{{ui:params.hires.methodSmooth}}** увеличивает без использования модели. Если установлена модель апскейла, которая используется на вкладке {{ui:app.tabs.upscaling}}, её тоже можно выбрать.
- **{{ui:params.hires.steps}}**: число шагов второго прохода. При значении 0 рисование идёт с тем же числом, что и в первый раз.

Времени уходит столько, сколько нужно на два рисования, потому что картинка рисуется дважды. Ход выполнения считается сразу по обоим проходам. LoRA и референсы используются и во второй раз.

Если итоговый размер значительно превышает размер, удобный для модели (длинная сторона около 2048 px у SDXL и около 1536 px у SD1.X), под кнопкой генерации появляется предупреждение. Генерировать можно, но если картинка исказилась, нужно уменьшить масштаб.

Вместе с картинкой сохраняются размер первого прохода и значения блока «{{ui:params.hires.title}}». Если загрузить её через «{{ui:gallery.menu.useAll}}» в галерее, блок «{{ui:params.hires.title}}» тоже заполнится так же.

## Итерации и кнопка генерации

![Меню, открытое стрелкой рядом с кнопкой генерации](shot:invoke-menu)

В верхней части левой панели собраны действия генерации.

- **{{ui:params.invoke.invoke}}** (синяя кнопка): добавляет задание в конец очереди и запускает генерацию. Можно также нажать `Ctrl+Enter`.
- **Число рядом с ×**: сколько картинок создаётся за одно действие. При значении «3» создаются 3 картинки.
- **Красная кнопка ×**: отменяет то, что рисуется сейчас.
- **∨** справа от каждой кнопки: меню остальных действий.

Если нажать нельзя, кнопка становится серой, а причина (например, не выбрана модель) показывается в строке под ней. При наведении курсора на кнопку можно увидеть список причин.
Пока идёт рисование, кнопка меняется на «{{ui:params.invoke.generating}}» и показывает ход выполнения (%) и число ожидающих в очереди.

### Меню ∨ кнопки генерации

- **{{ui:params.invoke.addBack}}** (`Ctrl+Enter`): задания рисуются в порядке нажатия. Это обычная генерация.
- **{{ui:params.invoke.addFront}}** (`Ctrl+Shift+Enter`): задание вклинивается в начало ожидающих. Подходит, когда срочно нужно попробовать одну картинку.
- **{{ui:xyplot.menu}}**: на основе текущих настроек в одну таблицу выкладываются картинки, у которых изменены один-два параметра. Рисование идёт с одним и тем же сидом, поэтому различие вызвано только изменёнными параметрами. По горизонтали и вертикали выбираются, например, масштаб CFG, число шагов или модель, вводятся значения, и нажимается **{{ui:xyplot.run}}**.

### Меню отмены

Если нажать ∨ справа от красной кнопки ×, появится следующее меню.

- **{{ui:params.invoke.cancelCurrent}}** (`Shift+X`)
- **{{ui:params.invoke.clearQueue}}** (`Ctrl+Shift+X`): удаляет всё, и ожидающее, и рисующееся сейчас. Подтверждение не запрашивается.
- **{{ui:params.invoke.pause}}** / **{{ui:params.invoke.resume}}**: останавливает и возобновляет обработку очереди.
- **{{ui:params.invoke.openQueue}}**

## Просмотр готовой картинки

![Экран после окончания генерации: картинка показана в центральной области просмотра и лежит в галерее справа](shot:generate-result)

Сразу после нажатия центральная область переключается на просмотр.
Пока идёт рисование, над правой галереей появляется полоса «{{ui:gallery.generating.title}}», где видны промежуточная картинка, номер шага и ход выполнения. Тонкая линия у верхнего края центра тоже показывает ход выполнения.

Когда картинка готова, она добавляется в галерею и показывается в области просмотра.
Картинка сохраняется на доску, выбранную в данный момент (на правой панели она помечена значком «{{ui:gallery.boards.autoBadge}}»). О досках, а также об упорядочивании, сравнении и повторном создании картинок рассказано в разделе [Галерея и просмотр](03-gallery.md).

> Если автоматическое переключение области просмотра на новую картинку мешает, отключите «{{ui:gallery.settings.autoSwitch}}» в «{{ui:gallery.settings.title}}» (кнопка с шестерёнкой).

## Пресеты

![Список пресетов: встроенные и сохранённые пресеты](shot:presets)

Часто используемые сочетания настроек можно сохранять как пресеты. Нажмите карточку «{{ui:presets.label}}» в самом верху левой панели, и откроется список.

В пресет входит следующее:

- промпт (позитивный и негативный)
- модель и параметры (размер, число шагов, CFG, планировщик, VAE и другие)
- LoRA и референсы

Сид и количество не входят.

Пользоваться так.

- Щелчок по пункту списка применяет эти настройки (**{{ui:presets.apply}}**).
- Кнопкой **{{ui:presets.saveNew}}** под списком (или кнопкой сохранения рядом с карточкой) текущие настройки сохраняются под именем.
- Через «…» справа от пункта доступны **{{ui:presets.apply}}**, **{{ui:presets.overwrite}}**, **{{ui:presets.rename}}** и **{{ui:presets.delete}}**.
- Список разделён на «{{ui:presets.group.mine}}» и «{{ui:presets.group.builtin}}». Встроенные пресеты — готовые образцы.

Отдельно над позитивным и негативным полями тоже есть поле «Пресет». Оно сохраняет и вызывает только текст промпта. Подходит для сохранения устойчивых фраз (наборов слов качества или нежелательных слов).

## Список промптов

![Список промптов: слова и их значения по категориям, кнопки добавления в позитивный и негативный промпты](shot:prompt-book)

Чтобы собирать промпт, не помня английских слов, есть **{{ui:params.promptBook.open}}**. Он открывается кнопкой над позитивным и негативным полями.

- Если слева выбрать категорию (причёска, выражение лица, одежда, композиция и т. д.), останутся только слова этой категории. Строка поиска вверху ищет сразу по словам, значениям, категориям и заметкам.
- Нажатие «{{ui:params.prompt.positive}}» или «{{ui:params.prompt.negative}}» справа от слова добавляет его в промпт. У добавленного слова появляется отметка, а повторное нажатие её снимает.
- В самое верхнее поле можно ввести слово и его значение и нажать **{{ui:params.promptBook.register}}**, чтобы добавить собственное слово. Карандаш справа от слова — правка, корзина — удаление.

## Референс

**{{ui:params.refImage.sectionLabel}}** — функция, которая подгоняет «атмосферу» и «стиль» новой картинки под уже имеющийся рисунок. Он не копируется как есть: опорой служат цвета, манера рисунка и общее впечатление.

1. Нажмите кнопку **＋** под промптом, чтобы добавить одну рамку.
2. Перетащите в эту рамку рисунок из галереи. Можно также перетащить файл изображения с компьютера.
3. Щелчок по рамке открывает окошко настроек.

В окошке можно задать следующее.

- **{{ui:params.refImage.model}}**: специальная модель для референса (IP-Adapter). Нужна модель, подходящая семейству выбранной модели.
- **{{ui:params.refImage.methodLabel}}**: что служит опорой — вся картинка, только стиль, только композиция и т. д. (у некоторых семейств моделей этого пункта нет).
- **{{ui:params.refImage.weight}}**: сила подгонки.
- **{{ui:params.refImage.begin}}** и **{{ui:params.refImage.end}}**: на каком отрезке процесса рисования это действует.

Если нужные модели или расширения не установлены, на рамке появляется значок предупреждения, а в окошке и под кнопкой генерации — подсказка. Установить недостающее можно кнопкой в подсказке.

> Референс нужен, чтобы «подогнать атмосферу». Если нужно «перерисовать на основе этой картинки», используется холст. См. раздел [Дорисовка на холсте](05-canvas.md).

### Персонаж

В поле «{{ui:character.row.label}}» над референсом можно вызвать зарегистрированного персонажа (сколько угодно рисунков одного персонажа вместе со словами о его внешности).
При выборе подставляются референс этого персонажа и слова о его внешности. О том, как зарегистрировать персонажа, рассказано в разделе [Доработка изображений](04-improve.md).

## Очередь

![Вкладка очереди: обрабатываемое задание и ожидающие в списке](shot:queue)

На вкладке **{{ui:app.tabs.queue}}** можно просматривать очередь генерации и управлять ею. Если есть ожидающие задания, на пункте {{ui:app.tabs.queue}} боковой навигации появляется значок с числом.

В верхней части экрана находятся следующие элементы.

- Состояние обработки («{{ui:queue.processor.running}}» или «{{ui:queue.processor.paused}}») и кнопки управления.
- Разбивка заданий по числу ({{ui:queue.status.pending}}, {{ui:queue.status.inProgress}}, {{ui:queue.status.completed}}, {{ui:queue.status.failed}}, {{ui:queue.status.canceled}}).
- В правом верхнем углу — ход выполнения задания, которое рисуется сейчас.

Кнопки работают так.

| Кнопка | Действие |
|---|---|
| **{{ui:queue.action.pause}}** / **{{ui:queue.action.resume}}** | Останавливает и возобновляет обработку очереди. То, что рисуется в данный момент, дорисовывается до конца |
| **{{ui:queue.action.cancelCurrent}}** | Останавливает то, что рисуется сейчас |
| **{{ui:queue.action.cancelAllExceptCurrent}}** | Отменяет все ожидающие задания |
| **{{ui:queue.action.prune}}** | Убирает из списка уже закончившиеся задания (завершённые, с ошибкой, отменённые) |
| **{{ui:queue.action.clear}}** | Удаляет все задания. Появляется окно подтверждения |

Если щёлкнуть строку в списке ниже, откроются подробные сведения о задании (время, готовые картинки, причина ошибки, содержание настроек).
Крестиком справа от строки можно отменить только это задание. У заданий с ошибкой или отменённых появляется кнопка повтора.

## Сочетания клавиш

Сочетания, которые не работают во время ввода текста, нужно нажимать после выхода из поля ввода.

| Действие | Клавиши |
|---|---|
| Сгенерировать (добавить в конец очереди) | `Ctrl+Enter` (работает и при вводе промпта) |
| Добавить в начало очереди и сгенерировать | `Ctrl+Shift+Enter` |
| Отменить то, что рисуется сейчас | `Shift+X` |
| Удалить всю очередь (без подтверждения) | `Ctrl+Shift+X` |
| Перейти в поле промпта | `Alt+A` |
| Открыть и закрыть левую и правую панели | `T`, `G` |
| Открыть и закрыть обе панели сразу | `F` |
| Переключить вкладки (по порядку от {{ui:app.tabs.generate}} до {{ui:app.tabs.queue}}) | от `1` до `9` |
| Открыть список сочетаний клавиш | `Shift+?` |

Сочетания клавиш можно посмотреть и в пункте «{{ui:app.nav.hotkeys}}» меню **{{ui:app.nav.settings}}** боковой навигации.
