# Управление моделями и их поиск

Чтобы создавать изображения, нужна «модель» — основа, из которой получаются картинки. В novira есть вкладка **{{ui:app.tabs.models}}** для упорядочивания имеющихся моделей и вкладка **{{ui:app.tabs.browse}}** для поиска моделей в интернете и их загрузки.

В этой главе рассказано, как пользоваться обеими вкладками, какие бывают типы моделей и как читать лицензии.

## Типы моделей

У модели есть «{{ui:models.sort.base}}» (к какому семейству она относится) и «{{ui:models.sort.type}}» (какую роль она играет).

### База (семейство)

Модели создаются по семействам, и модели разных семейств нельзя сочетать. Например, LoRA для SD1.5 нельзя использовать с моделью SDXL.

| Обозначение | Что это |
|---|---|
| SD1.X | Stable Diffusion 1.5 и подобные. Работает быстро и легко |
| SD2.X | Семейство Stable Diffusion 2 |
| SDXL | Семейство Stable Diffusion XL. Сюда же относятся многие модели для иллюстраций (Illustrious, NoobAI, Pony и другие) |
| SD3.X | Семейство Stable Diffusion 3 |
| FLUX | Семейство FLUX |
| Any | То, что не привязано к семейству (например, апскейлеры) |

> В нынешней настольной версии для создания изображений можно использовать модели SD1.X, SD2.X и SDXL. Модели FLUX и SD3.X отображаются в списке, но при попытке создать с ними изображение появится ошибка, означающая «пока не поддерживается».

Если базы модели и LoRA не совпадают, кнопка создания на экране **{{ui:app.tabs.generate}}** становится недоступной, а рядом указывается причина.

### Типы

| Тип | Роль |
|---|---|
| {{ui:models.rail.main}} ({{ui:models.type.main}}) | Главная часть, которая рисует картинку |
| {{ui:models.type.lora}} | Небольшая модель, которая добавляется к основной и вносит стиль рисунка или персонажа |
| {{ui:models.type.vae}} | Часть, которая отвечает за итоговые цвета и детали картинки |
| {{ui:models.type.controlnet}} | Задаёт форму картинки: позу, линейный рисунок и т. п. |
| {{ui:models.type.ipAdapter}}, {{ui:models.type.clipVision}} | Переносят настроение референса в создаваемое изображение |
| {{ui:models.rail.upscale}} | Увеличивают изображения |
| {{ui:models.rail.encoders}} | Части, которые понимают текст |
| {{ui:models.rail.diffusion}} | Модели для видео, например Wan, и для особых процессов |

Модели для видео, музыки, голоса и логотипов в этом списке не отображаются. Их загружают на соответствующих экранах ([Видео, музыка, голос, логотипы](07-media.md)).

## Вкладка моделей

![Вкладка моделей. Слева категории, посередине карточки моделей](shot:models)

Вкладка **{{ui:app.tabs.models}}** — это список установленных моделей.

### Поиск в списке

С помощью **{{ui:models.rail.title}}** слева список можно отфильтровать по типу. Справа показано количество.

- **{{ui:models.rail.all}}**: всё
- **{{ui:models.rail.favorites}}**: то, что отмечено звёздочкой
- **{{ui:models.rail.main}}**, **{{ui:models.rail.lora}}**, **{{ui:models.rail.controlnet}}**, **{{ui:models.rail.vae}}**, **{{ui:models.rail.ipAdapter}}**, **{{ui:models.rail.upscale}}**, **{{ui:models.rail.encoders}}**, **{{ui:models.rail.diffusion}}**

В верхней панели можно фильтровать по названию (**{{ui:models.searchPlaceholder}}**), фильтровать по базе, выбирать **{{ui:models.sort.label}}** («{{ui:models.sort.name}}», «{{ui:models.sort.size}}», «{{ui:models.sort.base}}», «{{ui:models.sort.type}}»), переключаться между **{{ui:models.view.grid}}** и **{{ui:models.view.list}}** и менять размер миниатюр.

В левом нижнем углу карточки есть метки базы (SDXL и т. п.) и формата. Если навести на карточку мышь, появятся звёздочка (избранное) и меню.

В правом нижнем углу экрана показаны количество моделей и их общий размер.

### Добавление моделей

В правом верхнем углу есть две кнопки.

- **{{ui:models.find}}**: переход на вкладку **{{ui:app.tabs.browse}}** (см. раздел ниже).
- **{{ui:models.import}}**: добавление имеющихся файлов или модели, адрес которой вам известен.

После нажатия **{{ui:models.import}}** открывается окно **{{ui:models.import.title}}**, где можно выбрать один из четырёх способов.

| Вкладка | Как пользоваться |
|---|---|
| {{ui:models.install.tab.source}} | Введите адрес модели или путь к файлу на компьютере и нажмите **{{ui:models.install.install}}** |
| {{ui:models.install.tab.scan}} | Введите путь к папке и нажмите **{{ui:models.install.scan}}** — модели из неё выстроятся в список. Кнопка **{{ui:models.install.installAll}}** устанавливает их все сразу |
| {{ui:models.install.tab.starter}} | Модели, которые приложение подобрало как полезные для начала. Модели, от которых они зависят (например, VAE), устанавливаются вместе с ними |
| {{ui:models.install.tab.huggingface}} | Поле для поиска по названию репозитория Hugging Face (`автор/название`) |

В поле вкладки **{{ui:models.install.tab.source}}** можно ввести следующее.

- Адрес страницы модели на Civitai
- Прямую ссылку на файл модели (начинающуюся с `https://`)
- Путь к файлу на компьютере (вида `C:\models\model.safetensors`)
- Файл на Hugging Face (в виде `автор/название::имя файла`)

Если указан файл на компьютере, он переносится в папку моделей приложения (на том же диске занимаемое место почти не растёт, на другом диске файл копируется).

> После ввода репозитория (`автор/название`) и нажатия **{{ui:models.install.hfLookup}}** вкладка **{{ui:models.install.tab.huggingface}}** показывает отдельные файлы моделей (`.safetensors`, `.gguf`, `.ckpt`, `.pt`, `.pth`) этого репозитория. Файлы из папок конвейера diffusers, например `unet` и `vae`, не показываются. Если сохранён токен Hugging Face, список получается с его помощью.

Установка идёт по очереди. Ход выполнения можно увидеть в окне **{{ui:models.queue.title}}**, которое открывается кнопкой **{{ui:models.dock.queue}}** в левом нижнем углу экрана (во время работы на ней написано «Устанавливается: N»). Здесь же можно по одной выполнять **{{ui:models.queue.cancel}}**, а завершённые — убирать кнопкой **{{ui:models.queue.prune}}**.

Файл, который ещё загружается, попадает в папку моделей только после завершения. Даже если остановить загрузку на полпути, недогруженный файл не останется.

### Сведения о модели

![При выборе модели справа открываются сведения: размер, расположение, лицензия, источник и т. д.](shot:models-detail)

Если нажать карточку, справа откроются сведения. Чтобы закрыть их, нажмите **{{ui:models.detail.close}}** в правом верхнем углу.

В сведениях показаны название, метки базы и типа, описание, **{{ui:models.details.size}}**, **{{ui:models.details.path}}** (его можно скопировать), **{{ui:models.details.license}}** и **{{ui:models.details.source}}**.

Кнопками сверху можно сделать следующее.

- **{{ui:models.detail.openSource}}**: открывает страницу распространителя в браузере (только для моделей, у которых есть адрес).
- **{{ui:common.edit}}**: исправляет название, описание, базу и тип. Пригодится, если база или тип не были определены автоматически верно.
- **{{ui:common.delete}}**: удаляет модель (см. ниже).

### Триггерные фразы

У LoRA и подобных моделей есть слова (триггерные фразы), которые срабатывают, если добавить их в промпт. Если зарегистрировать их в **{{ui:models.triggers.title}}**, то при выборе этой LoRA на экране **{{ui:app.tabs.generate}}** слова появятся в виде кнопок. Нажатие добавляет слово в промпт.

Чтобы зарегистрировать слово, введите его в поле и нажмите **{{ui:common.add}}**. Убрать слово можно крестиком ×. Изменения сохраняются сразу. В моделях, установленных с Civitai, слова, указанные распространителем, могут быть заполнены с самого начала.

### Настройки по умолчанию

У основной модели есть **{{ui:models.defaults.title}}**. Это значения, которые подставляются автоматически, когда эта модель выбирается на экране создания.

- **{{ui:models.defaults.scheduler}}**
- **{{ui:models.defaults.steps}}**
- **{{ui:models.defaults.cfgScale}}**
- Ширина и высота

Кроме того, можно сохранить **{{ui:models.defaults.vae}}** и **{{ui:models.defaults.vaePrecision}}**. Сохраняются только те пункты, у которых включён переключатель. Для подтверждения нажмите **{{ui:common.save}}**.

«Рекомендуемые значения» у разных моделей отличаются, поэтому, если один раз настроить часто используемые модели, не придётся править их каждый раз.

### Удаление

После нажатия **{{ui:common.delete}}** появится запрос подтверждения. **{{ui:models.deleteWarning}}**

При этом модель, установленная novira (находящаяся в папке данных приложения), удаляется вместе с файлом, а модель из папки, которую вы подготовили сами, лишь исчезает из списка, а файл остаётся.

## Метки лицензий

У моделей есть условия использования (лицензия), установленные распространителем. novira показывает их главные пункты метками.

| Метка | Значение |
|---|---|
| {{ui:browse.commercial.allowed}} | Разрешены продажа созданных изображений и использование в сервисах генерации |
| {{ui:browse.commercial.limited}} | У коммерческого использования есть условия (например, только продажа созданных изображений) |
| {{ui:browse.commercial.denied}} | Коммерческое использование не разрешено. Только для личного пользования |

Если нажать метку, откроется список **{{ui:browse.permission.title}}**. Он показывает, разрешено, запрещено или не указано, например, «{{ui:browse.permission.sellImages}}», «{{ui:browse.permission.sellModel}}» и «{{ui:browse.permission.shareMerges}}».

Метка определяется по разрешениям, заданным автором на Civitai, а на Hugging Face — по указанной лицензии. Это ориентир, основанный на данных сайтов, и в итоге обязательно проверяйте текст лицензии распространителя. **{{ui:browse.permission.disclaimer}}**

Если лицензия установленной модели неизвестна, отображается **{{ui:models.details.licenseUnknown}}**.

> Бывают и модели с некоммерческой лицензией. Например, у видеомодели **{{ui:video.model.fast}}** лицензия некоммерческая. Если вы используете созданные изображения или видео для работы или продажи, обязательно проверьте лицензию использованной модели.

## Вкладка обзора

![Вкладка обзора. Вверху источник поиска, тип, строка поиска и фильтры, ниже карточки моделей](shot:browse)

Вкладка **{{ui:app.tabs.browse}}** — это экран, где можно искать модели в интернете и сразу устанавливать их.

### Где искать

Переключателем в левом верхнем углу выбирается, где искать.

- **{{ui:browse.source.civitai}}**: сайт, где собрано много иллюстраций и LoRA.
- **{{ui:browse.source.huggingface}}**: сайт, где много моделей от научных организаций и компаний. Модели там нельзя найти по названию: вставьте URL страницы модели (подойдёт страница папки или файла) или `owner/name` в большое поле в центре экрана и нажмите **{{ui:models.install.hfLookup}}**. Отметьте показанные файлы, затем нажмите кнопку установки в правом верхнем углу, чтобы начать загрузку. Если вы вставили URL папки, сначала показываются только файлы этой папки.

Рядом выберите **{{ui:browse.kind.label}}**. Варианты: **{{ui:browse.kind.lora}}**, **{{ui:browse.kind.checkpoint}}**, **{{ui:browse.kind.controlnet}}**, **{{ui:browse.kind.vae}}**, **{{ui:browse.kind.diffusion}}** и **{{ui:browse.kind.all}}**.

### Фильтрация

В строку поиска вводятся название модели, автор или тег. После ввода и небольшой паузы результаты обновляются.

Результаты можно сузить с помощью меню справа.

| Пункт | Что это |
|---|---|
| {{ui:browse.base.label}} | {{ui:browse.base.sdxlCompat}}, {{ui:browse.base.illustrious}}, {{ui:browse.base.noobai}}, {{ui:browse.base.sdxl}}, {{ui:browse.base.pony}}, {{ui:browse.base.sd15}}, {{ui:browse.base.flux}}, {{ui:browse.base.anima}} и другие |
| {{ui:browse.sort.label}} | {{ui:browse.sort.downloads}}, {{ui:browse.sort.rating}}, {{ui:browse.sort.newest}} |
| {{ui:browse.period.label}} | За всё время, год, месяц, неделя, 24 часа (только для Civitai) |
| {{ui:browse.nsfw.label}} | По умолчанию выключено. Если включить, будут показаны и модели для взрослых |

Если прокрутить вниз до конца, подгрузится продолжение. Подгрузить можно и кнопкой **{{ui:browse.status.loadMore}}**. Если получить данные не удалось, нажмите **{{ui:browse.status.retry}}**.

### Как читать карточку и как загружать

На карточке показаны образец изображения, название модели, автор, число загрузок, число лайков и метка лицензии. У LoRA отображаются и триггерные слова.

- **{{ui:browse.card.download}}**: загружает основной файл этой модели.
- Значок справа (**{{ui:browse.card.openCivitai}}**): открывает сайт распространителя в браузере.

Если нажать карточку, справа откроются сведения. Можно увидеть версии, список файлов (размер и формат), триггерные слова, теги, описание и лицензию. Выберите версию и нажмите **{{ui:browse.card.download}}** у нужного файла. Нажатие на триггерное слово копирует его. Закрыть окно можно нажатием снаружи или клавишей `Esc`.

Когда загрузка начинается, в левом нижнем углу экрана появляется небольшое окошко **{{ui:browse.dock.title}}**, где виден ход выполнения. Остановить загрузку можно кнопкой **{{ui:browse.dock.cancel}}**, а завершённые — убрать кнопкой **{{ui:browse.dock.clear}}**. Карточка с завершённой загрузкой меняется на **{{ui:browse.card.installed}}**, а модель добавляется и в список на вкладке **{{ui:app.tabs.models}}**.

> Для загрузки моделей, требующих входа в аккаунт, зарегистрируйте ключ API Civitai в окне **{{ui:settings.title}}**. Для моделей Hugging Face, требующих запроса доступа, зарегистрируйте токен Hugging Face. Оба сохраняются на этом компьютере в зашифрованном виде и на экране не показываются. Подробнее см. [ИИ-ассистент и настройки](09-assistant-settings.md).

Чтобы перейти к созданию изображений, откройте [Создание изображений](02-generate.md).
