# 困ったとき

うまくいかないときの原因と、試すことをまとめます。画面に出る言葉から探してください。

まず、次の 2 つを見ると、原因の手がかりがつかめることが多いです。

- **{{ui:app.tabs.queue}}** タブ：失敗した項目に、理由が出ます（[下](#生成に失敗する)を参照）。
- {{ui:app.devlog.title}}：アプリの内部の記録です（[エージェント・設定](09-assistant-settings.md) を参照）。

## 起動とエンジン

novira は、画像などを作るために「画像生成エンジン」（ComfyUI と、それを動かす Python）を使います。エンジンは、アプリが自分でインストールして、自分で起動します。

### 起動に時間がかかる

初めて起動したときは、エンジンのダウンロードと展開があるため、時間がかかります。**{{ui:engine.firstRunNote}}**

最初の画面には、**{{ui:splash.step.downloading}}**・**{{ui:splash.step.extracting}}**・**{{ui:splash.step.starting}}** の 3 つの段階が出ます。ダウンロード中は、大きさ・速さ・残りの時間も出ます。終わるまで待ってください。

エンジンの用意が終わると、画面が切り替わります。2 回目からは、起動してエンジンが答えるまでの短い間だけです。

### 画面の上に出るメッセージ

エンジンの準備中や、うまくいかなかったときは、画面の上にメッセージが出ます。

| メッセージ | 意味 |
|---|---|
| {{ui:engine.title.downloading}} | エンジンをダウンロードしています。数 GB あります。回線が細いと時間がかかります |
| {{ui:engine.title.extracting}} | ダウンロードしたファイルを展開しています |
| {{ui:engine.title.starting}} | エンジンを起動して、つながるのを待っています |
| {{ui:engine.title.error}} | 準備に失敗しました。下に理由が出ます |

### 「{{ui:engine.title.error}}」と出た

起動したときの最初の画面に出たときは、**{{ui:splash.open}}** を押すと、エンジンなしでアプリを開けます。その場合、画像などは作れませんが、画像を見たり、モデルを整理したりはできます。

試すこと：

1. 理由の文章を読みます。インターネットにつながっているか、ディスクの空きがあるかを確かめます。
2. もう一度やり直します。エンジンの用意に失敗したあとでも、次に生成を始めたときに、アプリは準備をやり直します。それでも直らなければ、アプリを閉じて開き直します。
3. ダウンロードが済んでいて、展開だけに失敗したときは、ダウンロードしたファイルは残るので、やり直しでは展開から進みます。
4. セキュリティソフトが新しいファイルを調べていて、展開が止まることがあります。アプリは何度か自動でやり直しますが、続くときは、データフォルダ（下を参照）を対象から外すか、一時的に止めてみてください。
5. 理由に「see logs/comfyui.log」と出ていたら、エンジンのログに詳しい理由があります（[ログの見方](#ログの見方)）。

> エンジンは Windows 用の ComfyUI で、既定では NVIDIA の GPU 用のものをインストールします。AMD の GPU や、自分でインストールした ComfyUI を使う設定もありますが、これは上級者向けです（[上級者向け](#上級者向けの設定)）。

### エンジンが途中で止まったように見える

エンジンが起動してから、答えるまでに待つ時間は、既定で 3 分です。それを過ぎると、「ComfyUI did not answer in time」という意味のエラーになります。起動の途中でエンジンが終了したときは「ComfyUI exited while starting」と出ます。どちらも、エンジンのログ（`comfyui.log`）に理由が残ります。

## 生成できない

### 生成ボタンが押せない

**{{ui:app.tabs.generate}}** 画面の生成ボタンにマウスを重ねると、**{{ui:params.invoke.cannotInvoke}}** という理由の一覧が出ます。動画・音楽・音声・ロゴの画面では、ボタンの下に理由が並びます。出ている理由を 1 つずつ直すと、ボタンが押せるようになります。

| 出る理由 | 直し方 |
|---|---|
| {{ui:params.readiness.noModel}} | モデルを選びます。インストールされていないときは、次の「モデルがインストールされていない」へ |
| {{ui:params.readiness.loraMissing}} | 選んでいた LoRA が見つかりません。削除したか、移動した可能性があります。LoRA を選び直すか、外します |
| LoRA「○○」はモデルと互換性がありません | ベース（SDXL や SD1.X など）が違います。同じベースの LoRA にするか、外します |
| 参照画像 ○: 画像が選ばれていません、または モデルが選ばれていません | 参照画像の欄に、画像を入れ、モデルを選びます |
| 参照画像には拡張機能 ○○ が必要です | 参照画像の欄の案内から、拡張機能をインストールします（[拡張機能が足りない](#拡張機能が足りない)） |
| {{ui:params.readiness.upscaleNoImage}} | アップスケールする画像を選びます |
| {{ui:params.readiness.upscaleNoModel}} | アップスケール用のモデルを選びます。インストールされていないときは、{{ui:app.tabs.models}}タブの **{{ui:models.install.tab.starter}}** からインストールできます |
| {{ui:video.problem.prompt}}、{{ui:music.problem.tags}}、{{ui:voice.problem.text}}、{{ui:logo.problem.text}} | 必須の欄が空です。入力します |
| {{ui:video.problem.image}} | 「画像から」のときに、動かす画像が選ばれていません |
| {{ui:voice.problem.description}} | 「声を言葉で作る」のときに、声の説明が空です |
| {{ui:video.problem.pack}}、{{ui:music.problem.pack}}、{{ui:voice.problem.pack}}、{{ui:logo.problem.pack}} | 専用のモデルがインストールされていません。次の項目へ |

### 動画・音楽・音声・ロゴのモデルがインストールされていない

それぞれの画面の左パネルにカードが出ているので、**{{ui:pack.install}}** を押します。インストールが終わるまでは作れません。

- ダウンロードが途中で失敗したら、カードのボタンが **{{ui:pack.retry}}** に変わります。押すと、やり直します。
- 音声は、読み上げ用のエンジンもインストールします。画像生成エンジンの準備が先に済んでいる必要があります。
- 高速な動画モデルは、標準の動画モデルとは別のダウンロードです。

くわしくは [動画・音楽・音声・ロゴ](07-media.md) をご覧ください。

### モデルがインストールされていない

**{{ui:app.tabs.models}}** タブに **{{ui:models.empty.title}}** と出ているときは、モデルが 1 つもありません。

- **{{ui:models.import}}** の **{{ui:models.install.tab.starter}}** から、最初のモデルをインストールできます。
- **{{ui:app.tabs.browse}}** タブで、好みのモデルを探してダウンロードすることもできます。
- すでにモデルのファイルを持っているときは、**{{ui:models.import}}** の **{{ui:models.install.tab.scan}}** で、フォルダごと取り込めます。

くわしくは [モデル](08-models.md) をご覧ください。

### 拡張機能が足りない

「拡張機能 ○○ が必要です」と出る機能があります。顔を直す、範囲を選ぶ、背景を消す、動画のコマを補う、参照画像を使う、などです。

1. メッセージの横の **{{ui:params.refImage.installPack}}** を押します。
2. インストールが終わったら、**{{ui:params.refImage.restartEngine}}** を押して、エンジンを再起動します。
3. 再起動のあと、もう一度やり直します。

拡張機能は、**{{ui:app.tabs.workflows}}** タブの **{{ui:workflows.panel.packs}}** からも、一覧でインストールしたり、外したりできます。

> アプリがインストールしたエンジンではなく、自分で用意したエンジンにつないでいるときは、拡張機能のインストールはアプリからはできません。そのエンジンの側でインストールしてください。

### GPU のメモリが足りない・ほかのアプリと取り合っている

画像・動画・音楽は、パソコンの GPU を使います。ほかのアプリ（ゲーム、動画編集、ブラウザの動画など）が GPU を使っていると、メモリが足りなくなって失敗することがあります。

メモリが足りないと、エラーに「OOM」（メモリ不足の意味）の文字が出ることがあります。

メモリが足りずに失敗したときは、アプリがそれを見分けて、**{{ui:queue.oom.title}}** という知らせを出します。知らせは、ギャラリーの上、**{{ui:app.tabs.queue}}** タブの失敗した項目の下、動画・音楽・音声・ロゴの画面、画面の右下の通知に出ます。

![GPU のメモリが足りないときの知らせ。小さくして再試行と、省メモリモードにして再起動のボタンが並ぶ](shot:out-of-memory)

知らせのボタンで、次のどちらかを試せます。

- **{{ui:queue.oom.retrySmaller}}**：同じ設定とシードのまま、縦横の比を保って面積を約 75% にし、もう一度作ります。サイズを決めて作る画像にだけ出ます（動画・音楽・音声・ロゴ・アップスケールには出ません）。
- **{{ui:queue.oom.lowMemory}}**：**{{ui:settings.lowMemory.label}}**（[エージェント・設定](09-assistant-settings.md) を参照）をオンにして、エンジンを再起動します。作成中の項目があるときは、エンジンを次に起動したときから使われます。すでにオンのときは出ません。

メモリが足りずに失敗したあと、アプリはエンジンに、読み込んだモデルを外してメモリを空けるよう頼みます。そのため、次の作成はモデルの読み込みからになり、少し時間がかかります。

試すこと：

- ゲームや動画編集など、GPU を使うほかのアプリを閉じてから、もう一度作ります。
- 画像のサイズを小さくします。
- 使っている LoRA や参照画像を減らします。
- 動画は、サイズを小さくして作り、できてから **{{ui:video.finish}}** で大きくします。**{{ui:video.light.title}}** の **{{ui:video.light.fp8}}** と **{{ui:video.light.tiled}}** も試せます。
- アプリを開き直して、使われているメモリを手放します。

音声のモデルは、しばらく使わないと GPU から外れます。作成は 1 件ずつ順番に進みます。

### 生成に失敗する

画像・動画・音楽などの作成が失敗すると、**{{ui:app.tabs.queue}}** タブの項目が **{{ui:queue.status.failed}}** になります。項目を押して開くと、**{{ui:queue.detail.error}}** に理由が出ます。動画・音楽・音声・ロゴの画面では、真ん中の上のほうにも、失敗した表示と理由が出ます（直近の 3 件まで）。

理由が分かったら、項目の **{{ui:queue.action.retry}}** ボタンで、同じ設定のままやり直せます。

理由の文章は、エンジンやアプリの内部から出るため、英語のことがあります。よくあるものを挙げます。

| 理由の文章（要点） | 意味と試すこと |
|---|---|
| ComfyUI does not see ... (check model roots / extra_model_paths) | エンジンがそのモデルを見つけられません。モデルのファイルを動かしたか、探すフォルダの設定が合っていません。モデルタブでインストールし直すか、場所を確かめます |
| ComfyUI is not reachable at ... | 別に用意したエンジンにつながりません。そのエンジンが起動しているか確かめます |
| ComfyUI exited while starting / did not answer in time | エンジンが起動できません。エンジンのログを見ます |
| ... OOM | GPU のメモリが足りません。前の項目を参照 |
| ... models are not supported by the ComfyUI backend yet | FLUX や SD3.X のモデルは、まだ画像の生成に使えません。SDXL や SD1.X のモデルを選びます |
| Reference images need the ... custom node pack | 参照画像に必要な拡張機能がインストールされていません |
| This ComfyUI is too old for video / music | 動画や音楽に必要な機能が、使っているエンジンにありません。アプリがインストールしたエンジンなら起こりません。自分で用意したエンジンなら更新します |
| The video / music / logo models are not installed yet | 専用のモデルがインストールされていません。それぞれの画面からダウンロードします |
| ComfyUI has no ... node; install the custom node pack | ワークフローで使うノードの拡張機能がインストールされていません |
| Interrupted because novira was closed | 作成の途中で、アプリが閉じられました。もう一度作ります |

### 絵ができたのに見えない

作成が **{{ui:queue.status.completed}}** なのに、ギャラリーに出ないときは、次を確かめます。

- **ボードが違う**：新しい画像は、**{{ui:gallery.boards.autoBadge}}** の印が付いたボード（初期状態では **{{ui:gallery.boards.uncategorized}}**）に入ります。別のボードを開いていると、そこには出ません。ボードを切り替えるか、新しい画像を入れるボードを **{{ui:gallery.boards.setAutoAdd}}** で選び直します。
- **ロゴは「アセット」に入る**：ロゴは **{{ui:gallery.view.images}}** ではなく **{{ui:gallery.view.assets}}** のほうに入ります。
- **動画と音声の見え方**：動画は ▶、音声は ♪ の付いたサムネイルで並びます。検索や絞り込みが残っていると隠れます。

それでも見つからないときは、**{{ui:app.tabs.queue}}** タブで項目の **{{ui:queue.col.destination}}** を確かめます。出力先が **{{ui:queue.destination.canvas}}** の項目は、ギャラリーではなくキャンバスに出ます。

## データの置き場所とバックアップ

### データはどこにあるか

画像・モデル・記録は、すべて **`novira-data`** という名前のフォルダに入ります。場所は次のとおりです。

- 配布版：インストールのときに選んだフォルダ。初期値は、アプリの実行ファイル（`novira.exe`）と同じフォルダの中の `novira-data`。
- 開発中の版：リポジトリの一番上のフォルダの中の `novira-data`。

環境変数 `NOVIRA_DATA_DIR` で、別の場所に変えられます。

| フォルダ・ファイル | 入っているもの |
|---|---|
| `outputs` | 作った画像・動画・音声 |
| `novira.sqlite` | 画像の情報、ボード、キュー、モデルの一覧、ワークフローなどの記録 |
| `thumbnails` | 縮小画像 |
| `models` | インストールしたモデル |
| `comfyui` | アプリがインストールした画像生成エンジン |
| `cache` | エンジンが使う一時的なデータ |
| `voice` | 音声の読み上げ用のライブラリ |
| `logs` | ログ（下を参照） |
| `settings.json` | 上級者向けの設定（なくても構いません） |
| `secrets` | API キーとトークン（暗号化されています） |
| `agent.json` | エージェントで選んだ AI の種類 |

アプリがインストールしたエンジン（ComfyUI と Python）と、その作業用のデータも、データフォルダの中に入ります。

アプリの画面の設定（言語・テーマ・プリセット・AI のチャットの履歴など）は、`novira-data` ではなく、アプリの画面側の保存領域に入っています。

### バックアップ

novira には、バックアップを作る機能と、バックアップから復元する機能があります。大事な絵を守るには、設定の画面の **{{ui:share.backup.section}}** を使ってください（[エージェント・設定](09-assistant-settings.md#バックアップ) を見てください）。バックアップには、作った絵と、アプリの中で設定・登録したものが入りますが、モデルと画像生成エンジンは入りません。それらも残したいときは、自分でフォルダをコピーします。

1. アプリを閉じます（作成中のものがないことも確かめます）。
2. `novira-data` フォルダをまるごと、別のドライブなどにコピーします。

容量が大きいのは `models` と `comfyui` です。絵と記録だけを残すなら、`outputs` と `novira.sqlite` が中心です。`models` のモデルは、取り込み元からダウンロードし直せることが多いですが、配布が終わったものは戻せないことがあります。

> API キーとトークンは、Windows の機能で暗号化されています。別のパソコンや別のユーザーに写しても読めないことがあるので、そのときは、設定で入力し直してください。

アプリの画面の設定やプリセット、AI のチャットの履歴は、このコピーには含まれませんが、バックアップには入ります。

## ログの見方

ログは 3 か所で見られます。

| 場所 | 内容 |
|---|---|
| {{ui:app.devlog.title}}（アプリの中） | アプリの内部の記録と、画面の警告・エラー。設定で表示をオンにします（[エージェント・設定](09-assistant-settings.md)） |
| `novira-data\logs\novira.log` | アプリ自身の記録。大きくなると（2 MB を超えると）`novira.log.1` に移ります |
| `novira-data\logs\comfyui.log` | 画像生成エンジンの記録。起動できないときや、生成が失敗したときの理由が出ます |

ログは、新しい行が下に足されます。何かあったときは、一番下の近くを見てください。「error」や「failed」を含む行が手がかりです。

## 問題を報告するとき

次のものがそろっていると、原因が早く分かります。

1. **何をしたら、どうなったか**：操作の順番、期待したこと、実際に起きたこと。
2. **画面の言葉**：エラーの文章（**{{ui:app.tabs.queue}}** タブの **{{ui:queue.detail.error}}**、または画面の上に出たメッセージ）をそのまま写します。
3. **アプリの版**：設定の画面の一番下か、**{{ui:app.nav.about}}** に出ています。
4. **開発者ログ**：**{{ui:app.devlog.copy}}** でコピーした文章。
5. **ログのファイル**：`novira.log` と `comfyui.log` の、問題が起きた時刻のあたり。
6. **パソコンの情報**：GPU の種類とメモリ、Windows の版。

> ログには、プロンプトやファイルの場所が含まれることがあります。人に渡す前に、見せたくない部分がないか確かめてください。

## 上級者向けの設定

データフォルダに `settings.json` を置くと、エンジンなどの動きを変えられます。ふつうは要りません。

| 設定名 | 内容 |
|---|---|
| `comfyuiPackage` | インストールするエンジンの種類。`nvidia`（既定）か `amd` |
| `comfyuiUrl` | すでに動いている ComfyUI につなぐ（アプリはエンジンをインストールせず、起動もしません） |
| `comfyuiDir` | 自分でインストールした ComfyUI のフォルダを使う |
| `modelRoots` | モデルを探すフォルダを足す |
| `comfyuiStartTimeoutSecs` | エンジンの起動を待つ秒数（既定は 180） |
| `lowMemoryMode` | 省メモリモード（`true` か `false`）。設定の画面の **{{ui:settings.lowMemory.label}}** で切り替えると、ここに書き込まれます |

ファイルの書き方が壊れていると、アプリは起動せず、理由を表示します。変更したら、アプリを開き直します。
