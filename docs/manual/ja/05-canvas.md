# キャンバス

![キャンバスタブの全体。中央がキャンバス、右の下がレイヤーの一覧](shot:canvas)

**{{ui:app.tabs.canvas}}** タブは、絵を「描く・置く・一部だけ描き直す」ための作業台です。画像を置いて広げたり、描き直したい所にマスクをかけたり、棒人間でポーズを決めたりできます。

画面は 3 つに分かれています。

- 左: 生成タブと同じ設定のパネル（プロンプト、モデル、サイズなど）。キャンバスでは、**{{ui:params.compositing.title}}** の項目が増えます。
- 中央: キャンバス。上にツールのボタンが並びます。
- 右: 絵を入れる **{{ui:canvas.layers.title}}** の一覧。

何もない状態で **{{ui:params.invoke.invoke}}** を押すと、点線の枠（生成範囲）の中に、普通に絵を作ります。キャンバスの本領は、そこに絵や下描きを置いたときに出ます。 レイヤーとマスクは自動で保存され、アプリを開き直すと元に戻ります（元に戻す履歴は保存されません）。

## 絵を置く・描く

キャンバスに絵を置く方法は、いくつかあります。

- ブラシで描く（先に **{{ui:canvas.tool.brush}}** を選ぶか、`B` を押します）。レイヤーを選んでいなければ、{{ui:canvas.add.raster}}が自動で作られます。
- ギャラリーの絵を、キャンバスにドラッグする。置き場所（ラスター・コントロール・インペイントマスクなど）を選ぶ枠が出るので、そこにドロップします。
- `Ctrl+V` で、クリップボードの画像を新しいラスターレイヤーとして貼り付けます（ギャラリーにも保存されます）。
- ギャラリーの絵を右クリック（ビューアでは筆のアイコン）して、**{{ui:gallery.menu.sendToCanvas}}** から行き先を選ぶ。

行き先は次のとおりです。

| 行き先 | 何になるか |
|---|---|
| **{{ui:gallery.canvas.newCanvasRaster}}** | キャンバスをいったん空にして、その絵と同じ大きさで始めます。 |
| **{{ui:gallery.canvas.newCanvasControl}}** | 同じく新しく始めますが、絵はコントロールレイヤーになります。 |
| **{{ui:gallery.canvas.raster}}** | 今のキャンバスに、ラスターレイヤーとして足します。 |
| **{{ui:gallery.canvas.control}}** | コントロールレイヤーとして足します。 |
| **{{ui:gallery.canvas.inpaint}}** | インペイントマスクとして足します。 |
| **{{ui:gallery.canvas.regional}}** | 領域ガイダンスの参照画像として足します（[領域ガイダンス](#領域ガイダンス) を見てください）。 |

## ツール

上のバーにツールが並びます。キーボードの文字キーでも切り替えられます。アプリを起動したときは **{{ui:canvas.tool.view}}** が選ばれているので、最初にキャンバスをドラッグしても表示がずれるだけで、何も描かれません。

| ツール | キー | 使いみち |
|---|---|---|
| **{{ui:canvas.tool.brush}}** | `B` | 絵を描きます。色は、バーの色のボタンで変えます。 |
| **{{ui:canvas.tool.eraser}}** | `E` | 描いたところを消します。 |
| **{{ui:canvas.tool.mosaic}}** | `M` | なぞったところをモザイクにします（隠したい所に）。粗さはバーの数字で変えます。絵のあるレイヤーにだけかかります。 |
| **{{ui:canvas.tool.rect}}** | `U` | 四角を塗ります。 |
| **{{ui:canvas.tool.lasso}}** | `L` | 自由な形を囲んで、その中を色で塗りつぶします（マスクではマスクされます）。 |
| **{{ui:canvas.tool.pose}}** | `O` | コントロールレイヤーに棒人間のポーズを置いて、関節を動かします（下の「キャンバスでポーズを作る」）。 |
| **{{ui:canvas.tool.move}}** | `V` | レイヤーを動かします。矢印キーで、選んでいるレイヤーを 1 px ずつ（Shift で 10 px ずつ）動かせます。 |
| **{{ui:canvas.tool.bbox}}** | `C` | 生成範囲（バウンディングボックス）を動かす、大きさを変えます。 |
| **{{ui:canvas.tool.view}}** | `H` | 表示をずらします。 |
| **{{ui:canvas.tool.colorPicker}}** | `I` | 絵の中から色を拾います。 |
| **{{ui:canvas.tool.bucket}}** | `K` | 押した場所と近い色の領域を塗りつぶします。どこまで近い色とするかは、バーの **{{ui:canvas.toolbar.bucketTolerance}}** で決めます。 |

ほかに、次の操作ができます。

- ブラシの太さは、バーの **{{ui:canvas.toolbar.brushWidth}}**、または `[` と `]` のキーで変えます。`Q` で、直前に使ったツールと切り替えます。
- 拡大・縮小は、マウスホイールか、`+` と `-` のキーです。`Ctrl+0` で全体が見え、`Ctrl+1` で実寸（100%）になります。
- 表示をずらすには、`Space` を押しながらドラッグするか、ホイールのボタンを押しながらドラッグします。
- **{{ui:canvas.toolbar.undo}}**（`Ctrl+Z`）と **{{ui:canvas.toolbar.redo}}**（`Ctrl+Shift+Z`）で、描いたことを戻したり、やり直したりできます。

歯車の **{{ui:canvas.settings.title}}** には、グリッドの表示、生成範囲の外側を暗くする表示、描いた線を生成範囲の中だけにする設定、表示中のラスターレイヤーを 1 つにまとめる操作などがあります。

## 生成範囲（バウンディングボックス）

キャンバスの中の点線の枠が、「今回、絵を作る範囲」です。生成のたびに、この枠の中だけが作られ、その大きさが絵の大きさになります。

- **{{ui:canvas.tool.bbox}}**（`C`）に切り替えて、枠をドラッグで動かします。角や辺をドラッグすると、大きさが変わります。
- 左パネルの **{{ui:params.image.bboxWidth}}** と **{{ui:params.image.bboxHeight}}** でも、大きさを決められます。
- **{{ui:canvas.actions.fitBboxToLayers}}**（`Shift+C`）で、置いた絵に枠を合わせます。

## レイヤー

右下の **{{ui:canvas.layers.title}}** に、キャンバスに置いたものが一覧で出ます。**{{ui:common.add}}** ボタンで足します。

![レイヤーの「追加」メニューを開いたところ](shot:canvas-add-layer)

レイヤーには、役目の違う種類があります。

| 種類 | 役目 |
|---|---|
| **{{ui:canvas.add.raster}}** | 普通の絵のレイヤーです。描いたり、絵を置いたりします。ここにあるものが、「元の絵」になります。 |
| **{{ui:canvas.add.control}}** | 形・線・ポーズなどの手がかりにする絵です。生成の指示になり、絵の中身にはなりません。 |
| **{{ui:canvas.add.inpaint}}** | 「ここを描き直す」という範囲を、塗って指定します。 |
| **{{ui:canvas.add.regional}}** | 場所ごとに別のプロンプトを指定するレイヤーです（[領域ガイダンス](#領域ガイダンス) を見てください）。 |
| **{{ui:canvas.add.globalRef}}** | 絵全体の雰囲気を真似させる参照画像です。生成タブの参照画像と同じものです。 |

レイヤーの一覧では、次の操作ができます。

- 目のアイコンで表示と非表示、鍵のアイコンでロックを切り替えます。非表示のレイヤーは、生成に使われません。ロックしたレイヤーには描けません。
- 名前をダブルクリックすると、名前を変えられます。
- 右クリックで、複製、並べ替え（前後に動かす。同じ種類のレイヤーは、一覧の中でドラッグしても並べ替えられます）、**{{ui:canvas.entityMenu.flipHorizontal}}**、**{{ui:canvas.entityMenu.flipVertical}}**、**{{ui:canvas.entityMenu.rotateRight}}**、**{{ui:canvas.entityMenu.rotateLeft}}**、**{{ui:canvas.entityMenu.scaleUp}}**、**{{ui:canvas.entityMenu.scaleDown}}**、**{{ui:canvas.pose.random}}**（コントロールレイヤーのみ）、ほかの種類への変換、クリップボードへのコピー、**{{ui:canvas.entityMenu.saveToGallery}}**、**{{ui:canvas.entityMenu.exportToFile}}**、削除ができます。
- **{{ui:canvas.layers.more}}**（「…」）から、表示中のラスターレイヤーを 1 つにまとめる、全レイヤーを削除する、もできます。

![レイヤーを右クリックしたメニュー](shot:canvas-layer-menu)

選んだレイヤーの下に、そのレイヤーの設定が開きます。

- {{ui:canvas.add.inpaint}}: マスクの色や塗りの模様（画面での見え方のみ）、**{{ui:canvas.mask.denoiseLimit}}**（オンにして下げると、マスクの中でも元の絵を残しやすくなります）。右クリックの **{{ui:canvas.entityMenu.invertMask}}** で、生成範囲の中のマスクされた部分と空いた部分を入れ替えられます。
- {{ui:canvas.add.control}}: 次の「{{ui:canvas.add.control}}」の項を見てください。

## どんなふうに描き直されるか

キャンバスで **{{ui:params.invoke.invoke}}** を押すと、アプリが生成範囲の中を見て、絵の作り方を自動で決めます。自分で選ぶ必要はありません。

| 生成範囲の中の状態 | 作り方 |
|---|---|
| 表示中のラスターレイヤーに、何も描かれていない | 文章から新しく作ります（テキストから画像）。 |
| ラスターレイヤーで、一部だけが埋まっている | 空いている部分を足して広げます（アウトペイント）。空の部分は、先に色で埋められます。 |
| 全体が埋まっていて、インペイントマスクに塗りがない | 今の絵を土台に、描き直します（画像から画像）。 |
| 全体が埋まっていて、インペイントマスクに塗りがある | マスクの部分だけを描き直します（インペイント）。マスクの外は、元の絵のままです。 |

画像から画像のときの変え具合は、左パネルの **{{ui:params.image.strength}}** で決めます。0 で元のまま、1 で完全に描き直します。

アウトペイントで、空の部分を何で埋めるかは、左パネルの **{{ui:params.compositing.title}}** にある **{{ui:params.compositing.infillTitle}}** で選びます。**{{ui:params.compositing.infill.color}}** なら、選んだ色（黒・白・グレーなど）で埋めます。ほかを選ぶと、まわりの色をなじませて埋めます。つなぎ目のぼかし具合は **{{ui:params.compositing.maskBlur}}** で決めます。

> インペイントは、普通のモデルでそのまま使えます。専用の「インペイント用モデル」は要りません。

## 結果を採用するか決める（ステージング）

キャンバスで作った絵は、すぐにはキャンバスに入りません。生成範囲の上に重ねて表示され、下のバー（**{{ui:canvas.staging.title}}**）で、採用するか決めます。

| ボタン | 何をするか |
|---|---|
| 左右の矢印（`←` `→`） | 複数枚作ったときに、次の絵や前の絵を見ます。 |
| **{{ui:canvas.staging.accept}}**（`Enter`） | この絵を、新しいラスターレイヤーとして、キャンバスに入れます。ほかの絵は捨てられます。 |
| **{{ui:canvas.staging.hideResults}}** | 結果を隠して、元の絵と見比べます。 |
| **{{ui:canvas.staging.saveToGallery}}** | この絵をギャラリーに保存します。 |
| **{{ui:canvas.staging.discard}}** | この絵だけを捨てます。 |
| **{{ui:canvas.staging.discardAll}}**（`Esc`） | 全部捨てます。 |

> 結果の絵は、そのままではギャラリーに並びません。ギャラリーに残したい絵は、先に **{{ui:canvas.staging.saveToGallery}}** を押してください。捨てた絵は消えます。

結果のバーの左端のつまみ（⋮⋮）は、絵をほかの場所へドラッグして渡すためのものです。

## コントロールレイヤー

コントロールレイヤーは、「この形・この線・このポーズに沿って描いて」という手がかりです。線画、輪郭、ポーズの絵などを入れます。

使うには、メインモデルに合う ControlNet モデルが必要です。インストールの仕方は [モデル](08-models.md) の章を見てください。レイヤーを選んで、設定の **{{ui:common.model}}** を選びます。モデルがないままだと、生成のところに「コントロールレイヤー 1 にモデルがありません」などと出て、作れません。

設定は次のとおりです。

- **{{ui:canvas.control.weight}}**: 手がかりに従う強さです。
- **{{ui:canvas.control.begin}}** と **{{ui:canvas.control.end}}**: 生成の何割目から何割目まで効かせるかです。
- **{{ui:canvas.control.controlMode}}**: **{{ui:canvas.control.mode.balanced}}** と **{{ui:canvas.control.mode.moreControl}}** があります。**{{ui:canvas.control.mode.morePrompt}}** は、今のところ **{{ui:canvas.control.mode.balanced}}** と同じ動きです。
- **{{ui:canvas.control.filter}}**: 絵を、線や深度などの手がかり用の絵に変換します。アプリの中で行う簡易的な変換です。**{{ui:canvas.control.process}}** で試して、よければ **{{ui:common.apply}}** で絵に反映します。

## ポーズを作る（棒人間）

![棒人間でポーズを決めるダイアログ](shot:pose)

棒人間を動かして、ポーズを決められます。文章でポーズを指定してもうまくいかないときに便利です。

1. **{{ui:app.tabs.canvas}}** タブの、レイヤーの **{{ui:common.add}}** を押し、**{{ui:pose.menu}}** を選びます。
2. **{{ui:pose.preset}}** から、近いポーズを選びます（{{ui:pose.preset.standing}}、{{ui:pose.preset.armsUp}}、{{ui:pose.preset.sitting}}、{{ui:pose.preset.walking}}）。
3. 関節の丸をドラッグして、姿勢を変えます。丸を選んで、矢印キーでも動かせます（`Shift` を押すと大きく動きます）。**{{ui:pose.mirror}}** で左右を反転でき、**{{ui:pose.reset}}** で最初のひな形に戻ります。
4. **{{ui:pose.size}}** を選びます。普通は、キャンバスの大きさでかまいません。
5. **{{ui:pose.use}}** を押します。

ポーズは、コントロールレイヤーとして、キャンバスに入ります。キャンバスが空なら、その大きさで新しく始まります。

使うには、OpenPose に対応した ControlNet モデルが必要です。インストールされていれば、アプリがレイヤーのモデルに自動で選びます。インストールされていないときは、通知でお知らせします。モデルをインストールしてから、レイヤーの設定で選んでください。

> 1 人分のポーズだけ決められます。手の指や顔の向きまでは決められないので、顔や手は、プロンプトで指定してください。

> ポーズの効き目は、レイヤーの **{{ui:canvas.control.weight}}** で決まります。ポーズのレイヤーは、最初から最大の強さで、最初から最後まで効くように設定されます。ポーズの自由度を出したいときは、下げてください。

### キャンバスでポーズを作る

![ポーズツールで、キャンバスに棒人間を置いたところ](shot:canvas-pose)

**{{ui:canvas.tool.pose}}** ツール（`O`）を使うと、キャンバスの上で直接ポーズを作れます。置いたポーズは、あとから何度でも直せます。

- 何もないところをクリックすると、立った棒人間が置かれます。コントロールレイヤーを選んでいないときは、新しいコントロールレイヤーが作られ、ポーズ用の強さと、OpenPose に対応したモデル（インストールされていれば）が設定されます。
- 関節の丸をドラッグすると、その先の手足ごと回ります（骨の長さは変わりません）。首をドラッグすると、体全体が動きます。`Shift` を押しながらドラッグすると、その関節だけが動きます。
- `Alt` を押しながら関節をクリックすると、その関節を隠したり、また出したりできます（画面の外にはみ出した手足などに）。
- `R` キーか、バーの **{{ui:canvas.pose.random}}** ボタンで、選んでいるレイヤーのポーズが、新しいランダムなポーズに変わります。何度でも押せるので、気に入るまで試せます。
- ポーズツールのバーにある数字と稲妻のボタンで、その枚数だけ、ポーズを変えながら続けて生成します（最大 16 枚）。ポーズごとにシードも変わるので、同じ設定でいろいろな姿勢の絵が並びます。生成できる状態でないときは、理由が表示されて始まりません。
- 1 つのレイヤーに、何人でも置けます。左右反転、回転、拡大・縮小は、レイヤーの右クリックメニューから行えます。
- 文章でも頼めます。**{{ui:app.tabs.canvas}}** タブを開いたまま エージェントを開き、「走っているポーズ」「左手を上げて」のように伝えると、棒人間が置かれます（最大 4 人まで）。置いたあとに「もう少し前かがみに」と伝えると、そのポーズを直してくれます。頼んだポーズは言葉からの推測なので、思い通りでなければ、関節をドラッグして直してください。
- 絵に写っている人からも作れます。ギャラリーの絵を右クリックして **{{ui:canvas.poseFromImage.menu}}** を選ぶか、ポーズツールのバーにある同じ名前のボタンを押すと、写っている人の骨格を読み取って棒人間として置きます（最大 4 人まで）。置いたポーズは、ふつうのポーズと同じように直せます。使うには拡張機能（comfyui_controlnet_aux）が必要で、入っていなければ、その場でインストールを案内します。初めて読み取るときは、モデルのダウンロードで時間がかかります。人が小さすぎたり隠れていたりすると、見つからないことがあります。
- ポーズツールのバーの **{{ui:canvas.pose.presets}}** ボタンを押すと、左にカテゴリ、右にポーズのカードが並ぶ画面が開きます。カードには、生成範囲の枠の中に OpenPose の棒人間が描かれています。「{{ui:canvas.pose.group.panel}}」（寄りと引き、二人、三人以上、日常のワンシーン、ドラマ・感情）は人物の位置と大きさまで決まっていて、選ぶとレイヤーのポーズをすべて置き換えます。「{{ui:canvas.pose.group.standard}}」と「{{ui:canvas.pose.group.manga}}」は、選んでいるレイヤーの最初のポーズと入れ替わり、位置と大きさはそのままです。ポーズがなければ、新しく置かれます。腕を上げたり脚を蹴り上げたりして枠からはみ出す場合は、枠に収まるまで小さくなります。
- ポーズツールのバーの **{{ui:canvas.pose3d.menu}}** ボタンで、ポーズを3Dで編集できます（選んでいるコントロールレイヤーの最初のポーズ。なければ立った人形から始まります）。関節をドラッグすると、骨の長さを保ったまま動きます。奥へ向けたり手前に向けたりもできます。背景をドラッグすると体の向きが変わり、ホイールで拡大・縮小します。**{{ui:canvas.pose3d.front}}**・**{{ui:canvas.pose3d.side}}**・**{{ui:canvas.pose3d.back}}**・**{{ui:canvas.pose3d.top}}** のボタンで、決まった向きにできます。**{{ui:canvas.pose3d.apply}}** を押すと、いま見えている向きの形がポーズとしてキャンバスに入り（奥行きも覚えているので、もう一度3Dで開いて回せます）、押さずに閉じれば元のままです。3D表示にはブラウザの WebGL が必要で、使えない環境ではその旨が表示されます。

![絵から作ったポーズを、キャンバスに置く前の確認](shot:canvas-pose-from-image)

![「定番のポーズと構図」の画面。カテゴリ「二人」を選んだところ](shot:canvas-pose-presets)

![ポーズを3Dで編集するダイアログ](shot:canvas-pose-3d)

ポーズを写真から取り出したいときは、[ワークフロー](06-upscaling-workflows.md) のテンプレート「{{ui:workflows.templates.poseControl.title}}」が使えます。

## 領域ガイダンス

**{{ui:canvas.add.regional}}** のレイヤーは、塗った場所にだけ効くプロンプトを指定します。領域を塗り、レイヤーの設定でポジティブプロンプト（そこに描くもの）かネガティブプロンプト（そこに入れたくないもの）を足します。絵全体のプロンプトはこれまでどおり全体に効き、レイヤーのプロンプトはその領域の中で上乗せされます。**自動ネガティブ** をオンにすると、レイヤーのポジティブプロンプトは領域の外では抑えられるので、「赤い帽子」が狙った場所にだけ出ます。

- 生成範囲の中に塗りがないレイヤーや、プロンプトがないレイヤーは、何も指定しないので使われません。
- 同時に使えるのは 8 枚までです。非表示のレイヤーは使われません。
- 領域ガイダンスは SD1.X と SDXL のモデルで使えます。新しい系統（Flux や Qwen-Image など）では、生成が失敗してその旨が表示されます。そのときはレイヤーを非表示にしてください。
- 領域レイヤーに足した参照画像は、まだ使われません。

## 保存と後片づけ

- キャンバスの絵をギャラリーに保存するには、上のバーの **{{ui:canvas.toolbar.saveToGallery}}**（ディスクのアイコン）を押します。生成範囲の中にある、表示中のラスターレイヤーが、1 枚にまとめて保存されます。
- レイヤーを分けたまま PSD ファイルにするには、**{{ui:canvas.toolbar.savePsd}}**（書類と下向き矢印のアイコン）を押します。生成範囲の中が、ブラウザのダウンロードとして保存されます。ラスターレイヤーは、名前、位置、不透明度、表示・非表示を保ったまま、1 つずつ PSD のレイヤーになります。コントロールレイヤーは非表示のレイヤーとして入り、インペイントマスクと領域ガイダンスは入りません。
- 1 つのレイヤーだけを保存するには、レイヤーを右クリックして、**{{ui:canvas.entityMenu.saveToGallery}}** を選びます。
- **{{ui:canvas.settings.title}}** には、**{{ui:canvas.actions.clearCanvas}}**、**{{ui:canvas.actions.clearHistory}}**、**{{ui:canvas.actions.clearStaging}}** もあります。**{{ui:canvas.actions.clearCanvas}}** は、全部のレイヤーを消します。

絵を直す機能は、[絵を直す・使い回す](04-improve.md) にもあります。「{{ui:gallery.menu.segment}}」の結果は、キャンバスに送って、さらに描き直せます。
