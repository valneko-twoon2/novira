# 動画・音楽・音声・ロゴ・テキスト

画像のほかに、novira では動画・音楽・音声・ロゴを作り、画像に文字や吹き出しを入れることもできます。

どれも **{{ui:app.tabs.generate}}** タブの左パネルから使います。画像の使い方は [生成](02-generate.md) を先にご覧ください。

## 作るものを切り替える

左パネルの一番上に、アイコンだけが並んだ列があります。左から順に、**{{ui:media.tab.image}}**・**{{ui:media.tab.video}}**・**{{ui:media.tab.music}}**・**{{ui:media.tab.voice}}**・**{{ui:media.tab.logo}}**・**{{ui:media.tab.text}}**・**{{ui:app.tabs.comic}}** です。漫画のページは、いちばん右のアイコンで作ります（[漫画を描く](12-comic.md)）。

アイコンにマウスを重ねると名前が出ます。切り替えると、左パネルと真ん中の表示が、その種類用のものに変わります。

## 共通のしくみ

動画・音楽・音声・ロゴの画面は、同じ形をしています。

- 左パネルの一番上に、設定をまとめて呼び出せる**{{ui:presets.label}}**があります。
- その下に、作り始めるボタンがあります。足りないものがあるときは、ボタンが押せない状態になり、すぐ下に理由が出ます。
- 理由に「（作るもの）のモデルをダウンロードしてください」と出たときは、次に出てくる**モデルのカード**からインストールします。
- 作り始めるボタンの代わりに `Ctrl+Enter` でも作れます。
- 作っている間の様子（順番待ち、作成中、できなかった理由）は、真ん中の画面の一番上に出ます。**{{ui:media.job.cancel}}** で止められます。

> 作成は一度に 1 件ずつです。動画や音楽を作っている間は、画像など、ほかの生成は順番待ちになります。待っている項目は **{{ui:app.tabs.queue}}** タブでも確認できます。

### 最初に必要なモデルのダウンロード

動画・音楽・音声・ロゴは、それぞれ専用のモデルが必要です。インストールされていないと、左パネルに「モデルのカード」が出ます。**{{ui:pack.install}}** を押すと、アプリが自動で取り込みます。

| 作るもの | カードの名前 | 大きさの目安 |
|---|---|---|
| 動画 | {{ui:pack.title.video}} | 約 18 GB |
| 動画（高速版） | {{ui:pack.title.turbo}} | 標準と共通のファイルは重ねて取りません |
| 音楽 | {{ui:pack.title.music}} | 約 10 GB |
| 音声 | {{ui:pack.title.voice}} | 約 9 GB |
| ロゴ | {{ui:pack.title.logo}} | 約 12 GB |

大きさは目安です。正確な大きさは、カードに出る数字を見てください。

動画は、標準版と高速版の 2 つのモデルから選べます。カードには、このパソコンの GPU の名前とメモリが出て、モデルごとに合うかどうか（**{{ui:media.choice.fit.comfortable}}**、**{{ui:media.choice.fit.tight}}**、**{{ui:media.choice.fit.short}}**）が出ます。このパソコンに合うものには **{{ui:media.choice.recommended}}** の印が付きます。GPU のメモリを調べられないときは、合うかどうかが **{{ui:media.choice.fit.unknown}}** と出ます。目安なので、**{{ui:media.choice.fit.short}}** でも、遅くなるだけで動くことがあります。

ダウンロードは最初に一度だけです。進み具合がカードに出るほか、どの画面でも左下の「{{ui:media.downloads.title}}」の枠に名前と進み具合が出て、途中で **{{ui:common.cancel}}** もできます。失敗したときは、カードに理由が出て、ボタンが **{{ui:pack.retry}}** に変わります。

ダウンロードの大きさが分かるものは、「あと約 ○分」と残り時間も出ます（ダウンロードの速さから見積もるので、始めてしばらくは出ません）。大きさが分からないものや、インストールの作業中は、「経過 ○分」と、始めてからの時間が出ます。拡張機能のダウンロードのときは、枠の **{{ui:media.downloads.manage}}** から、インストールされている拡張機能の一覧を開けます。

インストールが終わるとカードは消えます。音声だけは、読み上げ用のエンジンも一緒にインストールされるため、少し時間がかかります。

> ダウンロードの前に、画像を作るエンジン（ComfyUI）の準備が終わっている必要があります。うまく進まないときは [困ったとき](10-troubleshooting.md) をご覧ください。

## 動画を作る

![動画の画面。左に作り方・プロンプト・サイズなどの設定、真ん中に作った動画の一覧が出る](shot:media-video)

動画は、文章から作る方法と、1 枚の画像を動かす方法があります。

### 作り方

1. 左パネルで **{{ui:media.tab.video}}** を選びます。
2. 初めてなら、**{{ui:pack.title.video}}** のカードで **{{ui:pack.install}}** を押します。
3. **{{ui:video.mode.label}}** で、**{{ui:video.mode.text}}** か **{{ui:video.mode.image}}** を選びます。
4. **{{ui:video.prompt}}** に、どんな動画にしたいかを書きます。画像から作るときは、どう動かしたいかを書きます。
5. **{{ui:params.invoke.invoke}}** を押します。

**{{ui:video.mode.image}}** を選ぶと、動かす画像を指定する欄が出ます。画像をドロップするか、ギャラリーで画像を選んでから **{{ui:video.pickFromGallery}}** を押します。

ギャラリーの画像を右クリックして **{{ui:gallery.menu.sendToVideo}}** を選ぶ方法もあります。

### 設定

| 項目 | 内容 |
|---|---|
| {{ui:video.negative}} | 入れたくない要素。最初から、ぼやけや文字などを避ける言葉が入っています |
| {{ui:video.model}} | **{{ui:video.model.standard}}** はていねいに作ります。**{{ui:video.model.fast}}** は短い時間で作れますが、細部が荒れることがあります |
| {{ui:video.size}} | 動画の大きさ。最初は 832×480 です。縦長・正方形も選べます |
| {{ui:video.fps}} | 1 秒あたりのコマ数（8〜30） |
| {{ui:video.lengthLabel}} | 1〜10 秒。コマ数は長さとフレームレートから自動で決まります |
| {{ui:video.steps}}、{{ui:video.cfg}} | 仕上がりの細かい調整。モデルを選ぶと、そのモデルに合う値に切り替わります |
| {{ui:params.seed.label}} | 左上の行で、サイコロ（{{ui:params.seed.random}}）のままなら毎回新しいシードになり、鍵（{{ui:params.seed.fixed}}）にすると同じシードで同じ動きを作り直せます |

**{{ui:video.model.fast}}** を使うには、別に **{{ui:pack.title.turbo}}** のダウンロードが必要です。このモデルは非商用ライセンスです。

**{{ui:video.model}}** の一覧には、インストール済みの動画モデルも並びます。Wan 2.1 と Wan 2.2（VACE を含む）、HunyuanVideo と HunyuanVideo 1.5、LTX-Video と LTX-2 のモデルに対応しています。選ぶと、そのモデルに合うステップ数・CFG・フレームレート・サイズに切り替わり、動画モデルのダウンロードは要りません。テキストエンコーダーと VAE は、インストール済みのモデルから名前で探して使います。足りないときは生成が失敗し、必要なファイルが表示されます（モデル画面の **{{ui:models.install.tab.starter}}** からまとめて入れられます）。

- Wan のテキストから動画のモデルは、画像から動かせません。画像から動かすには、Wan の画像から動画のモデルを選びます。
- Wan 2.2 の 14B は、高ノイズと低ノイズの 2 つのファイルで 1 組です。高ノイズのファイルを選ぶと、組の低ノイズのファイルも一緒に使います。
- HunyuanVideo（1.0 と 1.5）と LTX-Video は、テキストからも画像からも作れます（HunyuanVideo 1.0 は、画像から動画のモデルと、視覚用のファイル `llava_llama3_vision` が要ります）。LTX-2 は音も作り、動画に入ります。
- Wan の VACE モデルは、絵を動画の参照として使えます。Wan 2.1 の画像から動画のモデルは、CLIP vision のファイル（`clip_vision_h`）も要ります（スターターのモデルから入れられます）。
- 制御用の動画・音声・カメラの動き・ポーズの動画が要る Wan のモデル（Fun Control、S2V、Animate など）は、ここでは動かせません。生成が失敗し、必要なものが表示されます。

### GPU のメモリが少ないとき

**{{ui:video.light.title}}** に 2 つのスイッチがあります。

- **{{ui:video.light.fp8}}**：モデルが使うメモリがほぼ半分になります。細部がわずかに粗くなることがあります。
- **{{ui:video.light.tiled}}**：最後の仕上げでメモリが急に増えるのを抑えます。画質は変わらず、少し遅くなります。

それでも足りないときは、サイズを小さくして作り、できた動画を **{{ui:video.finish}}** で大きくする方法もあります。

### 結果

動画は数分〜十数分かかります。できあがると、真ん中に動画の一覧として並び、その場で再生できます。右側のギャラリーにも、▶ の付いたサムネイルとして入ります。

各動画の下には、プロンプトと大きさ・長さ・シードが出ます。ごみ箱のボタンで削除できます。

**{{ui:video.finish}}** を押すと、**{{ui:finish.title}}** の画面が開きます。

- **{{ui:finish.smooth.title}}**：コマの間を補って動きをなめらかにします。
- **{{ui:finish.enlarge.title}}**：拡大用のモデルで動画を大きくします。時間とメモリを多く使います。

もとの動画はそのまま残り、仕上げた動画が新しく増えます。コマを補うには、拡張機能が必要になることがあります（画面の案内に従って **{{ui:finish.install}}** を押してください）。

## 音楽を作る

![音楽の画面。左にスタイル・歌詞・長さ・テンポなどの設定が並ぶ](shot:media-music)

文章（スタイル）と歌詞から、曲を作ります。

### 作り方

1. 左パネルで **{{ui:media.tab.music}}** を選びます。
2. 初めてなら、**{{ui:pack.title.music}}** のカードで **{{ui:pack.install}}** を押します。
3. **{{ui:music.tags}}** に、ジャンル・雰囲気・楽器をコンマで区切って書きます。たとえば `upbeat J-pop, female vocal, piano, bright` のようにします。
4. 歌のある曲にするなら、**{{ui:music.lyrics}}** を書きます。歌なしにするときは **{{ui:music.instrumental}}** にチェックを入れます。
5. **{{ui:params.invoke.invoke}}** を押します。

スタイルは必須です。空のままだと作れません。

歌詞は `[verse]`（Aメロ）や `[chorus]`（サビ）のように、角かっこで区切りを付けて書けます。英語・日本語・中国語などで書けます。**{{ui:music.language}}** で歌詞の言語を選びます。迷うときは **{{ui:music.lang.unknown}}** にします。

### 設定

| 項目 | 内容 |
|---|---|
| {{ui:music.lengthLabel}} | 10〜240 秒 |
| {{ui:music.bpm}} | 曲の速さ（40〜220） |
| {{ui:music.timeSignature}} | 2/4・3/4・4/4・6/4 |
| {{ui:music.key}} | `C major` から `B minor` まで |
| {{ui:music.steps}}、{{ui:music.cfg}} | 仕上がりの細かい調整 |

### 結果

曲は数十秒〜数分で、真ん中の一覧に並びます。それぞれにプレーヤーが付いていて、そのまま再生できます。長さ・テンポ・キー・シードが出て、歌詞があるときは **{{ui:audio.lyrics}}** を開いて確かめられます。

ギャラリーにも音符のサムネイルで入ります。

## 音声を作る

![音声の画面。左に読み上げる文章・言語・ボイスの選び方が並ぶ](shot:media-voice)

入力した文章を、声にして読み上げます。

### 作り方

1. 左パネルで **{{ui:media.tab.voice}}** を選びます。
2. 初めてなら、**{{ui:pack.title.voice}}** のカードで **{{ui:pack.install}}** を押します。読み上げのエンジンとモデルが、アプリのフォルダの中だけに入ります。
3. **{{ui:voice.text}}** に、読み上げたい文章を入力します。
4. **{{ui:voice.language}}** を選びます。**{{ui:voice.lang.Auto}}** なら、文章から判定します。
5. 声を決めます（下を参照）。
6. **{{ui:params.invoke.invoke}}** を押します。

### 声の決め方

**{{ui:voice.mode.label}}** で 2 つの方法から選べます。

- **{{ui:voice.mode.preset}}**：用意されたボイスから選びます。日本語の女性、中国語、英語の男性、韓国語の女性などがあり、名前の後ろに言語と性別が出ます。**{{ui:voice.style}}** に「明るく元気に」「ゆっくり落ち着いて」のように書くと、話し方も指定できます。
- **{{ui:voice.mode.design}}**：**{{ui:voice.description}}** に、声の特徴を言葉で書きます。たとえば「落ち着いた低めの男性の声。ゆっくり、やさしく話す。」のようにします。説明は必須です。

読み上げられる言語は、日本語・英語・中国語・韓国語・ドイツ語・フランス語・ロシア語・ポルトガル語・スペイン語・イタリア語です。

### 結果

できあがった音声は、真ん中の一覧にプレーヤー付きで並びます。使ったボイス（{{ui:audio.voice.designed}}のときは「{{ui:audio.voice.designed}}」）と言語も出ます。ギャラリーにも入ります。

初めての生成は、モデルの読み込みで少し時間がかかります。しばらく使わないと、モデルは GPU から外れて、ほかの作業にメモリが戻ります。

## ロゴを作る

![ロゴの画面。左にロゴの文字・スタイル・形・候補の数が並ぶ](shot:media-logo)

文字を入れたロゴの候補を作ります。

### 作り方

1. 左パネルで **{{ui:media.tab.logo}}** を選びます。
2. 初めてなら、**{{ui:pack.title.logo}}** のカードで **{{ui:pack.install}}** を押します。
3. **{{ui:logo.text}}** に、ロゴに入れる文字を入力します（60 文字まで）。
4. **{{ui:logo.style}}** に、雰囲気・色・形を書きます。日本語でも英語でも構いません。たとえば「ミニマル、青と白、幾何学的」のようにします。
5. **{{ui:logo.size}}** で、**{{ui:logo.size.square}}**・**{{ui:logo.size.wide}}**・**{{ui:logo.size.tall}}** から形を選びます。
6. **{{ui:logo.countLabel}}** を 1〜4 から選び、**{{ui:params.invoke.invoke}}** を押します。

### 結果と文字の重ね方

できたロゴは、真ん中に候補として並びます。ギャラリーでは、**{{ui:gallery.view.images}}** ではなく **{{ui:gallery.view.assets}}** のほうに入ります。ロゴを作る画面を開くと、右側のギャラリーは自動でアセット表示になります。

英語の文字は正確に出ますが、日本語は崩れることがあります。そのときは、気に入った候補の **{{ui:logo.layText}}** を押してください。**{{ui:media.tab.text}}** に切り替わり、そのロゴが背景になるので、好きな文字を重ねられます。

## テキスト（文字と吹き出し）

![テキストの画面。左に文字を追加するボタン・背景・レイヤー・文字のスタイル、真ん中に編集中の画像が出る](shot:media-text)

**{{ui:media.tab.text}}** は、画像に文字や吹き出しを入れて、画像として保存する編集画面です。モデルのダウンロードは要りません。画像を作る処理も使わないので、すぐに使えます。

### 背景を決める

**{{ui:text.bg.title}}** で、何の上に文字を置くかを選びます。

- **{{ui:text.bg.image}}**：画像を背景にします。ギャラリーで画像を表示してから **{{ui:text.bg.useViewer}}** を押すか、画像をこの画面にドロップします。画像と同じ大きさで保存されます。
- **{{ui:text.bg.color}}**：単色の背景です。大きさは、一覧の 1024×1024 や 1920×1080 などから選ぶか、幅と高さを数字で入力します。
- **{{ui:text.bg.transparent}}**：背景なしです。文字だけを透明な画像として作れます。

ギャラリーの画像を右クリックして **{{ui:gallery.menu.sendToText}}** を選ぶ方法もあります。

### 文字と吹き出しを足す

- **{{ui:text.add.text}}**：文字のレイヤーを足します。
- **{{ui:text.add.bubble}}**：吹き出しを足します。形は **{{ui:text.shape.round}}**・**{{ui:text.shape.box}}**・**{{ui:text.shape.cloud}}**・**{{ui:text.shape.burst}}**・**{{ui:text.shape.whisper}}**・**{{ui:text.shape.narration}}** から選びます。

足したものは、画面の中でドラッグして動かせます。選ぶと四隅に丸いつまみが出て、ドラッグで大きさを変えられます。吹き出しには「{{ui:text.bubble.tail}}」があり、先のつまみをドラッグして向きを変えます。

`Delete` で削除、`Ctrl+D` で複製、矢印キーで少しずつ移動、`Ctrl+Z` で元に戻し、`Ctrl+Shift+Z`（または `Ctrl+Y`）でやり直しができます。画面上の **{{ui:text.undo}}**・**{{ui:text.redo}}** のボタンでも同じです。表示の大きさは **{{ui:text.zoom.in}}**・**{{ui:text.zoom.out}}**・**{{ui:text.zoom.fit}}** で変えられます。

### レイヤー

足した文字と吹き出しは、**{{ui:text.layers.title}}** に重なりの順で並びます。一覧の上にあるものほど手前です。

1 つずつ、**{{ui:text.layer.hide}}**、**{{ui:text.layer.lock}}**、**{{ui:text.layer.up}}**・**{{ui:text.layer.down}}** での順番の入れ替え、**{{ui:text.layer.duplicate}}**、**{{ui:text.layer.delete}}** ができます。**{{ui:text.layers.clear}}** で、まとめて消せます。

### 文字を整える

レイヤーを選ぶと、その下に設定が出ます。

| 項目 | 内容 |
|---|---|
| {{ui:text.content}} | 文字を入力します（改行できます） |
| {{ui:text.font}}、{{ui:text.weight}}、{{ui:text.size}} | 書体・太さ・大きさ。書体はアプリに入っているので、どの PC でも同じ見た目になります |
| {{ui:text.fill}} | **{{ui:text.fill.solid}}** か、**{{ui:text.fill.gradient}}**（上下で色を変える） |
| {{ui:text.stroke}}、{{ui:text.outline}} | 文字の縁取りと、その外側の縁取り |
| {{ui:text.shadow}} | 影。色・ぼかし・ずらしを選べます |
| {{ui:text.letterSpacing}}、{{ui:text.lineHeight}}、{{ui:text.align}} | 字と字、行と行の間隔、そろえ方 |
| {{ui:text.vertical}} | 縦書きにします。縦書きのときは、そろえ方が「{{ui:text.align.top}}・{{ui:text.align.center}}・{{ui:text.align.bottom}}」に変わります |
| {{ui:text.bend}} | 文字をカーブさせます（縦書きでは使えません） |
| {{ui:text.rotation}}、{{ui:text.opacity}} | 回転と不透明度 |

吹き出しでは、さらに大きさ・塗りの色・枠線・しっぽを調整できます。**{{ui:text.shape.burst}}** の形では **{{ui:text.bubble.shuffle}}** でギザギザを変えられます。**{{ui:text.bubble.autoFit}}** をオンにすると、文字が吹き出しに収まるよう縮みます。

### スタイルのプリセット

左パネルの一番上のプリセットには、**{{ui:text.preset.plain}}**・**{{ui:text.preset.pop}}**・**{{ui:text.preset.sfx}}**・**{{ui:text.preset.gold}}**・**{{ui:text.preset.sticker}}**・**{{ui:text.preset.soft}}** のロゴ風スタイルが入っています。文字のレイヤーを選んでから使うと、そのスタイルが当たります。

自分のスタイル（フォント・塗り・縁取り・影・字間）を保存することもできます。

### 保存

できあがったら **{{ui:text.save}}** を押します。背景の大きさの PNG 画像として、ギャラリーに入ります。保存したあとも、画面の編集内容は残るので、続けて直せます。

## プリセット

動画・音楽・音声・ロゴ・テキストの画面にも、画像と同じ形のプリセットがあります。画面の左上の **{{ui:presets.label}}** から選ぶと、保存しておいた設定がまとめて入ります。

自分の設定を保存するには、プリセットの横にある保存ボタン（**{{ui:presets.saveNew}}**）を押し、名前を付けます。保存したものは **{{ui:presets.group.mine}}** に並びます。一覧の各項目の「…」メニューから、**{{ui:presets.overwrite}}**・**{{ui:presets.rename}}**・**{{ui:presets.delete}}** もできます。最初から用意されたものは **{{ui:presets.group.builtin}}** に入っています（名前は英語です）。

画面ごとに、保存される内容は少しずつ違います。

| 画面 | 保存される内容 | 保存されないもの |
|---|---|---|
| 動画 | プロンプト・モデル・サイズ・長さ・品質の設定 | シードと元の画像 |
| 音楽 | スタイルのタグと曲の設定 | 歌詞とシード |
| 音声 | 言語と声（ボイスと話し方、または声の説明） | 読み上げる文章 |
| ロゴ | スタイルの言葉と形、候補の数 | ロゴに入れる文字 |
| テキスト | 文字のスタイル | 文字の内容 |
