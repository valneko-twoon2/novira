# ギャラリーとビューア

作った絵は、画面の右側の **ギャラリー** に並びます。ギャラリーで選んだ絵は、中央の **{{ui:app.views.viewer}}** で大きく見られます。
この章では、絵の整理のしかた、探しかた、ビューアでの見かた、設定の呼び出しかた、削除やダウンロードを説明します。

## ギャラリーの見かた

右のパネルは、上下 2 つの部分でできています。

- 上：**{{ui:gallery.boards.title}}**。絵をしまっておくフォルダのようなものです。
- 下：選んでいるボードの絵のサムネイルです。

サムネイルの上の行には、次のものがあります。

- 「{{ui:gallery.view.images}}」と「{{ui:gallery.view.assets}}」の切り替えと、絵の数。
- 虫めがねのボタン：検索（{{ui:gallery.search.label}}）
- カレンダーのボタン：{{ui:gallery.date.button}}
- 歯車のボタン：{{ui:gallery.settings.title}}
- 上向きの矢印のボタン：{{ui:gallery.upload}}

**{{ui:gallery.view.images}}** には、novira で作った絵（動画や音声も含みます）が入ります。
**{{ui:gallery.view.assets}}** には、アップロードした画像や、ロゴのように「作品とは別の素材」として扱うものが入ります。見当たらない絵があるときは、もう一方を見てみてください。

サムネイルの大きさは、歯車のボタンのスライダーで変えられます。
動画や音声のサムネイルには再生のマークが付いていて、カーソルをのせて横に動かすと、その位置の場面を確かめられます。

## ボード

ボードは、絵を分けて整理するための入れ物です。「{{ui:gallery.boards.uncategorized}}」は、はじめからあるボードで、ボードに入れていない絵が入ります。

- **作る**：ボード欄の右上の **＋**（{{ui:gallery.boards.add}}）を押します。名前をその場で入力できます。
- **切り替える**：ボードをクリックします。そのボードの絵だけが下に並びます。
- **名前を変える**：ボードの名前をダブルクリックするか、右クリックのメニューから「{{ui:common.rename}}」を選びます。
- **探す**：ボード欄の虫めがねで、ボード名を検索できます。
- **折りたたむ**：「{{ui:gallery.boards.title}}」の見出しをクリックします。ボード欄の下端をドラッグすると、高さを変えられます。

### 新しい絵がどのボードに入るか

新しく作った絵（アップロードした絵も）は、「**{{ui:gallery.boards.autoBadge}}**」の印が付いたボードに入ります。
初めはボードをクリックするたびに、そのボードが「{{ui:gallery.boards.autoBadge}}」になります。固定したいときは、ギャラリーの設定で「{{ui:gallery.settings.autoAssign}}」をオフにして、ボードの右クリックメニューの「{{ui:gallery.boards.setAutoAdd}}」で決めます。

### ボードの右クリックメニュー

- **{{ui:gallery.boards.setAutoAdd}}**：新しい絵の保存先にします。
- **{{ui:common.rename}}**
- **{{ui:gallery.boards.archive}}**：ボードを一覧から隠します。消えるのではなく、ギャラリーの設定の「{{ui:gallery.settings.showArchived}}」をオンにすると、また見えます。「{{ui:gallery.boards.unarchive}}」で元に戻せます。
- **{{ui:gallery.boards.delete}}**：確認の窓が出て、次のどちらかを選びます。
  - 「{{ui:gallery.boards.deleteBoardOnly}}」：絵は残り、「{{ui:gallery.boards.uncategorized}}」に移ります。
  - 「{{ui:gallery.boards.deleteBoardAndImages}}」：ボードの中の絵も消します。

> 「{{ui:gallery.boards.uncategorized}}」は、名前の変更・アーカイブ・削除ができません。

## 絵を選ぶ

サムネイルは、次のように選べます。

| 操作 | 結果 |
|---|---|
| クリック | その 1 枚を選ぶ。ビューアで見る絵も、その絵に替わります |
| `Ctrl` を押しながらクリック | 選んでいる絵に足す、または選びから外す（複数選択） |
| `Shift` を押しながらクリック | 前に選んだ絵から、クリックした絵までをまとめて選ぶ |
| `Alt` を押しながらクリック | ビューアの絵と見比べる（後述） |
| ダブルクリック | 中央をビューアに切り替えて、その絵を大きく見る |
| `Ctrl+A` | いま並んでいる絵をすべて選ぶ |
| 矢印キー | 前後・上下の絵に選びを移す。`Shift` を押しながらで、範囲を広げる |
| `Esc` | 選びを解除する |

> 矢印キーなどは、カーソルがギャラリーの上にあるか、中央がビューアのときに働きます。

選んだ絵には、青い枠が付きます。サムネイルにカーソルをのせると、次のものが出ます。

- 絵のサイズ（ギャラリーの設定の「{{ui:gallery.settings.alwaysShowSize}}」で、常に表示もできます）
- 星のボタン（スターを付ける・外す）
- ごみ箱のボタン（削除）

スターを付けた絵には、左上に黄色い星の印が付きます。

## 複数の絵をまとめて操作する

![2 枚を選んで右クリックしたときのメニュー](shot:gallery-multi-menu)

絵を 2 枚以上選んでから、選んだ絵の 1 つを右クリックすると、まとめて使えるメニューが出ます。先頭に「2 枚選択中」のように、選んだ数が出ます。

- **{{ui:gallery.menu.changeBoard}}**：選んだ絵を、まとめて別のボードに移します。
- **{{ui:gallery.menu.starAll}}** / **{{ui:gallery.menu.unstarAll}}**
- **{{ui:common.download}}**：選んだ絵を、続けて保存します。
- **{{ui:share.menu}}**：選んだ絵を、共有用のコピーとしてまとめて書き出します（動画と音声は除きます）。
- **{{ui:gallery.menu.batch}}**：選んだすべての絵に、同じ処理（背景の除去、拡大など）をかけます。1 枚ごとにキューに入ります。
- いちばん下の赤い項目：選んだ絵をまとめて削除します。

> 選んでいない絵を右クリックしたときは、その 1 枚のメニューが出ます。複数の絵に使いたいときは、先に選んでから、選んだ絵の上で右クリックしてください。

## 探す・絞り込む・並べ替える

### 検索

虫めがねのボタンを押すと、検索の欄が開きます。ファイル名か、ポジティブのプロンプトの一部を入れると、そのボードの絵が絞り込まれます。`Esc` で検索を閉じて、絞り込みを解除できます。

### 日付で絞り込む

![日付で絞り込むメニュー。今日・昨日などのボタンと、月のカレンダー](shot:gallery-date)

カレンダーのボタンを押すと、日付で絞り込むメニューが開きます。

- **{{ui:gallery.date.quick.today}}**・**{{ui:gallery.date.quick.yesterday}}**・**{{ui:gallery.date.quick.last7}}**・**{{ui:gallery.date.quick.last30}}**：ボタン 1 つで期間を決めます。
- 月のカレンダー：絵がある日には印が付きます。日付をクリックすると、その日の絵だけが並びます。上の矢印で月を移れます。
- **{{ui:gallery.date.custom}}**：開始日と終了日を入れて **{{ui:gallery.date.apply}}** を押すと、その期間の絵だけが並びます。どちらか片方だけでも使えます。
- **{{ui:gallery.date.quick.all}}**：絞り込みをやめます。

絞り込み中は、ギャラリーの上に期間の札が出ます。札の × でも解除できます。

### ギャラリーの設定

歯車のボタンでは、並びかたや見た目を変えられます。

- {{ui:gallery.settings.thumbnailSize}}
- {{ui:gallery.settings.autoSwitch}}：絵ができたとき、自動でその絵を見せます。
- {{ui:gallery.settings.autoAssign}}
- {{ui:gallery.settings.alwaysShowSize}}
- {{ui:gallery.settings.showArchived}}
- {{ui:gallery.settings.starredFirst}}：スターを付けた絵を、いちばん上に並べます（初めから入っています）。
- {{ui:gallery.settings.sort}}：「{{ui:gallery.settings.sortNewest}}」か「{{ui:gallery.settings.sortOldest}}」。
- {{ui:gallery.settings.groupByDate}}：日ごとの見出しを付けて区切ります。

## ビューアで見る

![ビューア。上にツールバー、中央に絵、右下に拡大縮小のボタン、下に絵の情報が出ている](shot:viewer)

中央の「{{ui:app.views.viewer}}」には、選んでいる絵が大きく出ます。
前後の絵には、画面の左右の矢印で移れます。いちばん下の行には、絵のサイズ、使ったモデル、シード、ファイル名が出ます。動画や音声は、そのまま再生できます。

### 拡大と移動

- マウスのホイール：カーソルの位置を中心に、拡大・縮小します。
- ドラッグ：拡大して絵がはみ出しているときに、絵を動かします。`Space` を押しながら、またはホイールのボタンを押しながらでも動かせます。
- ダブルクリック：全体表示と、等倍（100%）を切り替えます。
- 右下のボタン：縮小、倍率（押すとよく使う倍率の一覧）、拡大、`1:1`（等倍）、画面に合わせる。
- キー：`+` と `-` で 1 段階ずつ、`Ctrl+0` で画面に合わせる、`Ctrl+1` で等倍にします。

### ツールバー

絵の上のツールバーには、その絵への操作が並びます。ボタンにカーソルをのせると、名前とショートカットが出ます。

| グループ | ボタン |
|---|---|
| 情報 | **{{ui:gallery.viewer.toggleMetadata}}**（`I`） |
| 設定を読み込む | **{{ui:gallery.menu.remix}}**（`R`）、**{{ui:gallery.menu.usePrompt}}**（`P`）、**{{ui:gallery.menu.useSeed}}**（`S`）、**{{ui:gallery.menu.useAll}}**（`A`）、**{{ui:gallery.menu.loadWorkflow}}**（`W`）、**{{ui:gallery.derive.menu}}** |
| 送る・直す | **{{ui:gallery.menu.sendToCanvas}}**、**{{ui:gallery.menu.useAsReference}}**、**{{ui:gallery.menu.upscale}}**（`Shift+U`）、**{{ui:gallery.menu.segment}}**、**{{ui:cutout.menu}}**、**{{ui:facefix.menu}}**、**{{ui:gallery.manga.menu}}**、**{{ui:character.menu}}**、**{{ui:gallery.compare.toggle}}**（`C`） |
| 整理 | **{{ui:gallery.menu.star}}**、**{{ui:common.download}}**、**{{ui:share.menu}}**、**{{ui:gallery.menu.delete}}**（`Del`） |

働きは、サムネイルの右クリックメニューの同じ名前の項目と同じです。設定のない絵（アップロードした画像など）では、設定を読み込むボタンが灰色になります。

## 絵の情報と、設定の呼び出し

![メタデータのパネル。プロンプト、モデル、シード、ステップ数などの一覧](shot:viewer-metadata)

ツールバーの **{{ui:gallery.viewer.toggleMetadata}}** ボタン（`I`）を押すと、絵の上に情報のパネルが開きます。もう一度押すか、右上の × か、パネルの外を押すと閉じます。パネルの文字は、ドラッグで選んで `Ctrl+C` でコピーできます（文字を選んでいる間の `Ctrl+C` は、絵ではなく文字をコピーします）。
パネルには 4 つのタブがあります。

- **{{ui:gallery.meta.tabRecall}}**：絵を作ったときの設定が、項目ごとに並びます（プロンプト、モデル、シード、ステップ数、CFG スケール、スケジューラー、サイズ、LoRA など）。各行の右の矢印ボタンで、**その項目だけ**を左パネルに読み込めます。プロンプトの行は、矢印の左のボタンでプロンプトをそのままコピーできます。スケジューラーが決まっている系統のモデル（Anima、Flux など）の絵では、スケジューラーの代わりに「{{ui:gallery.meta.sampling}}」の行が出て、実際に使ったサンプラーとスケジューラーがわかります。この行は読み込めず、「{{ui:gallery.menu.useAll}}」でもスケジューラーは今のままです。
- **{{ui:gallery.meta.tabMetadata}}**：記録されている内容を、そのままの形で見られます。右上のボタンでコピーできます。
- **{{ui:gallery.meta.tabDetails}}**：ファイル名、サイズ、作った日時、ボード、スターの有無などです。
- **{{ui:gallery.meta.tabWorkflow}}**：ワークフローで作った絵なら、その中身が出ます。

設定を読み込む方法は、使いたい範囲によって選びます。

| 方法 | 読み込むもの |
|---|---|
| **{{ui:gallery.menu.useAll}}** | プロンプト、モデル、シード、サイズなど、設定のすべて。シードは固定になります。ほかのソフトで作って取り込んだ絵は、モデルを名前で探します（`v17` と `v170` のような書き方の違いは同じモデルとみなします）。見つからないときは、今のモデルのままで、通知でそう知らせます |
| **{{ui:gallery.menu.remix}}** | シード以外のすべて。いまのシードの設定（ランダムか固定か）は、そのまま残ります。「同じ設定で、別の絵を作りたい」ときに使います |
| **{{ui:gallery.menu.usePrompt}}** | プロンプト（ポジティブとネガティブ）だけ |
| **{{ui:gallery.menu.useSeed}}** | シードだけ。シードは固定になります |
| **{{ui:gallery.menu.useSize}}** | 幅と高さだけ（右クリックメニューのみ） |

読み込んだあとは、左パネルを見て、**{{ui:params.invoke.invoke}}** を押すだけです。

> novira で作った絵の画像ファイル（PNG）には、設定も一緒に記録されています。そのため、ファイルを別の場所に移してからアップロードし直した絵でも、設定を読み込めることがあります。ほかのソフトで作った画像や、加工して保存し直した画像には、設定が入っていません。

## 2 枚を見比べる

![スライダーで 2 枚を比べているビューア。真ん中の縦線を左右に動かす](shot:viewer-compare)

2 枚の絵の違いを見たいときは、比較を使います。

1. 比べたい絵の 1 枚目をクリックして選び、中央を「{{ui:app.views.viewer}}」のタブにします。
2. 2 枚目のサムネイルを、`Alt` を押しながらクリックします（右クリックメニューの「{{ui:gallery.menu.compare}}」でもできます）。
3. 2 枚目のサムネイルに「{{ui:gallery.compare.badge}}」の札が付き、ビューアが比較の画面に変わります。

> `Ctrl` を押しながら 2 枚を選んでおいて、ツールバーの比較ボタンか `C` キーを押しても始められます。1 枚しか選んでいないと「{{ui:gallery.compare.hint}}」と案内が出ます。

比較の画面の上には、次のボタンが出ます。

- **{{ui:gallery.compare.slider}}**：2 枚を重ねて、真ん中の縦線をドラッグすると、左右でどう違うかが見られます。
- **{{ui:gallery.compare.sideBySide}}**：2 枚を左右に並べます。
- **{{ui:gallery.compare.hover}}**：カーソルを絵にのせている間だけ、2 枚目に切り替わります。
- **{{ui:gallery.compare.swap}}**：1 枚目と 2 枚目を入れ替えます。
- **{{ui:gallery.compare.exit}}**：比較をやめます。`Esc` でもやめられます。

拡大・移動は、2 枚が連動して動きます。細かい部分の違いは、拡大して見ると分かりやすくなります。

## スターと削除

### スターを付ける

気に入った絵には、スターを付けておけます。サムネイルの星のボタン、右クリックメニュー、ビューアのツールバーのどれからでも付けたり外したりできます。
ギャラリーの設定の「{{ui:gallery.settings.starredFirst}}」が入っていると、スターの付いた絵が先頭に集まります。

### 削除する

絵を削除する方法は、次のとおりです。

- サムネイルのごみ箱のボタン
- 右クリックメニューの「{{ui:gallery.menu.delete}}」
- ビューアのツールバーのごみ箱のボタン
- 絵を選んで `Delete` キー（`Backspace` でも同じです）

確認の窓が出るので、「{{ui:common.delete}}」を押すと削除されます。

削除した絵はすぐには消えず、14 日間（500 枚まで）取っておかれるので、削除を取り消せます。

- 削除した直後に出るメッセージの **元に戻す** を押します（数秒だけ出ます）。
- ギャラリーの上の「{{ui:gallery.undoDelete.label}}」ボタンを押すか、ポインターをギャラリーの上に置いている間（またはビューアを開いている間）に `Ctrl+Z` を押します。直前の 30 回分までの削除を、新しいものから順に取り消せます。
- 元に戻した絵をもう一度削除したいときは、「{{ui:gallery.redoDelete.label}}」ボタンか `Ctrl+Shift+Z`（`Ctrl+Y`）を使います。

> 取り消せる履歴は、アプリを閉じると忘れます。削除から 14 日を過ぎた絵は、元に戻せません。ボードごと絵を削除した場合も、同じように取り消せます。ボードがなくなっているときは、絵は「{{ui:gallery.boards.uncategorized}}」に戻ります。

確認の窓の「{{ui:common.dontAskAgain}}」にチェックを入れると、以後は確認なしで削除します。確認を元に戻したいときは、**{{ui:app.nav.settings}}** の「{{ui:settings.confirmOnDelete}}」をオンにします。

## アップロードとダウンロード

### アップロード

手元の画像を、ギャラリーに入れられます。

- ギャラリーの上の **{{ui:gallery.upload}}** ボタンを押して、ファイルを選びます。
- エクスプローラーから、画像ファイルをギャラリーにドラッグ＆ドロップします。ボードの上にドロップすると、そのボードに入ります。

アップロードした画像は、「{{ui:gallery.boards.autoBadge}}」のボードの **{{ui:gallery.view.assets}}** に入り、画面もそこに切り替わります。複数のファイルを一度に入れられます。画像ではないファイルは無視されます。

### ダウンロード

絵のファイルを保存するには、右クリックメニューか、ビューアのツールバーの **{{ui:common.download}}** を使います。複数の絵を選んでいるときは、まとめて保存されます。

### 共有用に書き出す

![共有用に書き出すウィンドウ。形式（PNG・JPEG・WebP）、画質、長辺の上限、生成情報を取り除くスイッチが並ぶ](shot:share-export)

SNS に載せたり人に渡したりするための絵のコピーは、右クリックメニュー（複数の絵を選んでいるときも使えます）か、ビューアのツールバーの **{{ui:share.menu}}** で作ります。元の絵は変わりません。

- **{{ui:share.format}}**：PNG・JPEG・WebP から選びます。JPEG では **{{ui:share.quality}}**（1〜100）を決められ、透明な部分は白になります。WebP は劣化なしで保存します。
- **{{ui:share.size}}**：「{{ui:share.size.original}}」、2048・1536・1024 px、または「{{ui:share.size.custom}}」で長さを入れます。それより小さい絵は拡大しません。
- **{{ui:share.removeInfo}}**：初めはオフです。オンにすると、プロンプト・設定・ワークフローを含めず、絵を画素から保存し直すので、ほかの埋め込み情報も残りません。オフのときは、PNG だけが設定を残します。人に渡す前に、プロンプトを見せたくないときはオンにしてください。
- **{{ui:share.watermark}}**：初めはオフです。オンにすると、書き出す絵に、目に見えない透かし（TrustMark）、AI で作った絵であることを示す情報（IPTC）、署名付きのコンテンツ認証情報（C2PA）を入れます。透かしには novira の印と絵ごとに違うランダムな番号が入り、番号と元の絵の組はこのアプリに記録されます。

**{{ui:share.run}}** を押すと、デスクトップ版では保存先のフォルダーを選ぶ窓が開きます。ファイル名はギャラリーのファイル名に新しい拡張子を付けたもので、同じ名前のファイルがあるときは「-2」「-3」のように番号を付け、上書きはしません。書き出したあとは **{{ui:share.openFolder}}** でそのフォルダーを開けます。

> 書き出せるのは画像だけです。選んだ中の動画と音声は除かれます。ブラウザで開いているときは、ブラウザのダウンロードに保存されます。1 枚ならそのまま、2 枚以上なら 1 つの zip にまとめます。一度に書き出せるのは合わせて 1 GB までで、超えるときは枚数を減らすよう表示されます。

透かしに使うファイル（合わせて約 140 MB）は、アプリの起動時に自動でダウンロードされます。準備が終わるまではスイッチの下に進み具合が出て、**{{ui:share.run}}** は押せません。ダウンロードに失敗したときは **{{ui:share.watermarkRetry}}** を押してください。

> 透かしは絵の中央の正方形の部分に入ります。画質 80 の JPEG で保存し直したり、半分の大きさに縮めたりしても読み取れることを確かめていますが、切り抜き・作り直し・強い加工で消えることがあります。透かしは公開された方式なので、だれでも同じものを書き込めます。署名はこの PC で作ったものなので、ほかのアプリでは信頼されていない署名者と表示されます。透かしの処理には Microsoft Visual C++ 再頒布可能パッケージが必要で、ないときはエラーが表示されます。

### 透かしを調べる

サムネイルの右クリックメニューの **{{ui:share.check.title}}** で開きます。**{{ui:share.check.pick}}** で絵のファイル（PNG・JPEG・WebP）を選ぶと、次のことを調べて一覧にします。右クリックメニューから開いたときは、その絵をすぐに調べます。ブラウザで開いているときは、ファイルを選んで調べることはできません。

- **{{ui:share.check.watermark}}**：novira の透かしがあるか。あれば番号を表示します。
- **{{ui:share.check.original}}**：番号がこのアプリの書き出しの記録にあれば、元の絵と書き出した日時を表示し、**{{ui:share.check.showOriginal}}** でビューアに出せます。
- **{{ui:share.check.credentials}}**：コンテンツ認証情報があるか、署名のあとに変更されていないか、AI 生成と記録されているか、署名者はだれか。
- **{{ui:share.check.iptc}}**：AI で作った絵であることを示す情報があるか。

> 透かしが見つからなくても、AI で作っていない証明にはなりません。書き出しの記録はこのアプリのデータベースにあるので、ほかの PC の novira で書き出した絵の元の絵はわかりません。透かしに使うファイルの準備が終わっていないときは、透かし以外の項目だけを調べます。

## ドラッグ＆ドロップ

サムネイルは、ほかの場所にドラッグして使えます。複数選んでいるときは、選んだ絵がまとめて動きます。

- **ボードの上へ**：その絵をボードに移します。
- **{{ui:params.refImage.sectionLabel}}の枠へ**：参照画像にします（[画像をつくる](02-generate.md) を参照）。
- **キャンバスやアップスケールの画像欄、スタート画面のカードへ**：その画面の素材として使います。

エクスプローラーのファイルは、ギャラリー、ボード、参照画像の枠、スタート画面のカードなどにドロップできます。

## ギャラリーのショートカットキー

| 操作 | キー |
|---|---|
| 前後・上下の絵を選ぶ | 矢印キー（`Shift` で範囲を広げる） |
| すべて選ぶ | `Ctrl+A` |
| 選びを解除する | `Esc` |
| 選んでいる絵を削除する | `Delete` |
| ビューアの絵をコピーする | `Ctrl+C` |
| 情報パネルを開閉する | `I` |
| リミックス、プロンプト、シード、すべて | `R`、`P`、`S`、`A` |
| ワークフローを読み込む | `W` |
| アップスケールに送る | `Shift+U` |
| 比較を始める・やめる | `C` |
| 全体表示、等倍 | `Ctrl+0`、`Ctrl+1` |
| 拡大、縮小 | `+`、`-` |

これらは、カーソルがギャラリーの上にあるか、中央がビューアのときに働きます。一覧は、**{{ui:app.nav.settings}}** のメニューの「{{ui:app.nav.hotkeys}}」でも見られます。
