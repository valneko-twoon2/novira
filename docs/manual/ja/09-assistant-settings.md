# エージェント・設定・ショートカット

この章では、文章で伝えると設定を整えてくれる エージェントと、設定画面、ショートカットキーの一覧、アプリの情報の画面、開発者ログを説明します。

設定画面・ショートカットキー・アプリの情報は、画面の左下にある **{{ui:app.nav.settingsMenu}}** から開きます。

## エージェント

![エージェントのウィンドウ。使う AI を選んでログインする最初の画面](shot:agent)

左のナビゲーションの **AI** ボタン（**{{ui:agent.open}}**）を押すと、**{{ui:agent.title}}** のウィンドウが開きます。ウィンドウは、見出しをドラッグして動かせます。

モデルや LoRA を選んだり、プロンプトやサイズを設定したりする代わりに、「夕焼けの海辺に立つアニメ風の少女」のように、作りたいものを文章で伝えると、エージェントが設定を選んで入力してくれます。

### 使い始める（ログイン）

エージェントは、novira が自分で AI を動かすのではなく、あなたのパソコンにある AI のコマンド（Claude か Codex）を呼び出して答えを作ります。使うには、次の準備が要ります。

1. Anthropic の **Claude** か、OpenAI の **Codex** の、どちらかのコマンドをパソコンにインストールしておきます。
2. エージェントを開き、使いたいほう（**{{ui:agent.setup.claude}}** か **{{ui:agent.setup.codex}}**）を押します。
3. ブラウザが開くので、そこでログインします。

そのコマンドがパソコンに見つからないときは、「○○ のコマンドがこの PC に見つかりません。先にインストールしてください。」という案内が出ます。先にそのコマンドをインストールしてください。

使うサービスと契約は、あなたが選んだ側のものです。Claude と Codex では、novira は API キーを保存しません。やり取りの内容（送った文章と、エージェントが作業のために読んだアプリの情報。たとえばモデルの一覧、設定、開いている漫画やテキストの内容）は、選んだサービスに送られます。ギャラリーの画像の情報と、生成タブのプロンプトは、あなたが許可したときだけ読みます（下の「画像とプロンプトを読む許可」）。

選んだ AI は、ウィンドウの上の見出しに出ます。変えたいときは、上の **{{ui:agent.changeProvider}}** ボタンを押します。

### Ollama などのサーバーにつなぐ

![サーバーにつなぐ画面。Ollama のボタン、アドレス、モデル、接続テストの結果](shot:agent-server)

Claude と Codex のほかに、このパソコンやネットワーク上で動く、OpenAI 互換の API を持つサーバー（Ollama や LM Studio など）も、エージェントに使えます。novira がサーバーに答えを問い合わせ、エージェントの道具（設定やエディタの操作など）も自分で実行するので、ツール呼び出しに対応したモデルが必要です。

つなぐ手順は次のとおりです。

1. エージェントを開き、**{{ui:agent.setup.openai}}** を押します。
2. 使うサーバーのボタン（Ollama なら **Ollama** のボタン）を押します。アドレスが入り、サーバーにあるモデルの一覧を読み込みます。ほかのサーバーは、**{{ui:agent.endpoint.address}}** に、ふつう「/v1」で終わるアドレスを入力します。
3. **{{ui:agent.endpoint.model}}** は、一覧から選びます。サーバーが一覧をくれないときは、名前を入力します。
4. サーバーがキーを求めるときは、**{{ui:agent.endpoint.key}}** に入力します。キーは、このパソコンに暗号化して保存し、このサーバーにだけ送ります。自分のパソコン上のサーバーには、ふつう要りません。
5. **{{ui:agent.endpoint.test}}** を押します。サーバーが応答するか、モデルがあるか、そのモデルがアプリの道具を呼び出せるかを確かめます。
6. **{{ui:agent.endpoint.use}}** を押します。

モデルが道具を呼び出せないときは、テストでそう表示され、サーバーが返した理由も出ます。入力欄の上にも警告が残り、メッセージの送信は断られます。チャットの名前の横のボタンで別のモデルを選ぶと、もう一度確かめられます。サーバーのコンテキスト（一度に読める長さ）がエージェントの依頼に足りないときも、同じようにテストが失敗します。Ollama の標準の設定がそうです。サーバーのコンテキストの長さを 32768 以上にして（Ollama の設定、または環境変数 OLLAMA_CONTEXT_LENGTH で）、もう一度 **{{ui:agent.endpoint.test}}** を押してください。novira は、道具を使えるふりはしません。

サーバーを使っているときは、チャットの見出しに OpenAI API と出ます。**{{ui:agent.changeProvider}}** を押すと選ぶ画面に戻ります。入力したサーバーは、フォームに残ります。

このパソコンの外にあるサーバーには、あなたが送った内容と、許可した場合にエージェントが読んだ内容が、ネットワークを通って送られます。そのようなサーバーには、アドレスの下に警告が出ます。https を使わないサーバーでは、キーを含めすべてが暗号化されずに流れるため、その警告も出ます。「{{ui:agent.permission.title}}」の確認には、読んだ内容がどこに送られるかも出ます。サーバーの返事は、ただの文章として扱い、依頼は Claude や Codex のものと同じ確認を通ったものだけが実行されます。

### 何をしてくれるか

エージェントが、あなたの文章から次のことを決めて、設定に入れます。入れた内容は、返事の中に一覧で出ます。

| 内容 | 例 |
|---|---|
| モデルの選択 | インストールされているモデルの中から、合うものを選ぶ |
| LoRA の追加 | 画風に合う LoRA を足す |
| プロンプト | プロンプトとネガティブプロンプトを書く |
| 設定の変更 | サイズ・ステップ数・CFG・スケジューラー・シード |
| ワークフロー | グラフを作る、開いているグラフを直す（ComfyUI 本体のノードを使った音楽・動画・音声のグラフも組みます。動かすのはあなたで、**{{ui:params.invoke.invoke}}** を押します） |
| テキスト | **{{ui:media.tab.text}}** で開いている文字や吹き出しを直す |
| 動画・音楽・音声 | それぞれの画面の設定を変える |
| 漫画 | **{{ui:app.tabs.comic}}** で、コマ割り、コマの追加と分割、各コマのプロンプトとポーズ、吹き出しを変える（下の「漫画を手伝ってもらう」） |
| ポーズ | **{{ui:app.tabs.canvas}}** で、文章で頼んだポーズの棒人間を置く（[キャンバス](05-canvas.md#キャンバスでポーズを作る) を見てください） |
| 生成 | 頼んだときだけ、今の設定や漫画のコマを生成の順番待ちに入れる |
| 拡張機能のおすすめ | やりたいことに合う拡張機能を案内し、ボタンからインストールできる |
| アプリの使い方 | 画面の名前を使って、どこを押せばよいかを答える |
| 拡張機能の説明 | 何ができるか、どう使うかを説明する（下の「使い方や拡張機能を質問する」） |

どの画面を開いているかを、エージェントは見ています。たとえば **{{ui:media.tab.text}}** を開いて「文字を縦書きにして」と伝えると、その文字が変わります。

エージェントは、変えた内容を作業しながらすぐ画面に入れます。作業中は、変えた内容が「{{ui:agent.thinking}}」の下に順に出ます。絵や動画は、頼んだときだけ作ります（生成の順番待ちに入れます）。頼まないときは設定を変えるだけなので、結果を見て良ければ、返事の **{{ui:agent.generate}}** を押すと、そのまま作り始めます。漫画を開いているときは、その隣に「全ページを生成」のボタンも出ます。押すと、プロンプトのあるコマを全ページ分まとめて順番待ちに入れます（押さなければ入れません）。画像を消したり、モデルや拡張機能をインストールしたりはしません（拡張機能はおすすめを出すだけです）。

### 漫画を手伝ってもらう

**{{ui:app.tabs.comic}}** を開いた状態で頼むと、エージェントは開いているページ（コマの形、各コマのプロンプト、ポーズ、吹き出し）を読んで、直接書き換えます。たとえば次のように頼めます。

- 「見せ場のある 5 コマにして。1 コマ目を大きく、斜めに割って」と頼むと、コマ割りを作ります。特に形を決めずに頼むと、実際の漫画のように段の高さやコマの幅を不揃いにし、見せ場のコマを大きく取り、場面に応じて斜めの切れ目や紙の端まで伸びるコマを入れたコマ割りにします。コマの間は、上下を左右より広く空けます。ページごとに割り方を変えます。標準のテンプレートを使うことも、コマの形を自分で決めることもあります。
- 「この話で各コマのプロンプトを書いて」と頼むと、話の流れに合う構図（アップ、引き、あおりなど）を入れたプロンプトを、コマごとに書きます。
- 「この話で各コマのト書きを書いて」と頼むと、コマごとに場面（場所、時間、誰が何をするか）を文章で書きます。
- 「各コマにセリフを入れて」と頼むと、吹き出しを置いてセリフを入れます。セリフが吹き出しからはみ出すときは、文字を小さくして吹き出しに収めます。
- 「2 コマ目の女の子を走っているポーズにして」と頼むと、そのコマにポーズを付けます。登場人物（各キャラクターの見た目）も書き、どのコマでも顔や服が揃うようにします。吹き出しは、話す人の横に、ほかの人と重ならない大きさで置きます。
- 「新しく漫画を作って、30 ページ分のコマ割りを組み立てて」と頼むと、漫画を新しく作り、ページを足して、コマ割り・プロンプト・セリフを最後まで進めます。ほかの画面から頼んでも、漫画の画面に切り替えて作業します。長い作業でも、1 回の頼みの中で終わるまで続けます。途中でやめるときは **{{ui:agent.stop}}** を押します。

絵は、頼んだときだけ描きます（描く順番待ちに入れます）。頼まないときは、プロンプトが入ったら **{{ui:comic.panel.draw}}**、**{{ui:comic.page.drawAll}}**、**{{ui:comic.comic.drawAll}}** のどれかを押してください。「全ページを描いて」と頼むと、全ページのすべてのコマをまとめて順番待ちに入れます。返事の下の「全ページを生成」ボタンでも同じです。**{{ui:agent.undo}}** を押すと、その返事で変わった漫画のページが、まとめて元に戻ります。

### 画像を添付する

メッセージに画像を付けて、「この画像をもとにプロンプトを考えて」のように頼めます。

- 入力欄の左のクリップのボタン（**{{ui:agent.attach.add}}**）で、パソコンの画像を選びます。
- ギャラリーの画像や、パソコンの画像ファイルを、入力欄にドラッグして落としても付けられます。
- コピーした画像を、入力欄に貼り付けても付けられます。

付けた画像は入力欄の上に並び、右上の × で外せます。1 つのメッセージに 4 枚まで付けられます。文字を書かずに画像だけ送ると、「{{ui:agent.attach.defaultAsk}}」と頼んだことになります。パソコンから付けた画像は、ギャラリーにも入ります。画像は、そのメッセージと一緒に、選んでいる AI（Claude、Codex、つないだサーバー）へ送られます。あとのメッセージには付いていかないので、同じ画像についてまた頼むときは、もう一度付けてください。画像を読めないモデルでは、うまく答えられません。

### 画像とプロンプトを読む許可

ギャラリーの画像の情報（プロンプトやモデルなど）と、生成タブのプロンプト欄には、見せたくない内容があるかもしれません。そのため、エージェントがこれらを読もうとすると、初めはチャットの中で「{{ui:agent.permission.title}}」と確認が出ます。何を読もうとしているかも出ます。

- **{{ui:agent.permission.once}}**：今回の 1 回だけ読ませます。次に読もうとしたときは、また確認が出ます。
- **{{ui:agent.permission.always}}**：これからは確認せずに読ませます（設定が **{{ui:settings.assistantRead.always}}** に変わります）。
- **{{ui:agent.permission.deny}}**：読ませません。エージェントは、読まずに作業を続けるか、何が必要かを答えます。

漫画の画面を開いているときは、エージェントが描き終わったページの絵を見ることがあります（頼まれて、人物の見た目や吹き出しを確かめるため）。このときも同じ確認が出て、許可したときだけページの絵が送られます。ほかの画面では見ません。

確認するかどうかは、設定の **{{ui:settings.tab.generation}}** タブの **{{ui:settings.section.assistant}}** にある **{{ui:settings.assistantRead.label}}** で変えられます（下の「設定」）。漫画、テキスト、ワークフロー、動画・音楽・音声の画面、キャンバスのポーズのように、エージェントに直してもらう画面の内容は、確認せずに読みます。

### Wikipedia での調べもの

物語を作るとき（時代、服装、場所、職業、用語など）、エージェントは日本語または英語の Wikipedia で事実を調べ、記事の冒頭を最大 3 件まで読めます。パソコンの外に出るのは短い検索語だけで、送り先は Wikipedia だけです。送るのはアプリ本体で、画面が直接つながることはありません。検索語がインターネットに出るため、調べる前にチャットで「{{ui:agent.permission.webTitle}}」と確認が出て、送る検索語も表示されます。

- **{{ui:agent.permission.once}}**：今回だけ調べさせます。次に調べようとすると、また確認します。
- **{{ui:agent.permission.always}}**：以後は確認せずに調べさせます（設定が **{{ui:settings.assistantRead.always}}** に変わります）。
- **{{ui:agent.permission.deny}}**：調べさせません。エージェントは知っている範囲で進め、その依頼の間は、もう一度頼むことはしません。

これは別の設定で、設定の **{{ui:settings.tab.generation}}** タブの **{{ui:settings.section.assistant}}** にある **{{ui:settings.assistantWeb.label}}** です。画像の読み取りを許可しても、調べものは許可されません（逆も同じです）。Wikipedia の文章は CC BY-SA 4.0 のライセンスなので、エージェントは事実を使うとき、元の記事の名前を伝えます。答えが間違っていることもあるので、大事なことは確かめてください。

### モデルと思考の深さを選ぶ

チャットの名前の右にある、脳の形の小さなボタンを押すと、エージェントが使う **{{ui:agent.model.label}}** と **{{ui:agent.effort.label}}** を選べます。選んだものは、次に送るメッセージから使われます。Claude と Codex で、別々に覚えておきます。

- Claude のモデルは、**{{ui:agent.model.default}}**、Fable、Opus、Sonnet、Haiku から選べます。**{{ui:agent.model.custom}}** を押すと、モデルの名前を直接入れられます。思考の深さは、**{{ui:agent.effort.low}}** から **{{ui:agent.effort.max}}** までの 5 段階です。
- Codex のモデルは、**{{ui:agent.model.default}}** と、Codex があなたのアカウントで使えるとしているモデルの一覧から選べます（一覧は Codex がパソコンに保存したものを読みます。名前を直接入れることはできません）。思考の深さは、選んだモデルが受け付けるものだけが出ます（**{{ui:agent.effort.ultra}}** まで受け付けるモデルもあります）。
- サーバーでは、サーバーが一覧にしているモデルが出ます。名前を入力することもできます。思考の深さはありません。モデルはサーバーの設定の一部なので、別のモデルを選ぶとそれが保存されます。

**{{ui:agent.model.default}}** のときは、そのコマンドがモデルを決めます。思考の深さは、いつもどれか 1 つが選ばれています。初めはモデルごとの標準の深さが選ばれていて、別のモデルに替えたときに今の深さをそのモデルが受け付けなければ、そのモデルの標準の深さに戻ります。

### 入力欄の高さを変える

入力欄の上の端にある横長のつまみを上へドラッグすると入力欄が高くなり、下へドラッグすると低くなります。つまみを選んで上下の矢印キーを押しても変えられます。高さは次に開いたときも同じです。

### テンプレートを呼び出す

入力欄の先頭に「/」を打つと、よく使う頼み方のテンプレートが一覧で開きます。「/」に続けて文字を打つと、名前・コマンド・文章のどこかにその文字を含むものだけに絞られます（たとえば「/漫画」や「/comic」）。

上下の矢印キーで選び、Enter か Tab で決めます。一覧の行を押しても決まります。決めたテンプレートの文章が入力欄に入るので、続きを書き足してから送ってください（決めただけでは送られません）。Esc キーで一覧を閉じます。

### 使い方や拡張機能を質問する

設定を頼むだけでなく、質問もできます。たとえば「背景を消すにはどうすればいい？」「モデルを足すにはどこを押す？」のように聞くと、画面に出ている名前を使って、どこを押せばよいかを答えます。答えは、いま使っている言語で返ってきます。

拡張機能についても聞けます。何ができるのか、どんなときに使うのか、どう使うのかを、やさしい言葉で説明します。聞き方は 3 つあります。

- **{{ui:app.nav.extensions}}** の一覧でカードを押して詳細を開き、**{{ui:agent.ask.button}}** を押す。その拡張機能について聞く質問が、新しいチャットで送られます。
- **{{ui:app.nav.extensions}}** の上の検索欄に言葉を入れると出る **{{ui:agent.ask.resultsButton}}** を押す。ヒットした拡張機能（最初の 8 件まで）の違いと、どれから試すとよいかを答えます。
- チャットに拡張機能の名前（英字）を書いて聞く。公開されている拡張機能の中から、名前や説明が当たるものを探して答えます（一覧がまだ読み込まれていなければ、そのとき読み込みます）。

インストールされている拡張機能なら、追加されるノードの名前と、何につなぐかも答えます。まだインストールされていないものは、返事にカードが付き、**{{ui:workflows.packs.install}}** でそのままインストールできます。

> 拡張機能の説明は、公開されている説明文と、ノードの情報をもとにしています。知らないことは「分からない」と答えるはずですが、間違えることもあります。インストールする前に、配布元のページも確かめてください。

### 元に戻す

設定や編集を変えた返事には、**{{ui:agent.undo}}** ボタンが付きます。押すと、その頼みで変わった設定や編集が、まとめて頼む前に戻ります。生成の順番待ちに入れたものは取り消されません（キューで取り消してください）。

ただし、アプリを開き直したあとは、それ以前の変更は元に戻せません（ボタンが押せなくなります）。

### チャットの履歴

エージェントとのやり取りは「チャット」として残ります。ウィンドウの上の、チャットの名前の部分を押すと、**{{ui:agent.session.history}}** の一覧が開きます。

- 一覧から選ぶと、そのチャットの続きから話せます。
- **{{ui:agent.session.rename}}** で名前を付けられます。
- **{{ui:agent.session.delete}}** で消せます。
- 横の **{{ui:agent.session.new}}** で、新しいチャットを始められます。

チャットの文字は、ドラッグで選んでコピーできます。メッセージごとの右下のボタン（**{{ui:agent.copy}}**）を押すと、そのメッセージの文がまるごとコピーされます。

> 返事を待っている間は、続けて送れません。「{{ui:agent.thinking}}」の表示が消えるまで待つか、送信ボタンの代わりに出る **{{ui:agent.stop}}** ボタンで取り消してください。取り消すまでに変わった内容はそのまま残り、**{{ui:agent.undo}}** でまとめて元に戻せます。

ウィンドウの四辺と四隅のどこをドラッグしても、大きさを変えられます。右下の角には、その目印が出ます。大きさは覚えておいてくれます。返事に判断の流れが付いているときは、返事の上に 1 行で出ます。押すと全部が開きます（**{{ui:agent.thoughts.label}}**）。これは AI が、どう読み取ってなぜそうしたかを短くまとめたもので、AI の内部の思考そのままではありません。

## 設定

![設定の画面。左にタブが並び、右に選んだタブの項目が出る](shot:settings)

左下の **{{ui:app.nav.settingsMenu}}** から **{{ui:app.nav.settings}}** を選ぶと、設定の画面が開きます。左のタブを選ぶと、右にそのタブの項目が出ます。変えた内容はすぐに使われ、アプリを閉じても残ります。もう一度開くと、最後に見ていたタブが開きます。タブの一覧の下には、アプリの版（バージョン）が出ます。

> この画像は、ブラウザで動かす見本の画面です。デスクトップ版にだけある **{{ui:settings.uiZoom.label}}** は写っていません。

### {{ui:settings.tab.generation}}

- **{{ui:settings.antialiasProgressImages}}**：生成の途中の絵を、ギャラリーの「{{ui:gallery.generating.title}}」の枠でなめらかに表示します。オフだと、粗い点のまま見えます。
- **{{ui:settings.draftCount.label}}**：下書きの画面を開いたときの枚数の初めの値です（1〜24 枚。初めは 4 枚）。画面でその都度変えることもできます。
- **{{ui:settings.draftPosition.label}}**：下書きの画面を開いたときの位置の初めの値です（25〜60 %。初めは 35 %）。
- **{{ui:settings.lowMemory.label}}**：GPU のメモリが少ないパソコン向けです。オンにすると、モデルを GPU のメモリに置いたままにしないので、少ないメモリで作れますが、作るのは遅くなります。切り替えるとエンジンを再起動します。作成中の項目があるときは、エンジンを次に起動したときから使われます。ほかで起動したエンジンにつないでいるときは使えません。
- **{{ui:settings.assistantRead.label}}**（**{{ui:settings.section.assistant}}**）：エージェントが、ギャラリーの画像の情報と生成タブのプロンプトを読んでよいかどうかです。**{{ui:settings.assistantRead.ask}}**（初期値）、**{{ui:settings.assistantRead.always}}**、**{{ui:settings.assistantRead.never}}** から選びます。
- **{{ui:settings.assistantWeb.label}}**（**{{ui:settings.section.assistant}}**）：エージェントが Wikipedia で事実を調べてよいかどうかです。選び方は同じで、画像の読み取りとは別の設定です。

### {{ui:settings.tab.gallery}}

- **{{ui:gallery.settings.thumbnailSize}}**、**{{ui:gallery.settings.sort}}**、**{{ui:gallery.settings.starredFirst}}**、**{{ui:gallery.settings.groupByDate}}**、**{{ui:gallery.settings.alwaysShowSize}}**、**{{ui:gallery.settings.showArchived}}**、**{{ui:gallery.settings.autoSwitch}}**、**{{ui:gallery.settings.autoAssign}}**：ギャラリーの歯車のボタンで開く **{{ui:gallery.settings.title}}** と同じ項目です。どちらで変えても同じように変わります。
- **{{ui:settings.confirmOnDelete}}**：画像を消す前に、確認を出します。確認の画面で「{{ui:common.dontAskAgain}}」を選んだときも、ここがオフになります。
- **{{ui:settings.clearIntermediates}}**：キャンバスの途中結果など、ギャラリーに出ない画像を消します。消す数がボタンに出ます。

### {{ui:settings.tab.edit}}

- **{{ui:settings.undoLimit.label}}**：キャンバス、漫画、テキスト、ワークフローの編集で、元に戻せる操作の数です。10 から 200 まで選べます（初めは 60）。多くするとメモリを多く使います。

### {{ui:settings.tab.comicText}}

- **{{ui:settings.comicFont.label}}**：フォントを選んでいない吹き出しの文字に使うフォントです。アプリのフォントと、このパソコンにインストールされているフォントから選べます。**{{ui:common.font.standard}}** はアプリの標準の文字です。
- **{{ui:settings.textFont.label}}**：テキストの画面で新しく足す文字に使うフォントです。選び方は吹き出しのフォントと同じです。
- **{{ui:settings.section.comicPage}}**：新しく作る漫画と、あとから足すページの **{{ui:comic.page.size}}**、**{{ui:comic.page.direction}}**、**{{ui:settings.comicPage.panels}}**（1 から 6）、**{{ui:comic.page.frameWidth}}**、**{{ui:comic.page.margin}}** を決めます。今あるページは変わりません。

### {{ui:settings.tab.engine}}

アプリがデータを置く場所と、画像エンジン（ComfyUI）の起動のしかたです。ここで変えた内容は、アプリを次に起動したときから使われます（そのことが上に出ます）。

| 項目 | 内容 |
|---|---|
| {{ui:settings.engine.dataDir.label}} | 作った絵、モデル、画像エンジンなどを置くフォルダです。初めはユーザーフォルダの中の `novira-data` です。**{{ui:settings.engine.dataDir.change}}** を押すと、まず今のデータの扱いを選びます。**{{ui:settings.engine.dataDir.dialog.move}}** は、選んだ空のフォルダへ今のデータを移します（次の起動の最初に行うので、量が多いと時間がかかります）。**{{ui:settings.engine.dataDir.dialog.use}}** は、データを移さず、選んだフォルダを開きます（データがあればそれを、空なら新しく始めます）。そのあとフォルダを選ぶ窓が開き、選んだ場所は次の起動から使われます。**{{ui:settings.engine.dataDir.cancel}}** で取りやめられます。移動ができなかったときは、理由が出て、今のフォルダのまま起動します。環境変数 `NOVIRA_DATA_DIR` で決めているときは、ここでは変えられません |
| {{ui:settings.engine.comfyui.label}} | 使っている ComfyUI です。ふだんはデータフォルダの中の `comfyui` にあり、その場所が出ます。設定ファイルでほかの ComfyUI を指定したときは、その場所が出ます。**{{ui:settings.engine.comfyui.change}}** で、アプリがインストールする ComfyUI の置き場所を変えられます。選んだフォルダが空なら、次の起動で新しくインストールします（大きなダウンロードです）。すでにインストール済みのフォルダならそのまま使います。古い場所のファイルは自動では消えません。**{{ui:settings.engine.comfyui.reset}}** で、データフォルダの中に戻します |
| {{ui:settings.engine.package.label}} | **{{ui:settings.engine.package.nvidia}}** か **{{ui:settings.engine.package.amd}}**。次に ComfyUI をダウンロードするとき（初めてのインストールや版の切り替え）に使われます。ComfyUI がインストールされているときに、別の種類を選ぶと確認が出ます。確認すると、次に novira を起動したときに、選んだ種類で ComfyUI をインストールし直します（ダウンロードは大きく、時間がかかります） |
| {{ui:settings.engine.timeout.label}} | ComfyUI を起動してから応答するまで待つ秒数です。30 秒から 1800 秒まで選べます。遅いパソコンでは長くします |
| {{ui:settings.engine.modelRoots.label}} | データフォルダの models のほかに、モデルを探すフォルダです。**{{ui:settings.engine.modelRoots.add}}** を押すとフォルダを選ぶ窓が開きます。ComfyUI や Stability Matrix のフォルダの形が分かります。動画・音楽・音声・ロゴ・消去の追加モデルもここから見つかります（読むだけで、新しく入れるときはいつもデータフォルダに入ります）。16 個まで足せます。データフォルダの中や、すでにあるフォルダは足せません。× のボタンで外します。ブラウザで開いているときは、足すことはできず、外すことだけできます |

### {{ui:settings.tab.data}}

#### {{ui:share.backup.section}}

![設定の画面のバックアップの欄。バックアップを作るボタンと、バックアップから復元するボタン](shot:settings-backup)

作った絵と、アプリの中で設定・登録したものを、1 つの zip ファイルにまとめて保存できます。別のパソコンへの引っ越しや、もしものときの備えに使います。

- **{{ui:share.backup.create}}**：保存先を選ぶ窓が開きます。ファイル名は初めから「novira-backup-日付-時刻.zip」になっています。絵が多いと時間がかかり、進み具合がこの欄に出ます。
- **{{ui:share.backup.restore}}**：バックアップの zip ファイルを選びます。中身を確かめたあと、確認の窓が出ます。

バックアップに入るものと、入らないものは次のとおりです。

| 入るもの | 入らないもの |
|---|---|
| ギャラリーの絵・動画・音声と、そのサムネイル | モデル |
| ボード、ワークフロー、漫画、キューの記録 | 画像エンジン（ComfyUI）と拡張機能 |
| キャラクター、プリセット、プロンプトリスト、下書き、AI のチャット、画面の設定 | API キーとトークン、ComfyUI の場所などパソコンごとの設定 |

![復元の確認の窓。バックアップを作った日時と中身の数、置き換えの注意が出ている](shot:restore-confirm)

確認の窓には、バックアップを作った日時と、入っている画像・ボード・ワークフローの数が出ます。**{{ui:share.backup.confirm}}** を押すと、アプリがいったん終わって起動し直し、いまのデータがバックアップの内容に置き換わります。うまくいかなかったときは元のデータに戻し、そのことを知らせます。

> 置き換えたデータは元に戻せません。必要なら、復元の前にいまの状態のバックアップを作ってください。API キーとトークンはこのパソコン専用に暗号化されているため、復元したあとに **{{ui:settings.tab.accounts}}** でもう一度入力してください。ブラウザで開いているときは、バックアップの作成も復元もできません。デスクトップアプリで使ってください。

#### {{ui:settings.section.unfinished}}

ダウンロードが途中で止まると、書きかけのファイルがデータフォルダに残ります。この欄では、残っているファイルの名前、置かれているフォルダ、大きさを確かめられます。**{{ui:settings.unfinished.delete}}** で 1 つずつ、**{{ui:settings.unfinished.deleteAll}}** で全部を消せます（押すと、先に確認を求められます）。残ったファイルは、同じダウンロードを次に始めるときに続きから使われます。消すと、そのダウンロードは最初から取り直します。使用中のファイルは消えず、残ります。

#### {{ui:settings.section.reset}}

**{{ui:settings.reset.scope.label}}** で戻す範囲を選び、**{{ui:settings.resetWebUi}}** を押してから、もう一度 **{{ui:settings.resetConfirm}}** を押して確定します。画像、モデル、漫画、キャンバスは消えません。

設定、プリセット、下書き、履歴などの画面の状態は、データフォルダに保存されます。同じデータフォルダを使うかぎり、デスクトップアプリとブラウザで開いたときで同じ内容になります。2 つを同時には開けないので、続けて使うときに引き継がれます。リセットも両方に反映されます。

| 範囲 | 初期値に戻るもの |
|---|---|
| {{ui:settings.reset.scope.settings}} | 設定の画面の項目。すぐに戻ります |
| {{ui:settings.reset.scope.generation}} | 生成の画面のプロンプト、モデル、各パラメータ |
| {{ui:settings.reset.scope.gallery}} | ギャラリーの表示（サムネイルの大きさ、並び順など） |
| {{ui:settings.reset.scope.assistant}} | エージェントとの会話。すべて消えます |
| {{ui:settings.reset.scope.all}} | ブラウザに保存された設定と画面の状態すべて。プリセット、キャラクター、プロンプトリスト、エージェントの会話も消えます |

「{{ui:settings.reset.scope.settings}}」以外は、確定したあとに出る **{{ui:settings.reload}}** を押して読み込み直すと反映されます。

## このアプリについて

![アプリの情報の画面。ロゴ、バージョン、ライセンス、使っているオープンソースの一覧](shot:about)

左下の **{{ui:app.nav.settingsMenu}}** から **{{ui:app.nav.about}}** を選ぶと、上にアプリの名前、バージョン、ライセンス、著作権の表示が出ます。その下は 2 つのタブに分かれています。

- **{{ui:settings.about.license.title}}**: novira のライセンス（Apache License 2.0）の全文です。インストール先のフォルダにも同じ文書（`LICENSE`）があります。
- **{{ui:settings.about.oss.title}}**: 使っているオープンソースソフトウェアの一覧です。各行に名前とバージョンが並びます。**{{ui:settings.about.oss.showLicense}}** を押すと、その下にライセンスの全文が出ます（もう一度押すと閉じます）。**{{ui:settings.about.oss.homepage}}** を押すと、そのソフトウェアのページがブラウザで開きます。アプリに同梱していない生成エンジンと拡張機能は、ライセンスの全文をホームページで確かめてください。

一覧の上のボタンで、**{{ui:settings.about.oss.short.frontend}}**・**{{ui:settings.about.oss.short.backend}}**・**{{ui:settings.about.oss.short.engine}}**・**{{ui:settings.about.oss.short.packs}}**（いまインストールされている拡張機能）に絞り込めます。検索欄では、名前で探せます。同梱しているソフトウェアのライセンスの全文は、インストール先のフォルダの `THIRD_PARTY_NOTICES.txt` にもまとめてあります。

拡張機能（ComfyUI のカスタムノード）とモデルは、インストールしたときに、それぞれの配布元のライセンスに従います。

## 開発者ログ

何かうまくいかないときに、原因を探すためのログです。普段は使わなくて構いません。

**{{ui:settings.title}}** の **{{ui:settings.showDevLog}}** をオンにすると、左のナビゲーションに「{{ui:app.devlog.short}}」のボタンが出ます。押すと、右側に **{{ui:app.devlog.title}}** のパネルが開きます。

ここには、アプリの内部の記録（バックエンドのログ）、画面の警告、捕まえられなかったエラーが、時刻付きで並びます。

- 上の選択で、**{{ui:app.devlog.level.all}}**・**{{ui:app.devlog.level.warn}}**・**{{ui:app.devlog.level.error}}** に絞れます。
- 絞り込みの欄に言葉を入れると、その言葉を含む行だけが出ます。
- **{{ui:app.devlog.copy}}** で、出ている行を文章としてコピーできます。問題を報告するときに、貼り付けて使えます。
- **{{ui:app.devlog.clear}}** で消せます。

> ログは、アプリを開いている間の記録です。閉じると、画面のログは消えます。くわしい調べ方は [困ったとき](10-troubleshooting.md) へ。
