# はじめに

## novira でできること

novira は、画像・動画・音楽・音声をつくる Windows 用のデスクトップアプリです。
プロンプト（作りたいものの説明）を書いて **{{ui:params.invoke.invoke}}** ボタンを押すと、パソコンの中で絵が描かれ、右側のギャラリーに並びます。
画面のつくりと操作は、画像生成ツール InvokeAI の画面をもとにしています。使ったことがある方なら、同じ感覚で操作できます。

できることは、おおまかに次のとおりです。

- 文章から画像を作る（この手引きの中心です）
- 画像を元にした作り直し、一部だけの描き直し、拡大
- 動画・音楽・音声・ロゴ・文字入りの画像を作る
- エージェントに、設定やプロンプトの相談をする

> 絵を描く処理は、お使いのパソコンの中で行います。モデルの検索やダウンロード、エージェントなど、インターネットを使う機能は、使うことを選んだときだけ通信します。

## 画像が作られる仕組み

novira は、次の 4 つの部品でできています。

| 部品 | 役割 |
|---|---|
| novira（このアプリ） | 画面、ギャラリー、順番待ち（キュー）、モデルの管理 |
| 画像生成エンジン（ComfyUI） | 実際に絵を描く部分。novira が自分でインストールし、自分で起動して動かします |
| モデル | 絵を描くための学習データ。1 つが数 GB のファイルで、エンジンとは別に用意します |
| データフォルダ | 作った画像、モデル、エンジン本体などを保存しておく場所 |

エンジンは、使う人が自分でインストールする必要はありません。初めて起動したときに、novira が自動でインストールします。
エンジンとその部品（Python など）は、novira のデータフォルダの中だけに入ります。パソコンの別の場所や、すでにある Python には手を加えません。

初めて起動すると、データフォルダとエンジン（ComfyUI）のインストール先を決める画面が出ます。標準の場所のままでよければ「{{ui:firstrun.start}}」を押します。変えたいときは、それぞれの「{{ui:firstrun.choose}}」でフォルダを選びます。どちらも、あとから設定の「エンジン」で変えられます。画像やモデルを移したりバックアップしたりするときは、データフォルダを使います。

> 画像の生成には GPU（グラフィックスボード）を使います。標準では NVIDIA 製の GPU 向けのエンジンをインストールします。

モデルは「どんな絵柄で描くか」を決めるものです。最初に 1 つ必要です。インストールの仕方は [モデルを用意する](08-models.md) で説明します。

## 初めて起動したとき

アプリを開くと、まず起動画面（ロゴ）が出ます。
起動画面の下には、いま何をしているかを示すカードが出ます。

初めての起動では、画像生成エンジンのインストールが始まります。カードには、3 つの段階が順に表示されます。

1. **{{ui:splash.step.downloading}}**：ComfyUI と Python をダウンロードします。大きさ、速さ、残り時間の目安も表示されます。
2. **{{ui:splash.step.extracting}}**：ダウンロードしたファイルを展開します。
3. **{{ui:splash.step.starting}}**：エンジンを起動し、つながるのを待ちます。

> {{ui:engine.firstRunNote}}

インストールは一度だけです。2 回目からは、起動画面は数秒で終わり、エンジンもすぐに動き出します。

起動画面の下に **{{ui:splash.open}}** ボタンが出ている間は、ダウンロードの途中でもアプリを開けます。ダウンロードは裏で続き、上に出る帯で進み具合を確かめられます。ただし、エンジンの準備が終わるまで絵は作れません。

エンジンの準備が終わると、起動画面が消えて、メインの画面が開きます。
データを読み込んでいる間は「{{ui:splash.wait.heading.loading}}」、エンジンと編集に必要な情報の読み込みを待っている間は「{{ui:splash.wait.heading.preparing}}」と表示されます。

### 画面の上に出るメッセージ

アプリを開いたあとでエンジンが再起動したりインストールし直したりすると、画面の上の真ん中に帯（バナー）が出て、状況を知らせます。

- 「{{ui:engine.title.downloading}}」「{{ui:engine.title.extracting}}」「{{ui:engine.title.starting}}」：作業中です。終わるまで生成は始まりません。終われば帯は自然に消えます。
- 「{{ui:engine.title.error}}」：エンジンを準備できませんでした。帯の下の行に理由が出ます。

起動画面でエラーが出たときは、理由の下に **{{ui:splash.open}}** ボタンが出ます。押すと、エンジンなしでアプリを開けます。モデルの確認や設定は使えますが、絵は作れません。
エラーが続くときは、[困ったときは](10-troubleshooting.md) を見てください。

## 画面の見かた

![生成タブの全体。左にパラメーターパネル、中央にスタート画面、右にボードとギャラリーが並んでいる](shot:generate)

画面は、左から順に次のように並んでいます。

- いちばん左の細い縦の帯：**サイドナビゲーション**。タブを切り替えます。
- 左のパネル：**パラメーターパネル**。プロンプトやモデルなど、絵を作るための設定が入っています。
- 中央：**メインビュー**。スタート画面、画像のビューア、キャンバスなど、タブに合わせた作業の場所です。
- 右のパネル：**ギャラリー**。ボード（フォルダのようなもの）と、作った画像のサムネイルが並びます。

### サイドナビゲーション（タブ）

| タブ | 使いみち | 数字キー |
|---|---|---|
| **{{ui:app.tabs.generate}}** | 画像を作る。上部のアイコンで、動画・音楽・音声・ロゴ・テキストにも切り替えられます。そのアイコンの列の右端にある **{{ui:app.tabs.comic}}** で、漫画のページを作る画面に切り替わります（`1` キーは、最後に使ったほうを開きます） | `1` |
| **{{ui:app.tabs.canvas}}** | 画像を置いて、描き足したり、一部だけ描き直したりする | `2` |
| **{{ui:app.tabs.upscaling}}** | 画像を大きくしながら、細部を描き足す | `3` |
| **{{ui:app.tabs.workflows}}** | 部品（ノード）をつなぎ、自分だけの生成手順を作る | `4` |
| **{{ui:app.tabs.models}}** | 持っているモデルの一覧、インストール、削除 | `5` |
| **{{ui:app.tabs.browse}}** | インターネット上のモデルを探して取り込む | `6` |
| **{{ui:app.tabs.queue}}** | 生成の順番待ちを見る・止める。待っている数がバッジで出ます | `7` |
| **{{ui:app.nav.extensions}}** | ComfyUI の拡張機能を探してインストール・削除する | `8` |

サイドナビゲーションの下のほうには、次のものもあります。

- {{ui:app.tabs.comic}}：[漫画を描く](12-comic.md)

### 中央のタブ（スタート・ビューア・下書き）

{{ui:app.tabs.generate}}タブの中央には、上に 3 つの小さなタブがあります。

- **{{ui:app.views.launchpad}}**：始めかたの案内です。「{{ui:params.launchpad.generate.textTitle}}」「{{ui:params.launchpad.generate.refTitle}}」などのカードと、ショートカットのヒントが出ます。
- **{{ui:app.views.viewer}}**：画像を大きく見る場所です。ギャラリーで画像を選ぶと、ここに表示されます。
- **{{ui:app.views.drafts}}**：同じ設定でシードだけを変えて、途中まで描いた候補をたくさん並べ、気に入ったものだけを最後まで描く画面です。

ほかのタブにも、そのタブ用の小さなタブがあります（{{ui:app.tabs.canvas}}なら {{ui:app.views.canvas}} など）。

### パネルを隠す

画像を広く見たいときは、左右のパネルを隠せます。

- 中央の上の端にある小さな矢印のボタンで、左パネルとギャラリー（右のパネル）を開閉します。
- キーボードでは、`T` で左パネル、`G` でギャラリー、`F` で左右をまとめて開閉します。
- パネルとパネルの境目をドラッグすると、幅を変えられます。幅は、アプリを開いているあいだ覚えておきます（起動し直すと、もとの幅に戻ります）。

> `T`・`G`・`F` などの 1 文字のショートカットは、文字を入力している最中は働きません。入力欄から出てから押してください。

## 最初の 1 枚をつくる（3 ステップ）

はじめて絵を作る流れです。モデルがすでにインストールされている前提で説明します。

1. **モデルを選ぶ。** 左パネルの上のほうにあるモデル欄から、使いたいモデルを選びます。欄に「{{ui:params.model.noModels}}」と出ている場合は、先に [モデルを用意する](08-models.md) を済ませてください。
2. **プロンプトを書く。** 「{{ui:params.prompt.positive}}」の欄に、作りたい絵を言葉で書きます。たとえば `a lighthouse on a cliff at dusk, calm sea, warm light` のように、単語や短い文をカンマでつなぎます。多くのモデルは英語のほうが思いどおりになりやすいです。
3. **{{ui:params.invoke.invoke}}を押す。** ボタンを押すか、`Ctrl+Enter` を押します。右のギャラリーの上に「{{ui:gallery.generating.title}}」の表示が出て、途中経過の絵と進み具合が見えます。できあがると、中央のビューアに絵が出て、ギャラリーにも並びます。

ボタンが灰色で押せないときは、ボタンの下の行に理由が出ます（たとえば「{{ui:params.readiness.noModel}}」）。理由を直せば押せるようになります。

できた絵は、ギャラリーに自動で保存されます。気に入らなければ、プロンプトや設定を少し変えてもう一度押すだけです。
くわしくは次の [画像をつくる](02-generate.md) へ進んでください。
