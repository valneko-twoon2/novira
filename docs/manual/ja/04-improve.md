# 絵を直す・使い回す

できあがった絵を「もう少し直したい」「同じ雰囲気でもう何枚か欲しい」「このキャラクターを別の場面でも使いたい」と思ったときの機能をまとめた章です。

ほとんどの機能は、ビューア（絵を大きく見る画面）の上にあるツールバーのボタンか、ギャラリーの絵を右クリックしたメニューから呼び出します。ツールバーのボタンは、マウスを重ねると名前が出ます。ビューアとギャラリーの基本は [ギャラリー](03-gallery.md) を見てください。

## どこから何を使うか

| やりたいこと | 使うもの | 別に必要なもの |
|---|---|---|
| 同じ設定でもう何枚か作る、少しだけ変えて作り直す | **{{ui:gallery.derive.menu}}** | 元の絵に使ったモデルがインストールされていること |
| 背景を消して、人や物だけにする | **{{ui:cutout.menu}}** | 拡張機能 ComfyUI-RMBG |
| 透明な余白を詰める | **{{ui:gallery.menu.trim}}**（右クリックのみ） | なし |
| 絵の一部を塗って、消す・切り抜く・描き直す | **{{ui:gallery.menu.segment}}** | 消すときは拡張機能 comfyui-inpaint-nodes |
| 小さく崩れた顔をきれいにする | **{{ui:facefix.menu}}** | 拡張機能 ComfyUI-Impact-Pack と ComfyUI-Impact-Subpack |
| 絵を白黒のマンガ原稿にする | **{{ui:gallery.manga.menu}}**（ビューアのツールバーのみ） | 拡張機能 ComfyUI-MangaScreen |
| 絵からプロンプトを書き出す | **{{ui:caption.menu}}** | 拡張機能 ComfyUI-Florence2 |
| キャラクターを登録して、別の絵でも使う | **{{ui:character.menu}}** | 参照画像用の拡張機能（IP-Adapter） |
| 設定を変えた絵を 1 枚の表に並べる | **{{ui:xyplot.menu}}** | なし |
| 生成した絵や、途中まで描いた候補から選ぶ | **{{ui:app.views.drafts}}** タブ | なし |
| 何枚もの絵に同じ処理をかける | **{{ui:gallery.menu.batch}}**（複数選んで右クリック） | 処理によって異なる |

## 直す道具の使いかた

{{ui:facefix.menu}}、{{ui:cutout.menu}}、{{ui:caption.menu}}、{{ui:canvas.poseFromImage.menu}} の 4 つは、ギャラリーの絵の右クリックメニューで **{{ui:gallery.tools.heading}}** の下にまとまっています。どれも、ビューアの上に開く帯で使います。絵はビューアに出たままなので、拡大や移動をしながら確かめられます。

- 項目を選ぶと、前回の設定ですぐに実行します。ビューアにその絵が出て、帯に進み具合が出ます。
- 項目の右にある歯車のボタンを押すと、実行せずに帯で設定を開きます。設定を変えて **{{ui:gallery.tools.run}}** を押します。変えた設定は、次に実行するときも使われます。
- ビューアのツールバーの **{{ui:cutout.menu}}**・**{{ui:facefix.menu}}**・**{{ui:caption.menu}}** のボタンでも、帯の設定を開けます。もう一度押すと閉じます。
- 帯の左のボタンで、ほかの道具に切り替えられます。
- 終わると、帯に結果と使った設定が出ます。**{{ui:gallery.tools.edit}}** を押すと設定に戻り、変えてもう一度実行できます。
- 処理はキューで進みます。帯を閉じても、別の絵や別の画面に移っても止まりません。止めるのは、帯の **{{ui:common.cancel}}** だけです。絵を作る処理の結果は、帯を閉じていてもギャラリーに保存されます。

## 拡張機能が必要なとき

背景の除去、顔を直す機能などは、絵を作るエンジン（ComfyUI）に「拡張機能」を足して動きます。拡張機能がインストールされていないと、帯に「…には、拡張機能 ○○ が必要です。」と出て、インストールするボタンが並びます。

1. **{{ui:gallery.tools.install}}** を押します。必要なものを自動でダウンロードしてインストールします。インストールは裏で進み、ダウンロードの表示に進み具合が出ます。帯を閉じても止まりません。
2. インストールが終わると、帯のボタンが **{{ui:gallery.tools.restart}}** に変わります。押すと ComfyUI が再起動します。
3. 再起動が済むと、その道具がそのまま使えるようになります。

最初に使うときは、拡張機能が使うモデルのダウンロードも始まるため、時間がかかります。インターネットにつながっている必要があります。このダウンロードは実行した処理の中で進むので、帯を閉じても止まりません。

> 拡張機能の中には、インストールに時間と容量がかかるものがあります。ComfyUI-Impact-Pack は、インストールに Git が必要です。Git がインストールされていないパソコンではインストールに失敗します。メッセージが出たら、読んでから対処してください。

拡張機能は [ワークフロー](06-upscaling-workflows.md) の「{{ui:workflows.panel.packs}}」タブからもインストールできます。うまくいかないときは [困ったとき](10-troubleshooting.md) も見てください。

## 同じ設定でもう一度作る（派生）

![ビューアのツールバーで「派生させる」を開いたところ](shot:derive-menu)

気に入った絵をビューアで開き、ツールバーの **{{ui:gallery.derive.menu}}** ボタン（枝分かれのアイコン）を押します。ギャラリーでは、絵を右クリックして **{{ui:gallery.derive.menu}}** を選びます。

選べるのは次の 3 種類です。

| 項目 | 何をするか |
|---|---|
| 「同じ設定で別のシード」（1 枚または 4 枚） | プロンプト・モデル・サイズなどはそのままで、シードだけ変えて描きます。構図は変わりますが、雰囲気は同じです。 |
| 「少しだけ変えて作り直す」（1 枚または 4 枚） | 元の絵を土台にして、弱めに（強さ 0.45 で）描き直します。構図や色を残したまま、細部だけが変わります。 |
| **{{ui:gallery.derive.custom}}** | 変え具合を自分で決めます（次の項目）。 |

選ぶと、新しい絵がキューに入り、元の絵と同じボードに並びます。**生成タブの設定は書き換わりません。** 入力中のプロンプトも、そのまま残ります。

> 設定を画面に呼び戻してから、自分で直して作りたいときは、**{{ui:gallery.menu.remix}}** を使います。派生は「ボタン 1 つで、元の設定のまま作る」ためのものです。

### 変え具合を選んで作り直す

![変え具合を決めるダイアログ](shot:derive)

**{{ui:gallery.derive.custom}}** を選ぶと、ダイアログが開きます。

1. スライダー **{{ui:gallery.derive.dialog.strength}}** を動かします。左（{{ui:gallery.derive.dialog.close}}）ほど元の構図と色が残り、右（{{ui:gallery.derive.dialog.free}}）ほど別の絵に近づきます。
2. **{{ui:gallery.derive.dialog.count}}** を 1・2・4・8 から選びます。
3. **{{ui:gallery.derive.dialog.create}}** を押します。

目安は、0.25 くらいで元とほとんど同じ絵、0.75 くらいでキャラクターは残るのに構図が大きく変わる絵です。絵によって違うので、いくつか試してみてください。スライダーの値は、その 1 回だけに使われます。

### 引き継がれるもの・引き継がれないもの

- 引き継がれる: プロンプト、ネガティブプロンプト、モデル、LoRA、サイズ、ステップ数、CFG スケール、スケジューラーなど、絵を作ったときの設定。
- 参照画像とコントロールレイヤーも、絵と一緒に覚えているので、そのまま使われます。ただし、その画像がギャラリーから削除されていると、作れません。理由が通知に出ます。
- 引き継がれない: マスク、領域ガイダンス、下書きの設定。この機能ができる前に作った絵で参照画像などを使っていた場合も、覚えていないので引き継げません。引き継げなかったときは、通知で知らせます。

次の場合は、ボタンが押せません、または通知が出て作れません。

- 文章から作った絵（画像から画像、インペイント、アウトペイントを含む）ではない場合。拡大した絵、動画、音声などは対象外です。
- 元の絵に使ったモデルがインストールされていない場合。モデルの名前を添えた通知が出ます。

## 背景を除去する

![ビューアの帯で背景を除去して、元の絵と見比べているところ](shot:cutout)

写っているものを自動で見分けて、背景を取り除いた絵を作ります。クリックで指定する必要はありません。

1. ギャラリーの絵を右クリックして、**{{ui:gallery.tools.heading}}** の **{{ui:cutout.menu}}** を選ぶと、前回の設定ですぐに実行します。先に設定を変えたいときは、項目の右の歯車か、ビューアのツールバーのはさみのボタンで帯を開きます。
2. 帯で、必要なら設定を変えます。
   - **{{ui:cutout.model}}**: 通常はそのままで大丈夫です。
   - **{{ui:cutout.sensitivity}}**: 下げるほど、境目があいまいな部分も残します。
   - **{{ui:cutout.edge}}**: プラスで輪郭を広げ、マイナスで削ります。
   - **{{ui:cutout.background}}**: **{{ui:cutout.background.alpha}}** か **{{ui:cutout.background.white}}** を選びます。
3. **{{ui:gallery.tools.run}}** を押します。

できあがった絵は、元の絵と同じボードに、新しい絵として保存されます。**元の絵はそのまま残ります。** ビューアは、できた絵と元の絵を見比べる表示になります。結果に満足できなければ、**{{ui:gallery.tools.edit}}** を押して設定を変え、もう一度実行します。

白い背景は、あとで [キャラクター](#キャラクターを登録して使う) の参照画像にするときに向いています。背景の色が、新しく作る絵に移りにくくなります。

## 透明な余白を詰める

背景を透明にした絵は、絵の外側に透明な余白が残ります。**{{ui:gallery.menu.trim}}** を使うと、絵のある部分ぴったりに切り詰めた透明な絵を、新しく保存します。ステッカーや素材として使うときに便利です。

- ギャラリーの絵を右クリックして選びます。背景を除去した直後は、帯の **{{ui:cutout.trim}}**（背景を透明にしたときだけ出ます）からでも同じことができます。
- ほとんど見えないくらい薄い影は、余白として切り詰められます。
- 透明な部分が絵の端まで届いていない絵では、「切り詰める余白がありません」と出て、何も保存しません。全面が透明な絵も切り詰められません。

## 範囲を選んで直す

直したい部分をブラシで塗って選びます。絵は [キャンバス](05-canvas.md) で開くので、拡大・移動しながら細かく塗れます。

1. 絵をビューアで開き、**{{ui:gallery.menu.segment}}** を押します（ギャラリーの右クリックからも選べます）。
2. キャンバスが、その絵と空の **{{ui:canvas.add.inpaint}}** を選んだ状態で開きます。道具は **{{ui:canvas.tool.brush}}** です。
3. 直したい部分を塗ります。塗りすぎたところは **{{ui:canvas.tool.eraser}}** で削ります。残りの部分を選びたいときは、マスクを右クリックして **{{ui:canvas.entityMenu.invertMask}}** を選びます。
4. 塗った部分をどうするかを選びます。マスクの行を選ぶと、その下に入力欄とボタンが出ます（消すと切り抜くは、マスクの右クリックメニューにもあります）。

| やりたいこと | 操作 | 必要なもの |
|---|---|---|
| まわりの絵になじませて消す | **{{ui:canvas.partFix.erase}}**。結果はキャンバスに仮置きされるので、**{{ui:canvas.staging.accept}}** か破棄を選びます。 | 拡張機能 comfyui-inpaint-nodes。モデル LaMa（約 200MB）があると自然に消えます。なくても簡易的に消せます。 |
| 塗った部分だけを透明な絵として保存する | **{{ui:canvas.partFix.cutOutAction}}** | なし |
| 文章の指示で描き直す | 入力欄に「青いリボン」のように描き直す内容を書いて、**{{ui:canvas.partFix.redraw}}** を押します。生成タブのモデルや設定で、塗った部分だけを描き直します。入力欄が空なら、生成タブのプロンプトを使います。生成タブのプロンプトは書き換わりません。結果は仮置きされるので、**{{ui:canvas.staging.accept}}** か破棄を選びます。 | 画像用のモデル |
| モザイクをかける | マスクを使わず、**{{ui:canvas.tool.mosaic}}** の道具で直接なぞります。 | なし |

元の絵は変わりません。切り抜きはギャラリーに新しい絵として保存されます。

## 顔を直す

![ビューアの帯で、顔を直す設定を開いたところ](shot:facefix)

引きの絵では、小さく写った顔が崩れることがよくあります。**{{ui:facefix.menu}}** は、絵の中の顔を自動で見つけて、顔だけを高い解像度で描き直し、元の絵に戻します。顔以外は変わりません。

1. ギャラリーの絵を右クリックして、**{{ui:gallery.tools.heading}}** の **{{ui:facefix.menu}}** を選ぶと、すぐに実行します。設定を確かめてから実行したいときは、項目の右の歯車か、ビューアのツールバーの **{{ui:facefix.menu}}** のボタンで帯を開きます。
2. 最初だけ、拡張機能 ComfyUI-Impact-Pack と ComfyUI-Impact-Subpack が必要です。帯の **{{ui:gallery.tools.install}}** でインストールし、**{{ui:gallery.tools.restart}}** を押します。顔を見つけるモデルは、Subpack が自分で用意します。
3. 設定を確かめます。
   - **{{ui:facefix.model}}**: 元の絵に使ったモデルが選ばれています。
   - **{{ui:facefix.detector}}**: 顔を見つけるのに使うモデルです。通常はそのままで大丈夫です。
   - **{{ui:facefix.prompt}}**: 元の絵のプロンプトが入っています。顔の特徴を足すと効きます。
   - **{{ui:facefix.strength}}**: 低いほど元の顔に近く、高いほど大きく描き直します。
   - **{{ui:facefix.sensitivity}}**: 上げると確かな顔だけを、下げると小さな顔や横顔も拾います。ただし、顔でないものも拾いやすくなります。
4. **{{ui:gallery.tools.run}}** を押します。

結果は、元の絵と同じボードに保存され、ビューアは元の絵と見比べる表示になります。気に入らなければ、**{{ui:gallery.tools.edit}}** を押して設定を変え、もう一度実行します。モデルと描き直す内容は、同じ絵に使っているあいだだけ覚えています。

> LoRA を使って作った絵は、LoRA なしで描き直されます。そのため、顔だけ絵柄が少し違って見えることがあります。

> 「顔を見つけるモデル（YOLO）が見つかりません」と出たときは、ComfyUI を再起動するか、拡張機能をインストールし直してください。

## 絵をマンガ原稿に仕上げる

ビューアのツールバーの **{{ui:gallery.manga.menu}}** は、開いている絵を、線をくっきり残した白黒のマンガ原稿に変えます。陰影は、平らな面と本物のスクリーントーン（網点）になり、黒ベタの中の主な線は細く白く抜かれます。絵を描くときは常に普通のカラーの絵ができ、この仕上げは、気に入った絵に対してあとから行う操作です。

1. 絵をビューアで開き、**{{ui:gallery.manga.menu}}** を押します。左に元の絵が出ます。
2. 最初だけ、拡張機能 ComfyUI-MangaScreen が必要です。インストールされていないときは案内が出るので、**{{ui:gallery.manga.installPack}}** を押し、インストールしたあとは **{{ui:gallery.manga.restartEngine}}** を押します。インストールが終わるまで、下のボタンは押せません。
3. 必要なら値を変えます（次回のために覚えられます）。
   - **{{ui:gallery.manga.screenLines}}**：横幅に並ぶ網点の行数です。120 が粗め、200 が標準、300 が細かめです。
   - **{{ui:gallery.manga.whitePoint}}**：これより明るい所は紙の白になります。下げると、肌や明るい髪のトーンが消えます。
   - **{{ui:gallery.manga.blackPoint}}**：これより暗い所は黒ベタになります。上げると、黒い面が増えます。
   - **{{ui:gallery.manga.gradation}}**：なめらかに濃くなる影を、段にせず網点の大きさで表します。0 にすると平らな面だけになります。
   - **{{ui:gallery.manga.whiteLines}}**：黒ベタの中の線を白く抜く量です。0 で無効です。
   **{{ui:gallery.manga.reset}}** で、すべての値を戻せます。
4. **{{ui:gallery.manga.tryRun}}** を押すと、右に結果が出て、元の絵と見比べられます。試すだけでは何も保存されません。
5. 気に入ったら **{{ui:gallery.manga.save}}** を押します。仕上げた絵は、元の絵と同じボードに新しい絵として保存され、元の絵は変わりません。**{{ui:gallery.manga.open}}** で、その絵を開けます。

保存では、いま見ている値で仕上げ直すので、試すのと同じだけ時間がかかります。

## 絵からプロンプトを作る

![ビューアの帯で、絵を見てタグを書き出したところ](shot:caption)

絵を見て、その絵を描くためのプロンプト（タグか文章）を書き出します。気に入った絵に近い絵を作りたいときや、プロンプトの書きかたに迷ったときに使います。

1. ギャラリーの絵を右クリックして、**{{ui:gallery.tools.heading}}** の **{{ui:caption.menu}}** を選ぶと、すぐに書き出します。生成タブのプロンプト欄の上にある **{{ui:caption.fromPrompt}}** ボタンでも同じです。このボタンは、ギャラリーで選んでいる絵を使い、選んでいなければ画像ファイルを選ぶ画面を開きます。ギャラリーの絵やパソコンの画像ファイルを、このボタンにドロップしても使えます。
2. 書きかたを変えたいときは、帯の **{{ui:gallery.tools.edit}}** を押して、**{{ui:caption.style}}** で **{{ui:caption.style.tags}}** か **{{ui:caption.style.sentence}}** を選びます。
3. **{{ui:gallery.tools.run}}** を押します。
4. 出てきた言葉は、帯の中でその場で直せます。**{{ui:caption.replace}}**、**{{ui:caption.append}}**、**{{ui:caption.copy}}** のどれかを押します。

置き換える先・足す先は、生成タブの「{{ui:params.prompt.positive}}」です。この機能では、ギャラリーに絵は増えません。

> この機能には拡張機能 ComfyUI-Florence2 が必要です。インストールされていないときは、帯からインストールできます（この章の「拡張機能が必要なとき」を見てください）。初めて使うときは、言葉にするためのモデル（Florence-2 PromptGen）のダウンロードが始まります。

## キャラクターを登録して使う

![キャラクターとして登録するダイアログ](shot:character)

気に入ったキャラクターの絵を登録しておくと、別の場面の絵でも、同じキャラクターに近づけて描けます。登録するのは、次の 3 つです。

- 参照画像（同じキャラクターの絵。何枚でも）
- 見た目の言葉（髪や目の色、服など。プロンプトの先頭に足されます）
- 似せる強さ

### 登録する

1. ギャラリーで、登録したい絵を選びます。複数枚なら `Ctrl` を押しながらクリックします。
2. ビューアの **{{ui:character.menu}}** ボタン、または右クリックメニューの **{{ui:character.menu}}** を選びます。生成タブの **{{ui:character.row.choose}}** の欄を開くと、一覧の一番下に **{{ui:character.row.register}}** があり、ここからも開けます。
3. **{{ui:character.name}}** と、**{{ui:character.tags}}** を入力します。変わってほしくない特徴（茶色の髪、白いブラウス、青いスカートなど）を書きます。
4. **{{ui:character.weight}}** を決めます。上げるほど参照画像に似ますが、場面や構図の自由度が下がります。
5. **{{ui:character.save}}** を押します。

**{{ui:character.addSelected}}** を使うと、あとからギャラリーで選んだ絵を、参照画像に足せます。**{{ui:character.removePicture}}** は、画像の右上の ✕ です。

**{{ui:character.whiteBg}}** をオンにすると、登録する絵の背景を白に置き換えた絵を作り、それを参照画像にします。背景の色が、生成した絵に移るのを防げます。元の絵は残り、白い背景の絵が新しく保存されます。背景の除去に使う拡張機能 ComfyUI-RMBG がインストールされていないときは、このスイッチは使えず、元の絵がそのまま使われます。

### 使う

1. **{{ui:app.tabs.generate}}** タブ（または [キャンバス](05-canvas.md) タブ）の左パネルで、**{{ui:character.row.choose}}** を開き、使いたいキャラクターを選びます。
2. キャラクターの参照画像が「{{ui:params.refImage.sectionLabel}}」の欄に入り、見た目の言葉がプロンプトの先頭に足されます。
3. いつもどおり生成します。

使うときに、アプリが自動で調整することがあります。通知で知らせます。

- 参照画像を使うと、CFG スケールが高いと絵が焼けやすいため、CFG スケールが 5 より高ければ 4.5 に下げます。
- 参照画像は全部で 8 枚までです。ほかの参照画像と合わせて 8 枚を超えるときは、先頭の絵から使います。
- 参照画像が複数のときは、重なって濃くなりすぎないよう、1 枚あたりの強さを自動で下げます。
- ギャラリーから削除された絵は、使えません。全部削除されていると、キャラクターを使えません。

登録したキャラクターを直したり削除したりするには、一覧の項目の「…」ボタンを使います。

> 同じキャラクターに「近づく」機能で、完全に同じ顔になるわけではありません。髪型・色・服などは保たれやすいですが、顔立ちは少し変わります。保ちたい特徴は、見た目の言葉に書いておくと効きます。

> 参照画像を使うには、拡張機能 ComfyUI_IPAdapter_plus と、参照画像用のモデルが必要です。インストールされていないときは、生成タブの参照画像の欄からインストールできます。モデルは [モデル](08-models.md) の章を見てください。

## キャラクターに LoRA を選ぶ

キャラクターの編集ダイアログで、**{{ui:lora.section}}** から LoRA を選べます。選ぶと、**{{ui:lora.use}}** の入り切りと **{{ui:lora.weight}}** の変更ができ、キャラクターを使うと LoRA とトリガーワードがプロンプトに入ります。LoRA の学習は、別のアプリ novira-train で行います。

## 比較グリッドで設定を比べる

![比較グリッドのダイアログ](shot:xyplot)

CFG スケールやステップ数を変えると、絵がどう変わるか。それを 1 枚の表にして見比べる機能です。

1. 生成タブで、いつもどおりプロンプトとモデルを決めます。
2. **{{ui:params.invoke.invoke}}** ボタンの右にある「▼」を押し、**{{ui:xyplot.menu}}** を選びます。
3. **{{ui:xyplot.x}}** と **{{ui:xyplot.y}}** で、変える設定を選びます。片方だけでも作れます。
4. 値を入力します。数字は、カンマで区切って並べます（例: 3, 5, 7）。
5. **{{ui:xyplot.run}}** を押します。

ダイアログの下に、「3 列 × 2 行 = 6 枚を作ります。」のように、作る枚数が出ます。

変えられる設定は次のとおりです。

| 設定 | 入力のしかた |
|---|---|
| {{ui:xyplot.axis.cfgScale}} | 数字（1〜30） |
| {{ui:xyplot.axis.steps}} | 整数（1〜150） |
| {{ui:xyplot.axis.seed}} | 整数 |
| {{ui:xyplot.axis.strength}} | 数字（0.05〜1）。画像から画像で作るときだけ効きます。 |
| {{ui:xyplot.axis.scheduler}} | 一覧から選びます |
| {{ui:xyplot.axis.model}} | 同じ系統のモデルを、一覧から選びます |
| {{ui:xyplot.axis.prompt}} | 1 行に 1 つずつ書きます。プロンプトに足されます |

決まりごとは次のとおりです。

- 1 つの設定に入力できる値は 8 個までです。表は、全部で 36 枚までです。
- 横と縦に、同じ設定は選べません。
- 全部の絵を **同じシード** で描きます（シードを変える設定を選んだときは除く）。違いは、変えた設定だけです。
- 設定は、そのときの生成タブのフォームから取ります。フォームは書き換わりません。
- 作れなかった絵は、表の中で × になります。ほかの絵で表は作られます。

できた表は、ギャラリーに 1 枚の絵として保存されます。**{{ui:xyplot.open}}** で、ビューアに表示できます。表の元になった 1 枚ずつの絵も、ギャラリーに残ります。

> 枚数が多いと、それだけ時間がかかります。36 枚なら、36 回分の生成が必要です。最初は 2〜3 個の値で試すのがおすすめです。

## 下書きから選ぶ

![候補タブに、途中まで描いた候補が並んだところ](shot:drafts)

シードによって、絵は大きく変わります。下書きは、たくさんのシードで「途中まで」だけ描き、気に入った構図だけを最後まで描く機能です。時間を節約できます。

**{{ui:app.tabs.generate}}** タブの中央にある、**{{ui:app.views.drafts}}** タブを開きます。

1. **{{ui:drafts.model}}** を選びます。最初は、生成タブのモデルが選ばれています。生成タブで選べる絵のモデルは、SDXL や SD1.X のほか、Anima・Flux・FLUX.2・Z-Image などの本体だけのモデルも選べます。編集用のモデル（Flux Fill・Flux Kontext・Qwen-Image-Edit）は元の絵を直すためのものなので一覧になく、入っているときはその名前が下に出ます。
2. **{{ui:drafts.count}}** を決めます（1〜24 枚。最初は 4 枚で、設定の **{{ui:settings.draftCount.label}}** で変えられます）。枚数と位置は、ほかの画面に切り替えても、アプリを閉じるまでは画面で決めた値のままです。
3. **{{ui:drafts.position}}** を決めます（25〜60%。最初は 35%）。小さいほど早くできますが、粗い絵になります。
4. **{{ui:drafts.start}}** を押します。

下書きの絵は、できたものから順に並びます。プロンプトなどの設定は、生成タブのものが使われます。

絵をクリックすると、選ばれます（もう一度クリックすると外れます）。ダブルクリックすると、ビューアで大きく見られます。星のボタン（**{{ui:drafts.keep}}**）と ✕（**{{ui:drafts.reject}}**）は、自分用の目印です。下の右にある「○ 枚の{{ui:manual.drafts.finish}}」ボタン（○ は選んだ枚数）を押すと、選んだ絵が最後まで描かれます。選びなおしたいときは **{{ui:drafts.clearSelection}}** を押します。

最後まで描いた絵は、普通の生成と同じようにギャラリーに入り、下書きの上に「{{ui:drafts.badge.finished}}」と出ます。失敗した下書きがあるときは、「失敗 ○ 枚を{{ui:manual.drafts.retry}}」のボタンが出ます。

> 「{{ui:manual.drafts.finish}}」といっても、途中から再開するのではありません。同じシードで、最初から最後まで描き直します。そのため、完成までにかかる時間は、普通の生成と同じです。下書きで見た構図の絵ができます。

> 下書きは、文章から絵を作る生成と、**{{ui:params.i2i.title}}** に絵を置いた描き直しで使えます。{{ui:params.i2i.title}} では、**{{ui:params.image.strength}}** に応じて実際に描く分のステップのうち、位置の割合のところまで描きます。下書きの絵は、ギャラリーの一覧には並びません。

下書きは、「始めた順」に上のタブに並びます。タブに並ぶのは新しい 5 つだけです。すべての下書きは、タブの左の「履歴」ボタンで開く **{{ui:drafts.history.title}}** の画面で見られます。

- 左の列で期間（{{ui:drafts.history.period.today}}・{{ui:drafts.history.period.yesterday}}・{{ui:drafts.history.period.week}}・{{ui:drafts.history.period.older}}）とモデルを選ぶと、その下書きだけが並びます。上の欄では、プロンプトやモデル名の言葉で探せます。
- 下書きは日付ごとに分かれ、そのとき描いた絵、時刻、大きさ、下書きと仕上げの枚数が並びます。
- **{{ui:drafts.history.open}}** でその下書きを開き、**{{ui:drafts.history.reuse}}** でその下書きの設定を生成の欄に戻します。

不要になったら、タブや履歴の ✕ で閉じます。履歴の画面の「{{ui:drafts.closeOlder}}」で、タブに無い古いものをまとめて閉じることもできます。

### 生成した絵を、候補から選ぶ

**{{ui:app.tabs.generate}}** タブで作った絵は、まずこの **{{ui:app.views.drafts}}** タブに並びます。ボードには入りません。たくさん生成しても、ボードに絵があふれません。

- 生成を始めると、スタート画面のときは中央が **{{ui:app.views.drafts}}** タブに切り替わります。1 回押すごとに、上のタブが 1 つ増えます。絵はできたものから順に並び、「{{ui:drafts.badge.finished}}」と出ます。
- 要る絵をクリックで選び（もう一度クリックすると外れます）、下の右にある「○ 枚を「ボード名」へ入れる」を押すと、その生成を始めたときに選んでいたボードへ入ります。絵を右のギャラリーのボード欄へドラッグしても、そのボードへ入ります。
- 絵をダブルクリックすると、ビューアで大きく見られます。
- 要らない絵は、下の「{{ui:drafts.discardRest}}」でまとめてゴミ箱へ送れます。タブの ✕ で閉じたときも、残りの絵はゴミ箱へ行きます。通知の「元に戻す」で取り戻した絵は、もとのボードに戻ります。
- 生成した絵をすぐボードへ入れたいときは、{{ui:gallery.settings.title}}（歯車のボタン）で「{{ui:gallery.settings.newToCandidates}}」をオフにします。

## まとめて処理する

![まとめて処理のダイアログ](shot:batch)

背景の除去や拡大を、選んだ複数の絵に 1 度にかけられます。

1. ギャラリーで、絵を複数選びます（`Ctrl` を押しながらクリック、または `Shift` を押しながらクリックで範囲選択）。
2. 選んだ絵の上で右クリックし、**{{ui:gallery.menu.batch}}** を選びます。
3. 処理を選びます。
   - **{{ui:batch.op.removeBackground.title}}**: 背景を透明にします。拡張機能 ComfyUI-RMBG が必要です。インストールされていないときは、インストールのボタンが出ます。
   - **{{ui:batch.op.upscale.title}}**: 拡大用のモデルで大きくします。モデルがないときは、[モデル](08-models.md) の画面からインストールします。
4. **{{ui:batch.run}}** を押します。

絵 1 枚ごとに、キューに 1 つずつ入ります。進み具合は **{{ui:app.tabs.queue}}** タブで見られます。結果は、元の絵と同じボードに、新しい絵として入ります。元の絵は変わりません。

絵 1 枚を、設定を変えながら丁寧に処理したいときは、この章の個別の機能（[背景を除去する](#背景を除去する)）を使います。1 枚を大きくするときは、[アップスケール](06-upscaling-workflows.md) のタブも使えます。
