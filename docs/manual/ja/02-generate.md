# 画像をつくる

この章では、**{{ui:app.tabs.generate}}** タブで絵を作る方法を説明します。
画面の見かたは [はじめに](01-start.md) を、できた絵の見かたや整理は [ギャラリーとビューア](03-gallery.md) を見てください。

作る流れは、いつも同じです。

1. モデルを選ぶ
2. プロンプトを書く
3. 必要なら、サイズやシードなどの設定を整える
4. **{{ui:params.invoke.invoke}}** を押す

押した瞬間に絵が描き始まるのではなく、まず「{{ui:app.tabs.queue}}」（順番待ちの列）に入ります。順番が来ると、1 枚ずつ描かれます。

選んだモデル、プロンプト、設定は、アプリを閉じても残り、次に起動したときもそのまま使えます。

## プロンプトを書く

![プロンプトに文を書き、シードを固定にした生成タブ](shot:generate-prompt)

左パネルの「{{ui:params.prompt.title}}」には、2 つの欄があります。

- **{{ui:params.prompt.positive}}**：描いてほしいものを書きます。
- **{{ui:params.prompt.negative}}**：出てほしくないものを書きます。たとえば `blurry, watermark`（ぼやけ、透かし文字）のようにです。空のままでも生成できます。

書きかたの目安です。

- 単語や短い文を、カンマ（`,`）で区切って並べます。
- 多くのモデルは、英語で書くほうが思いどおりになりやすいです。モデルの説明に書きかたの指定があれば、それに合わせてください。
- 大事な言葉は前のほうに置きます。

欄の上にある小さなボタンの働きは、次のとおりです。ボタンはアイコンだけで、触れると名前が出ます。

| ボタン | 働き |
|---|---|
| **{{ui:params.prompt.recommended}}** | 選んでいるモデルの種類で広く使われている品質の言葉を「{{ui:params.prompt.positive}}」に、避けたい言葉を「{{ui:params.prompt.negative}}」の最後に足します。タグで書くモデル（Illustrious、NoobAI、Pony、Anima など）は `masterpiece, best quality` のようなタグを先頭に、文で書くモデル（FLUX、Qwen-Image など）は品質を表す言葉を最後に足します。ネガティブを使わないモデル（FLUX.1）には、ネガティブを足しません。すでに入っている言葉は、重ねて足しません |
| **{{ui:params.prompt.expand}}** | ポジティブとネガティブを、左右に並べた大きな窓で編集します |
| **{{ui:params.prompt.textView}}** / **{{ui:params.prompt.tagView}}** | 欄の見せ方を、文字のままの表示と、言葉ごとの札（タグ）の並びとで切り替えます。札を押すとポップアップが開き、言葉を書き換えたり、スライダーで強度を変えたり、1 に戻したり、札を消したりできます。強度を変えた札は `(smile:1.3)` の形でプロンプトに書かれます。下の入力欄に言葉を打って Enter で札を足せます |
| **{{ui:params.promptBook.open}}** | 単語を意味つきで集めたプリセットを開きます（後述） |
| **{{ui:caption.fromPrompt}}** | 絵を見て、プロンプトに使える言葉を書き出します。ギャラリーの絵やパソコンの画像ファイルを、このボタンにドロップしても使えます（[絵を直す・使い回す](04-improve.md) で説明します） |

### トークン数

欄の上の「0 / 77 トークン」は、いま書いている言葉の量の目安です。
トークンは、モデルが言葉を読むときの区切りのことです。上限の数を超えると、数字が警告の色になります。モデルによっては、上限を超えた部分が効きにくくなることがあります。
数は「おおよそ」の値です。ぴったりの数ではありません。

### 組み合わせをまとめて作る `{red|blue}`

ポジティブの欄に `{red|blue}` のように、波かっこの中を縦棒（`|`）で区切って書くと、選択肢ごとに別々の絵が作られます。

- `a {red|blue} flower` と書くと、`a red flower` と `a blue flower` の 2 通りになります。
- 波かっこを 2 つ以上書くと、すべての組み合わせになります。`a {red|blue} {cat|dog}` なら 4 通りです。
- 波かっこの中に、さらに波かっこを入れることもできます。
- 波かっこそのものを文字として使いたいときは、前に `\` を付けます（`\{`）。
- 組み合わせの数は、最大 100 通りまでです。

「{{ui:params.invoke.iterations}}」（後述）が 2 以上のときは、組み合わせの数 × 枚数の絵が作られます。たとえば 2 通りで枚数が 3 なら、6 枚です。
この書きかたが使えるのはポジティブの欄だけです。ネガティブの欄では、波かっこはそのまま文字として扱われます。

どんな文に広がるかは、ポジティブの欄の上の **{{ui:params.prompt.dynamicPreview}}** ボタン（`{ }` のアイコン）で確かめられます。押すと、組み合わせの一覧が出ます。ネガティブの欄にも同じボタンがあり、ネガティブにも `{a|b}` やワイルドカードを書けます。組み合わせは、ポジティブとネガティブの全部の組で作られます。

### ワイルドカード `__名前__`

![ワイルドカードの窓。左にリストの一覧、右に選んだリストの名前と項目が並んでいる](shot:wildcards)

ポジティブの欄に `__名前__`（名前の前後に下線を 2 つずつ）と書くと、その名前の「{{ui:params.wildcards.title}}」のリストから項目が 1 つずつ入ります。よく使う選択肢をリストにしておけば、`{red|blue}` を毎回書かずに済みます。

- `1girl, __hair-color__` と書くと、リスト hair-color の項目の数だけプロンプトができます。
- 項目の中にも `{a|b}` や、ほかのワイルドカードを書けます。ワイルドカードの中のワイルドカードは 6 段までです。
- 組み合わせの数の上限（100 通り）は、`{ }` と同じです。
- 無い名前、項目が空のリスト、自分自身を使うリストを書くと、**{{ui:params.invoke.invoke}}** は押せず、ボタンの下に理由が出ます。

リストは、**{{ui:params.prompt.dynamicPreview}}** ボタンの窓のいちばん下にある **{{ui:params.wildcards.open}}** から開きます。はじめから hair-color（髪の色）、expression（表情）、time-of-day（時間帯）の 3 つが入っています。

| 操作 | 働き |
|---|---|
| **{{ui:params.wildcards.new}}** | 空のリストを足します |
| 「{{ui:params.wildcards.name}}」の欄 | リストの名前を変えます。使えるのは文字・数字・`-`・`_` で、最初と最後は文字か数字です |
| 「{{ui:params.wildcards.entries}}」の欄 | 1 行に 1 つ書きます。空の行と `#` で始まる行は項目になりません |
| **{{ui:params.wildcards.import}}** / **{{ui:params.wildcards.export}}** | 1 つのリストを、1 行に 1 項目の .txt ファイルとして読み書きします。読み込んだファイルは、ファイル名を名前にした新しいリストになります |
| **{{ui:common.delete}}** | 選んでいるリストを削除します |

リストは、このアプリの中（いま使っているパソコン）に保存されます。

### ランダムに選ぶ

組み合わせが多すぎるときは、**{{ui:params.prompt.dynamicPreview}}** ボタンの窓で「{{ui:params.prompt.dynamicMode}}」を切り替えます。

- **{{ui:params.prompt.modeCombinatorial}}**（はじめの設定）：組み合わせごとに、枚数の分だけ絵を作ります。
- **{{ui:params.prompt.modeRandom}}**：枚数の分だけ絵を作り、1 枚ごとに組み合わせを 1 つ選びます。どれを選ぶかはその絵のシードで決まるので、同じシードで描き直すと同じプロンプトになります。

どちらの選び方でも、できた絵には、実際に使ったプロンプトが保存されます。

## シード

絵は「{{ui:params.seed.label}}」という数字から作られます。同じシードと同じ設定なら、同じ絵ができます。

左パネルの上のほうの「{{ui:params.seed.label}}」の行に、2 つのボタンがあります。

- **{{ui:params.seed.random}}**（サイコロ）：生成のたびに、新しいシードを使います。毎回ちがう絵になります。初めはこちらです。
- **{{ui:params.seed.fixed}}**（鍵）：いまのシードで描きます。同じ設定で何度作っても、同じ絵になります。プロンプトの言葉を 1 つ変えたときの違いを見たいときに便利です。

固定にすると、シードの数字の欄と「{{ui:params.seed.shuffle}}」ボタンはロックされます（うっかり変えてしまうのを防ぐためです）。
決まった数字を使いたいときは、「{{ui:params.seed.random}}」の状態で数字の欄に入れてから、「{{ui:params.seed.fixed}}」に切り替えてください。
気に入った絵のシードを使いたいときは、ギャラリーでその絵を開き、「{{ui:gallery.menu.useSeed}}」を押すと、シードを固定にして読み込めます（[ギャラリーとビューア](03-gallery.md) を参照）。

固定のままで枚数を増やすと、2 枚目以降はシードが 1 ずつ増えた絵になります。

## モデルを選ぶ

![モデルの一覧が開いている。FLUX・SDXL・SD1.X などの系統ごとに分かれている](shot:model-picker)

左パネルの上のほうにあるモデルのカードで、絵を描くモデルを選びます。

1. モデル名の欄をクリックします。
2. 一覧から選びます。一覧はモデルの系統（FLUX、SDXL、SD1.X など）ごとに分かれています。数が多いときは、上の検索欄に名前の一部を入れて絞り込めます。

Anima・Flux・FLUX.2・Chroma・Qwen-Image・Z-Image・SD3・HiDream・AuraFlow・HunyuanImage のモデルも、ここで選べます。本体・テキストエンコーダー・VAE が別々のファイルで配られているときは、テキストエンコーダーと VAE をインストール済みのモデルからアプリが名前で探して使います。足りないファイルがあるモデルをインストールすると、すぐに「{{ui:params.parts.title}}」と確認が出て、名前と大きさを見てから足りないファイルだけをインストールできます。あとで、と閉じた場合も、生成ボタンの下にそのモデルで足りないファイルの案内と、画面を移らずにそれらをインストールするボタンが出ます。5 GB を超えるときは、ボタンを押したあとにも確認が出ます。モデル画面の **{{ui:models.install.tab.starter}}** からもインストールできます。これらのモデルでも、マスク、コントロールレイヤー、高解像度化は使えます。参照画像は SD1.X と SDXL のモデルだけで使えます。スケジューラーは選べず、それぞれの系統で決まったサンプラーとスケジューラー（Anima なら `euler / simple`）で描きます。「{{ui:params.generation.scheduler}}」の欄には、実際に使う組み合わせが表示されます。

- **編集モデル。** FLUX Kontext と Qwen-Image-Edit は、渡した絵を書き換えます。元の絵をソース（画像から画像）に入れ、変えたい内容をプロンプトに書きます。FLUX Fill はマスクした部分を描き直します（マスク付きのインペイントかアウトペイントで使います）。これらのモデルでは、高解像度化・ドラフト・コントロールレイヤーは使えません。アプリは、ファイルの中身で、Kontext と Qwen の編集モデルはファイル名の `kontext` や `edit` という語で、普通のモデルと見分けます。名前を変えないでください。
- **FLUX.2。** klein は少ないステップで動きます（蒸留版は CFG 1）。dev は CFG の値をガイダンスとして使います。元の絵をソース（画像から画像）に入れると、FLUX.2 がプロンプトに従って書き換えます。マスク・コントロールレイヤー・高解像度化は FLUX.2 では使えません（下書きは使えます）。
- **量子化（GGUF）モデル。** 拡張子が `.gguf` のモデルやテキストエンコーダーは、拡張機能 ComfyUI-GGUF が読み込みます。拡張機能の画面で一度インストールし（https://github.com/city96/ComfyUI-GGUF）、エンジンを再起動してください。入れるまでは、生成が失敗してその旨が表示されます。
- **ほかの入力が要るモデル。** 制御用の動画・音声・カメラの動き・ポーズの動画が要るモデル（Wan Fun Control、Wan Animate、Flux Canny など）は、まだ動かせません。生成が失敗し、そのモデルに必要なものが表示されます。
3. 選んだモデルに ✓ が付き、カードの絵（カバー画像）も切り替わります。

一覧の下の **{{ui:app.tabs.short.models}}** ボタンで {{ui:app.tabs.models}} タブ（持っているモデルの管理）へ、**{{ui:app.tabs.short.browse}}** ボタンで {{ui:app.tabs.browse}} タブ（インターネットで探す）へ移れます。モデルを増やす方法は [モデルを用意する](08-models.md) で説明します。

モデルにおすすめの設定（ステップ数、CFG、スケジューラー、サイズ）が登録されていれば、モデルを選んだときに自動で入ります。
系統の違うモデルに切り替えると、新しいモデルと合わない LoRA などは外されます（外した数が通知されます）。

モデル欄の下の **{{ui:params.profile.title}}** ボタンを押すと、そのモデルのおすすめ値が一覧で出ます。いまの設定がおすすめからずれていると、ボタンが目立つ色になり、**{{ui:params.profile.apply}}** でおすすめ値にそろえられます。 ステップ数は、おすすめの少し下から少し上までを幅として見ます。Anima のモデルは少ないステップで絵が崩れやすい（一色に塗りつぶされることもある）ので、幅の下限が高めです（おすすめが 30 なら 24 以上）。

> モデルが 1 つもインストールされていないときは、欄に「{{ui:params.model.noModels}}」と出て、生成できません。先に [モデルを用意する](08-models.md) を済ませてください。

## そのほかの設定

プロンプトの下には、設定をまとめた区画が並んでいます。クリックで開閉できます。

| 区画 | 入っているもの |
|---|---|
| **{{ui:params.refImage.sectionLabel}}**（プロンプトのすぐ下） | 絵の雰囲気や登場人物を寄せるための画像（後述） |
| **{{ui:params.image.title}}** | {{ui:params.image.aspect}}、幅と高さ。「{{ui:params.image.swap}}」「{{ui:params.image.lock}}」「{{ui:params.image.optimal}}」のボタンもあります |
| **{{ui:params.generation.title}}** | LoRA（絵柄や人物を足す小さな追加モデル）、{{ui:params.generation.scheduler}}、{{ui:params.generation.steps}}、{{ui:params.generation.cfg}} |
| **{{ui:params.hires.title}}** | 描いた絵を拡大して、もう一度描き直す 2 回目の生成（後述） |
| **{{ui:params.advanced.title}}** | {{ui:params.advanced.vae}}、{{ui:params.advanced.clipSkip}}、{{ui:params.advanced.seamless}}（つなげても継ぎ目が出ない絵。SD1.X と SDXL のモデルで使え、拡張機能 ComfyUI-seamless-tiling を拡張機能の画面から入れておく必要があります）など |

迷ったら、サイズ以外はモデルを選んだときに入ったままで構いません。
項目名（「{{ui:params.generation.steps}}」「{{ui:params.generation.cfg}}」など）にカーソルを合わせると、短い説明が出ます。区画の見出しには、いまの値の要約が小さく出ます。

サイズを大きくするほど、時間とパソコンへの負担が増えます。まずは小さめで試し、よければ [拡大](06-upscaling-workflows.md) で大きくするのがおすすめです。

## 高解像度補正

![高解像度補正の区画を開いて、オンにしたところ](shot:hires-fix)

最初から大きなサイズで描くと、人物が 2 人になったり、形が崩れたりしやすくなります。**{{ui:params.hires.title}}** は、まず設定したサイズで描き、それを拡大してから、同じシードと設定でもう一度描き直します。1 回の生成で、細部まで描かれた大きな絵ができます。この区画は {{ui:app.tabs.generate}} タブと {{ui:app.tabs.comic}} タブにあります。

- **{{ui:params.hires.enable}}**：オンにすると使います。
- **{{ui:params.hires.scale}}**：1.25〜2 倍です。仕上がりの大きさは、区画の見出しと、いちばん下の行に出ます。
- **{{ui:params.hires.strength}}**：0.2〜0.75 です。低いと 1 回目の絵をほぼ保ち、高いと大きく描き直します。はじめは 0.45 です。
- **{{ui:params.hires.method}}**：**{{ui:params.hires.methodSmooth}}** は、モデルを使わずに拡大します。{{ui:app.tabs.upscaling}} タブで使うアップスケールモデルがインストールされていれば、それも選べます。
- **{{ui:params.hires.steps}}**：2 回目のステップ数です。0 のときは 1 回目と同じ数で描きます。

時間は 2 回描く分かかります。進み具合は、2 回分を通して数えます。LoRA と参照画像は、2 回目にも使われます。

仕上がりが、モデルの得意な大きさを大きく超えるとき（長い辺が SDXL では 2048 px、SD1.X では 1536 px ほど）は、生成ボタンの下に注意が出ます。生成はできますが、絵が崩れたら拡大率を下げてください。

絵には、1 回目のサイズと{{ui:params.hires.title}}の値が保存されます。ギャラリーの「{{ui:gallery.menu.useAll}}」で読み込むと、{{ui:params.hires.title}}もそのとおりに入ります。

## 生成回数と生成ボタン

![生成ボタンの横の矢印を押して開いたメニュー](shot:invoke-menu)

左パネルの上のほうに、生成の操作がまとまっています。

- **{{ui:params.invoke.invoke}}**（青いボタン）：キューの最後に追加して生成します。`Ctrl+Enter` でも押せます。
- **× の横の数字**：1 回の操作で作る枚数です。「3」にすると 3 枚作ります。
- **赤い × ボタン**：いま描いているものをキャンセルします。
- 各ボタンの右の **∨**：その他の操作のメニューです。

押せないときは、ボタンが灰色になり、ボタンの下の行に理由（モデルが選ばれていない、など）が出ます。ボタンにカーソルを合わせると、理由の一覧が見られます。
描いている間は、ボタンが「{{ui:params.invoke.generating}}」に変わり、進み具合（%）と、キューの待ち数が出ます。

### 生成ボタンの ∨ メニュー

- **{{ui:params.invoke.addBack}}**（`Ctrl+Enter`）：押した順に並べて描きます。ふつうの生成と同じです。
- **{{ui:params.invoke.addFront}}**（`Ctrl+Shift+Enter`）：待っている列の先頭に割り込ませます。急ぎで 1 枚だけ試したいときに使います。
- **{{ui:xyplot.menu}}**：今の設定をもとに、設定を 1〜2 個だけ変えた絵を、1 枚の表に並べます。同じシードで描くので、違いは変えた設定だけです。CFG スケール、ステップ数、モデルなどを横と縦に選び、値を入れて **{{ui:xyplot.run}}** を押します。

### キャンセルのメニュー

赤い × ボタンの右の ∨ を押すと、次のメニューが出ます。

- **{{ui:params.invoke.cancelCurrent}}**（`Shift+X`）
- **{{ui:params.invoke.clearQueue}}**（`Ctrl+Shift+X`）：待っているものも、描いているものも、すべて消します。確認は出ません。
- **{{ui:params.invoke.pause}}** / **{{ui:params.invoke.resume}}**：キューの処理を止めたり、再開したりします。
- **{{ui:params.invoke.openQueue}}**

## できあがった絵を見る

![生成が終わった画面。中央のビューアに絵が表示され、右のギャラリーにも並んでいる](shot:generate-result)

押すと、すぐに中央がビューアに切り替わります。
描いている間は、右のギャラリーの上に「{{ui:gallery.generating.title}}」の帯が出て、途中経過の絵とステップ数、進み具合が見えます。中央の上端の細い線も、進み具合を示します。同じ絵はギャラリーの先頭にも小さな枠として並びます。この枠を押すと、中央のビューアで途中経過の絵を大きく見られます。生成が終わると、できた絵に切り替わります。

できあがると、絵がギャラリーに加わり、ビューアにその絵が出ます。
絵は、いま選んでいる（右パネルで「{{ui:gallery.boards.autoBadge}}」の印が付いている）ボードに保存されます。ボードのことや、絵の整理・比較・やり直しは [ギャラリーとビューア](03-gallery.md) で説明します。

> ビューアが自動で新しい絵に切り替わるのが邪魔なときは、{{ui:gallery.settings.title}}（歯車のボタン）で「{{ui:gallery.settings.autoSwitch}}」をオフにしてください。

## プリセット

![プリセットの一覧。組み込みのプリセットと、保存したプリセットが並ぶ](shot:presets)

よく使う設定の組み合わせは、プリセットとして保存できます。左パネルのいちばん上の「{{ui:presets.label}}」のカードを押すと、一覧が開きます。

プリセットには、次のものがまとめて入ります。

- プロンプト（ポジティブとネガティブ）
- モデルと各設定（サイズ、ステップ数、CFG、スケジューラー、VAE など）
- LoRA と参照画像
- {{ui:params.hires.title}}、**{{ui:app.tabs.upscaling}}** タブの設定、インペイントの設定（マスクのぼかし、塗り足しなど）、動的プロンプトの作り方

シードと枚数、アップスケールする画像は入りません。

使いかたは次のとおりです。

- 一覧の項目をクリックすると、その設定が反映されます（**{{ui:presets.apply}}**）。
- 一覧の下の **{{ui:presets.saveNew}}**（またはカードの隣の保存ボタン）で、いまの設定を名前を付けて保存します。
- 項目の右の「…」では、**{{ui:presets.apply}}**・**{{ui:presets.overwrite}}**・**{{ui:presets.rename}}**・**{{ui:presets.delete}}** ができます。
- 一覧は「{{ui:presets.group.mine}}」と「{{ui:presets.group.builtin}}」に分かれています。組み込みのプリセットは、はじめから入っている見本です。

## プロンプトのプリセット

![プロンプトのプリセット。分類ごとに単語と意味が並び、「ポジティブ」「ネガティブ」の追加ボタンがある](shot:prompt-book)

英語の単語を覚えていなくても、プロンプトを組み立てられるように、**{{ui:params.promptBook.open}}** があります。ポジティブ・ネガティブの各欄の上のボタンから開きます。

- 左で分類（人数・人物、人物の関係・やりとり、ポーズ、動き、表情、視線、構図、髪型、服装など）を選ぶと、その分類の単語だけが並びます。上の検索欄では、単語・意味・分類・メモをまとめて探せます。
- 単語の右の「{{ui:params.prompt.positive}}」「{{ui:params.prompt.negative}}」を押すと、その単語がプロンプトに足されます。足した単語はチェックが付き、もう一度押すと外れます。
- いちばん上の入力欄に、単語と意味を入れて **{{ui:params.promptBook.register}}** を押すと、自分の単語を足せます。単語の右の鉛筆で編集、ごみ箱で削除ができます。

## 参照画像

**{{ui:params.refImage.sectionLabel}}** は、すでにある絵の「雰囲気」や「スタイル」を、新しい絵に寄せるための機能です。そのままコピーするのではなく、色づかいや絵柄、全体の印象を手がかりにします。

1. プロンプトの下の **＋** ボタンを押して、枠を 1 つ足します。
2. ギャラリーの絵をその枠にドラッグ＆ドロップします。パソコンの画像ファイルをドロップしても使えます。
3. 枠をクリックすると、設定の小窓が開きます。

小窓では、次のことを決められます。

- **{{ui:params.refImage.model}}**：参照画像用の専用モデル（IP-Adapter）。選んでいるモデルの系統に合ったものが必要です。
- **{{ui:params.refImage.methodLabel}}**：全体・スタイルのみ・構図のみなど、何を手がかりにするか（モデルの系統によっては出ません）。
- **{{ui:params.refImage.weight}}**：寄せる強さ。
- **{{ui:params.refImage.begin}}** と **{{ui:params.refImage.end}}**：描く過程のどこからどこまで効かせるか。

必要なモデルや拡張機能がインストールされていないときは、枠に警告の印が出て、小窓や生成ボタンの下に案内が出ます。案内のボタンからインストールできます。

> 参照画像は「雰囲気を寄せる」ためのものです。「この絵をもとに描き直したい」ときは、キャンバスを使います。[キャンバスで描き足す](05-canvas.md) を見てください。

### キャラクター

参照画像の上の「{{ui:character.row.label}}」の欄では、登録した人物（同じ人物の絵を何枚でも、見た目の言葉つき）を呼び出せます。
選ぶと、その人物の参照画像と見た目の言葉が設定されます。人物の登録のしかたは、[画像を直す](04-improve.md) で説明します。

## キュー

![キュータブ。処理中の項目と、待っている項目が一覧で出ている](shot:queue)

**{{ui:app.tabs.queue}}** タブでは、生成の順番待ちを見たり、操作したりできます。待っている項目があると、サイドナビゲーションの {{ui:app.tabs.queue}} に数のバッジが出ます。

画面の上には、次のものがあります。

- 処理の状態（「{{ui:queue.processor.running}}」か「{{ui:queue.processor.paused}}」）と、操作ボタン。
- 項目の数の内訳（{{ui:queue.status.pending}}、{{ui:queue.status.inProgress}}、{{ui:queue.status.completed}}、{{ui:queue.status.failed}}、{{ui:queue.status.canceled}}）。
- 右上に、いま描いている項目の進み具合。

ボタンの働きは次のとおりです。

| ボタン | 働き |
|---|---|
| **{{ui:queue.action.pause}}** / **{{ui:queue.action.resume}}** | 順番待ちの処理を止める、再開する。描いている最中のものは、そのまま最後まで描きます |
| **{{ui:queue.action.cancelCurrent}}** | いま描いているものを止める |
| **{{ui:queue.action.cancelAllExceptCurrent}}** | 待っているものを、すべてキャンセルする |
| **{{ui:queue.action.prune}}** | 終わった項目（完了・失敗・キャンセル）を一覧から消す |
| **{{ui:queue.action.clear}}** | すべての項目を消す。確認の窓が出ます |

下の一覧の行をクリックすると、その項目の詳しい情報（時刻、できた絵、失敗したときの理由、設定の中身）が開きます。
行の右の × でその項目だけをキャンセルできます。失敗したりキャンセルしたりした項目には、再試行のボタンが出ます。

## ショートカットキー

文字を入力している最中に働かないものは、入力欄から出てから押してください。

| 操作 | キー |
|---|---|
| 生成する（キューの最後に追加） | `Ctrl+Enter`（プロンプトの入力中でも使えます） |
| キューの先頭に追加して生成する | `Ctrl+Shift+Enter` |
| 描いているものをキャンセルする | `Shift+X` |
| キューをすべて消す（確認なし） | `Ctrl+Shift+X` |
| プロンプトの欄に移る | `Alt+A` |
| 左パネル、右パネルを開閉する | `T`、`G` |
| 左右のパネルをまとめて開閉する | `F` |
| タブを切り替える（サイドナビゲーションの順に、{{ui:app.tabs.generate}} から {{ui:app.nav.extensions}} まで） | `1` から `9` |
| ショートカットの一覧を開く | `Shift+?` |

ショートカットは、サイドナビゲーションの **{{ui:app.nav.settings}}** のメニューにある「{{ui:app.nav.hotkeys}}」でも確かめられます。
